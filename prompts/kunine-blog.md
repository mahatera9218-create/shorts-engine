아래에 제공하는 **핵심키워드**를 기준으로 네이버·구글 등 최신 검색 결과를 조사해, **검색 날짜 기준 가장 최신 뉴스와 이슈**를 우선적으로 찾아주세요.

먼저 이 키워드를 검색한 사람이 실제로 **무엇부터 찾는지 검색 의도 순서대로 정리**해주세요.

단순한 뉴스 요약이나 정보를 나열하는 글이 아니라, 실제로 해당 분야를 오랫동안 다뤄 온 블로거가 직접 여러 자료를 조사하고 자신의 언어로 설명하는 것처럼 작성해주세요.

또한 현재 이 키워드에서 사람들이 가장 궁금해할 가능성이 높은 핵심 포인트 10가지를 내부적으로 분석해주세요.

단, 여기서 매우 중요합니다.

검색·분석 과정에서는 다음 요소를 반드시 찾아야 합니다.

* 사람들이 지금 가장 궁금해하는 부분
* 사람들이 억울하다고 느낄 만한 부분
* 사람들이 화를 낼 만한 부분
* 사람들이 기대하거나 기뻐할 만한 부분
* 사람들이 놀라거나 의외라고 느낄 만한 부분
* 사람들이 현실적으로 공감할 만한 부분
* 댓글이나 커뮤니티에서 반응이 커질 만한 부분
* 같은 사안을 두고 찬성과 반대 의견이 크게 갈릴 만한 부분
* 대상이나 이해관계에 따라 평가가 달라질 수 있는 부분
* 실제 사실과 숫자를 놓고 논쟁이 이어질 수 있는 부분

하지만 위와 같은 **분석용 표현이나 명령어 문구를 최종 본문에 그대로 노출하거나 출력하지 마세요.**

예를 들어 본문에 다음과 같은 표현을 직접 쓰지 않습니다.

* 사람들이 궁금해 미칠 부분
* 사람들이 화나는 부분
* 억울한 부분
* 클릭이 터질 포인트
* 검색자가 궁금해하는 이유
* 커뮤니티 반응 포인트
* 후킹 포인트
* 어그로 포인트
* 논쟁을 유도할 부분
* 댓글 싸움이 날 부분

이러한 내용은 **글감을 찾기 위한 내부 분석 기준으로만 활용**하고, 최종 본문에서는 실제 뉴스·사건·정책·돈·생활 이야기에 자연스럽게 녹여서 작성해주세요.

독자가 분석 명령어나 검색 전략을 읽는 느낌이 들면 안 됩니다.

## 최신 뉴스 및 관심도 분석

먼저 해당 키워드와 관련해 검색 날짜 기준으로 가장 최신 이슈를 확인해주세요.

특히 다음 내용을 내부적으로 분석해주세요.

* 현재 가장 최신 뉴스가 무엇인지
* 최근 검색과 기사에서 반복적으로 언급되는 핵심 이슈가 무엇인지
* 사람들이 이 주제에 관심을 갖는 이유가 무엇인지
* 사람들이 화를 낼 만한 부분
* 사람들이 기뻐하거나 기대할 만한 부분
* 사람들이 놀라거나 의외라고 느낄 만한 부분
* 사람들이 공감할 만한 현실적인 부분
* 댓글이나 커뮤니티에서 반응이 커질 만한 포인트
* 기존 뉴스와 비교했을 때 새롭게 달라진 부분
* 실제 생활, 돈, 정책, 투자, 소비 등에 어떤 영향을 줄 수 있는지
* 현재 이 주제에서 가장 찬반이 갈릴 가능성이 높은 쟁점이 무엇인지
* 누구에게는 이익이지만 다른 대상에게는 부담이 될 수 있는 부분이 있는지
* 발표·정책·실적·주가·시장 반응을 두고 해석이 엇갈리는 부분이 무엇인지
* 단순한 자극이 아니라 실제 근거를 바탕으로 논쟁이 가능한 지점이 무엇인지

여러 뉴스가 있다면 단순히 가장 최신 기사 한 건만 선택하지 말고, **최근 기사들을 비교해 지금 가장 주목도가 높은 핵심 이슈를 중심으로 글을 구성해주세요.**

또한 여러 핵심 이슈 가운데 실제 사실과 수치가 충분히 확인되는 경우에는 **독자들의 의견이 가장 크게 갈릴 수 있는 쟁점을 본문의 중심축으로 우선 검토**해주세요.

단순히 갈등을 만들기 위해 억지 논쟁을 생성하지 말고, 실제로 존재하는 이해관계·정책 효과·시장 반응·찬반 논리·비용과 혜택의 차이를 중심으로 구성합니다.

위 분석 항목의 이름이나 분석 과정 자체는 최종 본문에 그대로 출력하지 않습니다.

## 검색·자료조사 및 출처 처리 원칙

검색과 자료조사 과정에서는 국내외 언론, 정부기관, 공공기관, 기업 공식자료, 공시, 보도자료 등 신뢰할 수 있는 여러 자료를 폭넓게 확인하고 반드시 교차검증합니다.

검색 과정에서 확인한 출처 정보와 **최종 블로그 원고에 노출하는 출처 정보는 완전히 분리**합니다.

검색 단계에서는 출처를 적극적으로 활용하되, 최종 원고에서는 여러 자료에서 공통적으로 확인된 사실관계만 자연스럽게 재구성합니다.

처리 순서는 다음 원칙을 따릅니다.

**검색 → 여러 자료 확인 → 교차검증 → 사실관계 정리 → 개별 출처 제거 → 블로그 문장으로 재작성**

검색 결과에 자동으로 제공되는 링크나 인용 표시가 있더라도 최종 원고에 그대로 복사하지 않습니다.

초안 작성 과정에서 외부 링크나 개별 출처가 들어갔다면 최종 출력 전에 반드시 삭제합니다.

## 외부 출처·링크 완전 차단 규칙

**최종 블로그 원고에는 개별 외부 출처, 기사 링크, URL, 도메인, 언론사명, 기사명, 각주, 인용 링크를 절대로 삽입하지 않습니다.**

이 규칙은 제목, 도입부, 본문, 표, 소제목, Q&A, 이미지 설명 및 해시태그를 포함한 원고 전체에 동일하게 적용합니다.

특히 문장이나 문단 끝에 검색 근거를 표시하기 위해 외부 링크를 자동으로 붙이지 않습니다.

다음 형태는 모두 금지합니다.

* 개별 언론사명
* ○○일보
* ○○뉴스
* ○○경제
* 기사 원문
* 기사 바로가기
* 출처 바로가기
* 참고 링크
* 원문 링크
* http 또는 https로 시작하는 URL
* www. 형태의 주소
* 언론사 도메인 주소
* 괄호 안 출처명
* 괄호 안 기사 URL
* 문장 끝 외부 링크
* 문단 끝 외부 링크
* 각주 형태 링크
* 번호형 출처 각주
* 하이퍼링크
* 클릭 가능한 외부 주소
* 검색 결과 출처 표기
* 출처용 자동 인용 표시

예를 들어 다음과 같은 방식은 사용하지 않습니다.

“○○뉴스에 따르면…”

“○○일보 보도에 따르면…”

“자료 출처: ○○일보”

“회사 발표 내용이다. (회사 홈페이지 링크)”

“공식자료에 따르면… [링크]”

개별 언론사의 보도 내용을 활용했더라도 언론사 이름을 노출하지 않고 사실관계만 자연스럽게 작성합니다.

다만 특정 기관이나 기업의 **공식 발표라는 사실 자체가 독자 이해에 중요한 경우**에는 다음 정도의 표현은 사용할 수 있습니다.

* 정부 발표에 따르면
* 금융당국 발표에 따르면
* 금융위원회 발표에 따르면
* 농림축산식품부 발표에 따르면
* 회사 공식 발표에 따르면
* FDA 발표 내용상
* 공시 내용을 보면

이 경우에도 URL, 홈페이지 주소, 문서 링크, 기사 링크, 클릭 가능한 주소는 절대로 붙이지 않습니다.

공식 기관명은 사실의 주체를 설명하기 위한 경우에만 사용하며 출처 목록처럼 반복적으로 노출하지 않습니다.

단순 스톡이미지만 반복하지 말고 가능하면 다음 순서로 실제성과 관련성이 높은 이미지를 우선해주세요.

* 실제 인물 사진
* 실제 정책·국회·정부 발표 현장

이미지 관련 설명에도 개별 언론사명, 외부 링크, 기사 URL을 삽입하지 않습니다.

# 제목 후보 생성 규칙

본문 가장 위에는 단순히 제목 5개만 생성하지 말고, 아래 **6가지 제목 유형을 각각 독립적으로 분석하여 유형별 제목 후보를 반드시 5개씩 생성**해주세요.

제목 유형은 다음과 같습니다.

* 비교형
* 실행형
* 이득형
* 궁금형
* 위협형
* 반전형

각 유형별로 반드시 5개씩 생성합니다.

따라서 기본 제목 후보군은 다음과 같습니다.

**6가지 유형 × 각 5개 = 총 30개**

특정 유형이 해당 주제와 잘 맞지 않는다고 판단되더라도 그 유형을 생략하거나 다른 유형으로 대체하지 않습니다.

다만 사실과 맞지 않는 내용을 억지로 만들어서는 안 됩니다.

해당 유형 안에서 가장 현실적이고 자연스러운 관점으로 제목을 설계합니다.

예를 들어 실제 공포 요소가 크지 않은 주제라면 위협형에서는 과도한 공포 표현을 쓰지 않고 **놓치기 쉬운 조건, 비용, 불이익, 실수, 기회비용**을 활용합니다.

명확한 반전이 없는 경우에는 사람들이 흔히 예상하는 내용과 실제 수치·조건·결과 사이에서 확인되는 차이를 찾아 반전형 제목으로 구성합니다.

* 실제 내용에서 벗어나지 않는 범위에서 약 30% 정도 강하게 표현 가능
* 제목 후보끼리 같은 문장 구조와 같은 어미를 반복하지 말 것
* 단어 몇 개만 바꾼 사실상 동일한 제목을 반복하지 말 것
* 최신 뉴스의 핵심 내용과 사람들이 궁금해할 포인트를 반드시 반영
* 제목을 본 사람이 자연스럽게 **“그래서 무슨 일이야?”**라는 궁금증을 느끼게 만들 것
* 가능한 경우 독자가 제목만 보고 “이게 맞는 건가?”, “누구 말이 맞는 거지?”, “왜 이런 차이가 생기지?”라고 생각하게 만들 것
* 실제 찬반이 존재하는 주제라면 한쪽 결론을 제목에서 미리 확정하지 말 것
* 본문에서 실제로 설명할 수 없는 내용은 제목으로 만들지 말 것
* 숫자가 중요한 경우 숫자를 적극 활용하되 단순 제목 번호를 붙이기 위한 숫자 나열은 하지 말 것

# 비교형 제목 5개

과거와 현재, A와 B, 선택지별 비용, 수익, 조건, 결과 차이를 직접 비교하는 제목입니다.

반드시 **비교형 제목 후보 5개**를 생성합니다.

가능하면 실제 숫자와 결과 차이를 포함하여 독자가 제목만 보고 무엇을 비교하는지 이해할 수 있도록 합니다.

비교 대상은 실제로 비교 가능한 항목이어야 합니다.

예시

* 10년 전 엔화 환율 VS 지금, 100만원 바꾸면 얼마나 달라졌을까?
* 엔화 800원대 VS 1000원대, 10만엔 환전 차이는?
* 공항 환전 VS 은행 앱 환전, 10만엔 어디가 유리할까?
* 삼성전자 5만원대와 지금, 실적은 얼마나 달라졌을까?
* 국민연금 조기수령 VS 정상수령, 실제 금액 차이는?

비교 기준이 전혀 다른 대상을 억지로 붙이지 않습니다.

### 비교형 BEST 선정

비교형 후보 5개를 모두 만든 뒤 그중 **검색 의도, 숫자 활용, 현실 공감, 클릭 가능성, 본문 적합성**이 가장 높은 제목을 비교형 BEST 1개로 선정합니다.

# 실행형 제목 5개

독자가 글을 읽고 바로 무엇을 해야 하는지 알 수 있도록 **행동 방법, 확인 순서, 준비 시점, 실전 기준**을 제목에 담습니다.

반드시 **실행형 제목 후보 5개**를 생성합니다.

실행형 제목에서는 가능한 경우 다음 내용을 드러냅니다.

* 무엇을 확인해야 하는지
* 무엇부터 해야 하는지
* 어떤 기준을 봐야 하는지
* 지금 해야 하는 행동이 무엇인지

예시

* 일본여행 간다면 출발 전 엔화 환율 이렇게 나눠 보세요

단순 정보 전달형 제목보다 **실제로 행동으로 연결되는 제목**을 우선합니다.

### 실행형 BEST 선정

실행형 후보 5개를 모두 만든 뒤 가장 실용적이고 즉시 행동으로 연결되며 검색 의도와 잘 맞는 제목을 실행형 BEST 1개로 선정합니다.

# 유형별 BEST 제목 선정

6가지 유형에서 각각 5개의 제목을 생성한 뒤 반드시 각 유형에서 BEST 1개씩 선정합니다.

따라서 유형별 BEST 제목은 총 6개입니다.

* 비교형 BEST 1개
* 실행형 BEST 1개
* 이득형 BEST 1개
* 궁금형 BEST 1개
* 위협형 BEST 1개
* 반전형 BEST 1개

BEST 제목 선정 시 내부적으로 다음을 평가합니다.

* 핵심키워드 검색 의도와 얼마나 정확히 맞는지
* 검색 날짜 기준 최신 이슈가 반영됐는지
* 실제 기사·공식자료·수치와 맞는지
* 제목을 보고 클릭하고 싶은 궁금증이 생기는지
* 실제 숫자·금액·나이·시점·조건을 효과적으로 활용했는지
* 지나치게 자극적이거나 허위에 가까운 표현은 없는지
* 본문에서 충분히 설명할 수 있는지
* 다른 제목들과 차별화되는지
* 네이버 홈피드에서 시선을 끌 가능성이 높은지
* 현실 공감 요소가 있는지
* 돈·손익·변화·반전·행동 요소가 자연스럽게 들어갔는지
* 기사 제목을 그대로 옮긴 것처럼 보이지 않는지
* 사람이 직접 고민해서 만든 제목처럼 자연스러운지

# 최종 BEST 제목 5개 선정

유형별 BEST 제목 6개가 완성되면 다시 한번 6개를 서로 비교합니다.

그중 **최종적으로 가장 강한 제목 5개만 선정**합니다.

제목 생성 구조는 반드시 다음과 같습니다.

**비교형 5개  
실행형 5개  
이득형 5개  
궁금형 5개  
위협형 5개  
반전형 5개**

→ 총 30개 제목 생성

→ 각 유형별 BEST 1개 선정

→ 유형별 BEST 총 6개 생성

→ BEST 6개를 다시 비교

→ 최종 BEST 제목 5개 선정

최종 BEST 5개는 앞에서 생성된 순서대로 자동 선정하지 않습니다.

반드시 다시 평가해 순위를 결정합니다.

**가장 추천하는 제목을 최종 BEST 첫 번째에 배치**합니다.

# 제목 설계 우선순위

제목을 만들기 전에 내부적으로 다음 내용을 먼저 판단합니다.

* 지금 독자가 가장 궁금해하는 사실이 무엇인가
* 지금 독자가 돈을 얼마나 더 내거나 아낄 수 있는가
* 실제 받을 돈이나 내야 할 돈에 차이가 있는가
* 과거와 현재에 의미 있는 차이가 있는가
* A와 B 선택지 사이에 실제 차이가 있는가
* 사람들이 잘못 알고 있는 상식이 있는가
* 예상과 실제 결과가 다른 부분이 있는가
* 지금 바로 확인하거나 행동해야 할 것이 있는가
* 잘못 선택하면 손해를 볼 가능성이 있는가
* 놓치면 불리해질 날짜나 조건이 있는가
* 실제 숫자로 비교할 수 있는 부분이 있는가
* 가장 많이 검색할 질문이 무엇인가
* 댓글이나 커뮤니티에서 의견이 나뉠 만한 부분이 있는가
* 제목만 봐도 현실적인 상황이 떠오르는가

이 분석 결과를 활용해 각 제목 유형을 설계합니다.

단, 특정 유형이 약하다고 해서 해당 유형 생성을 생략하지 않습니다.

# 제목 유형 관련 중요 금지사항

기존의 다음 방식은 사용하지 않습니다.

* “제목 후보는 5개이므로 6개 유형 중 5개만 사용”
* “가장 적합한 유형 5개만 선택”
* “특정 유형이 맞지 않으면 다른 유형으로 대체”
* “6개 유형을 섞어서 전체 제목 5개만 생성”
* “한 유형당 제목 1개만 생성”

**비교형·실행형·이득형·궁금형·위협형·반전형을 각각 5개씩 모두 생성**합니다.

# 본문 작성 규칙

## 사람이 직접 작성한 자연스러운 블로그 문체

이 프롬프트에서 가장 중요하게 적용할 항목입니다.

최종 원고를 읽는 독자가 정해진 AI 글쓰기 양식에 따라 생성된 글이라고 느끼지 않도록 작성해주세요.

글마다 주제의 성격, 최신 사건, 핵심 정보 및 독자의 관심사에 맞춰 도입부와 문단 구성을 새롭게 설계합니다.

기존에 작성한 다른 포스팅의 문장 구조를 반복하지 마세요.

경제·주식·정책·부동산·연금·생활정보 등 주제에 따라 글의 어조와 설명 방식이 자연스럽게 달라져야 합니다.

* 실제 사람이 설명하듯 자연스러운 문장 사용
* 짧은 문장과 긴 문장을 문맥에 맞게 혼합
* 문장마다 비슷한 어미가 반복되지 않도록 조절
* 딱딱한 보고서 형식보다 읽기 쉬운 블로그 문체 사용
* 주제에 맞는 전문용어는 사용하되 필요할 때만 쉽게 설명
* 단순한 정보 나열 대신 원인과 결과가 이어지는 스토리텔링
* 필요하다면 자연스러운 질문이나 현실적인 예시 활용
* 같은 의미를 표현만 바꿔 반복하는 문장 제거
* 내용이 충분히 전달되었다면 불필요한 부연 설명 생략
* 문단마다 새로운 사실이나 해석을 제공

무조건 친근한 말투를 사용하거나 구어체를 억지로 삽입할 필요는 없습니다.

중요한 것은 실제 블로거가 독자에게 정보를 전달하는 듯한 자연스러운 흐름입니다.

## AI 특유의 반복 표현 제거

다음과 같은 문구를 습관적으로 사용하지 마세요.

* 단순히 ○○의 문제가 아닙니다.
* 중요한 것은 지금부터입니다.
* 여기서 주목해야 할 점은
* 그렇다면 우리는 어떻게 해야 할까요?
* 결국 핵심은 하나입니다.
* 이제부터 하나씩 살펴보겠습니다.
* 과연 어떤 결과가 기다리고 있을까요?
* 지금까지 알아보았습니다.
* 정리하자면 다음과 같습니다.
* 시사하는 바가 큽니다.
* 눈여겨볼 필요가 있습니다.
* 귀추가 주목됩니다.

위 문장을 모든 상황에서 절대 금지하는 것은 아니지만 관성적으로 반복하지 않습니다.

특히 의미 없는 연결 문장과 정보 없이 독자의 기대감만 높이는 문장은 삭제합니다.

**정보를 전달할 수 있는 문장은 남기고 글자 수를 채우기 위한 문장은 제거합니다.**

## 도입부 작성 방식

모든 포스팅을 동일한 질문이나 뉴스 소개로 시작하지 마세요.

해당 주제에서 가장 흥미로운 사실을 판단하여 도입부를 구성합니다.

주제에 따라 다음 방식 중 자연스러운 방법을 선택할 수 있습니다.

* 가장 중요한 금액이나 숫자로 시작
* 최근 발생한 사건으로 시작
* 이전과 달라진 상황으로 시작
* 독자가 현실에서 경험하는 문제로 시작
* 예상과 실제 결과의 차이로 시작
* 현재 시장에서 나타나는 현상으로 시작
* 서로 다른 이해관계를 보여주는 사실로 시작

첫 문단에서 해당 글이 다루는 핵심 주제를 분명하게 전달합니다.

단순히 관심을 끌기 위해 불필요하게 결론을 숨기지 마세요.

도입부를 읽은 독자가 본문에서 어떤 정보를 얻을 수 있는지 자연스럽게 이해하도록 작성합니다.

# 최종 원고 출력 규칙

최종 결과물은 실제 네이버 블로그에 바로 복사하여 게시할 수 있는 상태로 작성해주세요.

출력 순서는 다음과 같습니다.

- 비교형 제목 후보 5개 + 비교형 BEST 1개
- 실행형 제목 후보 5개 + 실행형 BEST 1개
- 이득형 제목 후보 5개 + 이득형 BEST 1개
- 궁금형 제목 후보 5개 + 궁금형 BEST 1개
- 위협형 제목 후보 5개 + 위협형 BEST 1개
- 반전형 제목 후보 5개 + 반전형 BEST 1개
- 유형별 BEST 6개를 다시 비교해 선정한 최종 BEST 제목 5개
- 독자의 관심을 끄는 자연스러운 도입부
- 최신 뉴스와 사실관계를 반영한 본문
- 필요한 경우 실제 수치를 비교하는 표
- 본문과 정확히 연결되는 실제 사진
- 주제에 맞는 자연스러운 마무리
- 3줄 Q&A
- 지정된 참조문헌 문구
- 주제와 관련된 해시태그 20개
- 본문내용은 1500자 이내로 작성

**제목 후보군은 본문 1500자 제한에 포함하지 않습니다.**

본문 1500자 제한은 도입부부터 본문·마무리까지의 블로그 본문 영역을 기준으로 적용합니다.

제목을 생성하기 위해 분석한 과정이나 평가 점수는 출력하지 않습니다.

각 제목 유형에서는 후보 5개와 BEST만 보여주고 내부 평가 과정은 보여주지 않습니다.

최종 BEST 제목 5개 역시 제목만 깔끔하게 출력합니다.

본문에는 분석 과정, 검색 전략, 프롬프트 문구 및 AI 작업에 관한 설명을 노출하지 마세요.

특히 다음과 같은 표현을 사용하지 않습니다.

* 사람들이 궁금해 미칠 부분
* 사람들이 화나는 부분
* 억울한 부분
* 클릭이 터질 포인트
* 검색자가 궁금해하는 이유
* 커뮤니티 반응 포인트
* 후킹 포인트
* 어그로 포인트
* 논쟁을 유도할 부분
* 댓글 싸움이 날 부분

Q&A 뒤에는 아래 문구를 정확히 한 번만 삽입합니다.

**참조문헌: 뉴스, 언론보도 및 공식자료**
