# 어사이드 「경제」 — 연결 고리 스크립트 (V6.0 원문 연동 · 판단 없음)

어사이드는 **판단하지 않는다.** 정해진 순서대로 **명령 전송 · 복사 · 붙여넣기 · 임시저장**만 한다. 글·제목·사진의 내용은 전부 클로드(V6.0)·그록이 만든다. 어사이드는 **연결 고리**다.

## 준비 (1회) · 창 구성
- 클로드 프로젝트 **「경제」** = V6.0 원문 상주.
- 그록 프로젝트 **「경제 사진수집」** = 실물 썸네일 **수집+편집**(생성 X).
- 지피티 프로젝트 **「경제 사진」** = 본문 무드컷 **생성**.
- 네이버 블로그.
→ 사진은 **그록(실물 썸네일) + 지피티(무드 생성)** 2도구. 글당 **총 2~3장**.

## 입력 (매일 아침)
대표가 **오늘 키워드 N개**를 준다 (예: `삼성전자 주식 / 분당 재건축 부동산 / 국민연금 / 금시세`). 어사이드는 **그 키워드를 그대로** 쓴다(고르지 않음).

---

## A. 오늘 9편 = 클로드 「경제」 대화창 9개 병렬
- 키워드 9개 각각 = **「경제」 프로젝트에서 새 대화 1개씩, 총 9개 탭을 띄운다.**
- **동시에 돌린다(병렬):** 한 탭이 생성 중일 때 다른 탭을 진행해 기다리는 시간을 메운다.

### 각 탭(키워드 1개) 안 순서 — 고정
1. **`[키워드] 시작` 입력** (예: `삼성전자 주식 시작`).
2. 클로드가 **제목 35개 + BEST 5** 출력 → **BEST 5를 그대로 복사해 둔다**(나중 메모칸용) → **`1위` 입력** *(고정 — 항상 1위, 어사이드가 고르지 않음)*.
3. 클로드가 **완성 본문**(한 복사상자 = 제목·본문·표·Q&A 3개·참조문헌·해시태그 20) 출력 → **상자 통째 복사.**
4. **`사진 찾아` 입력** → 클로드가 **소제목 목록**(각 소제목이 무슨 내용인지) 출력 → **그 목록 복사.**
5. **사진 = 총 2~3장 (그록 실물 썸네일 + 지피티 무드 1~2):**
   - **썸네일 1장** → **그록 「경제 사진수집」**에 메인 키워드 → **실물 수집+편집 1장**(생성 X, 못 구하면 '미확인' 보고·대표 판단).
   - **무드컷 1~2장** → **지피티 「경제 사진」**에 글 주제·장면 → **실사 무드 생성.**
   - 소제목·순서 라벨대로 저장.

### 병렬 운영 팁 (기다리는 시간 메우기)
- **탭1에 `시작` 쳐두고 생성되는 동안 탭2·3…에도 `시작`.** 결과 나온 탭부터 `1위` → 본문 → `사진 찾아` 순으로 진행.
- **그록 사진도 병렬:** 클로드가 본문 뽑는 동안 그록이 사진 수집(여러 그록 탭 또는 목록 몰아 넣기).
- **먼저 끝난 편부터 네이버 조립(B) 시작** — 9편 다 모을 때까지 기다리지 않는다.
- 각 탭·이미지는 **편 번호 라벨**(편3-사진5 등)로 관리해 섞이지 않게.

## B. 네이버 조립·임시저장 (키워드마다)
**`docs/prompts/조립-규칙-공통.md`를 그대로 따른다.** 순서만 짚으면:

6. 새 글쓰기 → **제목칸 = BEST 1위.**
7. **본문칸 = 복사상자 통째 붙여넣기.** *(원문 그대로 — 내용·순서 안 건드림. 특히 Q&A 3개 → 참조문헌 → 해시태그 20 순서 유지.)*
8. **사진 삽입:** 복사상자엔 사진이 없으니 어사이드가 넣는다. **썸네일(대표사진) 맨 위 + 본문에 생성컷 1~2장 적절히 배치** (글당 **총 2~3장**, 소제목마다 아님). 사진 밑 **캡션 없음.**
9. **표:** 본문의 `|`격자/`[표:]`를 **네이버 표로** 손수 옮기고 격자 글자는 지움 (글마다 1개 이상, 자주 빠뜨림).
10. **서식:** 소제목 줄 = **Alt+3(인용구)**, 볼드 Alt+1, 구분선 Alt+5. **3~4문장마다 빈 줄** 한 줄.
11. **마무리 정리:** AI 체크버튼 **끔** / 마크다운 기호(`*` `#` `-`) 제거(서식 변환 후) / 부호(`...`·둥근 따옴표) 정리.
12. **함께 보면 좋은 글 (내 과거 글 링크 — 빼먹지 말 것):** 내 경제 블로그에서 **'같은 키워드'로 최근 발행한 내 글**을 블로그 내 검색으로 찾는다. **최소 2개·최대 3개**(같은 키워드 2개 안 되면 키워드 비슷한 최근 글로 채움, 억지 무관 연결 ❌). **위치 = 참조문헌 줄과 해시태그 20개 '사이'** ("함께 보면 좋은 글" 한 줄 + 링크). 링크 = 네이버 **'URL 복사' → 붙여넣기 → 썸네일 카드 뜨면 생 URL 삭제**(타이핑 ❌, 자기 글만).
13. **맨 위 메모칸 = BEST 5 붙여넣기** (대표가 발행 때 제목 교체용).
14. **임시저장. 발행 ❌.**

## C. 마무리 보고
"오늘 **N편 임시저장 완료** + 키워드 목록" + **사진 미확보·막힌 곳**을 함께 보고.

## 대표 (발행 — 아침/폰)
각 초안 → 사진 출처·이용조건 훑기 → 메모칸 BEST 5 중 제목 고르거나 1위 유지 → **발행(띄엄띄엄).**

## ★ 절대 규칙 (판단 제거)
- 어사이드는 **내용 판단 0.** 제목은 **항상 1위**, 글·사진은 **받은 그대로.** 고치거나 고르지 않는다.
- **임시저장까지만. 발행·로그인 자동화 금지** (발행은 대표).
- 막히면(로그아웃·보안문자·사진 안 열림) **그 자리에서 멈추고 보고.** 비밀번호 직접 입력 ❌.
