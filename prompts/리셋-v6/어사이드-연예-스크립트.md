# 어사이드 「연예」 — 연결 고리 스크립트 (V3.1 원문 연동 · 판단 없음)

어사이드는 **판단하지 않는다.** 정해진 순서대로 **명령 전송 · 복사 · 붙여넣기 · 수집 · 임시저장**만. 글·제목·사진 내용은 클로드(V3.1)·그록이 만든다.

## 준비 (1회) · 창 구성 — ★경제와 다름(인스타 추가)
- 클로드 프로젝트 **「연예패션」** = V3.1 원문 **+ 1위 지침** 상주.
- 그록 프로젝트 **「연예 사진」** = 사진 규칙 상주.
- **인스타** = 대표 로그인 해둠(공식 계정 사진 수집용, **Imageye 확장 ON**).
- 네이버 블로그 = 캐시미어다이어리.
→ 경제(클로드+그록+네이버)와 달리 **인스타 창이 하나 더** 붙는다.

## 입력 (매일) — 소재 파일에서 (대표가 키워드 안 줌)
- **운영총괄이 새벽에 채운 `연예소재-<날짜>.md`(Drive)**를 읽는다.
- 거기 **오늘 인물/커플 N명**(극중 커플 메인 + 보조)이 있다. 어사이드는 **그대로** 쓴다(고르지 않음).

---

## A. 오늘 N편 = 클로드 「연예패션」 대화창 N개 병렬
각 인물/커플마다 새 대화:
1. **`[인물명] 가자`** (극중 커플이면 소재 파일의 작품·커플 정보 그대로. 예: `신민아♥이종석 가자`).
2. 클로드가 **제목 BEST 5** 출력 → **BEST 5 복사해 둠**(메모칸용) → **`1위 확정` 입력** *(고정 — 1위 지침이 우리 유형을 1위로 보장)*.
3. 클로드가 **완성 본문**(한 복사상자 = 본문 + 해시태그 20. **Q&A·참조문헌 없음**) → **상자 통째 복사.**
4. **`사진 찾아`(이미지 요청)** → 그록 「연예 사진」에 **인물 + 소제목 목록** 전달.
5. 그록이 **① 공식 인스타 핸들(@) ② 포토뉴스·웹 직접 URL ③ 썸네일 주인공 사진**을 줌 → 어사이드가 수집:
   - **인스타 핸들** → **로그인 상태로 그 계정에서 Imageye로 수집**(본인 실착).
   - **URL** → 다운로드.
   - **★ 워터마크·로고·자막 = 제거/크롭.** 인물·얼굴 보존.
   - 소제목·순서 라벨대로 저장. 못 구한 자리는 '미확보'.

## B. 네이버 조립·임시저장 (키워드마다) — `조립-규칙-공통.md` 그대로
6. 새 글쓰기 → **제목칸 = BEST 1위.**
7. **본문칸 = 복사상자 통째 붙여넣기**(원문 그대로 — 내용·순서 안 건드림).
8. **사진 삽입:** **썸네일(주인공) 맨 위 → 각 소제목 '위'에 그 소제목 사진** (대표사진 → 인용구 소제목 → 글). **사진 밑 캡션 없음.**
9. **서식:** 소제목 줄 = Alt+3(인용구), 볼드 Alt+1. **3~4문장마다 빈 줄.** AI 체크버튼 **끔.** 마크다운 기호(`*` `#` `-`) 제거. 부호(`...`·둥근 따옴표) 정리.
10. **함께 보면 좋은 글:** 내 연예 블로그에서 **같은 인물/작품 최근 글 2~3개**(없으면 비슷한 결). **위치 = 본문 끝과 해시태그 20개 '사이'.** 네이버 'URL 복사 → 붙여넣기 → 카드 뜨면 생 URL 삭제'(타이핑 ❌, 자기 글만).
11. **맨 위 메모칸 = BEST 5 붙여넣기** (대표가 발행 때 제목 교체용).
12. **임시저장. 발행 ❌.**

## C. 마무리 보고
"오늘 **N편 임시저장 완료** + 인물 목록" + **사진 미확보·인스타 막힌 곳** 함께 보고.

## 대표 (발행 — 아침/폰)
각 초안 → 사진 훑기 → 메모칸 BEST 5 중 제목 고르거나 1위 유지 → **발행(띄엄띄엄).**

---

## ★ 절대 규칙 (판단 제거)
- 어사이드는 **내용 판단 0.** 제목은 **항상 1위**, 글·사진은 **받은 그대로.**
- **임시저장까지만. 발행·로그인 자동화 금지.**
- 막히면(인스타 로그아웃·보안문자·사진 안 열림) **그 자리에서 멈추고 보고.** 비밀번호 직접 입력 ❌.
