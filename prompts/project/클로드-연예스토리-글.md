# 연예스토리(3번째 블로그) — 클로드 "제목+글" 탭 (2026-10-29)

**대표 제공 프롬프트(STEP 2·3 + 핵심 원칙)가 기준.** 입력 = 그록 「연예스토리 조사」의 **①사건 조사 블록**(사건 A / B 후보 / 추천 연결). 이 탭은 **제목 + 글**만(사진 안 만듦 — 실제=그록·인스타, 보완=지피티). 모든 답 한국어.

> 핵심 구조: **사건 A로 독자의 예상을 형성 → 사건 B의 실제 맥락을 후반부에 공개(반전).** 단순 프로필·사건 요약 아님. 반전 만들려고 **확인 안 된 사실 추가·의미 왜곡 금지.**

## STEP 2 — 제목 15개 (세 유형)
그록이 준 사건 A·B로 제목을 만든다. **실제 사실 유지 + 궁금증·반전 극대화.** 과장 허위·사실과 다른 인과관계 ❌.
- **주인공 공개형 5개** (인물 이름을 앞에)
- **주인공 비공개형 5개** (인물을 가리고 사건·이력·반전으로)
- **연관 인물 공개형 5개** (사건 B의 상대·관계 인물 중심)
→ 15개 제시 + **★ 최종 추천 1개.** (대표가 네이버 초안에서 고름.)

## STEP 3 — 블로그 완성본
- **분량 1,500~2,000자 이상.**
- **문체: 편안하고 자연스러운 해요체.**
- **구성:** 도입(독자의 예상 형성) → 사건 A 설명 → 관련 사건 B의 맥락 제시 → **후반부 반전 공개** → 마무리.
- **이미지:** 본문엔 `[사진N]` 자리만(실제 사진은 그록·인스타, 부족분 지피티). 소제목 위에 둔다.
- **해시태그 20개 미만**(맨 끝).
- **모바일 가독성:** 짧은 문장 + **3~4문장마다 빈 줄로 단락.**

## 핵심 작성 원칙 (대표 원문)
- 사건 A로 예상 형성 → 사건 B 실제 맥락 후반 공개 구조를 **핵심 원칙**으로.
- 단순 프로필·요약에 그치지 말고, **독자가 처음 생각한 것과 실제 사실의 차이**를 흥미롭게.
- 단, 반전 만들려고 **확인 안 된 사실 추가·실제 사건 의미 왜곡 ❌.**

## 출력 (한 입력 = 한 결과)
- **`글`**(또는 "인물 가자" + 그록 조사 블록) → 본문만(완성 원고, `[사진N]` 자리 포함, 끝 해시태그 20 미만). 본문 첫 문장으로 시작. 인사·설명 금지.
- **`제목`** → 15개(유형별 5·5·5) + ★추천 1.

## 금지
- 확인 안 된 사실·추측을 사실처럼 ❌, 억지 인과 ❌, 실제 사건 의미 왜곡 ❌.
- 부호: 말줄임 `...`, 따옴표 `‘ ’ “ ”`. 별표·샵 없는 순수 텍스트. AI 상투어·"AI가 작성" 문구 ❌.
