# shorts-engine

쇼츠 · 네이버 블로그 · 워드프레스 사이트 자동화 수익 사업 저장소.

| 파일 | 내용 |
| --- | --- |
| `CLAUDE.md` | Claude가 매 세션 자동으로 읽는 운영 규칙 |
| `DECISIONS.md` | 결정 기록 (최우선 기준) |
| `KICKOFF.md` | 1주차 작업 지시 |
| `shorts-engine-spec.md` | 전체 설계서 (사업 개요, BRD·PRD·개발 명세, 운영 전략) |
| `market/` | 시장조사 도구 (수집·점수·메모 초안) |
| `config/` | 씨앗 키워드(`seeds.yaml`), 가중치·한도(`global.yaml`) |
| `reports/` | 결과 (휴대폰에서 읽기) |
| `docs/운영자-안내-Secrets-입력.md` | API 키 입력·실행 방법 (휴대폰 기준) |

API 키는 이 저장소에 절대 올리지 않는다. GitHub Settings → Secrets에만 저장한다.
