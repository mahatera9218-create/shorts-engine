# 네이버 임시저장 프로그램 (윈도우)

어사이드 대신, **내 PC에서 공짜로 도는 프로그램**으로 네이버 블로그에 글을
임시저장한다. (발행은 안 한다 — 사람이 확인 후 직접 발행)

- **드는 돈:** 거의 0 (크레딧·토큰 안 씀, 내 PC에서 클릭만 자동)
- **v1 범위:** 글·제목만 임시저장. **사진은 내가 직접 넣는다**(실사).
- **단점:** 네이버가 글쓰기 화면을 바꾸면 고장 날 수 있다 → 그때 Claude가 고친다.

---

## 처음 한 번만 (세팅)

### 1. 파이썬 설치 (이미 있으면 건너뜀)
- https://www.python.org/downloads/ 에서 윈도우용 설치.
- 설치 화면 맨 아래 **"Add python.exe to PATH"** 체크 꼭! 하고 설치.

### 2. 크롬 설치 확인
- 이 프로그램은 PC에 깔린 **크롬**을 쓴다. 없으면 크롬 먼저 설치.

### 3. 이 폴더(tools/naver_draft)를 PC에 내려받기
- 이 폴더 전체를 바탕화면 등에 둔다.

### 4. 세팅 실행
- 폴더 안 **`setup.bat` 더블클릭** → 끝날 때까지 기다린다.

### 5. 네이버 로그인 저장 (1회)
- 폴더 주소창에 `cmd` 치고 Enter → 검은 창이 뜨면:
  ```
  py login_capture.py
  ```
- 크롬이 열리면 **네이버에 로그인**(아이디·비번·2단계 인증 직접).
- 다 되면 검은 창 클릭하고 **Enter**. → 로그인이 저장된다.

---

## 매번 (글 올릴 때)

### 먼저 '테스트'로 한 번 (저장 안 누름)
- 폴더에서 **`run-dry.bat` 더블클릭.**
- 크롬이 열리고 → 오늘 건강 초안의 제목·본문이 네이버 글쓰기에 들어가는 걸
  **눈으로 확인**한다. (임시저장은 안 누름)
- 제목·본문이 제대로 들어갔으면 OK. **이상하면 `debug` 폴더의 스크린샷을
  Claude에게 주면** selector를 고쳐 준다.

### 진짜 임시저장
- `run.bat` 더블클릭 → 오늘 초안이 **임시저장**된다. **발행은 안 한다.**
- 네이버 '임시저장 글'에서 열어 **사진 넣고(실사)** 검토 후 **직접 발행.**

### selector가 안 맞을 때 (화면이 바뀌었을 때)
네이버 글쓰기 화면 구조를 정확히 따오려면 한 번 녹화해서 Claude에게 준다:
1. 검은 창(cmd)에서: `py -m playwright codegen https://blog.naver.com`
2. 왼쪽 브라우저에서 **글쓰기 → 제목 → 본문 → 임시저장**을 평소대로 한 번.
3. 오른쪽에 뜬 코드를 **전부 복사**해 Claude에게 주면 draft_naver.py를 고친다.

### 매일 자동 (선택)
- 윈도우 '작업 스케줄러'에 `run.bat`을 매일 특정 시각에 돌게 등록하면
  PC가 켜져 있을 때 자동으로 임시저장된다. (등록법은 Claude가 안내)

---

## 안전
- 이 프로그램은 **'임시저장'까지만** 한다. **발행 버튼은 절대 누르지 않는다.**
- 같은 제목이 이미 임시저장돼 있으면 건너뛴다.
- 로그인 정보(chrome-profile 폴더)는 **내 PC에만** 있고 어디에도 안 올라간다.
