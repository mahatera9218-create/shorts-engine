모션 패널 북마크

버전 1.1 · 예전에 만든 북마크가 있으면 먼저 지우고 아래에서 새로 만드세요. 패널 맨 위에 v1.1이 보이면 새 버전입니다.

파일을 넣거나 코드를 연결할 필요가 없습니다. 북마크 하나만 만들어 두고, 내 웹앱 화면에서 누르면 옆에 패널이 뜹니다. PC의 Chrome·Edge 기준입니다.

  1. 북마크바를 켭니다. 윈도우 Ctrl+Shift+B, 맥 ⌘+Shift+B
  2. 아래 파란 버튼을 마우스로 끌어서 북마크바에 놓습니다.

    ✦ 모션 패널
    누르는 버튼이 아니라 북마크바로 끌어다 놓는 버튼입니다.
  3. 평소처럼 개발 중인 내 웹앱을 브라우저로 엽니다. (예: localhost:3000)
  4. 북마크바의 모션 패널을 누르면 화면 오른쪽에 패널이 뜹니다. 패널 맨 위 줄을 잡고 끌면 원하는 곳으로 옮길 수 있고, ⇆를 누르면 반대쪽으로 갑니다.
  5. 패널에서 요소 선택을 누르면 패널이 잠깐 사라집니다. 화면의 버튼이나 카드를 누르면 패널이 다시 나타나고, 효과와 속도를 고르면 바로 움직여 보입니다.
  6. 마음에 들면 패널 아래 복사를 누르고, VS Code의 AI 채팅창에 붙여넣습니다. AI가 그대로 코드로 만들어 줍니다.

끌어다 놓기가 안 되면

아래 버튼으로 코드를 복사한 뒤, 북마크바에서 오른쪽 클릭 → 페이지 추가 → 이름은 "모션 패널", URL 칸에 붙여넣기 하세요.

알아 두면 좋은 점

· 북마크를 한 번 더 누르면 패널이 닫힙니다. 새로고침하면 사라지지만, 조절한 값은 그 브라우저에 남아 있어 다시 열면 그대로입니다.

· 패널에서 바꾼 것은 미리보기입니다. 실제 코드에 남기려면 6번(복사 → AI에게 붙여넣기)을 꼭 하세요.

· 보안 설정이 강한 일부 사이트에서는 열리지 않을 수 있습니다. 개발 중인 내 화면(localhost)에서는 열립니다.
