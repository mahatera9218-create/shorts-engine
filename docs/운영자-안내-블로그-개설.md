# 운영자 안내 · 네이버 블로그 개설 (휴대폰 기준)

첫 블로그 주제: **스포츠 × 돈·숫자 (선수 중심)** (DECISIONS 2026-09-29)

블로그는 **대표님 본인 명의 네이버 아이디**로 만듭니다 (본인 명의 최대 3개, 가족 명의 사용 안 함).
메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다. 막히면 화면에 보이는 버튼 이름을 Claude에게 알려주세요.

---

## 0. 아이디

- **추천: 사업용 새 아이디.** 나중에 연예·생활 경제 블로그를 따로 열 때 주제별로 나누기 쉽고, 개인 글과 섞이지 않습니다.
- 새 아이디는 휴대폰 번호 1개(본인 인증)당 최대 3개까지 만들 수 있습니다.
- 쓰던 아이디의 블로그가 비어 있다면 그대로 써도 됩니다.

## 1. 블로그 앱 설치와 로그인

1. 앱스토어·플레이스토어에서 **네이버 블로그** 앱을 설치합니다.
2. 사용할 아이디로 로그인합니다. 아이디마다 블로그가 자동으로 하나씩 있습니다.

- 몸값 계산소

**소개글**
> 선수 연봉·계약·이적료를 1경기당, 1골당 같은 숫자로 다시 계산합니다. 공식 발표와 보도를 기준으로 하고, 추정치는 추정이라고 적습니다.

## 3. 카테고리 만들기 (4개)

앱에서 안 되면 휴대폰 브라우저로 blog.naver.com에 접속해 브라우저 메뉴에서 **"데스크톱 사이트"**를 켜고 **관리 → 메뉴·글·동영상 관리 → 블로그 → 카테고리 관리**로 들어갑니다. 태블릿이 편합니다.

| 카테고리 | 역할 |
| --- | --- |
| 선수 몸값 | 한 선수의 연봉·계약을 1경기당·1타석당 등으로 다시 계산 |
| 몸값 대결 | 선수 vs 선수, 국내 vs 해외파, 종목끼리, 아파트·영화 매출 같은 다른 숫자와 비교 |
| 팀 돈 순위 | 팀 총연봉 vs 성적 ("돈 쓴 만큼 이겼나") |
| 계약·이적 소식 | FA·이적·재계약 소식을 숫자로 빠르게 정리 (최신성) |

## 4. 하지 않을 것

- 선수 사생활·연애·가족·논란·개인 재산 (명예훼손·사생활 위험)
- 선수 사진·기사 사진·중계 화면 캡처 (직접 만든 표·그래픽만)
- 토토·배당 같은 도박 관련 내용
- 이웃·공감·댓글 품앗이, 다른 블로그 글 복사
- 하루 여러 편 몰아서 발행 (미리 쓸 수 있는 글은 예약, 시점이 중요한 글만 즉시)
