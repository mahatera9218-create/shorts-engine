## 0. 아이디

- **추천: 사업용 새 아이디.** 나중에 연예·생활 경제 블로그를 따로 열 때 주제별로 나누기 쉽고, 개인 글과 섞이지 않습니다.
- 새 아이디는 휴대폰 번호 1개(본인 인증)당 최대 3개까지 만들 수 있습니다.
- 쓰던 아이디의 블로그가 비어 있다면 그대로 써도 됩니다.

## 1. 블로그 앱 설치와 로그인

1. 앱스토어·플레이스토어에서 **네이버 블로그** 앱을 설치합니다.
2. 사용할 아이디로 로그인합니다. 아이디마다 블로그가 자동으로 하나씩 있습니다.

## 3. 카테고리 (종목별 3개, 2026-09-30 개편)

앱에서 안 되면 휴대폰 브라우저로 blog.naver.com에 접속해 브라우저 메뉴에서 **"데스크톱 사이트"**를 켜고 **관리 → 메뉴·글·동영상 관리 → 블로그 → 카테고리 관리**로 들어갑니다. 태블릿이 편합니다.

| 카테고리 | 들어가는 글 |
| --- | --- |
| 야구 | 프로야구(KBO)·메이저리그 선수 |
| 축구 | 해외축구(프리미어리그·라리가 등) 선수 |
| 농구·골프 | NBA 선수, 골프 선수 (글이 쌓이면 나눔) |

두 선수를 비교하는 글은 첫 번째 선수의 종목에 넣습니다. 글마다 어느 카테고리인지 발행 도우미 글 화면 제목 아래에 적혀 있습니다.

**기존 4개에서 바꾸는 법 (한 번만)**
1. "선수 몸값" 선택 → 이름을 **야구**로 고치기 (지금까지 올린 글이 모두 야구 선수라 그대로 따라옵니다)
2. "몸값 대결" 선택 → 이름을 **축구**로 고치기 (글이 있으면 먼저 야구로 옮기기)
3. **+ 카테고리 추가** → **농구·골프**
4. "팀 돈 순위", "계약·이적 소식" 선택 → **삭제**
5. 아래 **확인** 누르기
