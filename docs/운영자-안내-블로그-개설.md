# 운영자 안내 · 네이버 블로그 개설 (휴대폰 기준)

블로그는 **대표님 본인 명의 네이버 아이디**로 만듭니다 (DECISIONS: 본인 명의 최대 3개, 가족 명의 사용 안 함).
메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다. 막히면 화면에 보이는 버튼 이름을 Claude에게 알려주세요.

---

## 0. 먼저 정할 것 (대표님 결정)

1. **주제:** 추천은 자동차(차종·인증중고차·중고차 플랫폼 비교)입니다. 블로그 이름과 카테고리가 주제에 따라 달라집니다.
2. **아이디:**
   - **추천: 사업용 새 아이디.** 블로그를 나중에 3개까지 늘릴 때 주제별로 나누기 쉽고, 개인 글과 섞이지 않습니다.
   - 쓰던 아이디의 블로그가 비어 있다면 그대로 써도 됩니다.
   - 새 아이디는 휴대폰 번호 1개(본인 인증)당 최대 3개까지 만들 수 있습니다.

## 1. 블로그 앱 설치와 로그인

1. 앱스토어·플레이스토어에서 **네이버 블로그** 앱을 설치합니다.
2. 사용할 아이디로 로그인합니다. 아이디마다 블로그가 자동으로 하나씩 있습니다.

## 2. 기본 정보 (앱 → 내 블로그 → 톱니바퀴 설정)

| 항목 | 넣을 내용 (자동차로 정할 경우 예시) |
| --- | --- |
| 블로그명 | 아래 후보 중 하나 |
| 별명 | 블로그명과 같게 (실존하지 않는 인물 이름은 쓰지 않음) |
| 소개글 | 아래 문구 |
| 블로그 주제 | 자동차 (네이버가 주는 주제 목록에서 선택) |
| 프로필 사진 | 비워 두거나 단색 로고. 다른 사람 사진·차 사진 도용 금지 |

**블로그명 후보 (자동차)**
- 숫자로 고르는 중고차
- 차 비교표
- 카 비교 노트

**소개글**
> 공식 자료와 공개 약관으로 인증중고차·중고차 사이트·차급별 유지비를 비교합니다. 시승기나 후기가 아니라 숫자로 비교하고, 기준일을 적고, 바뀌면 고칩니다.

## 3. 카테고리 만들기 (4개)

앱에서 안 되면 휴대폰 브라우저로 blog.naver.com에 접속합니다. 브라우저 메뉴에서 **"데스크톱 사이트"**를 켜고 **관리 → 메뉴·글·동영상 관리 → 블로그 → 카테고리 관리**로 들어갑니다. 태블릿이 편합니다.

| 카테고리 | 역할 |
| --- | --- |
| 인증중고차 비교 | 브랜드별 보증 기간·조건 비교 (대표 글 + 세부 글) |
| 중고차 사이트 비교 | 수수료·환불·보증 조건 비교 |
| 차급별 유지비 | 경차·소형·SUV 등 연비·자동차세 기반 연간 비용 |
| 조건 변경 소식 | 보증·수수료·가격 변경 반영 (최신성) |

차종·모델명 정리 글(예: 기아차종류)은 쓰지 않습니다. 네이버 검색 화면에서 블로그가 한참 아래에 나오기 때문입니다 (2026-09-29 대표 확인).

허브 글이 세부 글을 묶고, 세부 글끼리 서로 연결하는 구조입니다 (설계서 13.2).

## 4. 하지 않을 것

- 이웃 추가·공감·댓글을 품앗이로 주고받기 (어뷰징으로 보일 수 있음)
- 다른 블로그 글 복사, 다른 사람 사진 사용
- 개설 직후 하루 여러 편 몰아서 발행 (하루 1편 예약 발행, DECISIONS)

## 5. 끝나면 Claude에게 알려줄 것

- 정한 **블로그명**과 **블로그 주소**(blog.naver.com/아이디). 비밀번호는 알려주지 마세요.
- 그다음 Claude가 첫 주 글 7편을 준비하고, 대표님은 주 1회 태블릿으로 예약 발행합니다.
