# 경제 블로그 운영 가이드 (풀세트) — 2026-10-23

'억선생의 경제판'(eokonomy) 글 한 편을 **처음부터 발행까지** 돌리는 순서. **AI 2개**(클로드·GPT) + 어사이드 조합. (경제는 그림을 GPT가 생성 → 그록 안 씀. 클로드가 조사·글·제목·사진장면까지 다 함.)

---

## 한 번만 세팅 (경제 프로필)
- 어사이드 **경제 프로필** → 경제 네이버(eokonomy) 로그인
- 어사이드에 **클로드 + GPT(사진 프로젝트)** 연결
- AI 탭 2개에 프롬프트 붙여놓기: **클로드-경제-글** / **지피티-경제-사진** (지피티-경제-제목은 더 다듬고 싶을 때만 쓰는 선택지)

## 글 한 편 흐름 (키워드 1개 기준)

**1. 클로드 "글" 탭** — 키워드 입력 (예: `SK하이닉스`) (대화창 제목도 `SK하이닉스`)
   → 클로드가 **직접 조사 → 초안 제목 1개 + 완성 본문**(해석·대응·다양한 관점 반영, [사진N] 자리 포함) 나옴
   → 이어서 **"사진"** 치면 → `[사진 장면]` 7줄 나옴 → **복사**

**2. GPT "사진" 탭** — 장면 7줄 붙여넣기 → 1번부터 "다음"으로 7장 (대화창 제목도 `SK하이닉스`)

**3. 완성 표시** — 글 끝에 한 줄 `*ㄱ키워드`, 사진 끝에도 한 줄 `*ㄱ키워드` (예: 둘 다 `*ㄱSK하이닉스`). 대화창 이름은 안 바꿔도 됨.

→ 여러 키워드면 1~3을 키워드마다 반복(글·사진 끝에 같은 `*ㄱ키워드`).

## 하루 끝 — 어사이드 "조합"
`aside-경제-조합`의 코드블록 붙여넣기 → 오늘 **`*ㄱ` 붙은 것만** 키워드로 글+사진 묶어 **네이버 임시저장**에 넣음.

## 대표 마무리
네이버 임시저장 열기 → **제목 확정**(초안 그대로 쓰거나 다듬기) → 사진·본문 확인 → **발행 버튼.**

---

## 체크 (매 글)
- [ ] 조사한 사실만 썼나(미확인·지어내기 X)
- [ ] 소제목마다 '해석·대응' 한두 줄, 마무리 '내일 대응법'
- [ ] 쟁점엔 양쪽 관점 → 내 해석
- [ ] 제목: 감정·충격 동사 + 작은따옴표 (+전언 꼬리), 결론 숫자는 본문
- [ ] 글·사진 끝에 같은 `*ㄱ키워드`
- [ ] 발행은 대표가 (자동발행 금지)

## 네이버 공식 5기준 매핑 (이 세트가 지키는 것)
① 개성 제목+실사 썸네일 / ② 경험·해석·전문성 / ③ 다양한 관점 / ④ 트렌드+나만의 해석 / ⑤ 신뢰 정보 — 전부 프롬프트에 반영됨.
