# 경제 블로그 운영 가이드 (풀세트) — 2026-10-23

'억선생의 경제판'(eokonomy) 글 한 편을 **처음부터 발행까지** 돌리는 순서. 탭 4개(그록·클로드·GPT제목·GPT사진) + 어사이드 조합.

---

## 한 번만 세팅 (경제 프로필)
- 어사이드 **경제 프로필** → 경제 네이버(eokonomy) 로그인
- 어사이드에 **클로드 + GPT(사진 프로젝트)** 연결 (GPT 제목 프로젝트는 연결 안 함 — 제목은 대표가)
- AI 탭 4개에 각 프롬프트 붙여놓기: 그록-경제-조사 / 클로드-경제-글 / 지피티-경제-제목 / 지피티-경제-사진

## 글 한 편 흐름 (키워드 1개 기준)

**1. 그록 "조사" 탭** — 키워드 입력 (예: `SK하이닉스`)
   → '조사 세트' 나옴 → **복사**

**2. 클로드 "글" 탭** — 조사 세트 붙여넣기
   → **초안 제목 1개 + 완성 본문**(해석·대응·다양한 관점 반영, [사진N] 자리 포함) 나옴
   → 이어서 **"사진"** 치면 → `[사진 장면]` 7줄 나옴 → **복사**

**3. GPT "사진" 탭** — 장면 7줄 붙여넣기 → 1번부터 "다음"으로 7장
   → 사진 대화 **마지막 메시지 끝에 `*ㄱ키워드`** (예: `*ㄱSK하이닉스`)

**4. 클로드 "글" 탭** — 본문 맨 끝에도 **`*ㄱ키워드`** (사진과 같은 키워드!)

**5. (선택) GPT "제목" 탭** — 본문 붙여넣어 제목 더 뽑고 싶을 때만. 아니면 2번 초안 제목 사용.

→ 여러 키워드면 1~5를 키워드마다 반복(대화창 분리, 각각 `*ㄱ키워드`).

## 하루 끝 — 어사이드 "조합"
`aside-경제-조합` 지시문 붙여넣기 → 오늘 `*ㄱ`만 모아 **네이버 임시저장**에 글+사진 넣음.

## 대표 마무리
네이버 임시저장 열기 → **제목 확정**(초안 그대로 쓰거나 다듬기) → 사진·본문 확인 → **발행 버튼.**

---

## 체크 (매 글)
- [ ] 조사 세트에 있는 사실만 썼나(지어내기 X)
- [ ] 소제목마다 '해석·대응' 한두 줄, 마무리 '내일 대응법'
- [ ] 쟁점엔 양쪽 관점 → 내 해석
- [ ] 제목: 감정·충격 동사 + 작은따옴표 (+전언 꼬리), 결론 숫자는 본문
- [ ] 글·사진 `*ㄱ키워드` 동일
- [ ] 발행은 대표가 (자동발행 금지)

## 네이버 공식 5기준 매핑 (이 세트가 지키는 것)
① 개성 제목+실사 썸네일 / ② 경험·해석·전문성 / ③ 다양한 관점 / ④ 트렌드+나만의 해석 / ⑤ 신뢰 정보 — 전부 프롬프트에 반영됨.
