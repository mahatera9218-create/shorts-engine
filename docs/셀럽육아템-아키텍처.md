# 셀럽 육아템 — 전체 아키텍처 (2026-11-28)

## 0. 한 줄 정의
**셀럽이 쓰는 고가 육아템을 '미끼'로 노출 → 쇼커에 있는 동급 제품으로 "별 차이 없다(가성비)" 전환.** 타깃 = 30대 중반 엄마(실측 구독층).

## 1. 3대 원칙
- **역방향:** 쇼커 제품(링크 가능)을 **먼저** 찍고 → 셀럽을 엮는다. (찾아도 쇼커에 없으면 헛수고 방지.)
- **공정 비교:** "별 차이 없다"는 **실제 스펙 동급일 때만.** 날조·깎아내리기 ❌.
- **역할:** 노출 = 셀럽 이름 / 전환 = 쇼커 제품 / 신뢰 = 엄마 가성비 설득.

## 2. 소재 파이프라인 (역방향 — 이게 핵심)
```
① 쇼커 제품 풀            ② 셀럽 매칭(그록)              ③ 소재 확정
대표가 쇼커에서     →   같은 카테고리에서 셀럽이     →   [쇼커 제품 + 셀럽 + 비교각도]
발급 가능한 고단가       공개적으로 쓰는 유명템 찾기        = 오늘 1편 소재
제품 리스트              + 둘 스펙 비교(동급?)
```
- **쇼커 제품 풀** = 대표가 '상품 찾기'에서 링크 발급 가능 확인한 고단가 제품(유모차·카시트·하이체어·바운서). 틈새표·발급후보 기반.
- **셀럽 매칭** = 그록이 **공개·보도 확인된** 셀럽 육아템만(추정은 '~로 알려진', 아기·사생활 ❌).
  - 예: 쇼커 '부가부 유모차' → 손연재(부가부 폭스5 공개) / 쇼커 '하이체어' → 트립트랩 쓰는 셀럽 → 동급 하이체어.

## 2.5 ★★ 투트랙 + '도망 방지' (셀럽 먼저, 모자라면 일반)
**문제(대표 지적):** 생산자(AI)에게 "셀럽 찾아"라고 시키면 귀찮아서 **"없다"하고 일반 비교로 다 채운다** — 경제에서 겪음(쉬운 쪽으로 도망).
**해결 = 경제 구조 그대로: 발굴/생산 분리 + 셀럽 풀 미리 축적.**
1. **새벽 '셀럽 발굴' 루틴:** 매일 셀럽 육아템 공개(SNS·포토뉴스·방송)를 스캔 → **`셀럽매칭풀.md`에 누적**(쇼커 제품 후보와 연결). 못 찾는 날은 추가 0, 재고는 유지.
2. **생산:** 발행이력에 없는 **셀럽 풀 재고를 먼저 소진**(셀럽 편) → **모자란 만큼만** 일반 비교(기존 A/B모드).
3. **★ 강제 규칙:** 풀에 미사용 재고가 있으면 **무조건 셀럽 우선.** **재고 수가 기준** — 생산자가 임의로 '없다'며 일반으로 채우는 것 **금지.** 일반으로 채운 편수는 "셀럽 N / 일반 M (사유)" **명시 보고.**
→ 생산자한테 찾으라 안 시키고 **미리 쌓인 풀에서 꺼내게** 하므로 '없다' 도망이 구조적으로 불가능. 유모차·하이체어는 재고가 빨리, 카시트는 느리게 쌓임(매칭 쉬운 카테고리 위주로 자연 집중).

### 셀럽매칭풀.md 템플릿 (Drive `공장/데이터/키워드/`)
```
| 카테고리 | 쇼커제품(후보) | 셀럽 | 셀럽템 | 공개출처·날짜 | 비교각도 | 상태(미사용/발행) |
| 유모차 | 부가부 비6 등 | 손연재 | 부가부 폭스5 | SNS(보도) | "200만 유모차 vs 동급 반값" | 미사용 |
```
- 상태=발행이면 제외(중복방지). 같은 셀럽 연속 노출 ❌.

## 3. 생산 파이프라인 (한 편)
```
대표(쇼커 제품 찍기)
  → 그록 「육아 조사」: 셀럽 유명템 발굴 + [셀럽템 vs 쇼커제품] 스펙 비교
  → 클로드 「셀럽 육아템」: 제목12 + 본문(해요체·비교표·[사진N]자리) + 대가성·[상품링크N]
  → 지피티 「육아 사진」: 비교표 이미지 + 무드컷(보완)
  → 어사이드: 쇼커 링크 발급·삽입 + 셀럽 공식사진(그록 URL) + 쇼커 제품 공식 + 조립·임시저장
  → 대표: 발행
```

## 4. 쇼커 링크 체계 (2모드)
- **A모드** (셀럽템이 쇼커에 **있음**): 그 제품 직접 링크. (부가부·싸이벡스·브라이텍스 등 대형 브랜드는 입점 확률 높음.)
- **B모드** (셀럽템이 쇼커에 **없음** — 예: 트립트랩): 셀럽템은 **노출 미끼**, 링크는 **동급 쇼커 유사품.** ← 역방향의 메인.
- 링크풀·발급 = 어사이드 「쇼핑커넥트 링크발급」(상품찾기), 단가 10만원↓ 부속 거름.

## 5. 사진
- **셀럽 공식** = 그록 URL 수집(공식 SNS·포토뉴스). **아기 얼굴·사생활 컷 ❌, 제품 보이는 컷·상반신만.**
- **쇼커 제품 공식** = 어사이드. **비교표** = 지피티 이미지(숫자는 그록 확인분).
- 규격 1:1 1024·워터마크 제거. 썸네일 = 제품 or 셀럽 상반신(실사·텍스트 없음).

## 6. 중복·로테이션
- **발행이력**(제품 + 셀럽) 기록 → 같은 제품·셀럽 반복 방지. 한 셀럽 연속 노출 ❌.

## 7. 품질·안전 게이트 (저품질·신뢰 붕괴 방지)
- "별 차이 없다" = **실제 동급일 때만**(셀럽템이 더 나으면 솔직히 + "그 차이가 ○○만원 값이냐" 가성비).
- **금지:** 가짜 "OO가 쓴다" 날조 / 셀럽템 허위 비하 / 추정 단정 / 아기 얼굴·이름·사생활 / 기사 사진·문장 복제 / 생 URL(수익 0) / 대가성 누락 / 효능·과장.

## 8. 데이터 루프 (경제처럼 자가 보정)
- 블로그 통계(크리에이터 어드바이저) → ① **체급**(노출 되는 셀럽·카테고리 문서수) ② **타깃**(실제 유입 연령·성별) ③ **먹히는 각도**(어떤 셀럽·제품이 유입 터졌나) → 소재 풀·훅 보정.

## 9. 자동화 분업
| 사람(대표)만 | 자동(공장) |
|---|---|
| 쇼커 제품 찍기 · 링크 발급(로그인) · **발행** | 셀럽 매칭·비교 조사 · 글·제목 · 비교표·사진 · 조립·임시저장 |

## 10. 착수 전 결정할 것 (대표)
- **발행 블로그:** mahatera(육아)로? 아니면 별도?
- **편수·주기:** 정기 새벽 루틴(매일 N편) vs 대표 요청 시.
- **쇼커 제품 풀 초기 세팅:** 대표가 '상품 찾기'에서 **링크 발급 가능한 고단가 제품 리스트**를 한 번 확정(이게 역방향의 출발점).
- **셀럽 소재원:** 셀럽 육아템 공개는 포토뉴스·SNS·방송 — 그록이 그때그때 발굴(별도 소재 파일 둘지 여부).
