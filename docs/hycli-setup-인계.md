# Hycli 설치·세팅 인계 쪽지 (VS Code Claude Code용)

> 이 파일은 **대표 B의 PC에서 도는 Claude Code(VS Code)**가 읽고 이어서 진행하라고 만든 인계 문서다. 클라우드 세션에서 여기까지 합의한 내용을 넘긴다.

## 너(로컬 Claude Code)의 역할
- 대표 B는 **비개발자**다. **모든 소통은 한국어**, 쉬운 말, 단계별로. 키 입력·로그인·승인·발행 버튼만 대표에게 부탁한다.
- 세션 시작 시 이 저장소의 **CLAUDE.md, DECISIONS.md(맨 아래 최신 결정들)**를 읽어라. 특히 2026-10-20 결정들(블로그 3-서브에이전트 구조, 저장소 개편, 트렌드 착장 추종).
- **추측 금지.** Hycli 사용법은 공식 저장소/`--help`/대시보드로 확인하고 진행한다.

## 목표 (1단계부터)
**Hycli로 네이버 블로그 '임시저장'을 자동화**하는 것이 1단계. 대표가 챗(그록·클로드·지피티)에서 받은 **글 + 사진**을 네이버 블로그 임시저장에 자동으로 넣는 게 목표. ("대표가 손으로 네이버에 붙여넣기" 제거.)

- Hycli = https://github.com/Hybirdss/Hycli — **로그인된 웹사이트를 CLI + MCP 도구로** 바꿔주는 오픈소스(러스트). 내 브라우저 로그인 세션을 그대로 쓴다. 네이버는 발행 API가 2020년에 막혀서, 이게 현실적인 자동화 통로다.

## 안전 순서 (반드시 이 순서)
1. **읽기(reads)부터** — 네이버 크리에이터 어드바이저 트렌드, 블로그 통계. 안전하고 성공률 높다.
2. **쓰기(writes)는 그다음** — 임시저장부터. Hycli는 쓰기가 **기본 꺼짐 + 1회 승인(`writes allow`)**. 켠 뒤에도 **소량·사람처럼 천천히** 테스트. 네이버 계정 밴 위험이 있으니 **무리한 대량 자동발행 금지**(우리 원칙 CLAUDE.md). 발행 버튼은 대표가 직접.
3. 봇 차단 화면이 뜨면 Hycli가 멈춘다 — 그때는 **중단하고 대표에게 보고.**

## 설치 단계
1. **네이버에 브라우저로 로그인**돼 있는지 먼저 확인(크롬/엣지 등 — Hycli가 그 세션을 가져온다).
2. **설치**: GitHub Releases에서 이 PC OS에 맞는 설치파일(윈도우면 x64/ARM64). **러스트·Node 불필요.** 설치 후 `hycli open` → 브라우저에 `http://127.0.0.1:4318` 대시보드.
3. **prepare**: `hycli prepare <네이버 블로그 글쓰기 페이지 URL>` → Hycli가 세 AI 워커로 그 사이트의 읽기/쓰기 기능을 자동 생성. **이때만 AI 모델이 필요**한데, **API 키 대신 'ChatGPT 로그인(Codex app-server)'도 지원**된다 — 대표는 구독 선호이니 **ChatGPT 로그인 방식을 먼저 검토**(API 키는 그다음).
4. **describe**: `hycli describe`로 만들어진 읽기/쓰기 목록 확인.
5. **읽기 먼저 테스트** → `hycli check`로 로그인 만료/사이트 변경 점검(LLM 없이 반복 가능 → 이후 비용 거의 0).
6. 검증되면 **`hycli writes <site> allow`**로 쓰기 켜고 → **임시저장 write를 초안 1개로** 조심스럽게 테스트.

## 참고 (이 저장소 안)
- `prompts/project/` — 경제·건강·패션 블로그 프롬프트 탭(그록 조사 / 클로드 글 / 지피티 제목·사진). 글·사진이 여기서 나온다.
- `tools/naver_draft/` — 예전에 Playwright로 네이버 임시저장을 시도한 로컬 프로그램. **Hycli가 이걸 대체**할 수 있다(더 견고·안전). 참고만.
- `DECISIONS.md` — 최신 운영 결정 전부. 세션 시작 시 필독.

## 다음 단계(1단계 성공 후, 서두르지 말 것)
- 네이버 트렌드·통계 reads 정식화 → 패션 트렌드 키워드 자동 수집, 주간 성과 자동 수집.
- (욕심) 챗 답변 자동 읽기 = '버퍼(답변 끝나면 N초 뒤 읽기)' 방식 — 챗 화면은 깨지기 쉬우니 맨 나중, 선택.
- 지식인 답글: 일일 건수·시차 제한 안에서 사람처럼 소량만(밴 위험 관리). 자동 대량 금지.

## 금지/원칙
- API 키·비밀번호를 코드·로그·커밋·대화에 남기지 않는다(Hycli는 OS 키링/로컬 금고에 저장).
- 외부 공개(발행·게시)는 대표 승인 + 소량. 가짜·무단 크롤링 금지(CLAUDE.md 그대로).
