# Aside 루틴 지시문 (참고 블로거 글 모양 조사)

공개 RSS로는 **주제·제목·썸네일·요약 글자 수**까지만 매일 자동으로 모아요 (05:40, `content/econ_refs.py`).
**표·글꼴·정렬·인용·구분선**은 글을 열어 봐야 알 수 있어서 이건 Aside가 맡아요.
아래 글을 Aside의 루틴(매일 반복)에 그대로 붙여넣으세요.

매일 아침, 아래 네이버 블로그 8곳에서 어제·오늘 올라온 글을 블로그마다 1편씩 열어 봐 줘.
blog.naver.com/balahk, dutyfrees, meaning87, ranto28, rmsgud2007, ishisheido77, antsal, zkfldb888

글마다 아래만 적어 줘. 글 내용(문장)은 옮기지 말고 모양만 적어.
1. 제목, 올린 시각
2. 글자 수(대략), 사진·그림 수, 표 수, 동영상 유무
3. 글꼴: 본문 글꼴 이름과 크기, 소제목 글꼴·크기·굵기·색
4. 정렬: 가운데 정렬인지 왼쪽 정렬인지, 문단 사이 줄 띄우기 방식
5. 인용구 사용 여부와 모양(따옴표형·세로줄형·말풍선형 등), 구분선 사용 여부와 모양
6. 강조 방식: 굵게·색 글자·형광펜·밑줄 중 무엇을 얼마나
7. 글 순서: 처음 3줄은 무엇으로 시작하는지, 끝은 어떻게 맺는지(요약·질문·면책 문구 등)
8. 썸네일(대표 사진): 사진/그림/캡처, 글자 유무와 위치
