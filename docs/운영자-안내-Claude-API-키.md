# 운영자 안내 · Claude API 키 (자동 글쓰기용, 휴대폰 기준)

매일 아침 글을 자동으로 쓰려면 **Claude API 키 1개**가 필요합니다. 대화용 Claude 구독과는 **별도 결제**입니다 (쓴 만큼 충전금에서 빠짐).

- 예상 비용: 글 1편에 약 100~200원, **하루 1편이면 한 달 약 3천~7천 원** (설계서 14.5 예산 안)
- 결제 수단 등록과 충전은 **대표님 결정**입니다. 처음엔 **$10(약 1만 4천 원)** 충전을 권합니다.
- 키는 **GitHub Secrets에만** 넣습니다. 채팅·메모·사진으로 보내지 마세요.

메뉴 이름은 바뀔 수 있습니다. 막히면 보이는 버튼 이름을 알려주세요.

---

## ① 가입과 충전

1. 휴대폰 브라우저로 **console.anthropic.com** 접속 (platform.claude.com으로 넘어갈 수 있음, 정상)
2. 구글 계정 또는 이메일로 가입·로그인 (**계정 생성은 대표님 결정**)
3. 메뉴(☰) → **Settings → Billing**
4. 결제 카드 등록 → **Buy credits**(크레딧 구매)로 **$10** 충전
5. 자동 충전(Auto-reload)은 **꺼 두세요.** 충전금이 떨어지면 글쓰기만 멈추고 추가 결제는 없습니다.
6. 가능하면 **Limits**(사용 한도)에서 월 한도를 **$20** 정도로 걸어 두세요.

## ② 키 만들기

1. 메뉴 → **API Keys** → **Create Key**
2. 이름: `shorts-engine` → 만들기
3. 화면에 뜬 키(`sk-ant-`로 시작)를 **복사**. 이 화면을 닫으면 다시 볼 수 없습니다.

## ③ GitHub에 넣기

1. 브라우저로 github.com → 저장소 **shorts-engine** → **Settings**
2. **Secrets and variables → Actions → New repository secret**
3. Name: `ANTHROPIC_API_KEY` (그대로) / Secret: 복사한 키 붙여넣기 → **Add secret**

## ④ 첫 실행 (확인용)

1. 저장소 **Actions** 탭 → 왼쪽 **자동 글쓰기** → **Run workflow**
2. 실행 방식 **실제**, 선수 이름은 비워 두고 초록 버튼
3. 3~5분 뒤 초록 체크 ✅ → 저장소 **posts** 폴더를 열면 맨 위에 새 글이 보입니다
4. 끝나면 Claude에게 "자동 글쓰기 돌렸음"이라고 알려주세요. 첫 결과는 제가 직접 검토합니다.

그다음부터는 **매일 오전 5시 13분(늦으면 7시 37분)에 자동으로** 1편씩 씁니다.

## 매일 하실 일 (2~3분)

1. GitHub 앱 → shorts-engine → **posts** 폴더 → 맨 위 글 (상태가 **✅ 발행 가능**인 것만)
2. 글을 열어 **★ 제목**, 본문, 태그를 복사해 네이버 블로그 앱에 붙여넣기
3. 이미지 2장(thumb.png, receipt.png)을 받아 [이미지] 자리에 넣고, thumb.png를 대표이미지로
4. 발행 (또는 예약 발행)

**⚠️ 확인 필요** 표시가 붙은 글은 발행하지 말고 Claude에게 알려주세요.
