# 집 PC = LLM 에이전트 공장 (로드맵)

*2026-11-09 신설 · 집 PC를 상시 서버로 돌려 콘텐츠 생산을 공장처럼 자동화하는 그림. 집 PC 세팅할 때 이 문서 하나만 보면 됨.*

## 0. 한 줄 요약
집 PC(상시 ON) 위에 **구독제 LLM 런타임 + 우리 스킬 + MCP + 어사이드 + 로컬 GPU**를 올려 **라인별 콘텐츠 공장**을 돌린다. **토큰값(API) 최소화, 발행은 끝까지 대표 수동.**

## 1. 런타임 — 구독제로 (핵심: 토큰값 회피)
- **Claude Code = 두뇌.** **Claude 구독(Max)으로 로그인 → API 키 없이 정액**으로 돈. 우리 스킬 다 여기서 실행.
- (선택) **Codex = ChatGPT 구독**으로 코드·엔진 유지보수 보조.
- **키가 필요한 곳은 LLM이 아니라 데이터 API만** (niche 엔진의 네이버 검색광고·API HUB 문서수). 토큰값 아님, 소액. **키는 Secrets/로컬 안전저장에만.**
- 제약: 구독도 **사용량 캡**(주간 한도) 있음 → 24h 풀가동 말고 **필요할 때 깨우는** 구조.

## 2. 작업자 — 이미 보유한 스킬
`money-content-writer`(글) · `market-research-memo`(틈새·메모) · `shorts-script`(쇼츠) · `blog-voice`(말투·AI티 검사). 새 CLI 짤 필요 없음 — Claude Code + 이 스킬이 곧 작업자.

## 3. 손 — MCP (연결)
- **1순위 = 구글시트 MCP.** 공장의 피가 전부 시트에 있음(틈새표·경제로그·인플로그·테스트지시). 붙이면 "시트 읽고 → 글 쓰고 → 시트 기록"이 사람 손 없이 한 런타임에서 돈다.
- 파일시스템(reports·원고). 추후 niche 엔진 래퍼 등.

## 4. 오케스트레이션 (herder)
작업 큐 + 역할 분담: **Claude = 판단·창작·글·리서치**, **Codex = 코드·엔진·데이터 처리.** herder가 "오늘 할 일"을 던지면 각자 집어가 결과를 시트/reports에 쌓음.

## 5. 어사이드 — 네이버 팔 (유지)
네이버 **임시저장**은 어사이드(브라우저 자동화)가 담당. LLM 일은 구독 런타임이 하고, 어사이드는 "네이버에 넣기"만. **로그인·발행은 대표.**

## 6. 사진 라인 — 지피티 제거 → 그록(실물) + 로컬 GPU(3060 Ti 8GB)
지피티가 "지맘대로 상상"(구축 시켜도 신축, 단지 틀림)하는 문제를 **로컬 GPU가 구조적으로 해결.**
```
연예/패션:  그록(+인스타) 실물 → 끝     (생성 최소)
경제 부동산: 그록/어사이드 실물 → 부족분만 로컬 생성
경제 추상:   로컬 text-to-image (오브젝트·무드)
썸네일:      실사 기반 가공 (아래)
지피티:      제거 ✂️
```
### 썸네일 = 실사 기반 + 구도·조명·배경 가공 (로컬이 핵심)
- **ComfyUI + img2img + ControlNet.**
- **변형 강도(denoise) 낮게** → 건물 그대로, 조명·하늘·분위기만.
- **ControlNet(구조 잠금)** → 원본 사진의 윤곽·깊이를 틀로 고정 → **건물 모양 안 바뀜**(구축→신축 둔갑·단지 틀림 불가).
- **negative 확실히 먹힘** → "사람 없음·차트 없음" 진짜 반영(지피티가 무시하던 것).
- 3060 Ti(8GB): SD1.5 + ControlNet이면 빠르고 충분. SDXL도 가능(느림).
- 생성은 **오브젝트·무드·실사가공 중심.** (가짜 인물 생성은 CLAUDE.md 금지선 그대로.)

## 7. 하드웨어 전제 (집 PC 세팅)
- **예약 ON:** 스마트플러그(16A/3520W, 앱 예약 ON/OFF) + BIOS **AC 복구 시 켜짐**. 아침 ON→부팅, 밤 OFF(정상 종료 후).
- **어사이드 자동 실행**(부팅 시 시작프로그램).
- **크롬 원격 데스크톱**(폰에서 확인·정상 종료).
- **팬 불빛 OFF**(MasterPlus+ / OpenRGB — ASRock Pro + 쿨러마스터).
- 유선 랜 + 공유기 상시 ON.
- 끄기 = **윈도우 정상 종료 먼저, 그다음 플러그 OFF**(강제차단 ❌).

## 8. 착수 순서 (라인 하나씩 검증 후 복제)
1. **뼈대:** Claude Code(Max 구독) + **구글시트 MCP** 연결 → 경제 생산 라인 한 바퀴 자동으로.
2. **어사이드 연계:** 생산물 → 네이버 임시저장 연결 확인.
3. **사진 라인:** ComfyUI + ControlNet 설치(원격) → 썸네일 실사가공 + 경제 추상 생성.
4. **쇼츠 라인:** shorts-script → 장면 → 렌더.
5. 검증된 라인을 다른 블로그(패션·연예)로 복제.

## 9. 끝까지 지키는 선
- **발행·외부공개 = 대표 수동** (공장은 임시저장까지).
- **키는 데이터 API만, Secrets/로컬 안전저장.** LLM은 구독제.
- 가짜 인물·날조 생성 ❌ (CLAUDE.md 금지선).
