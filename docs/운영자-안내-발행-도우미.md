# 운영자 안내 · 발행 도우미 (태블릿으로 3분 발행)

매일 아침 6시 47분에 새 글이 만들어지면, **발행 도우미 페이지**에 자동으로 올라옵니다.
대표님은 페이지를 열어 **버튼 몇 번 + 네이버 앱에 붙여넣기**만 하면 됩니다.

페이지는 Cloudflare(무료)에 올립니다. 검색엔진에는 안 나오게 막아 둡니다 (발행 전 글이 먼저 수집되면 우리 글이 중복 문서가 될 수 있어서).

---

## 처음 한 번: Cloudflare 키 2개 (약 10분)

### ① 가입 (계정 생성은 대표님 결정, 무료)

1. 휴대폰·태블릿 브라우저로 **dash.cloudflare.com/sign-up** 접속
2. 이메일·비밀번호로 가입 → 메일함에서 인증 링크 누르기
3. 요금제를 물으면 **Free(무료)**

### ② 계정 ID 복사

1. 로그인한 첫 화면 주소창을 보면 `dash.cloudflare.com/` 뒤에 **영문·숫자 32자리**가 있습니다. 그게 계정 ID입니다.
   (또는 왼쪽 메뉴 **Workers & Pages** → 오른쪽 **Account ID** 옆 복사 버튼)
2. 👉 [키 넣는 화면](https://github.com/mahatera9218-create/shorts-engine/settings/secrets/actions/new)
   - Name: `CLOUDFLARE_ACCOUNT_ID` / Secret: 붙여넣기 → **Add secret**

### ③ API 토큰 만들기 (템플릿 사용)

1. Cloudflare 오른쪽 위 사람 모양 → **My Profile** → **API Tokens** → **Create Token**
2. 목록에서 **Edit Cloudflare Workers** 줄의 **Use template** (이 템플릿에 필요한 권한 "Cloudflare Pages 편집"이 들어 있음)
3. 권한은 그대로 두고, **Account Resources**: `Include` → 대표님 계정
4. **Zone Resources**가 보이면 `Include` → `All zones`
5. **Continue to summary** → **Create Token** → 나온 토큰 **복사** (다시 볼 수 없음)
6. 👉 [키 넣는 화면](https://github.com/mahatera9218-create/shorts-engine/settings/secrets/actions/new)
   - Name: `CLOUDFLARE_API_TOKEN` / Secret: 붙여넣기 → **Add secret**

### ④ 첫 배포

1. 👉 [발행 도우미 배포](https://github.com/mahatera9218-create/shorts-engine/actions/workflows/desk.yml) → **Run workflow**
2. ✅ 나오면 Claude에게 알려주세요. 페이지 주소를 드립니다.
3. 받은 주소를 태블릿에서 열고 **공유 → 홈 화면에 추가** (앱처럼 아이콘이 생김)

---

## 매일 (약 4분, 클립 포함)

매일 아침 발행 가능한(✅) 글 1편과 클립이 자동으로 올라와요. 기준 미달이면 알아서 다시 써서, 도우미에는 ✅ 글만 보여요. 완료를 Claude에게 알려주지 않아도 돼요.


1. 홈 화면의 **발행 도우미** 열기 → 맨 위 ✅ 글 누르기
2. **① 사진 한 번에 저장** → 공유 창에서 "이미지 저장"
3. 네이버 블로그 앱 → 글쓰기
4. **② 제목** 하나 눌러 복사 → 제목 칸에 붙여넣기
5. **④ 본문 복사** → 본문에 붙여넣기 → "📷 사진 N" 줄을 지우고 그 자리에 N번 사진 넣기
6. 사진 1(썸네일)을 **대표이미지**로 지정
7. **⑤ 태그** 한 번에 복사 → 태그 칸에 붙여넣기 (안 되면 태그를 하나씩 눌러 복사·붙여넣기) → 카테고리는 **도우미 글 화면 제목 아래에 적힌 종목**(야구 / 축구 / 농구·골프) → 발행
8. (클립, 1분) 도우미 페이지 **⑥ 클립 영상 저장** → 블로그 앱 아래 **+** → **클립 만들기** → 저장한 영상 고르기 → **음악**에서 추천 음악 하나 → **⑥ 클립 설명 복사**한 것 붙여넣기 → 올리기

9. 글 화면 맨 아래 **✅ 발행 완료 표시** → GitHub 화면이 열리면 초록 **Create**만 누르기 → 2~3분 뒤 목록에서 "발행한 글"로 내려감 (같은 글을 두 번 올리지 않게)

**글이 마음에 안 들면**: 글 화면의 **🔄 다른 글로 다시 뽑기** → GitHub 화면에서 **Create** → 그 글은 목록에서 빠지고 5~10분 뒤 다른 선수·테마의 새 글이 올라와요. (Claude 요금이 한 편만큼 더 들어요, 약 $1 이하)

(사진까지 통째로 복사는 시험해 보니 네이버가 사진을 받지 않아 뺐어요. 2026-09-30)

**도우미 첫 화면 맨 아래 버튼 (필요할 때만)** — GitHub Actions에 들어갈 필요 없어요.
- **🎨 사진·클립 다시 그리기**: 글은 그대로, 썸네일·클립만 새 디자인으로. 무료, 5~10분.
- **✍️ 후보 4편 새로 쓰기**: 오늘 후보가 다 마음에 안 들 때. Claude 비용 약 $2~3, 20~30분.
- 둘 다 누르면 GitHub 화면이 열리고, 초록 **Create**만 누르면 돼요.
