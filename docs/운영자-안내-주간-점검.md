# 운영자 안내 · 주간 점검 (주 1회, 약 5분)

전체 규칙·목표는 `docs/운영-계획.md`. 매주 월요일 오전에 Claude가 이 대화창에서 캡처를 요청해요.

매주 월요일쯤 캡처 몇 장을 이 대화창(Claude)에 붙여 주시면 돼요. Claude가 읽고 가설·가중치를 고친 뒤 `reports/`에 결과를 남겨요.

## 캡처할 것

1. **블로그 통계** (네이버 블로그 앱 → 내 블로그 → 통계)
   - 지난 7일 조회수 (일간 그래프)
   - 게시물별 조회수 순위
   - 평균 사용 시간 (있으면)
   - 유입 경로: 홈판(추천) / 검색 비율 (있으면)
2. **클립 통계** (클립 크리에이터 앱 또는 네이버 앱의 내 클립)
   - 클립별 조회수·좋아요·댓글
3. **유튜브 스튜디오** (YT Studio 앱 → 분석 → 콘텐츠 → Shorts)
   - 쇼츠별 "시청함 / 스와이프함" 비율(또는 평균 시청 비율) 화면
   - 조회수·구독자는 Claude가 자동으로 모아서 캡처하지 않아도 돼요
4. **댓글** (블로그 글·클립·쇼츠에 달린 댓글)
   - 선수 이름이 나온 댓글만 캡처해 주셔도 돼요. 요청받은 선수는 3주 동안 더 자주 뽑혀요.

메뉴 이름이 조금 다르면, 보이는 화면을 그대로 캡처해 주세요. 거기에 맞춰 이 안내를 고칠게요.

## Claude가 하는 일

- 편집장 점수·글 설계와 실제 조회수·체류를 맞춰 보고, 맞지 않는 가설을 고친다 (money-content-writer 0단계, DECISIONS 기록)
- 잘 된 종목·선수·테마·제목 유형의 가중치를 올린다 (`config/players.yaml`)
- 댓글 요청 선수를 `config/requests.yaml`에 적는다 (풀에 없는 선수는 팀·등번호 확인 후 추가)
- 콘텐츠 재고를 잰다 (`python -m content.inventory`): 먼저 마르는 테마가 있으면 선수·물건·테마를 채운다
- 광고 단가 결과(`reports/광고/`)를 보고 아이디어 창고(`config/ideas.yaml`)에서 다음 테마를 고른다
- 결과: `reports/주간/<날짜>.md`
