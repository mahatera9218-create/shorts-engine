# 운영자 안내 · 주간 점검 (주 1회, 약 5분)

매주 월요일쯤 캡처 몇 장을 이 대화창(Claude)에 붙여 주시면 돼요. Claude가 읽고 가설·가중치를 고친 뒤 `reports/`에 결과를 남겨요.

## 캡처할 것

1. **블로그 통계** (네이버 블로그 앱 → 내 블로그 → 통계)
   - 지난 7일 조회수 (일간 그래프)
   - 게시물별 조회수 순위
   - 평균 사용 시간 (있으면)
   - 유입 경로: 홈판(추천) / 검색 비율 (있으면)
2. **클립 통계** (클립 크리에이터 앱 또는 네이버 앱의 내 클립)
   - 클립별 조회수·좋아요·댓글
3. **댓글** (블로그 글·클립에 달린 댓글)
   - 선수 이름이 나온 댓글만 캡처해 주셔도 돼요. 요청받은 선수는 3주 동안 더 자주 뽑혀요.

메뉴 이름이 조금 다르면, 보이는 화면을 그대로 캡처해 주세요. 거기에 맞춰 이 안내를 고칠게요.
