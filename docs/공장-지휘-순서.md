# 공장 지휘 순서 (지휘자 = 클라우드 클로드, 어사이드 = 수동 탭) 2026-11-11

## 왜 이 문서
어사이드는 **폴더를 지켜보다 자동 실행하는 게 안 된다**(대표 확인 2026-11-11). 그리고 **클로드는 어사이드를 못 누른다**(전용 MCP 없음). 다리는 **구글 드라이브**(파일이 놓일 뿐 스스로 안 깨움).
→ 그래서 **지휘자 = 드라이브에 직접 닿는 클라우드 클로드**가 맡고, **어사이드 출발은 대표가 탭**한다. 이 문서가 "누가 언제 무엇을" 의 순서표다.

## 역할 한 줄
- **클라우드 클로드(지휘자+뇌):** 드라이브 읽고/쓰기 — 생산지시·글·제목·검수. 각 ★에서 **멈추고 대표에게 어사이드 실행을 요청**한다.
- **대표(손 트리거):** ★ 표시에서 **어사이드를 탭(실행)** 한다. 되면 "됐어"라고만 한다. + 마지막 발행.
- **어사이드(손):** 그록 조사·사진수집 → 드라이브, 그리고 네이버 임시저장. (대표가 실행시킬 때만 돈다.)

---

## 경제 1편 순서 (★ = 대표가 어사이드 탭)
```
1. 클로드  : 오늘 키워드·제목 결 정함 → 드라이브 공장/작업대/경제/오늘/생산지시.md
2. ★대표   : 어사이드 "경제 수집" 실행 → N_조사.md (조사) 드라이브에
3. 클로드  : N_조사 읽고 → 글·제목(12+추천)·검수 → N_원고.md + N_사진요청.md
4. ★대표   : 어사이드 "경제 사진수집" 실행 → N_사진/ (썸네일·실물컷) 드라이브에
5. 클로드  : 사진까지 검수 OK → N_완료 신호
6. ★대표   : 어사이드 "경제 저장" 실행 → 네이버 임시저장(발행 X)
7. 대표    : 제목 골라 발행
```
→ 대표가 실제로 하는 건 **어사이드 탭 3번(2·4·6) + 발행 1번.** 나머지는 전부 클로드.

**멈춤 규칙:** 클로드는 ★ 직전에서 멈추고 **"지금 어사이드에서 ○○ 실행해주세요. 되면 '됐어'"** 라고 한 줄로 요청한다. 흩지 말고 **같은 타이밍 건 모아서** 요청(여러 편이면 "경제 수집 5편 한 번에").

## 패션 1편 순서
경제와 **같은 패턴**. 단 ★2 "패션 수집"은 그록 연예패션/패션 조사 + 인스타 실물, ★4는 사진(실물 중심), ★6은 캐시미어다이어리 저장. 지시문: `패션-하루운영`.

## 가십 1편 순서 (비정기)
0. 대표가 MSN 소스 링크를 던진다(드라이브 소스함 또는 대화로). 그 뒤 경제와 같은 패턴. 지시문: `연예-하루운영`.

---

## 여러 편·여러 사업부 동시
- 클로드는 세 사업부(경제·패션·가십) 생산지시·글을 **다 만들어 드라이브에 쌓아두고**, ★ 요청을 **모아서** 대표에게 준다.
  - 예: "지금 어사이드 탭 ① 경제 수집 ② 패션 수집. 되면 '둘 다 됐어'."
- 대표는 어사이드 **프로필(경제/패션/가십)** 로 나눠 탭. 모니터로 어디까지 왔나 본다.

## 멈춤·장애
- 어사이드가 로그인 풀림·그록 한도로 멈추면 → 대표가 상태 알려주고, 클로드는 그 지점부터 재개. 비번 자동로그인·자동 발행은 **안 함**(대표만).

## 안 쓰는 길 (정리)
- PC 터미널/슬래시 명령/QR로 공장 돌리는 방식 = **폐기.** (뇌가 드라이브를 못 봐서 다리가 끊김 — 2026-11-11 확인.) PC는 **GPU 사진 생성** 때만.
