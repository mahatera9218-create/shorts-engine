# 인플준비용 보관 (경제 블로그 인플루언서 준비) — 색인

> **꺼내는 법:** 대표가 "**인플준비용**"이라고 하면 이 파일부터 열고, 아래 자료들을 꺼낸다. (지금은 **보관 상태** — 경제 발행 안정 후 가동.)
> 최종 정리: 2026-11-02. 기준 = kim_spoon 벤치 분석.

## 핵심 원칙 (두 엔진 구분 — 절대 혼동 금지)
- **미러글(매일·대부분) = 돈 엔진.** 조회수 볼륨(검색+홈판), 틈새 키워드·강도8 제목·해시태그 20·참조문헌. **재건축 홈판 급증이 실제 애드포스트 돈줄.** 건드리지 않는다.
- **인플 간판(소수) = 배지·신뢰 엔진.** 콘텐츠 질·팬. 태그 없음·참조문헌 없음·마무리 세트. 자기 자신은 돈 거의 못 범 → **배지를 따서 노출 우대·협찬으로 전환**이 목적.
- ⚠️ **블로그 전체를 인플(순수 콘텐츠)로 바꾸면 안 된다** — kim_spoon이 그래서 애드포스트 역대 최대가 6만원. 볼륨 엔진을 버리면 우리도 그렇게 된다.

## 인플 전용 글 프롬프트 현재 설정 (클로드-인플-부동산.md)
- 입력: 아파트(단지)·청약·정책 중 하나 → 출력: `제목`/`글`/`사진`
- 페르소나: 맞벌이 가장(인천·서울 통근, 5살 아들, 친어머니 부동산 중개), 공개 수위 지킴
- 2기둥: ① 내 과정으로 해석 ② 막힌 점 솔직 공개
- **문장체 습니다체 / Q&A 없음 / 해시태그 없음 / 참조문헌 없음**
- 마무리 세트: 시그니처+이웃추가 CTA · 면책 한 줄 · 함께 읽으면 좋은 글(관련 과거글 링크)
- 제목: 검색어(단지·청약·정책명) 앞 + 신뢰·공감 훅(낚시·공포어 금지), 30~40자

## 남은 것
- **닉네임 확정** (추천: 「일요일 부동산노트」 또는 「맞벌이집 내집마련 노트」) → 프롬프트 `[닉네임]` 치환.
- 프로필 사진(상징형), 홈페이지형 블로그(PC 필요)는 발행 안정 후.
- kim_spoon 벤치는 **구조·태도만** 참고. 문장·수치 복제 금지.
