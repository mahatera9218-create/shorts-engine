# 운영자 안내 · 구글 AI 목소리(TTS) 키 넣기 (약 10분, 한 번만)

> **지금은 필요 없어요 (2026-09-30 대표 결정: 목소리 없이 영상만).** 나중에 목소리를 켤 때 이 순서로 하면 돼요.

클립·쇼츠의 AI 목소리를 켜는 작업이에요. 우리 양(한 달 약 3만 자)은 구글 무료 한도(한 달 100만 자) 안이라 **요금이 나오지 않아요.** 다만 구글이 결제 카드를 등록해야 쓸 수 있게 해 둬서, 카드 등록이 한 번 필요해요.

유튜브 API 키를 만들 때 쓴 **같은 구글 계정·같은 프로젝트**에서 하면 돼요. 태블릿 브라우저가 편해요.

## 1. 결제 계정 연결 (카드 등록)
1. console.cloud.google.com 접속 → 위쪽에서 유튜브 키를 만든 프로젝트가 선택돼 있는지 확인
2. 왼쪽 메뉴(≡) → **결제** → **결제 계정 연결** (없으면 **결제 계정 만들기** → 카드 입력)
3. 무료 체험 크레딧 안내가 나오면 그대로 진행해도 돼요

## 2. 목소리 기능 켜기
1. 위쪽 검색창에 **Text-to-Speech** 입력 → **Cloud Text-to-Speech API** → **사용**

## 3. 키 만들기
1. 왼쪽 메뉴 → **API 및 서비스** → **사용자 인증 정보** → **+ 사용자 인증 정보 만들기** → **API 키**
2. 만들어진 키 옆 **수정(연필)** → **API 제한사항**에서 **키 제한** → **Cloud Text-to-Speech API**만 체크 → 저장
3. 키 값 복사

## 4. GitHub에 넣기
1. GitHub 앱 또는 브라우저 → shorts-engine 저장소 → **Settings** → **Secrets and variables** → **Actions**
2. **New repository secret** → 이름 `GOOGLE_TTS_API_KEY` → 값에 키 붙여넣기 → 저장

키는 이 대화창에 붙여넣지 마세요. GitHub Secrets에만 넣어 주시면 돼요.

## (안전장치) 예산 알림
- 결제 → **예산 및 알림** → 예산 만들기 → 금액 **1,000원** → 알림 켜기
- 혹시 무료 한도를 넘는 일이 생기면 메일로 바로 알려 줘요.

## 넣은 뒤
다음 날 아침 자동 글쓰기부터 클립·쇼츠에 목소리가 들어가요. 화면 오른쪽 위에 **AI 음성** 표시가 붙고, 설명란에도 "AI 음성입니다" 한 줄이 붙어요 (네이버 클립 규칙).
