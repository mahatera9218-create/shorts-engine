# 어사이드 자동 루틴 — 경제 (v1, 무인: 키워드 → 임시저장까지)

목표: **대표는 구글 시트에 키워드만 쌓고, 발행 직전에 제목만 고른다.** 나머지(조사·글·사진·임시저장)는 어사이드가 클로드·GPT를 몰아서 무인으로.
안전선: **발행은 절대 자동 안 함.** 임시저장까지만. (v1은 서식·관련링크 없음 — v2에서)

---

## 구글 시트 양식 (키워드 저장소)
스프레드시트 1개, **블로그별 탭**(경제/패션/건강). 경제 탭 칸:

| A 날짜 | B 키워드 | C 상태 | D 제목후보(어사이드가 채움) | E 비고 |
|---|---|---|---|---|
| 2026-10-24 | SK하이닉스 | 대기 | | |
| 2026-10-24 | 금값 | 대기 | | |

- **대표는 A·B만 채운다**(날짜·키워드). C는 `대기`로 시작.
- 어사이드가 한 건 끝낼 때마다 C를 `완료`로, D에 제목 후보 10개를 적어 둔다.
- 대표는 폰에서 **D(제목 후보)**를 보고 하나 골라 네이버에서 발행.

---

## 어사이드 루틴 지시문 (저장해서 반복/예약)

```
[경제 자동 글쓰기 — 임시저장까지. 발행은 절대 누르지 마라. 로그인·보안 화면 나오면 멈추고 알려라.]

1. 구글 시트 '경제' 탭을 연다. C열 상태가 '대기'인 행 중 맨 위 1건의 B열 키워드를 읽는다. (대기가 없으면 "대기 없음"이라 알리고 끝낸다.)

2. 클로드 '경제 글' 탭에 그 키워드를 입력한다. 결과로 [제목 후보] 5줄 + 완성 본문이 나온다. 이어서 '사진'이라고 입력해 [사진 장면] 7줄을 받는다.

3. GPT '경제 사진' 프로젝트에 [사진 장면] 7줄을 붙여넣는다. 1번 그림이 나오면 '다음'을 입력해 2~7번까지 총 7장을 받는다.

4. 경제 블로그 네이버 글쓰기 → 임시저장 화면을 연다.
   - 제목칸: 클로드가 준 [제목 후보] 1번을 임시로 넣는다.
   - 본문: 클로드 본문을 붙여넣고, 본문 안 [사진1]…[사진7] 자리에 사진을 순서대로 넣는다.
   - 본문 맨 위에 "■제목후보" 줄과 함께 [제목 후보] 5개 + (GPT가 준 제목이 있으면 그 5개)를 메모로 적어 둔다. (대표가 발행 때 고르고 지울 메모)
   - 임시저장만 누른다. 발행은 절대 누르지 마라.

5. 구글 시트로 돌아가 그 행 C열을 '완료'로, D열에 제목 후보 전체를 적는다.

6. '대기'가 더 있으면 1번부터 반복, 없으면 "경제 N건 임시저장 완료"라고 알린다.
```

## 예약 (스케줄)
위 루틴을 어사이드에 저장하고, 원하는 시각에 예약한다. (예: 매일 아침 8시 — 증시 글은 밤 발행 실험 중이면 밤 시각으로.) 한 번에 몇 건까지 돌릴지는 시트의 '대기' 수가 정한다.

## 대표가 할 일 (폰, 발행 직전)
1. 네이버 임시저장 열기 → 맨 위 **제목 후보 10개** 중 하나 골라 제목칸에
2. 그 제목 메모 줄 지우기 → 사진·본문 한 번 훑기
3. **발행 버튼** (YMYL·투자 과장 없는지 확인)
