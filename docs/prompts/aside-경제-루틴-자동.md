# 어사이드 새벽 자동 루틴 — 경제

목표: **어사이드가 매일 오늘 6편 키워드를 골라**(큰키워드 3 = 환율·종목·금·거시 중 오늘 개미 관심 이슈 / 부동산 2 = 주요 지역별 대장 단지 구체 이슈 / 정책 1 = 검색 되는 이벤트), 우리 글·제목·사진으로 써서 네이버 임시저장까지. 대표는 **발행 직전 제목만 고르고 발행.**
- ★ **큰키워드 3편의 '오늘 이슈'는 운영총괄(클로드)이 매일 새벽 웹으로 미리 뽑아 파일에 넣어둔다** — 어사이드는 웹 검색을 안 하니(네이버 전용), 그 파일을 **읽기만** 한다. 대표 손 0.

안전선: **발행·로그인 자동화 금지.** 임시저장까지만. 미러 블로그는 **주제·키워드·제목각도·본문각도·후킹만 배우고 제목·문장·사진은 베끼지 않는다(복제 ❌).**

## 프로젝트 위치 (어사이드가 열 곳 — 이름으로 찾아감)
- **글 + 제목:** 클로드 → 프로젝트 탭 **「쿠니 경제」** (제목도 여기서 — **총 12개 + ★추천·☆차선**)
- **본문 사진:** 지피티 → 프로젝트 탭 **「경제 사진」** (생성)
- **썸네일 실물 소스:** 그록 → 프로젝트 탭 **「경제 사진수집」**(`그록-경제-사진수집.md`) — 썸네일(사진1)용 실물 소스 1장 → 지피티 「경제 사진」에서 편집.
- **종목·바이오 조사:** 그록 → 프로젝트 탭 **「경제 조사」** (종목 현재 팩트·날짜)
- **부동산 소재 조사:** 그록 → 프로젝트 탭 **「경제 부동산조사」** (단지 실거래가·사연·호재)
- **이벤트 달력:** 그록 → 프로젝트 탭 **「이벤트달력」** (예정 일정 — 분석창이 주 1회 돌림)
- 각 단계마다 **해당 프로젝트를 먼저 연 뒤** 입력한다(다른 프로젝트에 붙이지 않게 확인).

## A. 오늘 키워드 정하기

### 0. 오늘 '모드' 먼저 확인
**맨 처음**, 구글시트 「쇼츠엔진-경제-로그」의 **「테스트지시」 탭**에서 **오늘 날짜 행**을 본다.
- **키워드 6개가 적혀 있으면 → '테스트날'.** 그 6개를 오늘 6편 키워드로 쓰고 **아래 깔때기는 건너뛴다**(B단계부터 동일). 테마는 대표가 고른 것(증시·금·정책 등 실험).
  - ※ 테스트날도 **그록 조사는 돈다**(현재 팩트 확인 — '파월' 사고 방지). 키워드만 대표 지정일 뿐 글 품질 틀은 똑같다.
- **비어 있으면 → '평소날'(기본).** 아래대로 **큰키워드 3 + 부동산 2 + 정책 1**로 오늘 6편을 뽑는다.

### 평소날 키워드 선정 — 오늘 6편 (C안: 큰키워드 중심 + 부동산 베이스캠프)

**왜 이 배분인가:** 부동산 단지는 파이가 작아 **천장(일조회 ~4천)이 구조적으로 막힌다.** 크게 뛰려면 파이 큰 **큰키워드(환율·종목·금·거시)**에서 뛰어야 한다. 단 큰키워드 파이는 대부분 뉴스·증권사·대형 블로그가 먹고, **우리 몫은 '경제판·구글 문'을 뚫을 때만** 생긴다. 그래서 **부동산 2편으로 바닥(C-Rank·꾸준한 조회)을 깔고** 그 위에서 큰키워드로 등반한다. (2026-11-22 대표 결정 = C안. 북극성 = 일일 조회수 ❌ → **경제판·검색 뚫은 글 수 + 글당 CTR** ✅.)

**배분:**

| 큰키워드 3편 (성장·천장 뚫기) | 부동산 2편 (베이스캠프·바닥) | 정책 1편 (검색 바닥) |
|---|---|---|
| 환율·종목·금·거시 중 **오늘 개미 관심 큰 이슈** | 주요 지역별 대장 단지 1개씩 구체 이슈 | 강사 정책 중 **검색 되는 이벤트** |

**▼ 큰키워드 3편 = 오늘 뜨는 경제 이슈 (운영총괄이 새벽에 웹으로 미리 뽑아둠)**
- **소재 출처 = `공장/데이터/키워드/큰키워드-<오늘날짜>.md`.** 이 파일은 **운영총괄(클로드)이 매일 새벽 웹으로 "오늘 한국 개미·투자자 관심 큰 경제 이슈 3~5개 + 공식 수치"를 뽑아** 채워 둔다. **어사이드는 이 파일을 읽기만** 한다(어사이드는 웹 검색 안 함).
  - 축: **환율·종목(실적·상장·급등)·금·금리·거시 지표.** 예정 이벤트(실적발표·FOMC·상장)는 **그록 「이벤트달력」**(주간)에서 미리, 당일 급변은 운영총괄 웹에서.
  - 파일이 비었거나 못 읽으면: 그날은 **그록 「이벤트달력」의 이번주 임박 이벤트**로 메우고, 그래도 없으면 **부동산으로 대체**(큰키워드 2·부동산 3). 조용히 생략 ❌ — 뭘로 메웠는지 보고.
- **각 좁히기 = 글·제목 프롬프트가 입힌다**(엔화 공식: 큰 주제 → **구체 타깃·생활밀착·개미 심리.** "엔화 830원" → "일본 여행 앞둔 분들만"). 어사이드는 키워드만 넘기면 됨.

**▼ 부동산 2편 = 주요 지역별 '대장 단지 1개'씩 (베이스캠프)**
- 2편 = **서로 다른 2개 지역**, 각 편 = 그 지역 대장 단지 **하나의 구체 이슈**(신고가·급락·심의·분양·규제·호재). **동향·시세훑기 ❌ — '특정 단지 + 특정 사건'** 하나로.
- **지역·제목 규칙(그대로):** 청약·재건축·리모델링 = **메인 지역만**(서울 핵심 구+경기 핵심 시), 단지명 **오픈**. 시세(급등·급락)·기타 = **전국 대도시로 확대**(+인천·부산·대구·광주·대전·울산), '이 아파트' **가림**.
- **고르는 법:** 오늘 이슈단지(`이슈단지-<오늘날짜>.md`)에서 **다른 2개 지역**(한 지역 여러 개 ❌), 각 '오늘 이슈 뜬 단지' 1개. 메인 우선, 2일 중복 제외.

**▼ 정책 1편 = 검색 되는 이벤트만**
- **★ 운영총괄이 새벽에 `큰키워드-<오늘날짜>.md`의 '## 정책 1편 추천'에 안 겹치게 골라 넣어둔다 — 어사이드는 그걸 그대로 쓰면 됨.** (아래는 그게 없을 때의 직접 선정법.)
- **강사 정책 리스트(연금·정년·농지·지원금)가 1순위.** ∩ 이벤트 달력 임박(D-2~3)이면 금상첨화. **검색 수요가 실제 있는 것**(예: 정년연장 65세·국민연금 수령액·감액). **제목 = 검색어 그대로 질문형.**
- ⚠️ **쿠니네 범위 밖(문화누리카드 등 생활 지원·문화 바우처) 집지 말 것.** 강사 정책 섹션에 마땅한 게 없으면 **부동산 1편으로 대체**(그날 부동산 3). **D-2~3 임박 이벤트가 없다고 범위 밖으로 넘어가지 말 것** — 강사 범위 안에서 검색 꾸준한 것(정년연장·국민연금)은 임박 아니어도 바닥용으로 OK.
- 파일(전부 Drive): 이벤트 달력 = `공장/데이터/키워드/이벤트달력-<월요일>.md`, **강사 리스트 = `공장/데이터/키워드/강사-키워드-<이번주>.md`.** (강사 리스트는 운영총괄이 Drive에 올려둠 — repo `docs/keywords/`는 원본.)

**▼ 공통**
- **미러 = 제목 유형 학습**(제목 뽑을 때 쿠니네·skwnstar 결 참고). 키워드는 큰키워드 파일·대장 맵·강사 리스트가 댄다.
- (※ 기존 'A안 부동산 5 전수' 배분은 DECISIONS 2026-11-19 항목 + git 이력에 있음. 큰키워드가 안 먹히면[2~3주 경제판·CTR 측정 후] 부동산 비중을 다시 올린다.)

**[키워드 6개 확정 후] 모든 편 = 키워드 → 그록 조사 → 클로드** (현재 사실을 그록이 확인해 줘야 클로드가 안 틀림 — '파월' 사고 방지).
- **큰키워드(환율·종목·금·거시)** = 그록 **「경제 조사」**(`그록-경제-조사.md`): 오늘 수치·뉴스·날짜 **재확인**(큰키워드 파일 수치가 맞는지 한 번 더). **수치 못 구하면 그 소재 버리고 다음 후보로.**
- **부동산·단지** = 그록 **「경제 부동산조사」**: 단지·전후 실거래가·사연·호재(소재만, 복제 금지). 노출/가림·숫자 후킹은 글·제목 프롬프트가 입힌다.

## B. 생산 (속도: 단계별 묶음 + 멀티탭 병렬)
대화창(탭)을 나눠 왔다갔다 하면 병렬이 된다. **느린 작업(사진)은 여러 탭에서 겹쳐 돌리고, 기다리는 동안 다른 단계를 미리 한다.** 아래 1→2→3으로 묶어 돈다(완전히 순서대로 안 해도 됨 — 맨 아래 '겹쳐 돌리기').

**⚠️ 한 입력 = 한 결과.** 클로드는 '글' 땐 본문만, '제목' 땐 제목만 낸다(섞어 주지 않음). 각 답을 **따로** 받아 둔다(글 = 본문칸 / 제목·해부 = 메모칸).

**⚠️ 부호 정리 (붙여넣기 전).** 제목·본문·캡션에서 `…`·`···`·`•••` → **`...`**, 곧은 따옴표 `'` `"` → 둥근 **`‘ ’` `“ ”`** 로 바꾼다(폰 입력과 같게).

### B-1. 텍스트 6편 '몰아서' 받기 (클로드 「쿠니 경제」 한 곳 — 앱 안 바꿈)
6편 각각, 클로드 「쿠니 경제」에서 **연속으로**:
- **그록 조사 블록 + 키워드**를 넣기 → **본문**(완성 원고)만. (종목·바이오 = 그록 「경제 조사」 블록, 부동산 = 그록 「경제 부동산조사」 블록. 현재 사실은 그록이 확인해 줘야 안 틀림.)
- `제목` → `[제목 후보]` **총 12개 + ★추천·☆차선**. (★ 이번주 `미러-주간-<월요일날짜>.md`가 있으면 **제목 요청에 함께 붙여** → 클로드가 이번주 쿠니네·skwnstar **실제 제목 결**을 반영, 후보에 (쿠니네형)/(여니네형) 태그로 보여줌.)
- `사진` → `[사진 장면]` 7줄.
→ 편별로 {본문 / 제목12 / 장면7}을 **받아 쌓는다**(메모·시트에). **클로드 한 창에서만 → 앱 전환 0, 연속이라 빠름.**

### B-2. 사진 '여러 탭 병렬' (지피티 「경제 사진」 2~3탭) ★제일 큰 효과

**썸네일(사진1)만 특별 처리:**
- **본문 사진(사진2~7) = 지피티 「경제 사진」이 전부 생성** (아래 그대로).
- **썸네일(사진1) = 생성이 아니라 '그록 실물 소스 → 지피티 편집'.** 그록 「경제 사진수집」에서 **메인 키워드 실물 소스 1장**을 받아, 지피티 「경제 사진」에 올려 **편집·처리**(톤·구도·1:1, 간판·건물 유지, 무인). 못 구하면 '미확인' → 대표 판단(정체성 컷은 가짜 생성 대체 금지).
- ※ **패션·가십은 사진 전부 그록 수집**(안정적) — 이 분담은 경제만.

1. 지피티 「경제 사진」을 **탭 2~3개** 연다.
2. 탭A ← 편1 장면 넣고 1번 생성 / 탭B ← 편2 / 탭C ← 편3 (동시에 그려짐).
3. **돌아가며** 각 탭에서 `다음`으로 다음 장을 뽑는다 — **한 탭이 그리는 동안 다른 탭 것 수거.** 편별 7장.
4. 편1~3 끝나면 **비는 탭에 편4·5·6** 이어서. 다 모을 때까지.
   - 각 그림은 **편·번호 라벨**(예: 편3-사진5)로 저장해 섞이지 않게.
   - **★ 편마다 '미리보기'로 사진 확인:** 지피티가 한 장을 **조용히 누락**하면 다음 장이 그 칸으로 밀려 들어가 **4·5번이 같은 그림**이 되기도 한다. 편별로 `[사진1]`~`[사진7]` 자리에 **그 번호 그림이 맞게 들어갔는지 미리보기로 눈으로 확인**(빠지거나 밀리거나 중복이면 그 번호만 다시 생성). 장수 합계 확인만으론 못 잡으니 **편마다** 본다.

**사진 규격·업로드 처리:**
- **규격(지피티가 지킴):** 모든 사진 **1:1 정사각, 800×800 이상**. 이 규격은 바꾸지 않는다.
- **업로드 전 처리(용량만 줄임):** 지피티 PNG가 크면(2~3MB) 네이버 업로드가 멈추거나 에디터가 꺼진다. 올리기 전 **JPEG(품질 88)로 변환** + **1:1 정사각 유지, 한 변 1024px**로 맞춘다(800↑이라 규격 충족 + 용량↓). **크기를 줄이는 게 목적이 아니라 용량 문제를 피하려는 것.**
- 사진이 정사각형이 아니면 **가운데 기준 1:1 크롭**(지피티가 1:1로 뽑으면 크롭 불필요).
- ※ 이 수치(1024px·품질88)는 용량 안정 기준. 규격(1:1·800↑)과 충돌 아님. 임의로 다른 값 쓰지 말 것.

**에디터 작업 노하우:**
- **제목 후보의 ★추천·☆차선 표시는 지운다** — 제목칸에 넣기 전에 `★`·`☆` 뗀다.
- **「작성 중인 글이 있습니다」 창은 '취소'로 닫는다**(이어쓰기 아님 — 새 글로).
- **표가 2개 이상일 때는 대상 표 안의 버튼만** 누른다(다른 표 건드리지 않게).
- **한 편은 한 에디터에서 끝까지** 만들고 **마지막에만 임시저장**(중간 저장·이동 반복 금지).
- (※ 새 노하우가 생기면 어사이드 자기 프롬프트 말고 **이 MD에 추가**해서 한 곳에서 관리.)

### B-3. 네이버 조립·임시저장 (6편)
각 편마다 경제 블로그 글쓰기 → **임시저장**:
- 제목칸: `제목` 후보 1번 임시.
- **본문칸: '글' 답 그대로** 붙이고, `[사진N]` **라벨 줄만** 그 사진으로 바꾼다. ★ **조립 규칙은 `docs/prompts/조립-규칙-공통.md`를 그대로 따른다** — 핵심: 순서=대표사진→인용구 소제목→글(반복), **캡션 없음**, **AI 체크버튼 안 누름**(업로드 창에 켜져 있으면 끈다), 단락 빈 줄, 서식키.
- **★ 단락 빈 줄 유지:** 붙여넣은 뒤 **3~4문장마다 빈 줄 한 줄**이 들어가 단락이 나뉘어 있는지 확인. 뭉쳐 있으면 **3~4문장 단위로 엔터**를 넣어 띄운다.
- **★ 표는 반드시 네이버 표로 바꾼다(아래 B-5) — 글마다 1개. 빼먹지 말 것(자주 놓침).** `|` 격자를 글자인 채로 두거나 지워 버리면 안 된다.
- 맨 위 메모칸: "■제목후보"(12개, ★추천·☆ 포함). (메모는 본문에 넣지 않음.)
- **함께 보면 좋은 글(아래 B-4) → 본문 끝 참조문헌과 해시태그 '사이'에 삽입.**
- 서식(아래) → **임시저장만. 발행 절대 금지.**
- **구글시트 한 줄 기록**(아래).

### B-4. 함께 보면 좋은 글 (내 과거 글 링크)
- 초안을 쓴 뒤, **내 경제 블로그에서 '같은 키워드'로 최근 발행한 내 글**을 찾는다(블로그 내 검색).
- **최소 2개·최대 3개.** 1순위 = **같은 키워드** 최근 글. 2개가 안 되면 **최근 발행 글 중 키워드 비슷한 것**으로 2~3개 채움. 그래도 모자라면 있는 만큼 넣고 로그에 남김(글 쌓이면 자연히 채워짐). 억지 무관 연결 금지.
- 삽입 위치 = **본문 맨 끝 `참조문헌` 줄과 `해시태그` 사이.** "함께 보면 좋은 글" 한 줄 적고 아래에 링크.
- 링크 넣는 법(썸네일 카드로):
  - 그 과거 글에서 네이버 **'URL 복사'(공유 → 주소 복사)**로 링크를 딴다.
  - 새 글 본문 그 자리에 **붙여넣는다** → 잠시 뒤 **썸네일 카드(링크 미리보기)**가 뜬다. **★ URL은 반드시 복사→붙여넣기. 절대 손으로 타이핑하지 말 것**(타이핑하면 글자 빠짐: `eokonomy`→`okonomy`).
  - **카드가 뜨면, 남아 있는 '생 URL 텍스트'는 지운다**(카드만 남게). 카드가 안 뜨면 URL을 잘라내 다시 붙여 카드가 뜨게 한다.
  - 2개면 카드 2개를 세로로.
- ※ 자기 글만(타 블로그 링크 금지). **같은 키워드 글이 없으면 이 섹션 통째 생략**(무관한 글을 억지로 넣지 말 것 — 없으면 0개가 맞다).

### B-5. 표 넣기 (★자주 빠뜨림 — 글마다 꼭 1개)
네이버는 `| 구분 | 값 |` 격자를 붙여넣어도 **표로 안 바뀐다**(작대기 글자로 남음). **손으로 네이버 표를 만들어 값을 옮겨 적는다.** 편마다 반드시 확인.
1. 본문에서 `[표: …]` 표시 줄과 그 아래 `| … | … |` 격자를 찾는다(클로드가 글마다 1개 심어 둠).
2. 격자의 **줄 수·칸 수**(보통 2칸 × 몇 줄)를 센다. 커서를 그 자리에 두고 네이버 **'표' 버튼**으로 **그 크기(칸×줄) 표**를 만든다.
3. 격자의 각 칸 값을 **네이버 표의 해당 칸에 하나씩 쳐 넣는다**(헤더 줄부터 순서대로). `|`·`---` 기호는 옮기지 않는다.
4. 다 옮기면 **`[표: …]` 표시 줄과 원래 `| … |` 격자 글자를 전부 지운다**(작대기 글자 남으면 안 됨).
5. **마지막 확인: 본문에 `|` 작대기가 한 개도 안 남았는지 본다.** 남아 있으면 아직 표로 안 바뀐 것 → 1번부터 다시.
   - ※ 표 값이 애매하거나 칸이 안 맞으면 억지로 말고, 그 표만 **'항목: 값' 글자 줄**로 풀어 적고 격자는 지운다(표 0개보다 나음). 단 기본은 네이버 표.

### 겹쳐 돌리기 (비는 시간 메우기)
1→2→3을 꼭 차례로 안 해도 된다:
- **B-1에서 한 편 장면이 나오는 즉시** → 그 편 사진을 지피티 탭에 던져 B-2 시작, 클로드는 **다음 편 텍스트** 계속.
- **B-2 사진이 그려지는 동안** → 먼저 끝난 편을 **네이버 조립(B-3)** 미리.
→ 어사이드가 "기다리는 시간"을 다른 탭 일로 메운다.

### 서식 (단축키 — '네이버 블로그 파워 단축키' 확장)
확장에 **Alt+2는 안 먹혀** Alt+1,3,4,5,6에 배정. 버튼 클릭보다 빠르고 안 깨짐.
**키 배정: Alt+1=볼드 / Alt+3=인용구(소제목) / Alt+4=글자크게 / Alt+5=구분선 / Alt+6=가운데정렬.** (Alt+2 미사용.)
- **강조(볼드):** 본문에서 **`**...**`로 감싼 글자** 선택 → **Alt+1** → `**` 기호 지움. (중요 수치·결론만, 대여섯 개 이내.)
- **소제목:** 각 소제목 줄 선택 → **Alt+3**(+원하면 Alt+4 글자크게).
- **표:** 위 **B-5**대로 네이버 표로 손수 옮기고 격자·`[표: …]` 글자는 지움(글마다 1개, 꼭).
- **구분선:** `---`만 있는 줄 → **Alt+5** → `---` 삭제. (글마다 1~2개.) ※ 확장에 구분선 기능 없으면 에디터 '구분선' 버튼.
- **정렬:** 전체선택(Ctrl+A) → **Alt+6(가운데 정렬)**. (빼려면 이 줄 삭제.) ※ 확장에 정렬 기능 없으면 생략.
- ※ 대표가 키를 바꾸면 그 키로 교체.

## 구글시트 기록
시트: **「쇼츠엔진-경제-로그」**의 **`경제로그`** 탭. 글 한 편마다 **맨 아래 빈 줄에 한 행** 추가(A열부터 Tab):

| A 날짜 | B 테마 | C 키워드 | D 검색량 | E 글수 | F 제목후보(12개) | G 선택제목 | H 임시저장 | I 모드 |
|---|---|---|---|---|---|---|---|---|
| 2026-11-01 | 바이오 | 펩트론 | 8,500 | 1,200 | 후보 12개를 줄바꿈(Alt+Enter)으로 | *비움 — 대표가 발행 때 채움* | ✓ | 평소날 |

- **I 모드:** 그 편이 **평소날**(자동)인지 **테스트날**(대표 지정 키워드)인지 적는다. → 2주 뒤 부검에서 **테스트날 글 성과를 평소날과 비교**하는 핵심 칸.
- 테스트날은 **D 검색량·E 글수를 비워도 됨**(틈새표 선정이 아니므로). C 키워드는 대표가 준 것 그대로.
- **B·C·D·E = 틈새표에서 그대로**(테마·키워드·검색량·글수). → 나중 부검에서 '어느 (검색량·글수) 구역이 먹혔나(우리 띠)'를 이 데이터로 찾는다. F = 제목 후보 12개를 한 칸에 줄바꿈으로.
- **G(선택제목)은 비워 둔다** — 대표가 발행하며 고른 제목을 나중에 적는다(어느 훅이 먹히는지 데이터).
- **★ 시트 헤더 확인:** 헤더가 옛 형식이거나 **I열 '모드' 제목이 없으면** 위 표 기준으로 맞추고, 못 고치면 대표에게 보고. 값은 항상 **A~I 순서**대로.
- 시트 쓰기가 불안하면(칸 밀림 등) 억지로 말고, 그 행은 **비고에 "수기확인"**만 남기고 넘어간다(임시저장이 먼저).

## 미러·참고 블로거 (베끼기 ❌, 결·구조·후킹만)
- **집중 미러 2 = 쿠니네(zkfldb888)·skwnstar** → 오늘 키워드·주제·제목각도·본문각도·후킹을 **깊게** 본다. **결·구조만** 배워 우리 글에 녹인다.
- **나머지(8starstarstar8·ranto28 등) = 후킹 문구만** 쌓는다(라이브러리). 요즘 뭐가 뜨나 '방향'은 참고하되 키워드를 그대로 쓰진 않는다.
- **주제·제목·문장·사진은 베끼지 않는다.** 미러 키워드도 **경쟁강도로 거르고**(큰 블로그와 정면 경쟁 회피 — 검색은 1등만 먹음), 글은 우리가 새로 쓴다.
