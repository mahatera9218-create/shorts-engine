# 어사이드 새벽 자동 루틴 — 경제 (틈새 키워드 방식, 2026-11-01 — '유미 미러'에서 전환)

목표: **어사이드가 매일 틈새표(검색 많고 글 적은 키워드)에서 오늘 5편을 골라**, 우리 글·제목·사진으로 써서 네이버 임시저장까지. 대표는 **발행 직전 제목만 고르고 발행.**
안전선: **발행·로그인 자동화 금지.** 임시저장까지만. 유미는 **방향 참고만**(제목·문장·사진 베끼기 ❌).

## 프로젝트 위치 (어사이드가 열 곳 — 이름으로 찾아감)
- **글 + 제목:** 클로드 → 프로젝트 탭 **「쿠니 경제」** (제목도 여기서 5개, 2026-10-23 B)
- **사진:** 지피티 → 프로젝트 탭 **「경제 사진」**
- **바이오 조사:** 그록 → 프로젝트 탭 **「경제 조사」** (종목 현재 팩트·날짜)
- **부동산 소재 조사:** 그록 → 프로젝트 탭 **「경제 부동산조사」** (재건축 단지 실거래가·사연)
- (지피티 「경제 제목」은 일상 루틴에서 뺌 — 수동으로 더 뽑고 싶을 때만.)
- 각 단계마다 **해당 프로젝트를 먼저 연 뒤** 입력한다(다른 프로젝트에 붙이지 않게 확인).

## A. 오늘 키워드 정하기 (틈새 방식 — 2026-11-01 대표, '유미 미러'에서 전환)
1. **틈새표를 연다.** 깃헙 저장소 `shorts-engine` → **`niche-results` 브랜치 → `reports/검색량/`** 폴더. 오늘 날짜 `틈새-<오늘날짜>.md`가 있으면 그걸, **없으면 폴더에서 날짜가 가장 최근인 틈새 파일**을 연다.
   - ★★ **오늘 파일이 없다고 절대 멈추지 말 것.** 틈새 점수는 하루 이틀 사이 거의 안 변하니 **가장 최신 파일(보통 어제 것)로 그대로 진행**한다. 마무리 보고 때 "오늘 틈새표가 없어 N월N일 표로 진행함" 한 줄만 덧붙이면 된다. (엔진이 새벽 4시 예약이지만 깃헙 사정으로 가끔 늦거나 걸러짐 → **최신 표로 진행이 정상 대응**이지 오류가 아니다. '못 했다'고 멈추지 말 것.)
   - 테마별(부동산·바이오)로 '검색 많고 글 적은(틈새 높은)' 키워드 순위가 있다.
2. **오늘 5편**을 비중대로 고른다(대표: 1일 5포). **부동산(재건축/선도지구) 3 · 바이오 2** (연금·금 제외, 2026-11-02 효율분석) — 비중은 대표·부검으로 조정.
   - 각 테마에서 **틈새 상위 + 아직 안 쓴 것**으로 고른다(구글시트 발행 로그와 겹치면 건너뜀).
   - 부동산 = **재건축/선도지구** 중심, 바이오 = **저경쟁 종목**(씨앗 기준).
3. **모든 편 = 틈새 키워드 → 그록 조사 → 클로드** (현재 사실을 그록이 확인해 줘야 클로드가 안 틀림 — '파월' 사고 방지).
   - **바이오** = 그록 **「경제 조사」**(prompts/project/그록-경제-조사.md): 종목의 **지금 팩트·뉴스·수치 + 날짜**.
   - **부동산** = 그록 **「경제 부동산조사」**: 재건축 키워드로 **단지·전후 실거래가·사연·호재**(소재만, 복제 금지). '단지명 가림 + 전후 숫자' 후킹은 글·제목 프롬프트가 입힌다.
4. **유미는 '방향 참고'만** (RSS `https://rss.blog.naver.com/8starstarstar8.xml`) — 요즘 뭐가 뜨나·말투만 보고 **주제·갯수를 베끼지 않는다**(미러 방식 폐기). 틈새표엔 없는데 유미가 크게 민 화제가 있으면 후보로만 메모.

## ★ 속도: 단계별 묶음 + 멀티탭 병렬 (2026-10-23 대표 — 내용 그대로, 빨리)
대화창(탭)을 나눠 왔다갔다 하면 병렬이 된다(대표 확인). **느린 작업(사진)은 여러 탭에서 겹쳐 돌리고, 기다리는 동안 다른 단계를 미리 한다.** 아래 1→2→3단계로 묶어 돈다(완전히 순서대로 안 해도 됨 — 맨 아래 '겹쳐 돌리기').

**⚠️ 한 입력 = 한 결과.** 클로드는 '글' 땐 본문만, '제목' 땐 제목만 낸다(섞어 주지 않음). 각 답을 **따로** 받아 둔다(글 = 본문칸 / 제목·해부 = 메모칸).

**⚠️ 부호 정리 (붙여넣기 전).** 제목·본문·캡션에서 `…`·`···`·`•••` → **`...`**, 곧은 따옴표 `'` `"` → 둥근 **`‘ ’` `“ ”`** 로 바꾼다(폰 입력과 같게).

## B-1단계. 텍스트 5편 '몰아서' 받기 (클로드 「쿠니 경제」 한 곳 — 앱 안 바꿈)
5주제 각각, 클로드 「쿠니 경제」에서 **연속으로**:
4. **그록 조사 블록 + 키워드**를 넣기 → **본문**(완성 원고)만. (바이오 = 그록 「경제 조사」 블록, 부동산 = 그록 「경제 부동산조사」 블록. 미러 글 전문 붙여넣기 폐기. 현재 사실은 그록이 확인해 줘야 안 틀림.)
5. `제목` → `[제목 후보]` 5개.
6. `사진` → `[사진 장면]` 7줄.
→ 편별로 {본문 / 제목5 / 장면7}을 **받아 쌓는다**(메모·시트에). **클로드 한 창에서만 → 앱 전환 0, 연속이라 빠름.**

## B-2단계. 사진 '여러 탭 병렬' (지피티 「경제 사진」 2~3탭) ★제일 큰 효과
8. 지피티 「경제 사진」을 **탭 2~3개** 연다.
9. 탭A ← 편1 장면 넣고 1번 생성 / 탭B ← 편2 / 탭C ← 편3 (동시에 그려짐).
10. **돌아가며** 각 탭에서 `다음`으로 다음 장을 뽑는다 — **한 탭이 그리는 동안 다른 탭 것 수거.** 편별 7장.
11. 편1~3 끝나면 **비는 탭에 편4·5** 이어서. 35장 다 모을 때까지.
    - 각 그림은 **편·번호 라벨**(예: 편3-사진5)로 저장해 섞이지 않게.

### ★ 사진 규격·업로드 처리 (2026-10-26 대표 — 어사이드 임의 처리 방지)
- **규격(지피티가 지킴):** 모든 사진 **1:1 정사각, 800×800 이상**(지피티 「경제 사진」 프롬프트 기준). 이 규격은 바꾸지 않는다.
- **업로드 전 처리(용량만 줄임):** 지피티 PNG가 크면(2~3MB) 네이버 업로드가 멈추거나 에디터가 꺼진다. 그래서 올리기 전 **JPEG(품질 88)로 변환**하고 **1:1 정사각 유지, 한 변 1024px**로 맞춘다(800 이상이라 규격 충족 + 용량↓). **크기를 줄이는 게 목적이 아니라 용량 문제를 피하려는 것.**
- 사진이 정사각형이 아니면 **가운데 기준 1:1 크롭**(지피티가 1:1로 뽑으면 크롭 불필요).
- ※ 이 수치(1024px·품질88)는 용량 안정 기준. 규격(1:1·800↑)과 충돌하지 않는다. 임의로 다른 값 쓰지 말 것.

### 에디터 작업 노하우 (2026-10-26 — 실행에서 얻음, 여기서 관리)
- **제목 후보의 ★ 표시는 지운다** — 클로드가 1순위에 붙인 `★`는 제목칸에 넣기 전에 뗀다.
- **「작성 중인 글이 있습니다」 창은 '취소'로 닫는다**(이어쓰기 아님 — 새 글로).
- **표가 2개 이상일 때는 대상 표 안의 버튼만** 누른다(다른 표 건드리지 않게).
- **한 편은 한 에디터에서 끝까지** 만들고 **마지막에만 임시저장**(중간에 저장·이동 반복 금지).
- (※ 새 노하우가 생기면 어사이드 자기 프롬프트 말고 **이 MD에 추가**해서 한 곳에서 관리.)

## B-3단계. 네이버 조립·임시저장 (5편)
12. 각 편마다 경제 블로그 글쓰기 → **임시저장**:
   - 제목칸: `제목` 후보 1번 임시.
   - **본문칸: '글' 답 그대로** 붙이고, `[사진N]` **라벨 줄만** 그 사진으로 바꾼다. **사진 밑 캡션(설명 글)은 넣지 않는다**(2026-11-01 대표 — 안 다는 것으로 통일). 배치 순서 = **사진 → 소제목(인용구) → 글**(클로드 글이 그 순서로 옴).
   - **★ 단락 빈 줄 유지 (2026-10-27 대표 — 안 먹힘):** 붙여넣은 뒤 **3~4문장마다 빈 줄 한 줄**이 들어가 단락이 나뉘어 있는지 확인. 붙이기에서 빈 줄이 사라져 뭉쳐 있으면 **3~4문장 단위로 엔터를 넣어** 띄운다.
   - **★ 표는 반드시 네이버 표로 바꾼다(아래 B-5) — 글마다 1개. 빼먹지 말 것(자주 놓침).** `|` 격자를 글자인 채로 두거나 지워 버리면 안 된다.
   - 맨 위 메모칸: "■제목후보" 5개 + "■미러해부" 3줄. (메모·해부는 본문에 넣지 않음.)
   - **함께 보면 좋은 글(아래 B-4) → 본문 끝 참조문헌과 해시태그 '사이'에 삽입.**
   - 서식(아래) → **임시저장만. 발행 절대 금지.**
   - **구글시트 한 줄 기록**(아래).

## B-4. 함께 보면 좋은 글 (내 과거 글 링크, 2026-10-25 대표 — 10-18 '관련글 안 넣음' 철회)
13. 초안을 쓴 뒤, **내 경제 블로그에서 '같은 키워드'로 최근 발행한 내 글**을 찾는다(블로그 내 검색).
   - **최대 2개**(관련·최신 우선). 없으면 **1개 또는 0개**(억지로 안 채움).
14. 삽입 위치 = **본문 맨 끝 `참조문헌` 줄과 `해시태그` 사이.** 그 자리에 한 줄 "함께 보면 좋은 글" 적고, 아래에 링크를 붙인다.
15. 링크 넣는 법(썸네일 카드로):
   - 그 과거 글에서 네이버 **'URL 복사'(공유 → 주소 복사)**로 링크를 딴다.
   - 새 글 본문 그 자리에 **붙여넣는다** → 잠시 뒤 **썸네일 카드(링크 미리보기)**가 뜬다.
   - **카드가 뜨면, 남아 있는 '생 URL 텍스트'는 지운다**(카드만 남게). 카드가 안 뜨면 URL을 잘라내 다시 붙여넣어 카드가 뜨게 한다.
   - 2개면 카드 2개를 세로로.
   - ※ 자기 글만(타 블로그 링크 금지). 같은 키워드 글이 없으면 이 섹션 통째 생략.

## B-5. 표 넣기 (★자주 빠뜨림 — 글마다 꼭 1개, 2026-10-25 대표: "초안에 표가 없더라")
네이버는 `| 구분 | 값 |` 격자를 붙여넣어도 **표로 안 바뀐다**(그냥 작대기 글자로 남음). 그러니 **손으로 네이버 표를 만들어 값을 옮겨 적는다.** 빼먹기 쉬우니 **편마다 반드시 확인.**
16. 본문에서 `[표: …]` 표시 줄과 그 아래 `| … | … |` 격자를 찾는다(클로드가 글마다 1개 심어 둠).
17. 격자의 **줄 수·칸 수**(보통 2칸 × 몇 줄)를 센다. 커서를 그 자리에 두고 네이버 에디터 **'표' 버튼**으로 **그 크기(칸×줄) 표**를 만든다.
18. 격자의 각 칸 값을 **네이버 표의 해당 칸에 하나씩 쳐 넣는다**(헤더 줄 `| 구분 | 값 |`부터 순서대로). `|`·`---` 같은 격자 기호는 옮기지 않는다.
19. 다 옮기면 **`[표: …]` 표시 줄과 원래 `| … |` 격자 글자를 전부 지운다**(본문에 작대기 글자가 남으면 안 됨).
20. **마지막 확인: 본문에 `|` 작대기 글자가 한 개도 안 남았는지 본다.** 남아 있으면 아직 표로 안 바뀐 것 → 16번부터 다시.
   - ※ 표 값이 애매하거나 칸이 안 맞으면 억지로 말고, 그 표만 **'항목: 값' 글자 줄**로 풀어 적고 격자는 지운다(표 0개보다 나음). 단 기본은 네이버 표.

## ★ 겹쳐 돌리기 (방안3 — 비는 시간 메우기)
1→2→3을 꼭 차례로 안 해도 된다. 겹치면 더 빠름:
- **1단계에서 한 편 장면이 나오는 즉시** → 그 편 사진을 지피티 탭에 던져 2단계 시작, 클로드는 **다음 편 텍스트** 계속.
- **2단계 사진이 그려지는 동안** → 먼저 끝난 편을 **네이버 조립(3단계)** 미리.
→ 어사이드가 "기다리는 시간"을 다른 탭 일로 메운다.

## 서식 (단축키 버전 — '네이버 블로그 파워 단축키' 확장, 대표 지정 키 2026-10-25 확정)
확장에 **Alt+2는 안 먹혀서** Alt+1,3,4,5,6에 배정했다(대표 확정). 버튼 클릭보다 빠르고 안 깨짐.
**키 배정: Alt+1=볼드 / Alt+3=인용구(소제목) / Alt+4=글자크게 / Alt+5=구분선 / Alt+6=가운데정렬.** (Alt+2 미사용.)
   - **강조(볼드):** 본문에서 **`**...**`로 감싼 글자**를 선택 → **Alt+1(볼드)** → `**` 기호는 지운다. (중요 수치·결론만, 대여섯 개 이내.)
   - **소제목:** 각 소제목 줄 선택 → **Alt+3(인용구)** (+원하면 Alt+4 글자크게).
   - **표:** 위 **B-5**대로 네이버 표로 손수 옮기고 격자·`[표: …]` 글자는 지운다(글마다 1개, 자주 빠뜨리니 꼭).
   - **구분선:** `---`만 있는 줄 → **Alt+5(구분선)** → `---` 삭제. (글마다 1~2개.) ※ 확장에 구분선 기능이 없어 Alt+5 지정을 못 했으면 에디터 '구분선' 버튼으로.
   - **정렬:** 전체선택(Ctrl+A) → **Alt+6(가운데 정렬)**. (빼려면 이 줄 삭제.) ※ 확장에 정렬 기능이 없으면 이 단계 생략.
   - ※ 대표가 키를 다시 바꾸면 그 키로 교체.

## 구글시트 기록 (제목 후보 + 유미 분석 데이터)
시트: **「쇼츠엔진-경제-로그」** 의 **`경제로그`** 탭. 글 한 편마다 **맨 아래 빈 줄에 한 행** 추가(A열부터 Tab):

| A 날짜 | B 테마 | C 키워드 | D 검색량 | E 글수 | F 제목후보(5개) | G 선택제목 | H 임시저장 |
|---|---|---|---|---|---|---|---|
| 2026-11-01 | 바이오 | 펩트론 | 8,500 | 1,200 | 후보 5개를 줄바꿈(Alt+Enter)으로 | *비움 — 대표가 발행 때 채움* | ✓ |

- **B·C·D·E = 틈새표에서 그대로** (테마·키워드·검색량·글수). → 나중 부검에서 '어느 (검색량·글수) 구역이 실제로 먹혔나(우리 띠)'를 이 데이터로 찾는다. F = 제목 후보 5개(클로드)를 한 칸에 줄바꿈으로.
- **G(선택제목)은 비워 둔다** — 대표가 발행하며 고른 제목을 나중에 적는다(어느 훅이 먹히는지 데이터).
- 시트 쓰기가 불안하면(칸 밀림 등) 억지로 말고, 그 행은 **비고에 "수기확인"**만 남기고 넘어간다(임시저장이 먼저).

## C. 마무리
21. 다 끝나면 **"오늘 5편 임시저장 완료 + 시트 5행 기록"**과 키워드 목록을 보고한다. **이때 '표 5편 다 넣음'도 함께 확인·보고**(표 누락 방지).

## 대표 (아침, 폰)
각 임시저장 글 → 제목 후보 중 하나 골라 제목칸에 + 메모 지우기 → 사진·본문 훑기 → **발행(띄엄띄엄).** 고른 제목은 시트 **G열(선택제목)**에 적어 둔다(나중에 '어떤 제목이 조회수 잘 나왔나' 분석용).

## 유미 방향 참고 (베끼기 ❌, 나침반만)
- 유미(8starstarstar8)는 돈 되는 쪽으로 빨리 움직이는 프로 → **요즘 뭐가 뜨나·말투·제목 결의 '방향'만** 본다.
- **주제·갯수·제목·문장·사진은 베끼지 않는다.** 키워드는 틈새표에서 잡는다(A단계). 유미 키워드를 그대로 쓰면 큰 블로그와 정면 경쟁이라 작은 우리가 밀린다(검색은 1등만 먹음).
