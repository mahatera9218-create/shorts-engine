# 어사이드 새벽 자동 루틴 — 경제 (유미 미러 방식)

목표: **새벽에 어사이드가 유미(1등)가 어제 쓴 주제·갯수를 그대로 따라 오늘 배치를 정하고**, 우리 글·제목·사진으로 써서 네이버 임시저장까지. 대표는 **발행 직전 제목만 고르고 발행.**
안전선: **발행·로그인 자동화 금지.** 임시저장까지만. 유미 **제목·문장·사진은 베끼지 않는다**(주제·갯수만 따라감 = 추세 추종).

## 프로젝트 위치 (어사이드가 열 곳 — 이름으로 찾아감)
- **글:** 클로드 → 프로젝트 탭 **「쿠니 경제」**
- **제목:** 지피티 → 프로젝트 탭 **「경제 제목」**
- **사진:** 지피티 → 프로젝트 탭 **「경제 사진」**
- 각 단계마다 **해당 프로젝트를 먼저 연 뒤** 입력한다(다른 프로젝트에 붙이지 않게 확인).

---

## A. 오늘 배치 정하기 (유미 미러)
1. 유미 블로그 RSS `https://rss.blog.naver.com/8starstarstar8.xml` (또는 블로그)를 연다. **전날 18:00 ~ 오늘 새벽**에 유미가 발행한 글을 모두 본다(보통 6편).
2. 제목만 보지 말고 **각 글을 열어 '글 전문'을 읽는다.** 오늘 쓸 **주제 목록 + 갯수**(보통 6)를 정한다. **여기에 부동산 1개 추가** — 틈새표(reports/검색량/) 부동산 1위 중 최근 안 쓴 것, 또는 config/niche_keywords.yaml 부동산 씨앗. → **오늘 총 7편.**

## B. 한 편씩 생성 (목록의 각 글마다 반복)
**⚠️ 한 입력 = 한 결과.** 클로드는 '글' 땐 본문만, '제목' 땐 제목만 낸다(섞어 주지 않음). 어사이드는 각 답을 **따로** 받아 둔다(글 답 = 네이버 본문에 붙임 / 제목·해부 답 = 메모칸에).

4. **클로드 프로젝트 「쿠니 경제」를 열고**, 그 글 '전문'을 통째로 붙여넣는다(제목 한 단어가 아니라 본문 전체 — 미러 입력). → 클로드가 **본문(완성 원고)만** 낸다. 이게 네이버에 붙일 글이다.
   - (유미 글이 없거나 따로 정한 주제면, 그 주제를 **키워드 한 줄**로만 입력해도 됨.)
5. **제목** — 두 군데서 받아 합친다(총 10개, 대표가 발행 때 고름):
   - 클로드 「쿠니 경제」에 **`제목`** 입력 → `[제목 후보]` 5개.
   - 지피티 프로젝트 **「경제 제목」**을 열고 **본문을 붙여넣기** → 5개 더.
   - 두 묶음을 메모칸용으로 따로 모아 둔다.
6. (선택) 클로드 「쿠니 경제」에 **`해부`** 입력 → `[미러 해부]` 3줄만 나온다(소재/각도/핵심키워드, 참고 메모용).
7. 클로드 「쿠니 경제」에 **`사진`** 입력 → `[사진 장면]` 7줄. → 지피티 프로젝트 **「경제 사진」**을 열고 붙여넣기 → 1장 나오면 `다음`을 6번 → 7장.
8. 경제 블로그 네이버 글쓰기 → **임시저장** 화면:
   - 제목칸: `제목` 후보 1번 임시로.
   - **본문칸: 4번 '글' 답을 그대로 붙여넣는다**(제목·해부 섞지 말 것). `[사진1]…[사진7]` 자리에 사진 순서대로.
   - 본문 맨 위 메모칸에 "■제목후보" 5개(대표가 발행 때 고르고 지움) + (있으면)"■미러해부" 3줄. **이 메모는 본문이 아니라 맨 위 메모 영역에만. `[미러 해부]`·제목후보는 본문에 절대 넣지 않는다.**
   - **임시저장만. 발행 절대 금지.**

## B-2. 서식 (대표 2026-10-23 "다 해" — ⚠️ 에디터 UI 조작이라 깨지기 쉬움, 처음엔 한 편으로 검증 후 켤 것)
   - **표:** 본문에 `| 구분 | 값 |` 격자가 있으면 → 네이버 **표 기능**으로 옮겨 넣는다.
   - **소제목:** 각 소제목 줄을 **인용 버튼** 서식 + **볼드**.
   - **정렬:** 글 전체 선택(Ctrl+A) → **가운데 정렬**. (※ 본문 가독성은 왼쪽정렬이 낫다는 의견 있음 — 대표 지정이라 적용. 바꾸고 싶으면 이 줄만 빼면 됨.)

## C. 마무리
9. 다 끝나면 **"오늘 N+1편 임시저장 완료"**와 주제 목록을 보고한다.

## 예약
이 루틴을 어사이드에 저장하고 **새벽 시각(예: 05:30~06:30)**에 예약. 유미가 밤에 다 올린 뒤라 그날 물량을 다 잡는다.

## 대표 (아침, 폰)
각 임시저장 글 → 제목 후보 중 하나 골라 제목칸에 + 메모 지우기 → 사진·본문 훑기 → **발행(띄엄띄엄).**

## 분류 참고 (유미 RSS 카테고리)
- `[투자]` = 증시(개별종목·테마·전략) · `[소식]` = 금·연금·정책 등 · `[청약]` = 부동산.
- 우리는 유미가 안 하는 **부동산 1개를 늘** 더한다(유미가 청약을 쓴 날은 부동산이 2개가 되어도 OK).
