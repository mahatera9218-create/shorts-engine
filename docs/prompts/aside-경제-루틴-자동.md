# 어사이드 새벽 자동 루틴 — 경제 (유미 미러 방식)

목표: **새벽에 어사이드가 유미(1등)가 어제 쓴 주제·갯수를 그대로 따라 오늘 배치를 정하고**, 우리 글·제목·사진으로 써서 네이버 임시저장까지. 대표는 **발행 직전 제목만 고르고 발행.**
안전선: **발행·로그인 자동화 금지.** 임시저장까지만. 유미 **제목·문장·사진은 베끼지 않는다**(주제·갯수만 따라감 = 추세 추종).

## 프로젝트 위치 (어사이드가 열 곳 — 이름으로 찾아감)
- **글 + 제목:** 클로드 → 프로젝트 탭 **「쿠니 경제」** (제목도 여기서 5개, 2026-10-23 B)
- **사진:** 지피티 → 프로젝트 탭 **「경제 사진」**
- (지피티 「경제 제목」은 일상 루틴에서 뺌 — 수동으로 더 뽑고 싶을 때만.)
- 각 단계마다 **해당 프로젝트를 먼저 연 뒤** 입력한다(다른 프로젝트에 붙이지 않게 확인).

---

## A. 오늘 배치 정하기 (유미 미러)
1. 유미 블로그 RSS `https://rss.blog.naver.com/8starstarstar8.xml` (또는 블로그)를 연다. **전날 18:00 ~ 오늘 새벽**에 유미가 발행한 글을 모두 본다(보통 6편).
2. 제목만 보지 말고 **각 글을 열어 '글 전문'을 읽는다.** 오늘 쓸 **주제 목록 + 갯수**(보통 6)를 정한다. **여기에 부동산 1개 추가** — 틈새표(reports/검색량/) 부동산 1위 중 최근 안 쓴 것, 또는 config/niche_keywords.yaml 부동산 씨앗. → **오늘 총 7편.**

## ★ 속도: 단계별 묶음 + 멀티탭 병렬 (2026-10-23 대표 — 내용 그대로, 빨리)
대화창(탭)을 나눠 왔다갔다 하면 병렬이 된다(대표 확인). **느린 작업(사진)은 여러 탭에서 겹쳐 돌리고, 기다리는 동안 다른 단계를 미리 한다.** 아래 1→2→3단계로 묶어 돈다(완전히 순서대로 안 해도 됨 — 맨 아래 '겹쳐 돌리기').

**⚠️ 한 입력 = 한 결과.** 클로드는 '글' 땐 본문만, '제목' 땐 제목만 낸다(섞어 주지 않음). 각 답을 **따로** 받아 둔다(글 = 본문칸 / 제목·해부 = 메모칸).

**⚠️ 부호 정리 (붙여넣기 전).** 제목·본문·캡션에서 `…`·`···`·`•••` → **`...`**, 곧은 따옴표 `'` `"` → 둥근 **`‘ ’` `“ ”`** 로 바꾼다(폰 입력과 같게).

## B-1단계. 텍스트 7편 '몰아서' 받기 (클로드 「쿠니 경제」 한 곳 — 앱 안 바꿈)
7주제 각각, 클로드 「쿠니 경제」에서 **연속으로**:
4. 유미 글 '전문' 붙여넣기 → **본문**(완성 원고)만. (유미 글 없으면 주제 키워드 한 줄.)
5. `제목` → `[제목 후보]` 5개.
6. `해부` → `[미러 해부]` 3줄(소재/각도/핵심키워드). **매 글 꼭**(시트 데이터용).
7. `사진` → `[사진 장면]` 7줄.
→ 편별로 {본문 / 제목5 / 해부 / 장면7}을 **받아 쌓는다**(메모·시트에). **클로드 한 창에서만 → 앱 전환 0, 연속이라 빠름.**

## B-2단계. 사진 '여러 탭 병렬' (지피티 「경제 사진」 2~3탭) ★제일 큰 효과
8. 지피티 「경제 사진」을 **탭 2~3개** 연다.
9. 탭A ← 편1 장면 넣고 1번 생성 / 탭B ← 편2 / 탭C ← 편3 (동시에 그려짐).
10. **돌아가며** 각 탭에서 `다음`으로 다음 장을 뽑는다 — **한 탭이 그리는 동안 다른 탭 것 수거.** 편별 7장.
11. 편1~3 끝나면 **비는 탭에 편4·5·6·7** 이어서. 49장 다 모을 때까지.
    - 각 그림은 **편·번호 라벨**(예: 편3-사진5)로 저장해 섞이지 않게.

## B-3단계. 네이버 조립·임시저장 (7편)
12. 각 편마다 경제 블로그 글쓰기 → **임시저장**:
   - 제목칸: `제목` 후보 1번 임시.
   - **본문칸: '글' 답 그대로** 붙이고, `[사진N — 설명]` **라벨 줄만** 그 사진으로 바꾼다. **그 아래 '캡션 한 줄'(텍스트)은 그대로 둔다**(네이버 4원칙).
   - 맨 위 메모칸: "■제목후보" 5개 + "■미러해부" 3줄. (메모·해부는 본문에 넣지 않음.)
   - 서식(아래) → **임시저장만. 발행 절대 금지.**
   - **구글시트 한 줄 기록**(아래).

## ★ 겹쳐 돌리기 (방안3 — 비는 시간 메우기)
1→2→3을 꼭 차례로 안 해도 된다. 겹치면 더 빠름:
- **1단계에서 한 편 장면이 나오는 즉시** → 그 편 사진을 지피티 탭에 던져 2단계 시작, 클로드는 **다음 편 텍스트** 계속.
- **2단계 사진이 그려지는 동안** → 먼저 끝난 편을 **네이버 조립(3단계)** 미리.
→ 어사이드가 "기다리는 시간"을 다른 탭 일로 메운다.

## 서식 (대표 2026-10-23 "다 해" — ⚠️ 에디터 UI 조작이라 깨지기 쉬움, 처음엔 한 편으로 검증 후 켤 것)
   - **표:** 본문에서 **`[표: …]` 줄 바로 아래 `| 구분 | 값 |` 격자**를 찾아 → 네이버 **표 기능**으로 옮기고, **`[표: …]` 표시줄은 지운다**(글마다 표 1개).
   - **강조(볼드):** 본문에서 **`**...**`로 감싼 부분**을 찾아 → 그 글자를 **볼드**로 바꾸고 **`**` 기호는 지운다.** (중요 수치·결론만, 대여섯 개 이내.)
   - **구분선:** **`---`만 있는 줄**을 찾아 → 네이버 **구분선**으로 바꾸고 **`---`는 지운다.** (글마다 1~2개.)
   - **소제목:** 각 소제목 줄 **인용 버튼** + **볼드**.
   - **정렬:** 전체선택(Ctrl+A) → **가운데 정렬**. (빼고 싶으면 이 줄만 삭제.)

## 구글시트 기록 (제목 후보 + 유미 분석 데이터)
시트: **「쇼츠엔진-경제-로그」** 의 **`경제로그`** 탭. 글 한 편마다 **맨 아래 빈 줄에 한 행** 추가(A열부터 Tab):

| A 날짜 | B 유미글(주제) | C 소재 | D 각도 | E 핵심키워드 | F 제목후보(5개) | G 선택제목 | H 임시저장 |
|---|---|---|---|---|---|---|---|
| 2026-10-23 | SK하이닉스 | (해부 소재) | (해부 각도) | (해부 키워드) | 후보 5개를 줄바꿈(Alt+Enter)으로 | *비움 — 대표가 발행 때 채움* | ✓ |

- C·D·E = `[미러 해부]` 3줄 그대로. F = 제목 후보 5개(클로드)를 한 칸에 줄바꿈으로.
- **G(선택제목)은 비워 둔다** — 대표가 발행하며 고른 제목을 나중에 적는다(어느 훅이 먹히는지 데이터).
- 시트 쓰기가 불안하면(칸 밀림 등) 억지로 말고, 그 행은 **비고에 "수기확인"**만 남기고 넘어간다(임시저장이 먼저).

## C. 마무리
13. 다 끝나면 **"오늘 N+1편 임시저장 완료 + 시트 N행 기록"**과 주제 목록을 보고한다.

## 예약
이 루틴을 어사이드에 저장하고 **새벽 시각(예: 05:30~06:30)**에 예약. 유미가 밤에 다 올린 뒤라 그날 물량을 다 잡는다.

## 대표 (아침, 폰)
각 임시저장 글 → 제목 후보 중 하나 골라 제목칸에 + 메모 지우기 → 사진·본문 훑기 → **발행(띄엄띄엄).** 고른 제목은 시트 **G열(선택제목)**에 적어 둔다(나중에 '어떤 제목이 조회수 잘 나왔나' 분석용).

## 분류 참고 (유미 RSS 카테고리)
- `[투자]` = 증시(개별종목·테마·전략) · `[소식]` = 금·연금·정책 등 · `[청약]` = 부동산.
- 우리는 유미가 안 하는 **부동산 1개를 늘** 더한다(유미가 청약을 쓴 날은 부동산이 2개가 되어도 OK).
