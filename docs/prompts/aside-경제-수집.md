# 어사이드 — 경제 수집 (조사 + 사진 → 드라이브) [A방향 신설 2026-11-11]

목적: 어사이드(브라우저)가 **그록 웹으로 조사·사진을 받아 드라이브에 떨군다.** 글·검수는 외부 Claude Code가 드라이브에서 집어간다. (어사이드 ↔ Claude Code 접점 = 드라이브. 기존 올인원 `aside-경제-루틴-자동`은 폴백으로 보존.)

안전선: **발행·로그인 자동화 금지. 수집(읽기)만.** 로그아웃이면 멈추고 보고. 토큰 절약 — 빠른 검색 기본, DeepSearch/Think는 숫자·시행단계·실거래가 확인 꼭 필요할 때만.

전제: 드라이브 `공장/작업대/경제/오늘/`에 **「생산지시」**(오늘 키워드5 + 제목 결)가 올라와 있다(Claude Code 분석본부가 새벽에 올림). 없으면 운영총괄에 요청하고 멈춘다.

---

## 수집-A. 조사 (글 쓰기 전) — 편마다
1. 「생산지시」의 키워드마다 **그록 조사**를 돌린다(프롬프트 그대로):
   - 종목·거시 = `prompts/project/그록-경제-조사.md` (지금 팩트·뉴스·수치 + 날짜)
   - 부동산 = `prompts/project/그록-경제-부동산조사.md` (단지·전후 실거래·사연·호재, 소재만)
2. 받은 조사 결과를 **`N_조사.md`**(편 번호 N)로 드라이브에 저장한다.
   - 확인 안 된 수치·단계는 **'미확인'**. 지어내기 금지('파월' 사고 방지).
3. `상태.md`에 **"조사 N/5 완료"** 기록.
→ 여기서 어사이드 1차 멈춤. **Claude Code가 N_조사를 읽어 글·제목·[사진 장면]을 만든다.**

## 수집-B. 사진 (글 나온 뒤) — 썸네일 + [실물] 본문컷
전제: Claude Code 사진담당이 **`N_사진요청.md`**에 [실물] 목록을 올렸다(썸네일 + 글담당이 `[실물]` 플래그한 본문컷. GPU 생성컷은 Claude Code가 이미 처리했으니 여기 없음).
4. 요청 대상마다 **그록 사진 수집·편집**(프롬프트 그대로 — `prompts/project/그록-경제-사진수집.md`):
   - 메인 키워드 알아볼 실물 **3~5장 수집 → 선명도·정합성 최고 1장 → 편집(간판·건물 유지 / 글 분위기별 톤·구도 / 산만한 요소 정리) → 1024×1024**.
5. 완성본을 **`N_사진/`**에 라벨대로 저장(썸네일=1, 본문=해당 번호).
6. 못 구하면 **'미확인'** → 상태판 기록, 대표 판단(정체성 컷은 생성 대체 금지).
7. `상태.md`에 **"사진 N편 완료"** 기록.
→ Claude Code 검수담당이 `N_완료`를 주면 → `aside-경제-저장`.

## 멈춤·장애
- 로그인 풀림·그록 한도·권한 팝업으로 멈추면 → **상태판 🔴 + 이유** 기록(기술보안팀이 감지·대표 알림). 처리되면 그 자리에서 재개.

## 금지
- 가짜 합성·없는 사건(화재·붕괴 등)·과장 연출 금지. 썸네일 무인(사람 모델 금지).
- 발행·로그인 자동화 금지. 수집만.
