# 어사이드 「쇼핑커넥트 링크 발급·관리」 (상품 찾기 탭)

쇼핑커넥트 **'상품 찾기' 탭**에서 대표가 준 **제품명(검색어)**으로 **전용링크를 발급**해 목록으로 관리한다. 이 목록을 글 작업 어사이드가 본문 `[상품링크N]`에 꽂는다. **발행·결제·로그인 자동화 ❌.**

## 입력
- **검색어 = 아래 '발급 후보 리스트'**(틈새표 기반) + 대표가 추가로 주는 제품명. 구체적으로(브랜드+모델). 범용어("카시트") ❌.
- (있으면) **링크풀 파일**(Drive `공장/데이터/키워드/링크풀-육아쇼핑.md`) — **이미 발급한 제품은 다시 안 함**(중복 방지).

## 발급 후보 리스트 (틈새표 2026-11-25 · 저경쟁 고단가 · 쇼커에 있는 것만 발급)
어사이드는 이 중 **링크풀에 없는 것**부터 검색·발급한다. **쇼커 '상품 찾기'에 없으면 '없음(B모드 노출자석 후보)'로 보고**(지어내기 ❌). 경쟁강도 괄호(낮을수록 좋음).
- **바운서:** 베이비뵨 바운서(0.50) · 베이비뵨 하모니(0.66) · 뉴나 바운서(3.9)
- **카시트:** 싸이벡스 제로나T(0.45) · 다이치 원픽스360(0.72) · 싸이벡스 레모(0.77) · 브라이텍스 듀얼픽스 프로(1.6) · 브라이텍스 듀얼픽스(2.5) · 조이 아이스핀360(0.78) · 순성 카시트(3.0) · 뉴나 카시트(2.9)
- **트라이크:** 에이블 트라이크(0.76) · 부가부 드래곤플라이(0.61) · 스쿳앤라이드(0.60) · 조이 트라이크
- **유모차:** 부가부 유모차(3.2) · 부가부 비6(2.2) · 싸이벡스 유모차(3.6) · 스토케 유모차(7.1) · 에그 유모차(7.5) · 오이스터 유모차
- **하이체어:** 스토케 하이체어 · 트립트랩(※ 쇼커에 없을 가능성 — 없으면 B모드 노출자석, 유사 하이체어로 전환)
- ※ 이 리스트는 월 1회 틈새표 갱신 때 함께 갱신(신상·시즌 반영).

## 단계 (제품마다 반복)
1. **'상품 찾기' 검색창에 제품명 입력** → 검색.
2. **결과에서 하나 선택:**
   - **★ 메인 본품만. 단가 10만원 미만은 제외**(쿠션·커버·트레이·레인커버·부품·호환 악세사리일 가능성 — 본품 아님). 제품명에 '쿠션/커버/매트/부품/호환/전용' 등 **부속 단어가 붙은 것 거른다.**
   - **브랜드·모델이 정확히 일치**하는 **본품**.
   - 여러 개면 **① 프로모션(브랜드데이·오늘끝딜·슈퍼적립) 붙은 것 → ② 적립률 높은 것 → ③ 단가 높은(정품 본품) 것** 순.
   - **품절·비정상 가격·짝퉁 의심 제외.**
3. 그 상품 클릭 → **'링크 발급' 버튼** → **전용링크 생성** → **복사.**
4. **기록 한 줄 추가**(아래 출력 형식):
   `제품명(브랜드·모델) | 전용링크 | 단가 | 적립률 | 프로모션(종류·마감) | 발급일`
5. **애매하면 멈추고 보고** — 검색 결과 0개 / 브랜드·모델 일치하는 게 없음 / 가격이 이상(너무 쌈·비쌈) / 여러 판매처가 비슷해 못 고르겠음. **임의로 아무거나 발급 ❌.**

## 출력 (발급 목록)
```
[쇼핑커넥트 발급 — <날짜>]
| 제품(브랜드·모델) | 전용링크 | 단가 | 적립률 | 프로모션 | 발급일 |
| 브라이텍스 듀얼픽스 프로 | <전용링크> | 39만 | 7% | 브랜드데이~11/30 | 2026-11-26 |
...
[보고] 발급 N건 / 멈춘 것 M건(사유: …)
```
- 이 목록을 **링크풀 파일에 누적**(또는 대표에게 전달) → 글 작업 어사이드가 `[상품링크N]`에 해당 전용링크를 **텍스트 링크**("최저가 확인하기" 등)로 삽입.

## 절대 규칙
- **전용링크만.** 상품 페이지 **생 URL ❌**(수익 0). 링크 지어내기 ❌.
- **중복 발급 ❌**(링크풀에 이미 있으면 건너뜀).
- 품질·최종 판단은 대표(발행 전 검토). 어사이드는 **발급·기록까지만**, 막히면 멈추고 보고.
