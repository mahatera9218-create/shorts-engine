# 어사이드 「쇼핑커넥트 링크 발급·관리」 (상품 찾기 탭)

쇼핑커넥트 **'상품 찾기' 탭**에서 대표가 준 **제품명(검색어)**으로 **전용링크를 발급**해 목록으로 관리한다. 이 목록을 글 작업 어사이드가 본문 `[상품링크N]`에 꽂는다. **발행·결제·로그인 자동화 ❌.**

## 입력
- **대표가 준 제품명(검색어) 목록** — 구체적으로(브랜드+모델: "브라이텍스 듀얼픽스 프로"). 범용어("카시트") ❌.
- (있으면) **링크풀 파일**(Drive `공장/데이터/키워드/링크풀-육아쇼핑.md`) — **이미 발급한 제품은 다시 안 함**(중복 방지).

## 단계 (제품마다 반복)
1. **'상품 찾기' 검색창에 제품명 입력** → 검색.
2. **결과에서 하나 선택:**
   - **브랜드·모델이 정확히 일치**하는 것.
   - 여러 개면 **① 프로모션(브랜드데이·오늘끝딜·슈퍼적립) 붙은 것 → ② 적립률 높은 것 → ③ 단가 높은(정품) 것** 순.
   - **품절·비정상 가격·짝퉁 의심 제외.**
3. 그 상품 클릭 → **'링크 발급' 버튼** → **전용링크 생성** → **복사.**
4. **기록 한 줄 추가**(아래 출력 형식):
   `제품명(브랜드·모델) | 전용링크 | 단가 | 적립률 | 프로모션(종류·마감) | 발급일`
5. **애매하면 멈추고 보고** — 검색 결과 0개 / 브랜드·모델 일치하는 게 없음 / 가격이 이상(너무 쌈·비쌈) / 여러 판매처가 비슷해 못 고르겠음. **임의로 아무거나 발급 ❌.**

## 출력 (발급 목록)
```
[쇼핑커넥트 발급 — <날짜>]
| 제품(브랜드·모델) | 전용링크 | 단가 | 적립률 | 프로모션 | 발급일 |
| 브라이텍스 듀얼픽스 프로 | <전용링크> | 39만 | 7% | 브랜드데이~11/30 | 2026-11-26 |
...
[보고] 발급 N건 / 멈춘 것 M건(사유: …)
```
- 이 목록을 **링크풀 파일에 누적**(또는 대표에게 전달) → 글 작업 어사이드가 `[상품링크N]`에 해당 전용링크를 **텍스트 링크**("최저가 확인하기" 등)로 삽입.

## 절대 규칙
- **전용링크만.** 상품 페이지 **생 URL ❌**(수익 0). 링크 지어내기 ❌.
- **중복 발급 ❌**(링크풀에 이미 있으면 건너뜀).
- 품질·최종 판단은 대표(발행 전 검토). 어사이드는 **발급·기록까지만**, 막히면 멈추고 보고.
