# Aside 지시문: 경제(eokonomy) 로우데이터 수집 — 제목·본문·통계 (2026-10-19)

대표 결정(2026-10-19): **어사이드가 경제 블로그(eokonomy)에 들어가 제목·본문·통계 로우데이터를 전부 긁어온다.** 클로드는 그 로우데이터로 **날짜별 다면평가**(제목 축·본문 축·성과 축)를 한다. 이번엔 **eokonomy(억선생의 경제판)만.**

- **대상 블로그:** 우리 = https://blog.naver.com/eokonomy (제목·본문·통계 전부) + **벤치마크 2곳 = 유미 https://blog.naver.com/8starstarstar8, 쿠니네 https://blog.naver.com/zkfldb888 (이 둘은 제목·발행날짜만, 통계·본문 불필요).** 벤치마크는 공개 블로그라 로그인 없이 보인다.
- **읽기 전용.** 발행·수정·삭제·임시저장 **어떤 버튼도 누르지 않는다.** 보고 복사만.
- 수집 범위: **2026-10-05 ~ 2026-10-18** 전체 글. 두 주로 나눠 본다 — **1주차 = 10/05~10/11, 2주차 = 10/12~10/18**. (10/19부터는 3주차라 이번엔 제외. 글이 너무 많으면 2주차 먼저, 그래도 다 못 하면 어디까지 했는지 보고.)
- 비밀번호는 어사이드가 입력하지 않는다.

```text
내 경제 블로그(eokonomy)의 글과 통계 로우데이터를 수집만 해 줘. 아무것도 발행·수정·삭제하지 마. 보고 복사만.

0. 로그인 확인: https://blog.naver.com/eokonomy 를 열어 내 계정 로그인 상태인지 본다. 로그인이 안 돼 있거나 로그인 화면이 뜨면 지금 바로 나(대표)에게 알리고 멈춰. (비밀번호는 네가 입력하지 마.)

1. 글 목록부터 만든다. '글 관리'(또는 블로그 글 목록)에서 2026-10-05부터 2026-10-18까지 발행된 글을 전부 찾아, 각 글의 ① 발행 날짜 ② 제목 ③ 글 주소(URL)를 모은다. (10/19 이후 글은 이번엔 제외.)

2. 각 글마다 아래를 수집한다(순서대로, 글 하나씩):
   a. 제목(그대로)
   b. 본문 전체 텍스트(사진·표는 '[사진]'·'[표]'로 자리만 표시, 글자만 복사)
   c. 그 글의 누적 조회수(글별 조회수에 보이는 수)

3. 블로그 통계를 수집한다. 가능하면 **1주차(10/05~10/11)와 2주차(10/12~10/18)를 각각** 기간 지정해 따로, 안 되면 10/05~10/18 전체로. 네이버 블로그 '통계' 메뉴에서:
   a. 유입분석 → 전체 유입경로 분포(%): 네이버 통합검색(모바일/PC), 네이버 블로그, 네이버 뷰, **네이버 홈피드**, 다음, 기타 — 보이는 항목 전부 수치로.
   b. 유입분석 → 검색 유입 키워드 상위 20개(키워드·유입수).
   c. 방문분석 → 평균 사용 시간(체류), 재방문율, 순방문자수(기간 합).
   d. 사용자분석 → 성별·연령 분포(%).
   e. 조회수 → 일별 조회수(10-05부터 10-18까지 날짜별 숫자).
   f. 조회수 → 글별 조회수 순위(상위부터 제목·조회수).

4. 수집한 걸 아래 형식으로 **한 덩어리 텍스트(마크다운)**로 만들어 나에게 줘(복사해 보낼 수 있게). 글은 발행 날짜 순서로.

=== 글 (날짜순, 주차 표시) ===
## [1주차 10/05~10/11]
### 2026-10-06
- 제목: (제목)

  본문:
  (본문 전체 텍스트)
...(1주차 글 전부)
## [2주차 10/12~10/18]
### 2026-10-12
...(2주차 글 전부, 같은 식)

=== 블로그 통계 ===
[1주차 10/05~10/11]
- 유입경로: 통합검색 __% / 블로그 __% / 뷰 __% / 홈피드 __% / 다음 __% / 기타 __%
- 검색 유입 키워드: 키워드 - 유입수 (상위 20)
- 체류: 평균 사용 시간 __, 재방문율 __%, 순방문자수 __
- 성별·연령: 남 __% / 여 __%, 연령 10대__ 20대__ 30대__ 40대__ 50대__ 60대+__
[2주차 10/12~10/18]
- (같은 항목 다시)
[공통]
- 일별 조회수: 10-05 __ / 10-06 __ / ... / 10-18 __
- 글별 조회수 순위: 1위 (제목) __ / 2위 ...
(기간을 못 나누면 10/05~10/18 전체로 한 번만 적고 '기간 못 나눔'이라고 표시)

5. **벤치마크 블로거 제목 수집(비교용).** 아래 두 공개 블로그(로그인 불필요)에 들어가 **2026-10-05~10-18에 발행된 글의 제목과 발행 날짜만** 모은다(본문·통계 안 봐도 됨). 각 블로그 글 목록에서 날짜가 그 범위인 것만.
   - 유미: https://blog.naver.com/8starstarstar8

6. 다 끝나면 위 덩어리(우리 글·통계 + 벤치마크 제목)를 주고, 수집 못 한 부분(예: 통계 특정 항목이 안 보임, 벤치마크 날짜 확인 어려움)이 있으면 그것도 알려 줘.
```
