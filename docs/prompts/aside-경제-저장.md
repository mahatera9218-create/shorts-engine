# 어사이드 — 경제 저장 (드라이브 → 네이버 임시저장) [A방향 신설 2026-11-11]

> ⛔ **폐기 (2026-11-12 대표):** split 방식 폐기. **올인원 `docs/prompts/aside-경제-루틴-자동.md`** 가 master(조립·저장 노하우도 거기 포함). 이 파일은 참고용. (DECISIONS 2026-11-12.)

목적: Claude Code 검수 통과분을 어사이드가 **네이버에 조립해 임시저장.** 네이버 편집 노하우는 기존 올인원 루틴에서 **그대로** 가져온다(이게 금 — 바꾸지 않음).

안전선: **임시저장까지만. 발행·로그인 자동화 금지(발행 = 대표).** 로그아웃이면 멈추고 보고.

전제: 드라이브 `공장/작업대/경제/오늘/`에 **`N_완료`**(검수 통과 신호)가 떴다. `N_원고.md` + `N_사진/` 준비됨. `N_완료` 없으면 **저장하지 않는다.**

---

## 시작
0. `상태.md`에 **"저장 시작"** 기록. (지시함은 Claude Code 분석이 이미 반영했으므로 여기선 안 봄.)

## 조립·임시저장 (편마다) — ★ 기계적으로, 마크대로만
검수 통과분은 표 격자·`**`·`---`·카드 자리가 다 완비돼 있다. **판단으로 바꾸지 말고 마크를 네이버 서식으로 변환만** 한다(판단 줄일수록 들쭉날쭉 줄어듦).
1. 경제 블로그 글쓰기 열기(「작성 중인 글이 있습니다」 창은 '취소'로 닫고 새 글).
2. **제목칸:** N_원고의 ★추천을 임시로. **맨 위 메모칸**에 제목 후보 전체(대표가 발행 때 고름).
3. **본문칸:** N_원고 본문 그대로 붙이고, **`[사진N]` 라벨 줄만** `N_사진/`의 사진으로 바꾼다(순서대로).
4. **조립 세부 = `docs/prompts/조립-규칙-공통.md` 그대로:** 본문 순서(사진→인용구 소제목→글), **캡션 없음**, **AI 체크버튼 안 누름**, 단락 빈 줄, 서식 단축키, 표.
   - **표:** `[표: …]`줄+`| 구분 | 값 |` 격자를 **네이버 표로 변환**하고 격자·`[표:]` 글자는 **전부 삭제**(본문에 `|` 작대기 안 남게). 글마다 1개.
   - **서식 단축키:** `**…**`→볼드(Alt+1), 소제목 줄→인용구(Alt+3)+글자크게(Alt+4), `---`→구분선(Alt+5), 전체→가운데정렬(Alt+6). 마커 글자는 지운다.
   - **단락:** 3~4문장마다 빈 줄 한 줄 유지(붙이며 뭉치면 엔터로 띄움).
5. **함께 보면 좋은 글:** 본문 끝과 해시태그 **사이**에, 내 과거 글 **URL 복사→붙여넣기**(손 타이핑 금지)로 썸네일 카드. 카드 뜨면 생 URL 텍스트 삭제. (N_원고에 자리·대상 표시됨. 없으면 생략.)
6. **임시저장.** 발행 절대 금지.

## ★ 저장 후 자가 확인 (편마다 — '같은 날인데 개판' 방지)
- [ ] 표가 네이버 표로 변환됐나(본문에 `|` 작대기 0개)
- [ ] 단락 빈 줄 유지 · [ ] 소제목 인용구 서식 · [ ] 카드 떴나 · [ ] 사진 밑 캡션 없나
- [ ] **AI 체크버튼 꺼져 있나**
- 하나라도 안 됐으면 **그 편만 다시 손보고**, 못 고치면 **상태판 🔴 + 어느 편 뭐가 빠졌는지** 기록(대표가 폰에서 바로 앎).

## 시트 기록
- 「쇼츠엔진-경제-로그」 **「경제로그」** 탭에 편마다 한 줄:
  `날짜 · 테마 · 키워드 · 검색량 · 글수 · 제목후보(12) · 선택제목(비움—대표가 채움) · 임시저장 · 모드 · 후킹메커니즘`
- 시트 쓰기 불안하면(칸 밀림) 억지로 말고 비고에 "수기확인"만 남기고 넘어간다(임시저장이 먼저).

## 마무리
- `상태.md`에 **"5편 임시저장 완료 + 표/카드 다 확인"** 또는 빠진 편 명시.
- 대표(아침): 각 임시저장 글 → 제목 골라 제목칸 + 메모 삭제 → 사진·본문 훑기 → **발행(띄엄띄엄).** 고른 제목은 시트 선택제목 칸에.

## 금지
- 발행·로그인 자동화 금지. 임시저장까지만. **AI 체크버튼 안 누름.**
