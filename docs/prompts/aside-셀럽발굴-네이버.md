# 어사이드 「셀럽 발굴 — 네이버 단서」 (셀럽 육아템 풀 축적 보조)

목적: **네이버 블로그·검색에서 '연예인이 쓰는 육아템 브랜드' 단서**를 모아 → **그록 교차확인**으로 넘긴다 → 확인된 것만 `셀럽매칭풀.md`에 쌓인다. ★ 어사이드는 **단서 수집만.** 확정은 그록(공식 SNS·언론 교차확인).

## 왜 어사이드가 하나
언론 기사는 "190만원대 그 유모차"처럼 **브랜드를 안 밝히는 경우**가 많다. 네이버 블로그엔 **"연예인 유모차 총정리 / 셀럽 육아템 브랜드"** 류 글이 브랜드·모델까지 적어둔 게 많아 **단서가 풍부.** 어사이드는 로그인 브라우저라 공개 블로그를 사람처럼 읽을 수 있다.

## 어디서 (네이버)
- 통합검색·블로그 탭에서: `연예인 유모차`, `셀럽 육아템 브랜드`, `OO(연예인) 유모차 브랜드`, `연예인 하이체어`, `스타 육아용품` 등.
- "연예인 유모차 총정리" 류 **정리 글** 위주(브랜드·모델 적힌 것).

## 수집 (단서만)
- **상위 몇 개 글을 사람처럼 훑어** `셀럽 | 카테고리 | 브랜드·모델(블로그 주장)` 단서만 적는다.
- **대량 크롤링·자동수집 ❌**(검색결과 페이지 긁기 ❌). 사람이 몇 개 읽는 수준.

## 절대 규칙 (원칙 — 어기면 못 씀)
- **블로그 글 문장·사진 복제 ❌.** 단서(셀럽–브랜드명)만 메모.
- **블로그 = 2차 정보, 추측일 수 있음.** 그대로 믿지 말고 전부 **'미확인(교차확인 필요)'**로 표시.
- **확정은 그록이 공식(본인 SNS·언론)으로 교차확인한 것만** 풀에 들어간다. (어사이드 단서만으로 풀에 바로 넣지 않는다.)
- 아기 얼굴·이름·사생활·열애 억측 ❌. 협찬 의혹·브랜드 불명은 '미확정'으로만.

## 출력 → 그록 「셀럽 발굴」로 넘김
```
[네이버 단서 — 교차확인 필요 · <날짜>]
| 셀럽 | 카테고리 | 브랜드·모델(블로그 주장) | 단서 비고 |
| 송중기 | 유모차 | 싸이벡스 프리암(블로그 다수 주장) | 교차확인 필요 |
...
```
→ 이 리스트를 **그록 「셀럽 발굴」**에 입력 → 그록이 공식 SNS·언론으로 **확인된 것만** `셀럽매칭풀.md`에 추가(미확인·의혹은 버림).

## 흐름 요약
어사이드(네이버 단서) → 그록(공식 교차확인) → 셀럽매칭풀.md → 생산(셀럽 편) → 대표 발행.
