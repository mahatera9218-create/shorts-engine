# 어사이드 통합 새벽 루틴 — 경제 먼저, 그다음 패션 (한 창에서 쭉)

한 창(한 루틴)에서 **① 경제 전부 → ② 패션 전부** 순서로 돈다. 새벽(예: 05:30)에 예약.

**공통 안전선 (끝까지 지킴):**
- **임시저장까지만. 발행·로그인 자동화 절대 금지.** (발행은 대표가 아침에.)
- **복제 금지:** 1등 블로그는 **주제·인물·키워드만** 따온다. 제목·문장·사진은 **우리 것**.
- 가짜 경험·가짜 후기·사생활/재산 단정·투자 권유 금지.
- **한 입력 = 한 결과.** 클로드/지피티가 '글' 땐 본문만, '제목' 땐 제목만 낸다. 섞여 나오면 섞인 채로 붙이지 말고, 본문·제목·사진을 **따로** 받아 둔다.

===================================================================
# ① 경제 (유미 미러) — 먼저 이거 다 끝내고 패션으로
===================================================================

## 1-A. 오늘 배치 정하기
1. 유미 RSS `https://rss.blog.naver.com/8starstarstar8.xml` 를 연다. **전날 18:00 ~ 오늘 새벽** 글을 **전문까지** 읽는다(보통 6편).
2. 오늘 쓸 **주제 목록 + 갯수**(보통 6)를 정한다. **여기에 부동산 1개 추가**(틈새표 reports/검색량/ 부동산 1위 중 최근 안 쓴 것, 또는 config/niche_keywords.yaml 부동산 씨앗). → **경제 총 7편.**

## 1-B. 한 편씩 생성 (각 글마다 반복)
3. **클로드 '경제 글' 탭에 유미 글 '전문'을 통째로 붙여넣는다**(제목 한 단어 말고 본문 전체 = 미러 입력). → **본문(완성 원고)만** 나온다. 이게 네이버에 붙일 글.
   - (유미 글이 없거나 따로 정한 주제면, 그 주제를 **키워드 한 줄**로만 입력해도 됨.)
4. 이어서 **`제목`** 입력 → `[제목 후보]` 5개. (따로 받아 메모칸용.)
5. (선택) **`해부`** 입력 → `[미러 해부]` 3줄(소재/각도/핵심키워드, 참고용).
6. 이어서 **`사진`** 입력 → `[사진 장면]` 7줄 → **지피티 '경제 사진'** 프로젝트에 붙여넣기 → 1장 나오면 `다음`을 6번 → 7장.
7. 경제 블로그 네이버 글쓰기 → **임시저장**:
   - 제목칸: `제목` 후보 1번 임시로.
   - 본문칸: **3번 '글' 답을 그대로** 붙여넣고 `[사진1]…[사진7]` 자리에 사진 순서대로.
   - 맨 위 메모칸: "■제목후보" 5개 + (있으면)"■미러해부" 3줄. **이 메모·제목·해부는 본문에 넣지 않는다.**
   - **임시저장만. 발행 금지.**

## 1-C. (선택) 서식 — ⚠️ 깨지기 쉬움, 처음엔 끄고, 한 편 검증 후 켤 것
   - 표: 본문에 `| 구분 | 값 |` 격자가 있으면 네이버 표 기능으로 옮김.
   - 소제목: 각 소제목 줄 인용 버튼 + 볼드.
   - 정렬: 전체선택(Ctrl+A) → 가운데정렬. (빼고 싶으면 이 줄만 삭제.)

→ 경제 7편 임시저장이 다 끝나면 **패션으로 넘어간다.**

===================================================================
# ② 패션 (jayuyu·kims718 미러, 올인원 GPT)
===================================================================

## 2-A. 오늘 배치 정하기
8. 두 블로그 RSS를 연다: `https://rss.blog.naver.com/jayuyu.xml` , `https://rss.blog.naver.com/kims718.xml`. **전날 18:00~오늘 새벽** 글을 본다.
9. 각 글에서 **인물 + 핵심 착장/아이템**만 뽑는다(제목 베끼지 말 것). 예: `신민아 / 유퀴즈 블라우스`.
10. 두 블로그 합쳐 **같은 인물 중복 제거**(한 인물이 양쪽에 나오면 1건). **최대 5편**(넘치면 방문자·화제성 큰 인물 우선).

## 2-B. 한 편씩 생성 (각 인물마다 반복)
11. **지피티 '패션 올인원'** 탭에 `인물 / 착장` 한 줄 입력. → `[제목 후보]` 5개 + 본문(`[사진N]` 자리) + 해시태그 + `[그록 조사 요청]` 한 줄이 나온다.
12. 패션 블로그 네이버 글쓰기 → **임시저장**:
    - 제목칸: 후보 1번 임시.
    - 본문 붙여넣고 **`[사진N]` 자리는 그대로 둔다**(실제 사진 아직 없음).
    - 맨 위 메모칸: "■제목후보" 5개.
    - **임시저장만. 발행 금지.**
13. `[그록 조사 요청]` 한 줄을 **따로 모아 둔다**(대표가 그록에 넣어 실사·아이템 조사 → 사진 확보).

===================================================================
# ③ 마무리 보고 (한 번만)
===================================================================
14. 다 끝나면 한 번에 보고한다:
    - "오늘 경제 N편 + 패션 M편 임시저장 완료."
    - 경제 주제 목록 / 패션 인물 목록.
    - 패션 **[그록 조사 요청] 목록**(대표가 아침에 그록 돌릴 것).

## 대표 (아침, 폰)
- 경제: 각 임시저장 → 제목 후보 중 하나 골라 제목칸에 + 메모 지움 → 발행(띄엄띄엄).
- 패션: 그록에 `[그록 조사 요청]` 넣어 실사 셀럽 사진 확보 → `[사진N]` 자리에 삽입(출처·초상권 확인) → 제목 골라 발행.

## 예약
이 통합 루틴을 어사이드에 저장하고 **새벽(05:30~)** 예약. 유미·패션 1등들이 밤에 다 올린 뒤라 그날 물량을 다 잡는다.

## 분류 참고 (유미 RSS)
- `[투자]`=증시(개별종목·테마·전략) · `[소식]`=금·연금·정책 · `[청약]`=부동산.
- 우리는 유미가 안 하는 **부동산 1개를 늘** 더한다(유미가 청약 쓴 날은 부동산 2개 OK).
