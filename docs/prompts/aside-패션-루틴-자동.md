# 어사이드 새벽 자동 루틴 — 패션 (트렌드 연예인 축, 2026-10-26 개편)

목표: 매일 아침 어사이드가 **네이버 메인 유입트렌드 상위 여자 연예인**을 뽑아, 그록(룩 조사·사진 URL) + 지피티(글·보완 사진)로 **한 세트(글+사진)를 완성해 네이버 임시저장**. **하루 5편.** 대표는 **발행 직전 제목만 고르고 출처 확인 후 발행.**
안전선: **발행·로그인 자동화 금지.** 임시저장까지만. 미러·트렌드 글의 **제목·문장·사진 복제 금지**(인물·룩만 따라감). 실제 셀럽 사진은 **출처·초상권 확인은 대표.** 사생활·재산 단정 금지.
**로그아웃이면 멈추고 보고**(네이버·인스타 로그인은 대표 수동, '로그인 유지' 체크). **인스타는 대표가 로그인 해둠 — 어사이드가 공식 계정 사진 수집에 사용**(로그인 풀리면 인스타만 건너뛰고 나머지로 진행).

- **룩 조사·사진 URL·공식 인스타 핸들:** 그록 → 프로젝트 탭 **「패션 조사」**
- **제목 + 글(해요체):** 클로드 → 프로젝트 탭 **「쿠니 패션」** (2026-10-27 — 지피티에서 클로드로 옮김)
- **보완 사진:** 지피티 → 프로젝트 탭 **「패션 자동화」** (아이템·무드컷만, 글·제목 안 씀)
- **네이버 패션 블로그(캐시미어 다이어리):** 계정 ID = `(대표 확인 — 지난 테스트 땐 tenbillionsound로 추정)`. 글쓰기 전 로그인 확인.
- 각 단계마다 **해당 프로젝트를 먼저 연 뒤** 입력.

## A. 키워드(연예인) 선정 — 트렌드 축 (대표가 트렌드 켜둠, 실행 전 새로고침 1회)
1. **크리에이터 어드바이저 → 메인 유입트렌드 1~20위** 글을 읽는다. 거기 뜬 **여자 연예인 이름 5명**을 뽑는다(아이템·키워드가 보이면 메모, 없으면 말고).
2. **5명을 못 채우면** → 미러(`rss.blog.naver.com/jayuyu.xml`·`rss.blog.naver.com/kims718.xml`)에서 **전날~새벽 글의 여자 연예인**으로 보충.
3. **미러 인물이 트렌드 인물과 겹치면** → 중복 제거(트렌드에서 조사된 대로 끝).
→ 오늘의 **연예인 5명** 확정.

## B. 한 편씩 완성 (연예인마다 반복, 5편)
**B-1. 그록 룩 조사 (「패션 조사」).** 연예인 이름(+아이템 있으면)을 넣어 **①조사(룩1~5) ②사진 목록(사진N·직접 URL·비율) ③확보 현황**을 받는다. ①블록은 글용, ②는 사진 다운로드용.
**B-2. 클로드 글 (「쿠니 패션」).** 그록 ①조사(룩) 블록을 넣어 **`[제목 후보]` 8개 + ★추천 1 + 본문(해요체, 소제목=룩, `[사진N]` 자리) + 해시태그**를 받는다. (제목·글은 클로드. 지피티는 사진만.)
**B-3. 사진 모으기 (7~10장).** 우선순위: ①공식 인스타 ②그록 URL ③지피티 보완컷.
   - **① 공식 인스타(대표가 로그인 해둠):** 그록 ①블록의 `[공식 인스타] @핸들`이 있으면, 그 공식 계정 페이지를 열고 **Imageye 확장으로 최근 착장 사진을 일괄 저장**한다(본인 실착이라 1순위). Imageye에서 **작은 아이콘·프로필썸네일은 거르고 큰 이미지만**(최소 긴 변 600px↑) 받는다. **"공식계정 없음"이면 패스.** 공식 계정만 — 팬·사칭 ❌.
   - **② 그록 URL:** 그록 ②목록의 **직접 URL로 각 사진 다운로드**, `사진N` 라벨대로 저장(순서 안 섞이게). URL이 막히면 그록 결과 페이지에서 **Imageye로 일괄 저장**(폴백).
   - **③ 부족분(보완컷):** 7~10장에 모자라면, 지피티 「패션 자동화」에 **그 자리 아이템·무드컷 생성** 요청 → 저장. (**인물 얼굴 없는 아이템/무드만** — 가짜 셀럽 금지.)
   - **비율:** **본문 사진은 원본 비율 그대로(세로 OK — 전신 착장 안 잘리게).** 썸네일(맨 위 1장)만 1:1 정사각으로(인물 **상반신 중심** 크롭, 얼굴 안 잘리게). 용량 크면 JPEG 품질 88로.
**B-4. 네이버 조립·임시저장.**
   - 제목칸: `[제목 후보]` 1번 임시. 맨 위 메모칸에 후보 8개.
   - 본문 붙이고, **`[사진N]` 자리에 사진N을 '순서대로' 삽입**(룩 순서 = 사진 순서라 그대로 맞음). 실제분→그 자리, 보완컷→남은 자리.
   - **★ 배치 순서 = 사진 → 인용구(소제목) → 글** (대표 지정): 각 룩 묶음이 **사진 먼저, 그 아래 인용구 서식 소제목, 그 아래 본문 글** 순으로 가게 한다.
   - 서식: 소제목 줄은 **인용구 서식(+볼드)**. (경제 루틴 서식 키와 동일.)
   - **★ 출처·경위 문구 삭제:** 본문에 "언론 사진/인스타 계정에 올라온/전신 컷에서는" 같은 출처·경위 문장이 남아 있으면 지운다(글 프롬프트가 안 넣지만 혹시 섞이면 제거).
   - **함께 보면 좋은 글(아래 B-5) → 본문 끝과 해시태그 '사이'에 삽입.**
   - **임시저장만. 발행 금지.**

**B-5. 함께 보면 좋은 글 (내 과거 패션 글 링크, 2026-10-26 대표 — 경제와 동일 방식).**
   - 초안을 쓴 뒤, **내 패션 블로그에서 '같은 연예인/키워드'로 최근 발행한 내 글**을 블로그 내 검색으로 찾는다. **1개**(관련·최신 우선, 없으면 0 — 억지로 안 넣음).
   - 위치 = **본문 맨 끝과 `해시태그` 사이.** "함께 보면 좋은 글" 한 줄 적고 아래 링크.
   - 링크: 그 과거 글에서 네이버 **'URL 복사'** → 본문에 붙여넣기 → **썸네일 카드가 뜨면 남은 생 URL 텍스트는 삭제**(카드만). **자기 글만**(타 블로그 ❌).

## 사진 — '수집'과 '삽입'은 다른 일 (2026-10-27 대표 확인)
- **★ 삽입(네이버 초안에 사진 넣기)은 어사이드가 지금 쓰는 '검증된 자동 삽입 방식' 그대로 유지한다. 이미 깔끔하게 잘 됨 — 바꾸지 않는다.** 모은 사진을 `[사진N]` 자리에 **순서대로** 넣기만.
- **수집(사진을 어디서 구하나)** 만 아래로 보탠다 — 삽입 방식은 안 건드림:
  - **공식 인스타**(대표 로그인): 개별 저장이 어려우면 **Imageye 확장으로 일괄 저장**(상시 ON). 작은 아이콘·프로필썸네일은 거르고 큰 이미지만.
  - **그록 URL**: 직접 URL로 다운로드. 막히면 Imageye 폴백.
  - **부족분**: 지피티 보완컷(아이템·무드, 얼굴 없이).
- 모은 사진은 **라벨·순서대로**(셀럽-사진1, 2 …) 두어 삽입 때 안 섞이게. 못 채운 자리는 비우고 대표에게 보고.
