# 어사이드 새벽 자동 루틴 — 패션 (jayuyu·kims718 미러, 올인원 GPT)

목표: 새벽에 어사이드가 **jayuyu·kims718(패션 1등들)이 어제 쓴 인물·주제**를 모아(중복 제거, **하루 5편 상한**), GPT 올인원 탭으로 글·제목·사진자리를 만들고 **네이버 임시저장(사진 자리 표시된 채)**. 실제 셀럽 사진은 대표가 그록 조사 보고 직접 삽입.
안전선: 발행·로그인 자동화 금지. 임시저장까지만. 미러 **제목·문장·사진 복제 금지**(인물·주제만 따라감). 사생활·재산 단정 금지.

## 프로젝트 위치 (어사이드가 열 곳 — 이름으로 찾아감)
- **글(올인원):** 지피티 → 프로젝트 탭 **「패션 자동화」**
- **사진 조사:** 그록 → 프로젝트 탭 **「패션 자동화」** (대표가 아침에 사용)
- 각 단계마다 **해당 프로젝트를 먼저 연 뒤** 입력한다.

---

**⚠️ 부호 정리 (붙여넣기 전).** 제목·본문을 네이버에 넣기 전, `…`·`···`·`•••` → **`...`**(마침표 세 개), 곧은 따옴표 `'` `"` → 둥근 **`‘ ’` `“ ”`** 로 바꾼다(폰 입력과 같게).

## A. 오늘 배치 정하기 (미러)
1. 유미처럼, 두 블로그 RSS를 연다: `https://rss.blog.naver.com/jayuyu.xml` , `https://rss.blog.naver.com/kims718.xml`. **전날 18:00~오늘 새벽** 글을 본다.
2. 각 글에서 **인물 + 핵심 착장/아이템**만 뽑는다(제목 베끼지 말 것). 예: `신민아 / 유퀴즈 블라우스`, `전지현 / 명품 코트`.
3. 두 블로그를 합쳐 **같은 인물 중복 제거**(한 인물이 양쪽에 나오면 1건). **최대 5편**까지만(넘치면 방문자·화제성 큰 인물 우선).

## B. 한 편씩 생성 (목록의 각 인물마다 반복)
4. **지피티 프로젝트 「패션 자동화」를 열고**, `인물 / 착장` 한 줄 입력. → `[제목 후보]` 5개 + 본문(`[사진1]…` 자리) + 해시태그 + `[그록 조사 요청]` 한 줄이 나온다.
5. 네이버(패션 블로그) 글쓰기 → **임시저장**:
   - 제목칸: 후보 1번 임시.
   - 본문 붙여넣고 **`[사진N]` 자리는 그대로 둔다**(실제 사진 아직 없음).
   - **서식(⚠️ 깨지기 쉬움, 처음엔 끄고 한 편 검증 후):** 본문은 올인원이 **빈 줄로 문단·소제목을 띄워** 준다 — 붙여넣을 때 그 **빈 줄(문단 구분)이 유지**되게 한다(한 덩어리로 뭉치지 않게). **소제목 줄**(앞뒤 빈 줄로 뜬 짧은 한 줄)은 **인용 버튼 서식 + 볼드**로 바꾼다.
   - 맨 위에 "■제목후보" 5개 메모.
   - 임시저장만. 발행 금지.
6. `[그록 조사 요청]` 한 줄을 **따로 모아 둔다**(대표가 그록에 넣어 실사·아이템 조사 → 사진 확보).

## C. 마무리
7. "오늘 패션 N편 임시저장(사진 자리 비움)"과 **그록 조사 요청 목록**을 보고.

## 대표 (아침)
1. 그록 프로젝트 **「패션 자동화」**에 `[그록 조사 요청]` 줄들 넣어 **실사 셀럽 사진** 확보
2. 네이버 임시저장 열어 `[사진N]` 자리에 **관련 셀럽 사진 삽입**(출처·초상권 확인)
3. 제목 후보 중 하나 골라 제목칸에 + 메모 지우기 → **발행(띄엄띄엄)**

## 예약
새벽(05:30~06:30) 예약. (경제 루틴과 시차를 둬서 겹치지 않게.)
