# 어사이드 「경제 블로그 통계 수집」 (체급 컷 보정용)

목적 = **내 블로그가 실제로 노출·유입된 검색어**를 뽑아 온다. 이걸로 "우리 체급이 소화하는 문서수 상한"을 역산해 키워드 선정 컷(🟢/🟡/🔴)을 보정한다. **어사이드는 수집만(판단·가공 ❌).**

## 준비
- 대상 = **경제 블로그**(대표가 통계를 켠 그 블로그). 네이버 **로그인 상태**.
- 경로(모바일/PC): **블로그 → 통계**. (관리 페이지 안. 비번 직접입력 ❌ — 이미 로그인된 상태에서만.)

## 수집 ① 유입 검색어 (★ 제일 중요)
**통계 → 유입분석 → 검색 유입(검색어)** 에서:
- **기간 = 최근 30일**(선택 가능하면 90일도).
- **유입 검색어 리스트를 위에서부터 그대로** 복사: `검색어 | 유입수(건)`. **많을수록 좋음(상위 50~100개).**
- 숫자는 **보이는 그대로**(반올림·추정 ❌). 없으면 '0' 또는 '표시 안 됨'.

## 수집 ② 글별 성과
**통계 → 순위(인기글) 또는 글별 통계** 에서:
- **조회수 상위 글**을 위에서부터: `글 제목 | 발행일 | 조회수(30일)`.
- 가능하면 각 글의 **대표 유입검색어 1~2개**도 함께(그 글이 어떤 검색어로 들어왔는지).

## 수집 ③ (가능하면) 노출 0 글
- 발행했는데 **검색 유입이 거의 0인 글**도 제목·발행일로 몇 개 적어 준다(=체급 초과로 묻힌 글 → 컷 역산에 중요).

## 출력 (그대로 복사해 저장)
```
[경제 블로그 통계 · 수집일 <날짜> · 기간 최근30일]

■ 유입 검색어
| 검색어 | 유입수 |
| ... | ... |

■ 조회수 상위 글
| 제목 | 발행일 | 조회수 | 대표 유입검색어 |
| ... | ... | ... | ... |

■ 유입 거의 없는 글(있으면)
| 제목 | 발행일 |
```
- 이 결과를 **Drive `공장/데이터/통계/경제-블로그통계-<날짜>.md`** 에 저장(또는 대표에게 그대로 전달).

## 다음 (운영총괄이 함 — 어사이드 아님)
- 유입 검색어 각각의 **블로그 문서수**를 재서 → "유입 생긴 검색어의 문서수 분포" = **우리 체급이 노출되는 상한**을 뽑는다. → `/경제키워드10` 체급 컷(잠정 3만/30만)을 실제 수치로 교체.

## 절대 규칙
- **읽기·복사만.** 글 수정·발행·블로그 설정 변경 ❌. 비밀번호 직접입력 ❌(로그인 상태에서만).
- 숫자 **가공·추정 ❌**(보이는 그대로). 통계가 안 보이면 **멈추고 보고**(어느 화면에서 막혔는지).
