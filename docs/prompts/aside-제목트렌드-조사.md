# Aside 지시문 — 제목 트렌드 조사 (제목 고수 블로거)

목적: 경제·패션 **제목 고수 블로거들의 최근 제목**을 모아 요즘 제목 결(트렌드)을 파악한다. 모은 결과를 대표에게 보여 주고, 대표가 Claude에게 넘기면 '제목 공식'을 갱신한다.

지킬 것: **제목과 올린 날짜만** 적는다. 본문 문장·사진은 옮기지 않는다. 네이버 검색 결과 화면은 쓰지 않고, **블로그 홈 화면**만 본다. (CLAUDE.md: 허용된 통로로만, 문장·사진 복제 금지)

조건: Aside 브라우저에 대표 네이버 계정이 로그인돼 있어야 한다.

```text
아래 블로거들의 블로그 홈에 들어가서, 최근에 올라온 글 제목을 블로거마다 20~30개씩 모아 줘. 제목과 올린 날짜만 적고, 글 내용이나 사진은 옮기지 마.

━━━━━━━━ 경제 제목 고수 ━━━━━━━━
blog.naver.com/kka_dream (경제토르)
blog.naver.com/8starstarstar8 (유미)

━━━━━━━━ 패션 제목 고수 ━━━━━━━━
blog.naver.com/qkrrnfjqm (쿠니네패션)
blog.naver.com/ohye1991
blog.naver.com/jayuyu

[블로거마다 이렇게 적기]
■ (블로거 이름)
- (제목 그대로) · (올린 날짜)
- ...

그리고 블로거마다, 제목들을 보고 요즘 결을 짧게 요약해 줘:
1. 평균 글자 수(대략)
2. 작은따옴표/큰따옴표를 넣은 제목 비율, 물음표로 끝내는 비율
3. 자주 쓰는 말머리([  ] 꼬리표)·자주 쓰는 단어나 말투
4. 숫자를 쓰는 방식(전후 비교 '13억→26억', 퍼센트 '-60%', 가격, 나이 등)
5. 핵심을 가리는 표현('이 가격', '이렇게', '이름 가리기')을 쓰는지
6. 지난번과 달라진 점이 보이면 한 줄

다 적으면 전부를 나(대표)에게 그대로 보여 줘. 내가 Claude에게 넘겨서 '제목 공식'을 새로 뽑을 거야.
```

쓰는 법: Aside가 보여 준 내용을 대표가 복사해 Claude(또는 이 저장소 세션)에 주면, `econ/ref/titles/제목-공식.md`와 프로젝트 제목 지침(지피티-경제-제목·지피티-패션-제목)을 갱신한다. 한 달에 한두 번이면 충분하다(제목 결은 자주 안 바뀜).
