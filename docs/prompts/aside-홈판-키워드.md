## 할 일 (매일, 경제·패션 각각)
각 참고 블로거의 **최근 2일(또는 최근 몇 편)** 글에서 아래 4가지를 뽑는다:
1. **주제** — 무엇에 대해 썼나 (한 줄)
2. **키워드** — 사람들이 검색창에 칠 짧은 말 (2~4단어)
3. **제목 각도** — 어떤 훅으로 제목을 달았나 (공포/갈등/수치반전/반문 등)
4. **본문 각도** — 어떻게 풀었나 (정보 나열 / 사연 / 비교 / 전망 등)

→ 블로거별로 위 4개를 표나 목록으로. 끝에 **"겹쳐 뜬 키워드 TOP"**(여러 블로거가 동시에 민 것)을 추려 적는다.
