# Aside 지시문: 홈판·인기글에서 경제·패션 키워드 뽑아 도우미에 바로 넣기 (2026-10-07)

RSS로 못 잡는 네이버 홈판(추천 피드)·인기글 주제를 대표가 Aside로 모은다. Aside가 GitHub 이슈
`[경제키워드추가] 어사이드`·`[패션키워드추가] 어사이드`를 만들면 desk-button이 '네이버 인기' 점수(순위대로, 배점 35로 가장 큼)로 넣고 그날 목록을 다시 채점한 뒤, 오늘 자동 글이 아직이면 바로 1~3위로 글을 만든다(대표 결정 2026-10-07). 목록은 위에서부터 많이 나온 순서여야 한다.
문장·사진은 가져오지 않고 키워드(사실)만. 글은 우리 프롬프트로 새로 쓴다.
조건: Aside 브라우저에 대표 GitHub 계정이 로그인돼 있어야 한다. 처음 한 번은 Create 전에 Aside가 확인을 물을 수 있다.

```text
경제 블로그와 패션 블로그에 쓸 키워드를 모아서, 아래 두 주소에 각각 새 이슈로 올려 줘.

[1. 경제 키워드]
아래를 훑어 줘. 글이나 기사를 열어 봐도 되지만 문장은 옮기지 마.
- 네이버 블로그 홈(https://section.blog.naver.com)의 비즈니스·경제 인기글, 네이버 앱 홈판에 뜨는 경제 글
- 네이버 뉴스 경제 '많이 본 뉴스'
- 네이버 증권 '인기 검색 종목'
뽑는 것: 사람들이 검색창에 칠 만한 짧은 말(2~4단어). 예) 원달러 환율, 삼성전자 3분기 실적, 기준금리 동결, 금값 전망
규칙: 오늘·어제 화제만 / 여러 곳에 겹쳐 나온 것부터 / 특정 코인·종목 매수 권유, 리딩방·광고 글은 빼기 / 최대 10개

[2. 패션 키워드]
네이버 블로그 홈의 패션·미용 인기글과 네이버 앱 홈판에 뜨는 패션·스타일 글을 20편 정도 훑어 줘. 문장이나 사진은 옮기지 마.
뽑는 것: 인물(연예인 이름) + 아이템 + 브랜드(나와 있으면) + 가격(나와 있으면)
예) 전도연 블랙 오프숄더 드레스 샤넬 / 원희 버킷백 샤넬 1238만원
규칙: 최근 이틀 안의 글만 / 같은 주제는 하나로 합치고 많이 나온 순서대로 / 인물이 없는 일반 코디 글, 광고·협찬 글은 빼기 / 최대 10개

[적는 모양 — 두 목록 모두]
- 한 줄에 키워드 하나, 다른 설명·번호·기호 없이
- 쉼표(,)를 쓰지 마. 가격도 1238만원처럼 쉼표 없이
- 한 줄은 40자 안으로

[올리기]
경제 목록 → 이 주소를 열고, 본문(설명) 칸에 경제 목록만 붙여넣고 초록색 Create 버튼
https://github.com/mahatera9218-create/shorts-engine/issues/new?title=%5B%EA%B2%BD%EC%A0%9C%ED%82%A4%EC%9B%8C%EB%93%9C%EC%B6%94%EA%B0%80%5D%20%EC%96%B4%EC%82%AC%EC%9D%B4%EB%93%9C
패션 목록 → 이 주소를 열고, 본문 칸에 패션 목록만 붙여넣고 Create
https://github.com/mahatera9218-create/shorts-engine/issues/new?title=%5B%ED%8C%A8%EC%85%98%ED%82%A4%EC%9B%8C%EB%93%9C%EC%B6%94%EA%B0%80%5D%20%EC%96%B4%EC%82%AC%EC%9D%B4%EB%93%9C
제목 칸은 이미 채워져 있으니 건드리지 마.

다 올리면 나한테 두 목록을 그대로 보여 줘.
```

수동으로 넣을 때: 목록을 복사 → 발행 도우미 경제·패션 탭 ① 아래 입력칸에 붙여넣기 → ➕ 내 키워드 넣기.
