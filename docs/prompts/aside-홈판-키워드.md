# Aside 지시문: 네이버 홈판 인기글에서 키워드만 뽑기 (2026-10-07)

RSS로 못 잡는 네이버 홈판(추천 피드) 인기 주제를 대표가 Aside로 모아, 발행 도우미 ①의 '내 키워드 넣기'에 붙여 넣는다.
문장·사진은 가져오지 않고 키워드(사실)만. 글은 우리 프롬프트로 새로 쓴다.

```text
네이버 블로그 홈(https://section.blog.naver.com)과 네이버 앱 홈판에서 지금 많이 보이는 패션·스타일 글을 20편 정도 훑어 줘. 글을 열어 봐도 되지만 문장이나 사진은 옮기지 마.

글마다 이것만 뽑아 줘: 인물(연예인 이름) + 아이템(가방·코트·드레스 등) + 브랜드(나와 있으면) + 가격(나와 있으면)

규칙
- 최근 이틀 안에 올라온 글만
- 같은 주제가 여러 글에 나오면 하나로 합치고, 많이 나온 순서대로
- 인물이 없는 일반 코디·쇼핑 정보 글은 빼기
- 광고·협찬 글은 빼기

결과는 아래처럼 한 줄에 하나씩, 맨 위에 많이 나온 것부터 최대 10줄만. 다른 설명은 붙이지 마.
윤아 트렌치코트 버버리
전도연 블랙 오프숄더 드레스 샤넬
원희 버킷백 샤넬 1238만원
```

쓰는 법: 결과를 통째로 복사 → 발행 도우미 패션 탭 ① 아래 입력칸에 붙여넣기 → ➕ 내 키워드 넣기.
