# 어사이드 새벽 루틴 — 경제 '올인원' 테스트판 (2026-10-24~, 며칠 A/B)

목표: 유미 미러로 오늘 배치를 정하고, **지피티 「경제 자동화」 한 채팅에서 글+사진을 뽑고**, **제목은 클로드 「쿠니 경제」**가 뽑아, 네이버 임시저장까지. 대표는 발행 직전 제목만 고르고 발행.
※ 기존 '클로드 글' 루틴(aside-경제-루틴-자동.md)은 **대조군으로 그대로 둠**. 며칠 양쪽 비교해 노출 좋은 쪽을 메인으로.

안전선: **발행·로그인 자동화 금지.** 임시저장까지만. 유미 **제목·문장·사진 베끼지 않음**(주제·갯수만). 복제·가짜경험·사생활단정·투자권유 금지.

## 프로젝트 위치 (이름으로 찾아감)
- **글 + 사진:** 지피티 → 프로젝트 탭 **「경제 자동화」** (한 채팅에서 둘 다)
- **제목:** 클로드 → 프로젝트 탭 **「쿠니 경제」** (본문 붙여넣어 제목만)

## ⚠️ 공통
- **한 입력 = 한 결과.** 지피티는 '글'이면 본문만, '사진'이면 이미지만, '해부'면 3줄만. 클로드는 제목만. 각 답을 따로 받아 둔다.
- **부호 정리(붙이기 전):** `…`·`···`·`•••` → **`...`**, 곧은 따옴표 `'` `"` → 둥근 **`‘ ’` `“ ”`**.
- **편마다 지피티 새 채팅**(글+사진이 한 대화라 길어지니).

## A. 오늘 배치 정하기 (유미 미러)
1. 유미 RSS `https://rss.blog.naver.com/8starstarstar8.xml` 열어 **전날 18:00~오늘 새벽** 글을 **전문까지** 읽는다(보통 6편).
2. 오늘 쓸 **주제 목록 + 갯수**(보통 6) 정하고 **부동산 1개 추가**(틈새표/씨앗) → **총 7편.**

## B-1단계. 글 + 사진 (지피티 「경제 자동화」, 편마다 새 채팅)
3. 지피티 「경제 자동화」 **새 채팅**에 유미 글 '전문' 붙여넣기 → **본문**(완성 원고)만. (유미 글 없으면 주제 키워드 한 줄.)
4. 같은 채팅에 **`사진`** → 본문 `[사진N]`·캡션대로 **1번부터** 이미지 → `다음` 6번 = 7장. (각 그림에 번호 라벨.)
5. 같은 채팅에 **`해부`** → `[미러 해부]` 3줄(소재/각도/핵심키워드, 시트용).
→ 편별 {본문 / 사진7 / 해부} 확보. 다음 편은 **새 채팅**으로.

**★ 병렬(속도):** 지피티 채팅 **탭 2~3개**로 편을 분산한다 — 탭A=편1(글→사진), 탭B=편2, 탭C=편3 동시에. 한 탭 사진 그리는 동안 다른 탭 진행.

## B-2단계. 제목 (클로드 「쿠니 경제」)
6. 각 편 **본문을 클로드 「쿠니 경제」에 붙여넣기** → `[제목 후보]` 5개 + ★ 최종 1개. 메모칸용으로 받아 둔다.
   (사진 그려지는 동안 먼저 끝난 편 본문으로 제목 돌리면 시간 겹쳐 아낌.)

## B-3단계. 네이버 조립·임시저장 (7편)
7. 경제 블로그 글쓰기 → **임시저장**:
   - 제목칸: ★ 최종(또는 후보 1번) 임시로.
   - **본문칸: 3번 '글' 답 그대로** 붙이고, `[사진N — 설명]` **라벨 줄만** 그 사진으로. **캡션 한 줄(텍스트)은 그대로 둔다**(네이버 4원칙).
   - 맨 위 메모칸: "■제목후보" 5개(+★) + "■미러해부" 3줄. (메모는 본문에 안 넣음.)
   - 서식(아래) → **임시저장만. 발행 절대 금지.**
   - 구글시트 한 줄 기록(아래).

## ★ 겹쳐 돌리기
1→2→3 꼭 차례로 안 해도 됨. 사진 그려지는 동안 → 먼저 끝난 편 제목(2단계)·조립(3단계)을 미리. 기다리는 시간을 다른 탭 일로 메운다.

## 서식 (⚠️ 깨지기 쉬움, 처음엔 끄고 검증 후)
- 표: `[표: …]` 줄 아래 `| 구분 | 값 |` 격자를 네이버 표 기능으로 옮기고 `[표: …]` 줄 삭제(글마다 1개).
- 소제목: 인용 버튼 + 볼드. 정렬: 전체선택 → 가운데(빼려면 이 줄 삭제).

## 구글시트 기록
시트 **「쇼츠엔진-경제-로그」**/`경제로그` 탭, 편마다 한 행:
`A 날짜 | B 유미글(주제) | C 소재 | D 각도 | E 핵심키워드 | F 제목후보(5개,줄바꿈) | G 선택제목(대표가) | H 임시저장✓`
- C·D·E = 해부 3줄. 쓰기 불안하면 그 행은 "수기확인"만 남기고 넘어감(임시저장 먼저).

## C. 마무리
8. "오늘 N+1편 임시저장 완료 + 시트 N행"과 주제 목록 보고.

## 대표 (아침, 폰)
각 임시저장 → ★ 제목 확정 + 메모 지우기 → 사진·본문 훑기 → 발행(띄엄띄엄). 고른 제목 시트 G열에 기록.
