# Aside 지침: 경제 블로그 글 구조 분석 (2026-10-04)

대표가 데스크톱 Aside에 그대로 붙여 넣는 지침. 결과 md를 Claude에게 주면 우리 글 양식(스킬)으로 만든다.

```text
너는 블로그 글 구조 분석가야. 아래 네이버 블로그들의 글을 직접 열어 읽고, "글을 어떻게 짜는지(구조)"만 분석해서 마크다운(md) 파일 하나로 답해줘.

[대상 블로그]
1. 메르: https://blog.naver.com/ranto28
2. 킴찹: https://blog.naver.com/ssibar1188
3. 재클쌤의 경제7스푼: https://blog.naver.com/lancelot85
4. 찐주부J의 생활금융: https://blog.naver.com/ekdud0706
5. 이우유의 머니 패스포트: https://blog.naver.com/by-habit

[고르는 글]
- 블로그마다 최근 1개월 글 중 4편. 공감·댓글이 많은 글 우선.
- 가능하면 종류를 섞어: 시황 / 오늘의 이슈·사건 / 기본기(예적금·ISA·ETF 같은 개념 설명) / 종목.

[반드시 지킬 것]
- 글의 문장을 그대로 옮기지 마. 5단어 이상 연속 인용 금지. 제목도 그대로 쓰지 말고 "패턴"으로 바꿔 적어 (예: "[자산] + [변화 숫자] + 이유는?").
- 숫자, 개수, 위치, 패턴, 순서만 적어.
- 모르는 칸은 "확인 못 함"이라고 적어. 추측하지 마.

[글 1편마다 적을 것]
- 주소, 날짜, 글 종류(시황/이슈/기본기/종목/기타), 공감·댓글 수(보이면)
- 제목 패턴, 제목 길이(대략 글자 수), 질문형인지, 숫자가 있는지
- 전체 길이(대략 글자 수), 문단 수, 문단 1개 평균 줄 수
- 첫 문단이 하는 일: 결론 먼저 / 질문 던지기 / 배경 / 숫자 제시 / 개인 이야기 (해당하는 것 모두)
- 답(핵심 결론)이 처음 나오는 위치: 첫 문단 / 앞부분 1/3 / 중간 / 끝
- 소제목: 개수, 모양(질문형/명사형/번호/이모지), 순서대로 각 소제목의 "역할"만 (예: 배경 → 원인 → 전망 → 내 생각)
- 사진·이미지: 개수, 종류(직접 만든 차트/캡처/표 이미지/사진/움짤), 각각 어디에 놓였는지
- 표: 있는지, 몇 개, 무엇을 정리했는지
- 강조: 굵게, 색 글씨, 인용구 박스, 구분선, 요약 박스, 목차 — 쓴 것과 위치
- 목록(번호·글머리표) 사용 여부와 위치
- 출처 표기: 있는지, 어떤 식으로, 어디에
- 다른 글로 이어지는 링크(내부 링크): 개수, 위치
- 끝맺음이 하는 일: 요약 / 글쓴이 의견 / 댓글 유도 / 이웃추가·구독 유도 / 다음 글 예고 / 면책 문구
- 광고·협찬 표기: 있는지, 위치, 방식
- 말투: 주로 끝나는 말(~다 / ~요 / ~음·함 / 섞임), 문장 길이(짧음/보통/김), 1인칭 사용 여부
- 오래 머물게 하는 장치(목차, 요약, 퀴즈, 질문, 시리즈 표시 등)

[마지막에 종합]
1. 블로그마다 "글 양식"을 섹션 순서로 한 줄씩 (예: 질문형 제목 → 결론 2줄 → 숫자 표 → 소제목 3개 → 의견 → 요약 → 댓글 유도)
2. 5개 블로그의 공통점 5개, 차이점 5개
3. 아래 조건의 블로그에 가장 맞는 "추천 양식" 1개를 섹션 순서와 각 섹션 길이로 제안:
   - 정보·정리형 종합 경제 블로그 (국내주식·미국주식·금·코인·돈 굴리기)
   - 질문형 제목, 답은 본문 맨 위, 투자 권유 안 함, 계산 글 안 씀, 무료 사진만
   - 하루 2편 (아침 시황 1 + 그날 화제 이슈 1)

[답변 형식]
- 파일 이름: 경제블로그-글구조-분석.md
- 맨 위에 "# 경제 블로그 글 구조 분석 (날짜)"
- 블로그별 "## 블로그 이름" 아래 글마다 "### 글 1" 식으로, 항목은 표나 목록으로
- 마지막에 "## 종합"
```
