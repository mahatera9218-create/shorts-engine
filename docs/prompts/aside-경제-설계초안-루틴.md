# 어사이드 새벽 루틴 — 경제 '클로드 설계 → 지피티 초안' (2026-10-24~, 며칠 A/B)

분업: **클로드 「쿠니 경제」 = 설계(해부·구성·분석·정리·제목)**, **지피티 「경제 자동화」 = 그 설계로 본문 초안 + 사진.** 네이버 임시저장까지. 대표는 발행 직전 제목만 고르고 발행.
※ 기존 '클로드가 글까지 쓰는' 루틴(aside-경제-루틴-자동.md)은 **대조군으로 보존**. 며칠 양쪽 비교해 노출 좋은 쪽을 메인으로.

안전선: **발행·로그인 자동화 금지.** 임시저장까지만. 유미 제목·문장·사진 베끼지 않음(주제만). 복제·가짜경험·사생활단정·투자권유 금지.

## 프로젝트 위치 (이름으로)
- **설계(해부·구성·정리·제목):** 클로드 → 프로젝트 탭 **「쿠니 경제」**
- **본문 초안 + 사진:** 지피티 → 프로젝트 탭 **「경제 자동화」**

## ⚠️ 공통
- **한 입력 = 한 결과.** 클로드는 설계서만, 지피티는 '글'이면 본문만·'사진'이면 이미지만. 각 답 따로 받음.
- **부호 정리(붙이기 전):** `…`·`···`·`•••` → `...`, 곧은 따옴표 → 둥근 `‘ ’` `“ ”`.
- **지피티는 편마다 새 채팅**(글+사진이 한 대화라 길어지니).

## A. 오늘 배치 정하기 (유미 미러)
1. 유미 RSS `https://rss.blog.naver.com/8starstarstar8.xml`로 **전날 18:00~새벽** 글을 **전문까지** 읽는다.
2. 오늘 **주제 7편**(보통 6 + 부동산 1) 정한다.

## B-1단계. 설계 (클로드 「쿠니 경제」)
3. 클로드 「쿠니 경제」에 유미 글 '전문' 붙여넣기(없으면 키워드) → **설계서 1장**이 나온다:
   `[미러 해부]` + `[제목 후보] 5+★` + `[구성]` + `[정리]`.
4. 설계서를 **통째로 받아 둔다**(지피티에 넘길 것 + 메모·시트용).

## B-2단계. 본문 초안 + 사진 (지피티 「경제 자동화」, 편마다 새 채팅)
5. 지피티 「경제 자동화」 **새 채팅**에 **클로드 설계서를 붙여넣기** → **본문 초안**(완성 원고)만. 지피티가 `[구성]`대로 `[정리]` 재료로 씀.
6. 같은 채팅에 **`사진`** → 본문 `[사진N]`·캡션대로 1번부터 → `다음` 6번 = 7장.
→ 편별 {설계서 / 본문 / 사진7} 확보. 다음 편은 새 채팅.

**★ 병렬(속도):** 클로드에서 설계서를 **여러 편 먼저 뽑아** 두고, 지피티 채팅 **탭 2~3개**로 편을 분산(탭A=편1 글→사진, 탭B=편2…). 한 탭 그리는 동안 다른 탭 진행.

## B-3단계. 네이버 조립·임시저장 (7편)
7. 경제 블로그 글쓰기 → **임시저장**:
   - 제목칸: 설계서 **★ 최종**(또는 후보 1번) 임시로.
   - **본문칸: 5번 '본문' 그대로** 붙이고, `[사진N — 설명]` 라벨 줄만 그 사진으로. **캡션 한 줄(텍스트)은 그대로 둔다.**
   - 맨 위 메모칸: "■제목후보" 5+★ / "■미러해부" 3줄(설계서에서). 본문엔 안 넣음.
   - 서식(아래) → **임시저장만. 발행 절대 금지.**
   - 구글시트 한 줄 기록(아래).
