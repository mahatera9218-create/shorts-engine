# [플랜B · 보관] 키워드 선정 — 강사 울타리 + 깔때기 (6편 혼합)

> **상태: 비활성(플랜B).** 2026-11-19 대표 결정으로 **A안(부동산 대장 전수)**이 기본이 됨. 이 방식은 **대장 전수가 안 통하거나(홈판 비중 급락 등) 되돌릴 때** 꺼내 쓰는 보관본. 활성 루틴은 `aside-경제-루틴-자동` A단계.

## 언제 이걸로 되돌리나
- 홈판 비중이 50%대로 떨어져 '부동산 홈판 올인'이 깨질 때
- 부동산 대장 소재가 구조적으로 마를 때
- 종목·정책 검색 바닥을 다시 비중 있게 밀어야 할 때

## 모델 (당시 활성본)
**하루 6편 = 부동산 3 + 나머지 3, 모두 강사 월간 리스트 범위 안.**

| 부동산 3편 (홈판) | 나머지 3편 (검색) |
|---|---|
| 강사 부동산 섹션 ∩ 이슈단지 2 + 미러 1 | 강사 종목·정책 섹션 ∩ 이벤트달력 2 + 미러 1 |

- **울타리:** 모든 키워드는 `docs/keywords/강사-키워드-<월>.md` 범위 안에서만.
- **이벤트 달력 = 타이밍**(강사 키워드 중 D-2~3 임박한 것 우선).

**깔때기 (후보 → 6개):**
1. 하드컷: 강사 범위 밖 / 검색량 1만 미만 / 어제 중복 / 최근 쓴 단지 / 미정·루머 탈락.
2. 점수(부동산·나머지 기준 다름):
   - 부동산(홈판): 이슈 강도 · 경쟁강도 낮을수록 · 대중수요 뜬 테마.
   - 나머지(검색): 검색량 클수록 · 경쟁강도 낮을수록 · 이벤트 임박.
3. 칸별 top: 부동산=이슈단지 top2+미러 top1 / 나머지=달력 top2+미러 top1 + 쏠림 조정.
4. 폴백: 샘 마르면 미러 → 틈새표(강사 범위 안).

- **미러 역할:** 키워드 2편(부동산1+나머지1) + 제목 유형 학습.

## 근거 메모
이 방식은 '종목·정책을 검색 바닥으로 깐다'는 가정 위에 섬. 2026-11 성과 데이터(6주)에서 **부동산 단지 글당 500~1,700 vs 종목·금·연금 글당 20~100**으로 격차가 극단적이라, 단기 최적은 부동산 올인으로 판명 → A안으로 전환. 단 검색 바닥의 **장기** 효과는 그 데이터로 확인 불가라, 되돌릴 여지를 위해 이 보관본을 남김.
