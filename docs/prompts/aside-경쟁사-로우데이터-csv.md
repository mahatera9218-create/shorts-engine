# Aside 지시문 — 경쟁사 블로그 로우데이터 CSV 수집 (최근 50편)

목적: 미러 대상(경제소녀 등) 블로그에서 **글별 반응 수치(공감·댓글)**까지 긁어 **CSV**로 받아, Claude가 "어떤 제목·주제가 실제로 먹혔는지"를 숫자로 분석한다. (RSS는 제목·도입만 주고 반응 수치는 안 줘서, 이게 필요.)

## 대상 (기본 = 경제소녀)
- 경제소녀: **m.blog.naver.com/mmoo0314** (부동산 미러 1순위)
- (다른 블로거도 같은 방식 — URL만 바꾼다. 예: 경제토르 kka_dream, 유미 8starstarstar8)

## 안전선 (CLAUDE.md — 타인 콘텐츠)
- **공개 페이지에 보이는 사실·숫자(제목·날짜·공감수·댓글수)만** 적는다 = 인용 OK.
- **본문 문장·사진은 복제·저장하지 않는다.** (본문은 '한 줄 요지'로 직접 요약만, 통째 복붙 금지.)
- 사람이 보는 화면 값을 **수기 수집**(무단 크롤링·검색결과 크롤링 아님). 로그인 자동화 금지.
- 못 찾은 값은 빈칸 두고 "못 찾음" 표시.

---

```text
경제소녀 블로그(m.blog.naver.com/mmoo0314)의 최근 글 50개를 CSV로 정리해 줘.
남의 블로그니까 제목·날짜·공감수·댓글수 같은 '보이는 숫자'만 가져오고, 본문 문장·사진은 복사하지 마(내용은 한 줄 요지로 네가 요약만).

■ 방법
1. 블로그 '글 목록(전체보기)'을 최신순으로 연다.
2. 위에서부터 50개. 목록에서 공감·댓글 수가 안 보이면 글을 하나씩 열어서 확인한다.
3. 각 글에서 아래 값을 뽑는다(조회수는 남의 블로그라 안 보이면 빈칸):

■ CSV 형식 (맨 윗줄 헤더 그대로, 쉼표 구분. 제목에 쉼표 있으면 큰따옴표로 감싼다)
번호,발행일시,카테고리,제목,공감수,댓글수,본문요지(한줄),URL
1,2026-10-24 20:57,비지니스 경제,"“은행 돈 1원도 없이…” 120억 신고가 ‘이 아파트’",,,반포 원베일리 105억→120억 신고가,https://blog.naver.com/mmoo0314/224452390310
2,...

■ 규칙
- 제목은 글자 그대로(가림·따옴표 포함).
- 공감수·댓글수는 숫자만. 안 보이면 빈칸.
- 본문요지는 '어느 단지·무슨 사건·숫자 전후' 한 줄로 네가 요약(원문 문장 복붙 금지).
- 50줄 다 채운다. 중간에 광고·제휴·정보성 글(IT리뷰·지원금 등)도 카테고리 그대로 적되 빼지 말 것(분석 때 거른다).

■ 저장/전달
- 완성된 CSV를 GitHub 이슈에 올린다:
  https://github.com/mahatera9218-create/shorts-engine/issues/new?title=%5B%EB%A1%9C%EC%9A%B0%EB%8D%B0%EC%9D%B4%ED%84%B0-%EA%B2%BD%EC%9F%81%EC%82%AC%5D%20%EA%B2%BD%EC%A0%9C%EC%86%8C%EB%85%80
  (제목 칸은 그대로 두고, 본문 칸에 CSV 전체 붙여넣고 초록 Create)
- 그리고 CSV 전체를 대표에게도 그대로 보여 준다.
- 안 보이던 값(공감·댓글·조회수)이 있으면 맨 아래 "○○는 화면에 안 보여 못 가져옴"이라고 적는다.
```

## 수집 후 — Claude 분석 (대표가 "분석해줘" 하면)
CSV를 받아 아래를 뽑는다:
- **반응 TOP/BOTTOM** — 공감·댓글 높은 글 vs 낮은 글의 **제목·주제 차이**(어떤 훅·소재가 먹혔나).
- **주제 분포** — 신고가/급락/분양/호재/사건 비율, 어느 쪽 반응이 센가.
- **제목 패턴 × 반응** — 가림·숫자전후·대사·반전 유무에 따른 공감·댓글 차이.
- **발행 패턴** — 요일·시간대, 하루 몇 편.
- → 결과를 `reports/`에 남기고, 먹히는 패턴을 `클로드-경제-설계.md`에 반영.
