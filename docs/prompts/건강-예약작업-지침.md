# 건강 블로그 예약작업 지침 (매일 2편 자동 생성) — 대표 2026-10-18

이 문서는 **매일 돌아가는 클로드 예약 작업**이 따를 지침이다. 경제 '구글글' 예약작업과 같은 방식(API 없이 클로드 세션이 초안 생성→저장→푸시).

## 무엇을
- 건강 블로그(갱년기 축)의 **발행 패키지 초안 2편**을 생성해 `reports/건강글-초안/<slug>.md`에 저장하고 main에 커밋·푸시.
- 키워드·제목은 **세션이 직접 선정**(대표 개입 없음). 축은 갱년기(DECISIONS 2026-10-18).

## 방향 (중요 — 대표 2026-10-18)
- **'여자 갱년기 증상'처럼 넓은 주제는 지양.** 넓은 허브글은 이미 있다. 갱년기 **안에서 좁은 세부 키워드**로 판다.
- 글은 아래 **독자 3부류** 중 하나를 겨냥한다(각 글이 누구를 위한 것인지 분명히). config/health_topics.yaml의 `seg`가 그 부류:
  - **seg1 = 이미 갱년기인 사람** → 지금 겪는 증상의 **완화·관리 how-to**(예: "열감 밤에 심할 때", "손가락 마디 관절통").
  - **seg2 = 갱년기를 앞둔 사람(40대 초중반)** → **준비·예방**(예: "폐경 전 생리불순", "뼈 건강 미리").
  - **seg3 = 갱년기인지 의심 중인 사람** → **자가 점검·감별**(예: "자가진단 체크리스트", "이 증상이 갱년기일까", "갑상선·우울증과 구분"). 검색 유입이 가장 커 우선순위 높음.
- 제목·도입은 그 부류의 '지금 상황·질문'에 꽂는다. 넓게 다 담으려 하지 말 것.

## 순서
1. `config/health_topics.yaml`의 `pending`에서, 아직 `reports/건강글-초안/<slug>.md`가 **없는** 주제를 위에서부터 **2개** 고른다.
2. 각 주제에 대해 `prompts/project/건강-블로그-홈판-프롬프트.md`를 그대로 따라 실행한다(턴1~3을 한 번에):
   - **턴1**: WebSearch/WebFetch로 **공식 의학기관 출처**(질병관리청·국가건강정보포털·건보공단·대한폐경학회·대학병원·식약처, 메이저 건강매체는 보조) 조사 → **F목록(근거 등급 태그)** + 출처 10개 이상. 제목 45개를 속으로 만들고 **최종 1개를 세션이 직접 선정**(SEO형·검색 롱테일 우선 — 건강은 검색 버팀목).
   - **턴2**: 본문 1200~1500자(해요체·공감 서사·병원 권유 마무리) + **팩트체크(F대조)** + 다듬기. 효능 단정·진단·처방·공포·제품 홍보 금지.
   - **턴3**: 이미지 프롬프트(실사 + 한글 인포 썸네일). 이미지 생성은 대표가 함(여기선 프롬프트만).
3. 저장 형식: `reports/건강글-초안/<slug>.md` 에
   - 맨 위 한 줄 `검증: 확인됨|부분확인|미확인` (숫자·효능을 공식 출처로 대조한 결과)
   - 선정 키워드·제목, 발행 본문(제목→본문→해시태그10, 순수 텍스트), 그 아래 `--- 이미지 프롬프트 ---` 블록, 그 아래 `--- 출처(F목록) ---`.
4. `config/health_topics.yaml`에서 생성한 주제를 `pending`→`done`으로 옮긴다. `pending`이 6개 미만이면 **갱년기 롱테일 10개를 보충**(정보형, 영양제 효능/제품 키워드 제외).
5. main에 커밋·푸시(커밋 메시지 "건강글 초안 YYYY-MM-DD"). 모델 식별자·키는 쓰지 않는다.

## 안전(필수)
- 효능 단정·치료 보장·진단·처방·공포 조장 금지. 전언·완화체("~에 도움이 된다고 알려져 있어요"). 증상 글은 **병원 권유 마무리** 필수.
- 특정 건강기능식품 브랜드·병원 홍보 금지. 숫자·권장량은 공식 기관·연도 표기, 확인 못 하면 쓰지 않음.
- 가짜 경험·가짜 후기 금지(CLAUDE.md). 경험담은 일반 패턴만, 구체 병명·수치·치료결과 생성 금지.

## 대표가 하는 것(자동 아님)
- 초안 검토 → 이미지 생성(이미지 프롬프트를 GPT/제미나이에 붙여넣기) → 네이버에 복붙 발행(하루 2편). 네이버는 자동 발행 API가 없다.
