# 어사이드 "조합" 지시문 — 패션 블로그

하루치 패션 글·사진을 **네이버 임시저장**에 한 번에 쌓는 어사이드 지시문.
경제와 거의 같지만 **사진 출처가 다르다** — 패션 사진은 그록이 찾은 **실사**다.

## 언제 쓰나
패션 프로필에서 그날 AI 채팅(그록 조사·사진 → 클로드 글)을 다 끝내고,
각 글·사진의 **마지막 메시지 끝에 `*ㄱ키워드`**를 달아둔 뒤, **하루 끝에 한 번** 어사이드에 아래 블록을 붙여넣는다.

## 준비 (대표)
- 어사이드를 **패션 프로필**로 열고, 그 프로필에 **패션 블로그 네이버**가 로그인돼 있을 것
- 어사이드에 **클로드 + 그록** 연결돼 있을 것
- 각 글: 클로드 "패션 글" 탭에서 **본문 맨 끝 줄에 `*ㄱ키워드`** (예: `*ㄱ신민아경량패딩`)
- 각 사진: 그록 "패션 조사" 탭에서 사진(②관련 사진)까지 다 나온 뒤 **마지막 메시지 끝에 `*ㄱ키워드`** (글과 **같은 키워드**!)
- 본문 안 사진 자리에는 `[사진1]` `[사진2]` … 표시

## 어사이드에 붙여넣기 ↓↓↓

```
오늘 날짜 대화만 본다. 끝에 *ㄱ 가 붙은 것만 수집한다. 어제 이전이거나 *ㄱ 없는 건 무시한다.
*ㄱ 뒤 키워드가 같은 것끼리 글 하나로 묶는다.

[글] 클로드 "패션 글" 탭: *ㄱ 로 끝나는 본문을 가져온다. 맨 끝 *ㄱ키워드 줄은 뺀다.
[사진] 그록 "패션 조사" 탭: 같은 키워드 *ㄱ 로 끝나는 대화의 사진(실제 셀럽 사진)을 가져온다.

패션 블로그 네이버 글쓰기 → 임시저장 화면을 연다.
제목은 비워 둔다.
본문을 붙여넣고, 본문 안 [사진1]·[사진2]… 자리에 사진을 순서대로 넣는다. (자리 표시가 없으면 본문 끝에 순서대로)
임시저장만 누른다. 발행은 절대 누르지 마라.
키워드가 여러 개면 글마다 따로 임시저장한다.
다 끝나면 '키워드별로 몇 개 임시저장했는지' 알려준다.
```

## ⚠️ 패션만 특별히 (대표)
- 그록이 가져온 건 **실사**라 **출처·초상권 확인이 필요**하다. 어사이드가 넣은 사진 중 **쓸 것만 남기고** 나머지는 네이버 임시저장에서 뺀다.
- 그록 조사 탭엔 참고용·초안 이미지도 섞여 들어올 수 있으니, **임시저장 단계에서 한 번 거른다.**

## 끝난 뒤 (대표)
네이버 임시저장 열어서 → **사진 출처 확인·추리기** → **제목 쓰고** → **발행 버튼.**
