# Aside 지시문: 착장 글 네이버 임시저장 (2026-10-10)

대표 결정: 착장 도우미에서 만든 글을 어사이드가 대표 PC에서 패션 블로그(tenbillionsound)에 **임시저장**까지(발행은 대표).
사진 자리는 '📷 사진 n (설명)' 문구 그대로 둔다. 사진은 대표가 넣는다.
조건: 어사이드 브라우저에 대표 네이버 계정이 로그인돼 있어야 한다.

```text
착장 도우미의 오늘 글을 내 네이버 패션 블로그에 임시저장해 줘. 발행은 절대 하지 마.

1. https://eok-econ-desk.pages.dev/outfit/ 를 열고 '오늘 착장 글' 목록을 봐.
2. 목록의 글마다 아래를 반복해:
   a. 글 제목을 눌러 글 화면을 열어.
   b. '제목' 칸의 '제목 복사' 버튼을 눌러 제목을 복사해.
   c. 새 탭에서 https://blog.naver.com/tenbillionsound 의 글쓰기(PC 에디터)를 열어. 제목 칸에 붙여넣어.
   d. 착장 도우미 글 화면으로 돌아가 '본문' 칸의 '본문 복사' 버튼을 눌러.
   e. 네이버 에디터 본문에 붙여넣어. 글자 서식이 따라오면 서식 없이 붙여넣기(Ctrl+Shift+V)로 다시 해.
   f. '📷 사진 1 (…)' 같은 사진 자리 문구는 지우지 말고 그대로 둬. 사진은 내가 넣을 거야.
   g. 에디터 위쪽 '저장'(임시저장)을 눌러. '발행'은 누르지 마.
   h. 저장됐다는 표시를 확인하고 다음 글로.
3. 이미 임시저장한 글(같은 제목이 임시저장 목록에 있음)은 건너뛰어.
4. 다 끝나면 임시저장한 글 제목 목록을 보여 줘.

[막히면] 네이버 로그인 화면이 나오거나, 인증(문자·보안문자)을 요구하거나, 에디터가 안 열리면 그 자리에서 멈추고 무엇이 필요한지 말해 줘.
비밀번호는 직접 입력하지 마. 발행 버튼은 어떤 경우에도 누르지 마.
```
