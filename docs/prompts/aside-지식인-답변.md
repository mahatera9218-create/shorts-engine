# Aside 지시문 — 지식iN 답변 "찾기·초안만" (게시는 사람이)

목적: 지식iN에서 우리가 **진짜 도움 줄 수 있는** 세금·건강보험·연금·부동산 질문을 찾아, 성실한 답변 **초안**을 큐에 쌓는다. **어사이드는 절대 직접 답글을 올리지 않는다.** 게시는 대표가 큐를 보고 손으로, 사람 속도로 한다.

**왜 자동 게시 안 하나:** 자동으로 답글을 다는 계정·같은 링크 반복은 네이버 스팸 필터의 대표 감지 대상 → 아이디 정지. 그 아이디가 날아가면 네이버 블로그 계획까지 죽는다. 그래서 "찾기·초안"만 자동, "게시"는 사람이 거른다. (DECISIONS 2026-10-18, 외부유입 조사와 같은 선)

전제: Aside 브라우저에 대표 네이버 계정 로그인. 로그인·보안·결제 화면이 나오면 멈추고 대표에게 묻는다. **읽기·검색·초안 작성까지만. 답변 등록·댓글 작성 버튼은 절대 누르지 않는다.**

```text
지식iN에서 내가 도와줄 수 있는 질문을 찾아 답변 초안만 만들어 줘. 절대 직접 등록하지 마(등록·답변 버튼 누르지 마). 로그인·보안 화면 나오면 멈추고 알려 줘.

1) 질문 찾기
- kin.naver.com 에서 아래 키워드로 '최신' 순 검색: 피부양자 자격, 건강보험 지역가입 전환, 1세대 1주택 양도세, 종합부동산세, 취득세 계산, 증여세 공제, 상속세, ISA 계좌, 연금저축 세액공제, 종합소득세 신고.
- 다음 조건을 모두 만족하는 질문만 고른다: ① 아직 채택 답변이 없거나 답변이 부실함 ② 최근 7일 이내 ③ 우리가 공식 기준으로 정확히 답할 수 있음 ④ 광고·과제 대행·도배성 질문이 아님.
- 하루 최대 8개만 고른다. 고른 질문 목록(제목·링크·질문 요지)을 먼저 나에게 보여 줘.

2) 답변 초안 쓰기 (질문마다)
- 질문자의 상황에 맞춘 성실한 답변을 쓴다. 공식 기준(국세청·건강보험공단·국가법령)에 근거하고, 확실하지 않은 숫자는 단정하지 말고 "공단/국세청 확인 권고"로.
- 가짜 경험("제가 해봤는데")·세무사 사칭 금지. 광고 말투 금지. 사람이 쓴 것처럼 담백하게.
- astacgroup 링크는 **정말 도움될 때만, 답변 맨 끝에 1개**. 해당 판정 도구가 있을 때만:
  · 피부양자 → https://astacgroup.com/tools/dependent-nhis
  · (그 외 관련 도구/글이 분명할 때만 해당 주소, 애매하면 링크 없이)
- 링크 없이도 답이 완결되게 쓴다. 링크는 "더 자세히 따져볼 수 있는 도구" 정도로만.

3) 큐에 저장
- 각 초안을 아래 양식으로 만들어 reports/지식인-답변-queue.md 에 붙일 수 있게 정리해 나에게 텍스트로 줘(파일 수정은 안 해도 됨, 내가 복사한다):
  ## [날짜] 질문제목
  - 링크: (지식iN 질문 URL)
  - 상황: (질문 요지 1줄)
  - 답변 초안:
    (본문)
  - 링크 포함: (있음/없음) · 상태: 대기

4) 끝나면 몇 개 찾았고 몇 개 초안 썼는지, 링크 넣은 건 몇 개인지 보고해. 등록은 하지 않았다고 분명히 적어.
```

## 대표가 할 일 (게시)
- 큐(`reports/지식인-답변-queue.md`)를 보고 **진짜 맞는 것만** 골라 지식iN에 직접 답변 등록.
- **하루 2~3개 이하, 띄엄띄엄.** 한 번에 몰아서 올리지 않는다(스팸 신호).
- 링크는 정말 도움되는 답변에만. 매 답변에 링크를 다는 건 피한다.
- 올린 것은 큐에서 '상태: 게시함(날짜)'으로 표시.
