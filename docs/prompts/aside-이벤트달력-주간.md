# 어사이드 — 경제 이벤트 달력 (주 1회 수집: 그록 「이벤트달력」 → 드라이브) · 2026-11-17 신설

**목적:** 주 1회, **그록 「이벤트달력」 프로젝트**를 돌려 **다음 2~4주 경제 예정 일정**을 받아 **드라이브에 저장**한다. 이게 매일 루틴의 **비(非)부동산 2편(검색 바닥용)** 키워드 소스.

**왜 어사이드가 하나:** 그록은 조사(웹)만 하고 드라이브에 직접 못 올린다. **어사이드가 손** — 그록 결과를 받아 드라이브에 저장하는 역할. (그록=조사 / 어사이드=저장 / 드라이브=공유 창고)

## 언제
- **주 1회(월요일 아침 권장).** 매일 ❌, **주 1회만.** (지난주 달력에 새 2주가 이어지게.)

## 할 일
1. **그록 「이벤트달력」 프로젝트를 연다.** (수집 지시문은 그 프로젝트에 이미 저장돼 있음 — 비어 있으면 `그록-이벤트달력-주간.md` 내용을 붙여넣어 둔다.)
2. **"이번 주 기준 다음 2~4주 일정 긁어줘"** 한 줄로 실행 → 그록이 5축 일정 **표**를 낸다.
3. **그 표를 그대로** 드라이브에 저장 → **`공장/데이터/키워드/이벤트달력-<이번주 월요일 날짜(YYYY-MM-DD)>.md`**
   - 같은 주 다시 돌리면 **덮어쓰기.** 지난주 파일은 **남긴다**(시계열).
   - 표 양식: `| 이벤트명 | 날짜 | 카테고리 | 핵심 검색어 | 메모 |` (그록이 준 그대로. 문장·사진 복제 ❌, 날짜·검색어만.)
4. **표가 비었거나 날짜가 이상하면** 그 자리에서 멈추고 보고.

## 막히면
그록·네이버·드라이브가 **로그인·보안문자**를 요구하거나 화면이 안 열리면 **멈추고 보고.** 비밀번호 직접 입력 ❌. 미확정 날짜는 **'미정'**으로 두되 지어내지 않는다.

## 쓰임 (뒷단)
- **매일** 작업창(`aside-경제-루틴-자동`)이 이 파일에서 **D-2~3 도래 이벤트**를 꺼내 → 틈새표(검색량·경쟁강도) 교차로 **비부동산 2편** 키워드.
- **클로드 「경제 분석」**도 이 파일을 읽어 "이번 주 뭐가 예정돼 있나" 브리핑에 쓴다.

## 선
그록 웹 요약만(검색결과 크롤링 ❌), 사실(날짜·이벤트·검색어)만, 발행·로그인 자동화 ❌.
