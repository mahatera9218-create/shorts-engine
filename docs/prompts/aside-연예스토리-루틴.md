# 어사이드 자동 루틴 — 연예스토리(가십 전담 블로그) (2026-10-29)

> ★ **재편(2026-11-12 대표 확정):** 이 가십 루틴이 도는 블로그 = **기존 '연예패션 남는 블로그' 계정을 가십 전담으로 이관한 것.** 패션 블로그(캐시미어다이어리)와 **다른 계정.** 비정기(대표 MSN 소스 줄 때만). 아래 '3번째 블로그' 표현은 이 가십 블로그를 가리킴.

목표: 어사이드가 **화제 연예인**을 잡아, 그록(사건 A·B 조사·사진) + 클로드(제목+글, 해요체) + 지피티(보완 사진)로 **한 세트를 완성해 네이버 임시저장**. 대표는 발행 직전 제목만 고르고 출처 확인 후 발행.
안전선(대표 책임): 발행·로그인 자동화 금지(임시저장까지). 실제 사진 출처·초상권은 대표 확인. ※ 리스크(사실성·명예) 판단은 대표 몫.
**로그아웃이면 멈추고 보고**(네이버·인스타 로그인 대표 수동).

## 프로젝트 위치 (★3번째 블로그 전용 — 경제·패션과 다른 계정·프로젝트)
- **사건 조사·사진 URL·공식 인스타:** 그록 → 프로젝트 탭 **「연예스토리 조사」**
- **제목 + 글(해요체):** 클로드 → 프로젝트 탭 **「연예스토리 글」**
- **보완 사진:** 지피티 → 프로젝트 탭 **「연예스토리 사진」**
- **네이버 블로그(3번째):** 계정 ID = `(대표 확인 필요)`. 글쓰기 전 로그인 확인.

## A. 인물 선정
- **대표 지정이 있으면 그 인물**(예: "김혜수 가자"). 없으면 **그날 화제 연예인**을 어사이드가 잡는다(크리에이터 어드바이저 메인 유입트렌드 / 연예 뉴스 랭킹에서 지금 화제인 인물). **하루 2~3편**(사건 조사가 무거우니 적게, 대표가 조정).

## B. 한 편씩 완성 (인물마다 반복)
**B-1. 그록 조사 (「연예스토리 조사」).** 인물명(+사건 A 있으면)을 넣어 **①사건 조사(A / B 후보 5~10 / 추천 연결) ②사진 목록(URL) ③공식 인스타·확보 현황**을 받는다. ①은 글용, ②는 사진 다운로드용.
**B-2. 클로드 글 (「연예스토리 글」).** 그록 ①블록을 넣어 **`[제목 후보]` 유형별 3개씩 총 9개(주인공 공개3/비공개3/연관인물3) + ★추천 1 + ☆차선 1 + 본문(해요체, A→B 반전 구조, 1,500~2,000자, `[사진N]` 자리) + 해시태그(20 미만)**를 받는다. (2026-11-03 경제와 출력 통일.)
**B-3. 사진 모으기.** ①공식 인스타(Imageye 일괄 저장) ②그록 URL 다운로드 ③부족분 지피티 보완컷(얼굴 없는 상징·장소·오브젝트). 라벨·순서대로.
**B-4. 네이버 조립·임시저장.**
   - **★ 썸네일 훅 얹기 (2026-11-13 대표 — 가십 썸네일은 클릭이 생명):** 맨 위 **대표사진(썸네일) 1장**에, 클로드가 준 **`썸네일훅` 구절 3개 중 하나**를 얹는다.
     - **방법:** 네이버 에디터 **사진 편집 → 텍스트** 기능으로 썸네일에 자막 한 줄. (안 되면 지피티 「연예스토리 사진」에 넘겨 텍스트 합성 폴백.)
     - **스타일:** 큰 볼드, 흰 글씨+그림자 또는 반투명 띠. **얼굴·핵심 식별요소 안 가리게**(상단/하단 띠). 6~12자 한 줄.
     - **안전선:** 단정(바람폈다·이혼 확정 등) ❌, **궁금증·암시형**(결별설 진실은?·충격 근황)만. 실제 셀럽 사진 출처·초상권=대표.
     - ※ 이건 **썸네일 '이미지 안' 자막** — 본문 사진 밑 캡션(`조립-규칙-공통` §2 '캡션 없음')과는 다른 것. **본문 사진엔 여전히 캡션 없음.** 썸네일 1장만 훅.
   - 제목칸: ★추천 제목 임시. 맨 위 메모칸에 후보 9개(유형별 3개씩).
   - 본문 붙이고 `[사진N]` 자리에 순서대로 삽입(삽입 방식은 어사이드 검증된 자동 방식 유지).
   - **3~4문장마다 빈 줄**로 단락 유지. 소제목은 인용구 서식.
   - **★ 전사 공통 조립 규칙 = `docs/prompts/조립-규칙-공통.md`** — 순서·**캡션 없음**·**AI 체크버튼 안 누름**·단락·서식. (단일 소스, 바꾸려면 그 파일만)
   - **임시저장만. 발행 금지.**
