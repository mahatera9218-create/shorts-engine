# 그록 — 경제 이벤트 달력 (주 1회, 다음 2~4주 예정 일정 수집) · 2026-11-17 신설

**목적:** 앞으로 2~4주 안에 **검색이 뜰 '예정된 경제 이벤트'**를 최대한 넓게 긁어, **미리 선점 발행할 후보 풀**을 만든다. 홈판(운)이 아니라 **검색(예정 수요)**으로 블로그 **바닥 조회**를 올리는 소스. → 나머지 2편(종목·정책, 검색 바닥용) 키워드가 여기서 나온다.

**왜 미래를 보나:** 공모주 청약·실적발표·금통위·정책 시행일 등은 **날짜가 미리 공개**돼 있고, 그 시기 관련 검색량이 **반드시 오른다.** 이벤트 **2~3일 전에 글이 떠 있어야** 그 검색 파도를 탄다(늦으면 경쟁 글이 선점). '시황·현황' 글이 검색 유입 0에 가까운 약점을 이걸로 메운다.

## 언제·어떻게
- **주 1회(월요일 아침 권장).** 지난주 달력에 **새 2주를 이어붙여** 항상 '앞으로 2~4주'가 차 있게.
- **그록 웹 검색만.** 공개된 **일정표·공시·보도자료**에서 **사실(날짜·이벤트)만.** 기사 문장·사진 복제 ❌. **검색결과 페이지 크롤링 ❌**(그록 웹 요약).
- **미확정 날짜는 '미정'으로** — 단정 금지. 루머 ❌.

## 긁는 범위 = 5축 (각 축에서 '날짜 잡힌' 것 전부, 넓게)
1. **증시·종목:** 공모주 **청약일·상장일** / 주요 종목 **실적발표일**(분기말+약 45일) / **배당락·배당기준일** / 주총·자사주·증자·**보호예수(락업) 해제** / 지수 정기변경(MSCI·코스피200) / 바이오 **임상·FDA 심사일(PDUFA)·학회**(ASCO·ESMO 등)
2. **거시·금리:** **금통위**(한은) / **FOMC**(미) / 한·미 **CPI·고용·GDP 발표일** / 주요국 중앙은행(ECB·BOJ)
3. **부동산:** **분양·청약 일정**(특공~1·2순위~당첨자발표~계약) / 재건축 **조합총회·심의일** / **입주장**(입주지정기간)·토허제 지정·해제 / 실거래·주간시세 **통계 발표일**
4. **정책·제도:** **세법·연금·건보 시행일**(종부세·양도세·금투세·연말정산) / 정년·최저임금 고시 / **대출규제**(DSR·스트레스금리) 시행 / **지원금·바우처 신청 개시일**
5. **생활·시즌:** 연말정산·종소세·재산세·자동차세 / **전기·가스요금 조정** / 명절·보조금(전기차·가전) 시즌

## 출력 양식 (한 이벤트 = 한 줄)
| 이벤트명 | 날짜(또는 기간) | 카테고리(1~5축) | 핵심 검색어 | 메모 한 줄 |
- **날짜 오름차순** 정렬. **이미 지난 건 빼고 '앞으로 2~4주'만.**
- **핵심 검색어 = 사람이 실제 검색창에 칠 구체 질문형 1~2개.** 예: `국민연금 2027 인상 얼마` · `디에이치 반포 청약 경쟁률` · `11월 FOMC 결과 전망`. (범용어 ❌ — '금리 전망' 말고 '11월 금통위 금리')
- **메모 = 왜 검색이 뜨는지 한 줄**(예: "D-1 당첨자 발표, 경쟁률 검색 폭증").

## 쓰임 (뒷단 — 매일 루틴이 꺼내 씀)
- 매일 발행 전, 루틴이 이 달력에서 **D-2~3 도래 이벤트**만 꺼내 → **틈새표(검색량·경쟁강도)·대중수요 레이더로 엄선** → **나머지 2편(검색 바닥용) 키워드**로. (`aside-경제-루틴-자동` A단계 사다리에 연결.)
- **이 글의 제목은 감정 훅이 아니라 '검색어 그대로'**(질문형 롱테일) — 검색 유입이 목적이라 사람이 치는 말이 제목에 그대로 있어야 한다.
