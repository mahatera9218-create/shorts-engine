# 어사이드 "조합" 지시문 — 경제 블로그 (`*ㄱ키워드` 방식, 검증됨)

하루치 경제 글·사진을 **네이버 임시저장**에 한 번에 쌓는 어사이드 지시문.
글·사진의 **마지막 메시지 끝에 `*ㄱ키워드`** 한 줄이 '완성 표시 + 글↔사진 묶기'를 동시에 한다. (대화창 이름은 안 바꿔도 됨.)

## 준비 (대표)
- 어사이드를 **경제 프로필**로 열고, 그 프로필에 **경제 블로그 네이버(eokonomy)** 로그인
- 어사이드에 **클로드 + GPT(사진 프로젝트)** 연결
- 각 글: 클로드 "경제 글" 탭에서 본문 다 나오면 **맨 끝에 한 줄 `*ㄱ키워드`** (예: `*ㄱSK하이닉스`)
- 각 사진: GPT "경제 사진" 프로젝트에서 사진 다 나온 뒤 **마지막 메시지 끝에 `*ㄱ키워드`** (글과 **같은 키워드!**)
- 본문 안 사진 자리에는 `[사진1]` `[사진2]` … 표시

## 어사이드에 붙여넣기 ↓↓↓

```
오늘 날짜 대화만 본다. 끝에 *ㄱ 가 붙은 것만 수집한다. 어제 이전이거나 *ㄱ 없는 건 무시한다.
*ㄱ 뒤 키워드가 같은 것끼리 글 하나로 묶는다. (예: *ㄱSK하이닉스 글 ↔ *ㄱSK하이닉스 사진)

[글] 클로드 "경제 글" 탭: *ㄱ 로 끝나는 본문을 가져온다. 맨 끝 *ㄱ키워드 줄은 뺀다.
[사진] GPT "경제 사진" 프로젝트: 같은 키워드 *ㄱ 로 끝나는 대화의 사진을 가져온다.

경제 블로그 네이버 글쓰기 → 임시저장 화면을 연다.
제목은 비워 둔다.
본문을 붙여넣고, 본문 안 [사진1]·[사진2]… 자리에 사진을 순서대로 넣는다. (자리 표시 없으면 본문 끝에 순서대로)
임시저장만 누른다. 발행은 절대 누르지 마라.
키워드가 여러 개면 글마다 따로 임시저장한다.
다 끝나면 '키워드별로 몇 개 임시저장했는지' 알려준다.
```

## 끝난 뒤 (대표)
네이버 임시저장 열기 → **제목 쓰고** → 사진·본문 훑고 → **발행 버튼.**

## 참고
- 아직 작업 중인 글은 `*ㄱ`를 안 붙이면 수집에서 저절로 빠진다.
- `*ㄱ`는 **글 끝 한 줄, 사진 끝 한 줄** — 이름 바꿀 필요 없음. (T2에서 검증된 방식)
