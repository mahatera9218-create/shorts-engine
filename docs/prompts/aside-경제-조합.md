# 어사이드 "조합" 지시문 — 경제 블로그 (제목 매칭 + '끝' 표시 방식)

하루치 경제 글·사진을 **네이버 임시저장**에 한 번에 쌓는 어사이드 지시문.
`*ㄱ` 태그 대신 **대화창 제목으로 글↔사진을 묶고, 제목에 '끝'이 붙은 것만** 수집한다.

## 왜 이 방식 (대표는 '대화'만)
- 글(클로드)과 사진(GPT)은 다른 앱이라, 짝을 맞추려면 공통 신호가 필요하다 → **대화창 제목을 같은 키워드로** 지어 묶는다.
- 다 끝났는지는 어사이드가 모른다 → 완성된 포스팅만 **글 대화창 제목 끝에 '끝'**을 붙여 표시한다(미완성은 안 건드림).

## 준비 (대표)
- 어사이드를 **경제 프로필**로 열고, 그 프로필에 **경제 블로그 네이버(eokonomy)** 로그인
- 어사이드에 **클로드 + GPT(사진 프로젝트)** 연결
- **키워드마다 대화창 2개**(클로드 "경제 글" / GPT "경제 사진")의 **제목을 같은 키워드로** 지음. 예: 둘 다 `SK하이닉스`
- 그 포스팅(글+사진)이 **다 완성되면 → 클로드 글 대화창 제목만 `SK하이닉스 끝`으로** 바꿈 (사진 대화창은 그대로 둬도 됨)
- 본문 안 사진 자리에는 `[사진1]` `[사진2]` … 표시

## 어사이드에 붙여넣기 ↓↓↓

```
오늘 날짜 대화만 본다.
클로드 "경제 글" 탭에서 대화창 제목 끝에 '끝'이 붙은 대화만 고른다. ('끝' 없는 건 미완성 → 무시)
각 대화의 제목에서 '끝'을 뗀 나머지가 그 글의 키워드다. (예: 'SK하이닉스 끝' → 키워드 'SK하이닉스')

[글] 그 대화의 완성 본문을 가져온다. (제목 줄·태그 없이 본문만)
[사진] GPT "경제 사진" 프로젝트에서 제목이 그 키워드와 같은 대화를 찾아, 그 대화의 사진을 가져온다.

경제 블로그 네이버 글쓰기 → 임시저장 화면을 연다.
제목은 비워 둔다.
본문을 붙여넣고, 본문 안 [사진1]·[사진2]… 자리에 사진을 순서대로 넣는다. (자리 표시 없으면 본문 끝에 순서대로)
임시저장만 누른다. 발행은 절대 누르지 마라.
'끝' 붙은 키워드가 여러 개면 글마다 따로 임시저장한다.
다 끝나면 '키워드별로 몇 개 임시저장했는지' 알려준다.
```

## 끝난 뒤 (대표)
네이버 임시저장 열기 → **제목 쓰고** → 사진·본문 훑고 → **발행 버튼.**

## 참고
- '끝' 표시는 **글 대화창 하나만** 하면 된다(사진은 같은 키워드로 알아서 딸려옴).
- 아직 작업 중인 대화는 제목에 '끝'을 안 붙이면 수집에서 저절로 빠진다.
- (검증 전) 집 PC에서 T4 테스트로 "제목 매칭 + 끝 수집"이 되는지 먼저 확인하고 실전 투입.
