# 어사이드 분석창 — 주간 통합 (매주 월요일 1회) · 2026-11-22 통합

이 창(어사이드 분석 작업창) 하나가 **일주일치 분석·수집을 몰아서** 한다. **매주 월요일 아침** 1회 돌린다. (C안 전환으로 매일 긁던 걸 주 1회로 묶음 — 부동산 2편은 아래 대장 맵에서 어사이드 새벽 루틴이 고르고 그록이 확인하므로 매일 수집 불필요.)

**안전선(공통):** **'읽기'만.** 내 블로그·내 통계·공개 글목록만. **로그아웃이면 멈추고 보고.** 문장·사진 **복제 금지**(주제·키워드·각도·유형만). 검색결과 페이지 크롤링 ❌, 루머 ❌. **못 긁은 항목은 비우되 '뭐가 안 됐는지' 꼭 보고 — 조용히 생략 ❌.**

저장은 전부 드라이브 **`공장/데이터/키워드/`**(통계류는 `공장/데이터/아카이브/`). 파일명 날짜 = `YYYY-MM-DD`, 주간 파일은 **이번주 월요일 날짜**. 같은 주 다시 돌리면 덮어쓰기, 지난 파일은 남김.

## 1. 미러 제목 학습 (쿠니네·skwnstar) — 지난 한 주
목적 = **제목 유형 학습(대표 편향 교정).** 키워드는 부산물.
- 두 블로그 모바일 글목록(`m.blog.naver.com/zkfldb888`, `m.blog.naver.com/skwnstar`)을 위→아래로 **화면 읽기.** 범위 = **지난 7일 올라온 글**(블로그당 보통 15~30편).
- 각 글에서: ① 주제 ② 키워드 ③ 제목 각도(훅) ④ 본문 각도 ⑤ 후킹 문구(""·'' 구절) ⑥ **제목 메커니즘**(8개 중 하나: 지목·내얘기 / 세력·큰손 / 충격·계좌 / 폭로·비밀 / 반전·의외 / 목표가·수치 / 상황콕·요즘말 / 속마음·반문).
- → **⑥ 메커니즘 분포**를 낸다(그들이 주로 쓰는 유형). 클로드 「경제 분석」이 대표가 실제 고른 제목 유형과 갭 비교 → ★추천 방향.
- (B) 나머지 경제 블로거(ranto28·8starstarstar8·dutyfrees·meaning87·rmsgud2007·ishiseido77·antsal·crazytech·balahk) = **후킹 문구만** 추출.
- **저장:** 후킹 문구 → `prompts/project/후킹-라이브러리.md`에 메커니즘별 누적(또는 `공장/데이터/키워드/후킹-<월요일날짜>.md`에 모아 클로드가 반영). 미러 요약 → `공장/데이터/키워드/미러-주간-<월요일날짜>.md`.

## 2. 대중 수요 레이더 — 네이버페이 머니스토리
- `story.pay.naver.com` 홈을 훑어 **글별 제목·분류·읽음 수**를 **읽음수 내림차순**으로.
- 왜: 경쟁 블로거는 제목만 보이고 조회는 안 보이는데, 여긴 **주제별 읽음 수**가 뜬다 = **대중 전체 반응(수요)** 데이터(네이버 공식 운영). 읽음수 큰 주제 = 지금 뜨거운 돈 관심사.
- ⚠️ 여긴 **수요(관심)만**, 경쟁강도(문서수)는 없음 — 테마만. **저장:** `공장/데이터/키워드/대중수요-<월요일날짜>.md`(주제·분류·읽음수).

## 3. 부동산 대장 맵 (울타리) — C안 부동산 2편의 소스
- 그록 웹으로 **지역별 '대장 단지' 목록 + 각 대장 최근 상태**(시세·이슈·날짜). **단지명·시세는 그록이 확인(추측 ❌).**
- **메인 지역**(청약·재건축/리모델링용) = 서울 핵심 구(강남3구·마용성·양천·영등포·강동·동작) + 경기 핵심 시(과천·성남[분당·판교]·광명·하남·안양·수원[광교·영통]·용인수지·화성동탄).
- **전국 대도시**(시세 급등락·기타용) = 위 + 인천·부산·대구·광주·대전·울산 등 광역시·대도시.
- **저장:** `공장/데이터/키워드/대장맵-<월요일날짜>.md`(지역·대장 단지명·유형·최근 시세·이슈·날짜).
- ★ **부동산 2편 '오늘 단지'는 어사이드 새벽 루틴이 이 맵에서 다른 2개 지역을 골라** 그록 「경제 부동산조사」가 그날 구체 이슈를 확인한다(별도 '이슈단지' 파일 불필요). **지역 쏠림(강남3구) 주의 — 주마다 다른 지역.**

## 4. 이벤트 달력 — 정책 1편 + 큰키워드 '예정' 보조
- 그록 프로젝트 **「이벤트달력」**을 열어 "이번 주 기준 **다음 2~4주 일정** 긁어줘" → 예정 경제 일정(5축: 증시·거시·부동산·정책·생활)을 표로.
- 표: `이벤트명 · 날짜 · 카테고리 · 핵심 검색어(질문형) · 메모`. **저장:** `공장/데이터/키워드/이벤트달력-<월요일날짜>.md`(그록 표 그대로).
- 왜: 실적·금통위·청약·정책시행 같은 **예정 이벤트는 날짜가 미리 공개**돼 그 시기 검색이 는다 → 2~3일 전 선점(정책 1편 + 큰키워드 예정분 보조).

## 5. 성과 수집 (글별 유입경로 → 성과로그)
개별 게시글 통계에서 **글별 조회수 + 유입경로(홈판/경제판/검색/기타 %)**를 읽어 **성과로그 시트**에 쌓는다. (전엔 "글 단위 못 봄"으로 잘못 알고 안 긁음 — 개별 글 통계에 유입경로 있음, 2026-11-20 대표.)
- **대상:** 조회 상위 ~30편(`공장/데이터/아카이브/글별-일별조회.csv` 누적 상위) **＋ 지난주 발행 글**. 중복 제거(보통 35~45편).
- **대상 글마다:** 개별 글 통계 진입 → ① 누적 조회수 ② **유입경로 비율: 홈판 % / ★경제판(네이버 메인_경제판) % / 검색 % / 기타 %** ③ (가능하면) 유입 검색어 top 몇 개. ★경제판은 '홈판'에 묻지 말고 **따로**(제3 유입 채널, 2026-11-22).
- **성과로그 시트**(「쇼츠엔진-경제-로그」 → `성과로그` 탭)에 한 행 추가/갱신:
  `발행일 | 키워드 | 제목 | 테마 | 측정일(오늘) | 조회수 | 홈판유입% | 경제판유입% | 제목유형 | 후킹메커니즘`
  (키워드·테마·제목유형·후킹메커니즘은 `경제로그` 탭에서 그 글 행을 찾아 가져옴. 같은 글이 있으면 측정일·조회수·홈판%·경제판%만 갱신.)
- **★ 측정 시점(지연 숙성):** 우리 글은 발행 **10~18일 뒤 홈판으로 터진다.** 발행 **2주+ 지난 글**이 숙성 완료라 그 홈판%가 신뢰값. 2주 안 된 글도 기록하되 측정일 남겨 **다음 주 재측정.**
- 막히면(로그인·보안문자) 그 자리에서 멈추고 보고. 유입경로 모르는 채 0으로 채우지 말 것.

## 6. 블로그 전체 통계 이어붙이기
- **글별 × 일별 조회 매트릭스:** `공장/데이터/아카이브/글별-일별조회.csv`에 **지난주 새 날짜 열만 이어붙인다**(행=글, 열=날짜, 값=그날 조회수). '게시물 분석 → 조회수 순위'를 **일간**으로 놓고 지난 7일 창을 넘기며. top 300 밖은 0. 누적 = 행 합계(자동).
- **주간 스냅샷(선택):** 방문 분석(조회수·순방문자·방문횟수·재방문율·평균사용시간)·유입경로 비율·유입검색어 TOP·기기·지역의 **지난주 추이**를 `공장/데이터/아카이브/통계-스냅샷.md`에 날짜별로. (※ 전체 글 본문 아카이브는 1회성이라 반복 불필요 — 이미 떠둠.)
- ⚠️ 네이버 일간 통계가 15일 창으로만 열리면 창 옮겨가며. 못 간 날짜·막힌 창 보고.
