# Aside 지시문: 내 블로그 통계 — 전일 데일리 + 주간 (2026-11-12 개편)

대표 결정(2026-11-12): **매일 아침 전일(어제) 1일치** 통계 + **매주 월요일 지난주 7일 합계.** 깃헙 이슈 폐기 → **드라이브.**
통계는 로그인해야 보이는 화면이라 공식 API가 없어 **대표 계정으로 로그인한 어사이드**가 읽는다(대표 본인 데이터). 글 문장·사진은 옮기지 말고 **숫자와 제목만.**

대상: 경제 `blog.naver.com/eokonomy` / 패션 `blog.naver.com/tenbillionsound`

## A. 매일 (전일 1일치)
네이버 블로그 관리 → 통계에서 **어제 하루치**를 읽어 아래 양식으로(블로그 자리엔 '경제'/'패션'):
```
[통계] 경제 | 어제날짜(YYYY-MM-DD) | 조회 | 방문
[글] 경제 | 글 제목 | 조회 | 공감 | 댓글        ← 어제 조회 상위 10개까지
[검색어] 경제 | 유입 검색어 | 숫자              ← 어제 유입 검색어 10개까지
[경로] 경제 | 유입 경로 | 비율                  ← 네이버 검색·홈판(블로그 홈)·기타
```
패션도 똑같이. 칸에 숫자가 없으면 0.
→ **드라이브** `공장/데이터/통계/통계-<어제날짜>.md`

## B. 매주 월요일 (지난주 7일 합계)
같은 양식으로 월~일 7일 합계 + 지난주 조회 상위 글 10개.
→ **드라이브** `공장/데이터/통계/통계-주간-<시작일>.md`

## 쓰임 (뒷단)
클로드 「경제 분석」이 **전일 통계로 데일리 브리핑**(어제 조회·유입 상위/하위, 국면 판단), **주간 합계로 PDCA·안된 글 부검**에 쓴다.

## 막히면
네이버·GitHub 로그인 화면·보안문자·인증을 요구하거나 통계 화면이 안 열리면 **그 자리에서 멈추고 보고.** 비밀번호 직접 입력 금지. 숫자를 모르는 채 0으로 채워 올리지 말 것.
