# 어사이드 「육아 쇼핑」 루틴 (쇼핑커넥트 전용 블로그 · 연결 고리)

어사이드는 **판단 최소.** 쇼핑커넥트에서 소재·공식 이미지를 모아 클로드·그록에 넘기고, 받은 글·이미지를 네이버에 조립해 **임시저장**한다. 발행·전용링크 삽입은 대표.

## 준비 (1회) · 창
- 클로드 프로젝트 **「육아 글」** = `클로드-육아쇼핑-홈판-글.md` 상주(제목·글·사진라벨).
- 그록 프로젝트 **「육아 조사」** = 스펙·안전인증·가격·A/B 비교 **팩트만**(사진·이미지 작업 ❌ — 한도 아낌).
- (선택) 지피티 **「육아 사진」** = 무드컷 생성만(제품 사진 크롭 ❌).
- 네이버 블로그(육아 쇼핑 전용 계정 — 대표 확인).
- **쇼핑커넥트 / brandconnect.naver.com 로그인**(대표 계정).

## A. 소재 선정 (매일, 쇼핑커넥트 로그인 상태)
1. **brandconnect '프로모션 상품' → 육아(또는 생활 내 육아템)** 탭을 연다.
2. **'업체가 돈 쓴 것' 우선으로 N개 고른다:** 브랜드데이·신상위크·오늘끝딜·슈퍼적립(높은 적립률) 태그 붙은 것 → 그중 **고단가 + 신상(블로그 경쟁 공백)** 우선. (애매하면 대표 지정.)
3. 각 상품마다 수집: **제품명·브랜드 / 딜 정보(딜 종류·할인율·적립률·마감) / 공식 상품 이미지 여러 장**(썸네일·상세컷·비교 대상 있으면 A/B 둘 다). 전용링크(또는 상품 URL)는 메모(대표 발행용).
   - ★ 이미지는 **공식 상품 이미지만**(블로거·언론 사진 ❌). 다운로드만, 생성·편집 ❌.

## B. 한 편 생산 (상품마다 반복)
**B-1. 그록 「육아 조사」(팩트만).** 제품명(+비교 대상)을 넣어 **스펙·안전인증(KC·ECE R129)·연령/체중 기준·가격대·장단점·A vs B 차이**를 받는다. **이미지·사진 요청 ❌**(한도 아낌, 텍스트 팩트만).
**B-2. 클로드 「육아 글」.** 입력 = **제품/상황 키워드 + 딜 정보 + 그록 조사 블록.**
   - `글` → 본문(비교표 포함·해요체·`[사진N]` 자리+라벨·대가성 문구·`[상품링크N]` 자리·해시태그 20).
   - `제목` → 12개(+★추천·☆차선). 딜 상품이면 딜 훅 섞음.
   - `사진` → 소제목별 `[사진N]` 라벨(`[공식]`=공식 이미지 자리 / `[무드]`=선택).
**B-3. 이미지 준비 (생성 안 씀).**
   - `[공식]` 자리 = A에서 받은 **공식 상품 이미지**를 라벨 순서대로 배치.
   - **썸네일(대표사진) 1장만 네이버 에디터 '자르기'로 1:1 중앙 크롭**(비생성). 본문 제품컷은 **원본 비율 그대로** OK.
   - 제품이 치우쳐 중앙크롭이 어색한 컷은 **'대표 보정' 플래그**(발행 때 손크롭).
   - `[무드]` 자리만(있으면) 지피티 무드컷.

## C. 네이버 조립·임시저장
**`docs/prompts/조립-규칙-공통.md`를 그대로 따른다.** 순서만:
1. 제목칸 = ★추천. 맨 위 메모칸 = 제목 후보 12 + **딜 마감일**(대표가 발행 타이밍 잡게).
2. 본문 붙이고 **`[사진N]` 자리에 라벨대로 이미지 삽입**(사진 → 소제목(인용구) → 글). 사진 밑 캡션 없음.
3. **비교표**(`[표:]`·`|격자|`)를 네이버 표로 옮기고 격자 글자 지움(글마다 1개+).
4. **대가성 문구** 그대로 둔다(맨 위 또는 맨 아래) — **지우지 말 것(필수 고지).**
5. **`[상품링크N]` 자리는 그대로 둔다** — 대표가 발행 때 **쇼핑커넥트 전용 링크** 삽입(어사이드가 생 URL 넣지 않음).
6. 서식(소제목 Alt+3 인용구·볼드·구분선), 3~4문장마다 빈 줄, AI 체크버튼 끔, 마크다운 기호 제거.
7. **임시저장. 발행 ❌.**

## D. 마무리 보고
"오늘 **N편 임시저장** + 상품·딜 목록 + **대표 보정 필요 이미지** + 전용링크 넣을 자리 수" 한 줄.

## 대표 (발행)
초안 → **[상품링크N]에 전용 링크 삽입** → 치우친 이미지 손크롭 → 딜 마감 전 타이밍에 **발행.** 대가성 문구 유지 확인.

## ★ 절대 규칙
- **공식 상품 이미지만**(블로거·언론 ❌). **생성 모델로 제품 사진 크롭·편집 ❌**(제품 왜곡·그록 한도).
- **대가성 문구 필수·전용링크는 대표.** 허위 할인·가짜 후기·안전 효능 과장 ❌.
- **임시저장까지만. 발행·로그인 자동화 금지.** 막히면 그 자리에서 멈추고 보고.
