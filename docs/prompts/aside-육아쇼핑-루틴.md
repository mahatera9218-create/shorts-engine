# 어사이드 「육아 쇼핑」 루틴 (쇼핑커넥트 전용 블로그 · 연결 고리)

어사이드는 **판단 최소.** 대표가 지정/발급해둔 상품을 받아 그록·클로드로 글을 만들고, 네이버에 조립(쇼핑커넥트 링크 삽입 포함)해 **임시저장**한다. **발행은 대표.**

## 준비 (1회) · 창
- 클로드 프로젝트 **「육아 글」** = `클로드-육아쇼핑-홈판-글.md` 상주.
- 그록 프로젝트 **「육아 조사」** = 스펙·인증·가격·A/B 비교 **팩트만**(이미지 작업 ❌).
- (선택) 지피티 **「육아 사진」** = 무드컷 생성만(B모드 썸네일용).
- 네이버 블로그(육아 쇼핑 전용 계정) + **쇼핑커넥트 로그인**(대표 계정).
- **발행이력 파일**(Drive `공장/데이터/키워드/발행이력-육아쇼핑.md`) — 이미 쓴 제품 목록. **중복 방지의 핵심.**

## 소재·링크 모델 (중요)
- **대표는 '오늘 쓸 제품명(검색어)'만 지정** — **구체적으로(브랜드+모델)**: "브라이텍스 듀얼픽스 프로"·"베이비뵨 바운서" ⭕ / "카시트" 같은 범용 ❌. 고단가·저경쟁·프로모션 판단은 대표(틈새표 참고).
- **어사이드가 네이버 에디터의 쇼핑커넥트 버튼에서 그 제품을 검색해 삽입** → **전용링크·대가성 문구 자동 생성**(별도 발급·담아두기 불필요). ※ 버튼이 '삽입 시 자동 발급'인지는 대표가 에디터에서 1회 확인.
- 버튼 검색 결과가 여러 개면 **브랜드·모델이 일치하는 것**으로. 애매하면 그 상품은 **멈추고 보고**(엉뚱한 링크 ❌, 조용히 넘기지 않음).
- **품질·링크·중복의 최종 거름망 = 대표의 초안 검토.** 임시저장은 초안이라 **삭제 비용 0** → 어사이드는 받은 제품 양껏 작업, 대표가 쓸데없거나 잘못된 초안은 **삭제**하고 좋은 것만 발행.

## A. 오늘 작업 목록 정하기
1. **발행이력 파일**을 읽는다(이미 쓴 제품).
2. **대표가 준 제품명(검색어)** 중 **발행이력에 없는 것 N개**를 오늘 작업으로 확정. (중복 ❌)
3. 각 상품 = **제품명·브랜드·모델 + 딜(종류·할인·적립·마감) + 공식 상품 이미지**(쇼핑커넥트/상품 페이지에서). 이미지는 **공식만**(블로거·언론 ❌), 다운로드만·편집 ❌.
   - **★ 모드 판정:** 상품이 쇼커에 **있으면 [A모드]** / 인기 키워드인데 쇼커에 **없으면 [B모드]**(노출 자석 — 그 제품은 주제로, 쇼커 유사품을 링크. ① 노출 제품 + ② 쇼커 유사품 둘 다 준비).

## B. 한 편 생산 (상품마다 반복, 여러 탭 병렬)
**B-1. 그록 「육아 조사」(팩트만).** 제품명(+비교 대상) → 스펙·인증·연령/체중·가격·장단점·A vs B. **이미지 요청 ❌.**
**B-2. 클로드 「육아 글」.** 입력 = **모드([A]/[B]) + 제품/상황 + 딜 + 그록 조사**(B면 노출제품+유사품 둘 다) → `글`(본문·비교표·`[사진N]`·대가성 문구·`[상품링크N]` 자리·해시태그20) / `제목`(12+추천) / `사진`(라벨).
**B-3. 이미지 (제품 사진 생성 안 씀).**
   - **A모드:** `[공식]` = hero 제품 쇼커 공식 이미지. **B모드:** `[공식]` = 쇼커 유사품 공식 이미지 / 노출 제품·썸네일 = **그록 공식 URL 우선**, 없으면 `[무드]`(지피티).
   - 썸네일 1장만 네이버 '자르기' 1:1 중앙. 본문컷 원본 비율 OK. 치우친 컷 = '대표 보정' 플래그.
   - **★ 썸네일 = 실사 베이스, 글자(텍스트) 박지 않는다**(텍스트 썸네일은 노출↓). 캔바 텍스트 오버레이 ❌.
     - **A모드 썸네일:** 공식 이미지 중 **연출/라이프스타일 컷 우선** → 1:1 중앙 크롭.
     - **B모드 썸네일(우선순위):** ① **그록이 찾은 노출 제품 공식/라이선스 이미지 URL** → 받아서 1:1 크롭(필요시 지피티 톤 보정만) ② 쇼커 유사품 연출 공식컷 ③ 지피티 실사풍 무드컷. (실제 제품 > 무드컷, 클릭 유리. 그록 URL은 공식·재게시 가능만 — 블로거·언론 ❌, 애매하면 대표 확인.)

## C. 네이버 조립·임시저장
**`docs/prompts/조립-규칙-공통.md` 그대로.** 순서:
1. 제목칸 = ★추천. 맨 위 메모칸 = 제목 후보 12 + 딜 마감일.
2. 본문 붙이고 `[사진N]` 자리에 이미지 삽입(사진→인용구 소제목→글, 캡션 없음).
3. 비교표(`[표:]`) → 네이버 표로.
4. **대가성 문구 유지**(제목 바로 아래/첫 링크 전) — 지우지 말 것.
5. **★ 상품링크 삽입 = 쇼핑커넥트 버튼으로.** `[상품링크N]` 자리에 **쇼핑커넥트 버튼 → 대표가 준 제품명으로 검색 → 브랜드·모델 일치하는 것 삽입**(전용링크·대가성 자동 생성). **상품 생 URL 붙이기 ❌**(수익 0). 버튼이 안 되거나 상품이 애매하면 **멈추고 보고**(그 편은 대표 수동).
   - **위치 = 비교 대상 제품마다 그 설명 옆 + 비교표 결론 직후 + 글 하단 '함께 보면 좋은 상품'.** **비교 제품 각각 링크(둘 다·셋 다) + 핵심 제품은 반복** OK. **한 문단 떡칠 ❌**(광고처럼 보이면 역효과).
6. 서식(소제목 Alt+3·볼드·구분선, **`[형광:…]` → 네이버 형광펜 마커** 적용), 3~4문장마다 빈 줄, AI 체크버튼 끔, 마크다운 제거.
7. **임시저장. 발행 ❌.**

## D. 마무리 보고 + 발행이력 기록
- **발행이력 파일에 오늘 작업한 제품명 추가**(다음에 중복 제외).
- 보고: "오늘 N편 임시저장 + 제품·딜 목록 + 대표 보정 필요 이미지 + 링크 삽입 상태" 한 줄.

## 대표 (발행 — 최종 거름망)
초안들 훑기 → **쓸데없거나 잘못된 초안은 삭제**(임시저장이라 부담 0), 좋은 것만 남김 → **링크·상품 맞는지 확인**(어사이드 삽입분) → 치우친 이미지 손크롭 → 딜 마감 전 **발행.**

## ★ 절대 규칙
- **중복 방지:** 발행이력에 있는 제품 다시 쓰지 않는다.
- **공식 상품 이미지만**. 생성 모델로 제품 사진 편집 ❌. **전용링크만**(생 URL 수익 0), 대가성 문구 필수.
- 허위 할인·가짜 후기·'최고' 단정·안전 과장 ❌. 깎아내리기식 비교 ❌.
- **임시저장까지만. 발행·로그인 자동화 금지.** 막히면 멈추고 보고(비밀번호 직접 입력 ❌).
