# 어사이드 「육아 쇼핑」 루틴 (쇼핑커넥트 전용 블로그 · 연결 고리)

어사이드는 **판단 최소.** 대표가 지정/발급해둔 상품을 받아 그록·클로드로 글을 만들고, 네이버에 조립(쇼핑커넥트 링크 삽입 포함)해 **임시저장**한다. **발행은 대표.**

## 준비 (1회) · 창
- 클로드 프로젝트 **「육아 글」** = `클로드-육아쇼핑-홈판-글.md` 상주.
- 그록 프로젝트 **「육아 조사」** = 스펙·인증·가격·A/B 비교 **팩트만**(이미지 작업 ❌).
- (선택) 지피티 **「육아 사진」** = 무드컷 생성만(B모드 썸네일용).
- 네이버 블로그(육아 쇼핑 전용 계정) + **쇼핑커넥트 로그인**(대표 계정).
- **발행이력 파일**(Drive `공장/데이터/키워드/발행이력-육아쇼핑.md`) — 이미 쓴 제품 목록. **중복 방지의 핵심.**

## 소재·링크 모델 (중요)
- **대표가 수시로** brandconnect에서 고단가·저경쟁 상품 **전용링크를 발급(담아두기)** → 네이버 글쓰기의 **쇼핑커넥트 버튼** 목록에 쌓인다. 어사이드는 **거기서 끌어다 삽입.**
- **오늘 쓸 상품 = 대표가 제품명 N개 지정(권장·안전)** 또는 어사이드가 쇼핑커넥트 버튼 목록에서 **발행이력에 없는 것** 선택. (엉뚱한 상품 방지 위해 대표 지정이 안전.)
- ※ 쇼핑커넥트 버튼이 '발급해둔 목록'인지 '즉시 검색'인지는 대표가 에디터에서 확인(어느 쪽이든 동작).

## A. 오늘 작업 목록 정하기
1. **발행이력 파일**을 읽는다(이미 쓴 제품).
2. 대표 지정 제품(또는 버튼 목록)에서 **발행이력에 없는 상품 N개**를 오늘 작업으로 확정. (중복 ❌)
3. 각 상품 = **제품명·브랜드 + 딜(종류·할인·적립·마감) + 공식 상품 이미지**(쇼핑커넥트/상품 페이지에서). 이미지는 **공식만**(블로거·언론 ❌), 다운로드만·편집 ❌.
   - **★ 모드 판정:** 상품이 쇼커에 **있으면 [A모드]** / 인기 키워드인데 쇼커에 **없으면 [B모드]**(노출 자석 — 그 제품은 주제로, 쇼커 유사품을 링크. ① 노출 제품 + ② 쇼커 유사품 둘 다 준비).

## B. 한 편 생산 (상품마다 반복, 여러 탭 병렬)
**B-1. 그록 「육아 조사」(팩트만).** 제품명(+비교 대상) → 스펙·인증·연령/체중·가격·장단점·A vs B. **이미지 요청 ❌.**
**B-2. 클로드 「육아 글」.** 입력 = **모드([A]/[B]) + 제품/상황 + 딜 + 그록 조사**(B면 노출제품+유사품 둘 다) → `글`(본문·비교표·`[사진N]`·대가성 문구·`[상품링크N]` 자리·해시태그20) / `제목`(12+추천) / `사진`(라벨).
**B-3. 이미지 (제품 사진 생성 안 씀).**
   - **A모드:** `[공식]` = hero 제품 쇼커 공식 이미지. **B모드:** `[공식]` = 쇼커 유사품 / 노출 제품·썸네일 = `[무드]`(지피티).
   - 썸네일 1장만 네이버 '자르기' 1:1 중앙. 본문컷 원본 비율 OK. 치우친 컷 = '대표 보정' 플래그.

## C. 네이버 조립·임시저장
**`docs/prompts/조립-규칙-공통.md` 그대로.** 순서:
1. 제목칸 = ★추천. 맨 위 메모칸 = 제목 후보 12 + 딜 마감일.
2. 본문 붙이고 `[사진N]` 자리에 이미지 삽입(사진→인용구 소제목→글, 캡션 없음).
3. 비교표(`[표:]`) → 네이버 표로.
4. **대가성 문구 유지**(제목 바로 아래/첫 링크 전) — 지우지 말 것.
5. **★ 상품링크 삽입 = 쇼핑커넥트 버튼으로.** `[상품링크N]` 자리에 **쇼핑커넥트 버튼 → 해당 상품 → 삽입**(전용링크·대가성 자동). **상품 생 URL 붙이기 ❌**(수익 0). 버튼이 안 되면 **텍스트 링크**("최저가 확인하기" 드래그 → 전용링크).
   - **위치 = 비교표 결론 직후 + 글 하단 '함께 보면 좋은 상품'.** 글당 **2~3개**(도배 ❌).
6. 서식(소제목 Alt+3·볼드·구분선), 3~4문장마다 빈 줄, AI 체크버튼 끔, 마크다운 제거.
7. **임시저장. 발행 ❌.**

## D. 마무리 보고 + 발행이력 기록
- **발행이력 파일에 오늘 작업한 제품명 추가**(다음에 중복 제외).
- 보고: "오늘 N편 임시저장 + 제품·딜 목록 + 대표 보정 필요 이미지 + 링크 삽입 상태" 한 줄.

## 대표 (발행)
초안 확인 → (링크·대가성 이미 삽입됨, 확인만) → 치우친 이미지 손크롭 → 딜 마감 전 **발행.**

## ★ 절대 규칙
- **중복 방지:** 발행이력에 있는 제품 다시 쓰지 않는다.
- **공식 상품 이미지만**. 생성 모델로 제품 사진 편집 ❌. **전용링크만**(생 URL 수익 0), 대가성 문구 필수.
- 허위 할인·가짜 후기·'최고' 단정·안전 과장 ❌. 깎아내리기식 비교 ❌.
- **임시저장까지만. 발행·로그인 자동화 금지.** 막히면 멈추고 보고(비밀번호 직접 입력 ❌).
