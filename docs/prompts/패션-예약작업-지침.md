# 패션 블로그 예약작업 지침 (매일 자동 생성) — 대표 2026-10-18

**매일 클로드 예약 세션이 '조사 세트'만 만든다(글·제목·사진 X).** 대표는 도우미에서 그 조사 세트를 한 번에 복사해 **패션 프로젝트 대화창에 '출발'까지 붙여넣어** 제목·본문을 받고(사진은 그 창에서 '사진' 요청), 네이버에 발행한다. (대표 2026-10-18: 도우미는 셀럽+아이템+조사한 정보만, 글·제목·사진은 프로젝트 창에서.)

## 컨셉 (최우선)
vividvortex·쿠니네식 **'셀럽 사복' 좁은 니치** (DECISIONS 2026-10-17). 1축=셀럽 사복 + 아이템 서브축(가방/아우터/니트·가디건/신발). **셀럽 풀 = 여배우·유명 방송인(배우·아나운서·예능인) 중심, 아이돌 그룹 피함.** 제목·본문·사진의 결은 prompts/project/클로드-패션-글.md가 '출발'로 받아 처리한다.

## 순서
1. config/fashion_topics.yaml의 `axes`에서 **최근에 안 쓴 아이템 서브축 2개**를 고른다. **하루 2건(셀럽 2명)이 기본** — 서로 다른 셀럽·다른 아이템.
2. 각 아이템을 **최근 공항·행사·화보·방송에서 착용해 화제된 여배우·유명 방송인**(배우·아나운서·예능인, 아이돌 그룹 피함)을 WebSearch로 찾는다(서로 다른 인물). **착용이 확인된 조합만**(지어내기 금지). 나이·브랜드·가격은 공식·신뢰 출처로 확인되면만. 한 명이 확인이 전혀 안 되면 그 건은 거르고 다른 후보로.
3. **글·제목·본문·사진 프롬프트는 만들지 않는다. '조사 세트'만** reports/패션글-초안/<slug>.md 에 저장한다. 형식:
   - 1줄: `키워드: <셀럽 아이템> (아이템=가방/아우터/니트·가디건/신발)`
   - 2줄: `사진 출처: <실제로 쓸 사진의 출처 URL 1개>` — 조사에서 참고한 그 링크. 도우미가 '원본 사진 보기'로 띄우고, 대표가 그 사진(또는 그록으로 찾은 사진)을 네이버에 직접 넣는다. (2026-10-19 대표: 패션 사진은 실제 셀럽 사진.)
   - 빈 줄 → `--- 프로젝트에 붙여넣기 ---` → 그 아래 = 패션 프로젝트 창에 그대로 붙여넣을 입력:
     - `<인물> / <시점·장소> / <제품>` 한 줄, 빈 줄, 이어서 `[조사 메모]` + 불릿(인물(배우/방송인) · 무슨 일 · 착용 확인(됨/안 됨) · 제품/브랜드 · 가격(확인된 것만, 아니면 '미확인') · 나이(확인된 것만, 아니면 '쓰지 않음') · 사진 링크 · 아이템 서브축 · 사진=실제 셀럽 사진(대표가 출처 링크/그록으로 구해 직접 삽입 — 가상모델 안 씀))
   - **다음글 큐·‘함께 보면 좋은 글’(관련글)은 넣지 않는다** — 쿠니네 원문에 없는 항목이라 뺀다(2026-10-18 대표). config/related_posts_fashion.csv는 보관만.
     - 마지막에 빈 줄 하나 두고 **`출발`**
   - slug는 인물-아이템 영문.
4. fashion_topics.yaml done에 (셀럽+아이템) 2개 기록(중복 방지, 같은 아이템은 다른 셀럽으로).
5. 지정 브랜치에 커밋·푸시 후 gh api로 main에 PR 생성·머지(머지하면 패션 도우미 자동 재배포). 끝나면 2건의 셀럽·아이템·확인상태를 한국어로 짧게 보고.

## 안전(필수)
- **사진 = 실제 셀럽 사진 사용 (2026-10-19 대표).** 기사 '문장'은 복제하지 않고 사실만. 착용 **미확인을 확정처럼 쓰지 않기**. 확인된 **가격만**. 외모·체형·나이·열애 **조롱·단정 금지**. API 키는 산출물에 쓰지 않는다.

## 대표가 하는 것
- 도우미 열기 → 카드의 **'복사'(끝에 출발 포함)** → **패션 프로젝트 창에 붙여넣기** → 제목 고르기·본문 받기 → '원본 사진 보기'(또는 그록)로 **실제 셀럽 사진을 구해 `[사진N]` 자리에 직접 넣고** → 네이버 발행. (가상모델 프롬프트는 안 씀.)

## 제품정보 보완(대표가 글에 제품정보 더하고 싶을 때)
자동 생성본은 그대로 발행해도 되고, 제품정보(품번·가격·공식명·링크)를 더하고 싶으면 **docs/prompts/패션-보완-프롬프트.md** 블록을 패션 프로젝트 대화창에 붙여 넣고 빈칸을 채운다. 준 것만 확정 반영, 안 준 건 그대로(지어내기 금지).
