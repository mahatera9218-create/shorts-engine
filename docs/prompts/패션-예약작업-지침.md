# 패션 블로그 예약작업 지침 (매일 자동 생성) — 대표 2026-10-18

건강 블로그처럼 **매일 클로드 예약 세션**이 패션 발행 초안을 생성→저장→푸시. 대표는 도우미에서 검토→이미지→네이버 발행.

## 컨셉 (최우선)
vividvortex·쿠니네식 **'셀럽 사복' 좁은 니치** (DECISIONS 2026-10-17). 1축=셀럽 사복 + 아이템 서브축(가방/아우터/니트·가디건/신발). **제목 아이템 먼저**(첫 15자에 아이템, 인물 뒤). prompts/project/클로드-패션-글.md 맨 위 '★★ 운영 개편' 블록을 그대로 따른다.

## 순서
1. config/fashion_topics.yaml의 `axes`에서 **최근에 안 쓴 아이템 서브축 1~2개**를 고른다. (하루 1~2편)
2. 그 아이템을 **최근(요즘) 공항·행사·화보에서 착용해 화제된 셀럽**을 WebSearch로 찾는다. **착용이 확인된 조합만** 쓴다(지어내기 금지). 인물 나이·제품 브랜드/가격은 공식·신뢰 출처로 확인되면만 쓰고, 안 되면 그 양념은 뺀다.
3. 클로드-패션-글.md대로 발행 패키지 생성:
   - **제목 후보 5개 + 추천 1** (아이템 먼저 + 따옴표 반전 + 가격/나이 양념 — 확인된 것만)
   - 본문(도입+소제목 구간, 소제목 위 [사진1]/[사진2]…, 끝에 해시태그 18~19)
   - 이미지 프롬프트: **가상 모델 실사**(실존 셀럽 얼굴·사진 복제 금지). **[사진1]=대표 썸네일 = 키워드 아이템 클로즈업**(시선 집중, 과하지 않게).
   - 글 끝 다음글 큐 + 함께 보면 좋은 글.
4. 저장: reports/패션글-초안/<slug>.md (맨 위 `검증:`(=착용·가격 확인 상태) → `키워드:`(셀럽+아이템) → `제목 후보:` 5 + `추천:` → `---` → 본문([사진N]+해시태그) → `--- 이미지 프롬프트 ---` → `--- 출처 ---` → `--- 함께 보면 좋은 글 ---`). slug는 인물-아이템 영문.
   - **함께 보면 좋은 글 (관련 URL 3개, 2026-10-18 대표):** 맨 끝 `--- 함께 보면 좋은 글 ---` 블록에 `config/related_posts_fashion.csv`(과거 글 제목·URL)에서 고른 **3줄**을 `제목 | URL` 형식으로 적는다. 도우미가 이 링크를 띄운다. **고르는 기준:** 지금 글을 클릭한 독자가 **이어서 관심 가질** 글 — 같은 셀럽·같은 착장 반복 말고, **연결되는 관심**(가방 글 → 다른 가방·명품 가격 반전·공항룩 등). 지금 글 자신 제외. CSV에 마땅한 게 적으면 2개만.
5. fashion_topics.yaml done에 (셀럽+아이템) slug 기록(중복 방지, 같은 아이템은 다른 셀럽으로).
6. 지정 브랜치에 커밋·푸시 후 gh api로 main에 PR 생성·머지(머지하면 패션 도우미 자동 재배포). 끝나면 제목 후보·경로·확인상태를 한국어로 짧게 보고.

## 안전(필수)
- 실존 셀럽 **사진·기사문장 복제 금지** → 사진은 가상 모델 실사. 착용 **미확인을 확정처럼 쓰지 않기**. 확인된 **가격만**. 외모·체형·나이·열애 **조롱·단정 금지**('뼈말라'·'워스트' 등). 모델 식별자·API 키는 산출물에 쓰지 않는다.

## 대표가 하는 것(자동 아님)
- 도우미 열기 → 제목 고르기 → 본문 복사 → 이미지 프롬프트로 가상모델 사진 생성 → 네이버 발행.
