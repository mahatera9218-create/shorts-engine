# 블로그·클립 운영 계획 (2026-09-30 대표 결정)

발행 규칙 → 기간별 목표 → 정기 점검(주간·월간) → 판정·개선 규칙. 목표 숫자는 **초기값**이다. 4주 데이터가 쌓이면 실제 기준선으로 고친다 (DECISIONS에 기록).

## 1. 발행 규칙

| 항목 | 규칙 |
| --- | --- |
| 양 | 하루 블로그 1편 + 클립 1개. 몰아서 여러 편 발행하지 않는다 (대량 발행 금지) |
| 만들기 | 매일 06:47 자동으로 **후보 4편** (편집장 4점 이상·숫자 검사 통과한 ✅만, 미달은 다시 씀, 하루 비용 상한 $5) |
| 고르기·발행 | 대표가 4편 중 **1편을 골라** 도우미에서 복사해 발행 (네이버에 글쓰기 API 없음) |
| 리셋 | 매일 아침 전날까지의 **발행 안 한 후보는 지운다**. 발행한 글만 남겨 성과·중복 방지에 쓴다 |
| 발행 시간 | 오전 7~9시를 기본값으로 시작 (출근길 홈피드). 4주 뒤 시간대별 조회수로 다시 정함 |
| 클립 | 블로그 발행 직후 같은 날. 음악은 클립 에디터 추천곡 |
| 표시 | 발행 후 도우미에서 ✅ 발행 완료 표시 (중복 발행 방지, 성과 집계 기준) |
| 빠진 날 | 못 올린 날은 넘어간다 (다음 날 새 후보에서 1편만, 밀린 글을 몰아서 올리지 않는다) |
| 금지 | 같은 글 재발행, 다음 글 예고, 광고 클릭 유도, 도박·투자 권유, 가짜 경험 |

## 5. 판정·개선 규칙

1. **숙성**: 발행 후 7일 조회수로 판정한다 (홈판 유입은 첫 2~3일에 몰린다). 7일이 안 된 글은 판정에 넣지 않는다.
2. **묶음**: 테마·제목 유형·썸네일 유형은 각각 최소 5편이 모여야 비교한다. 한 편의 대박·쪽박으로 바꾸지 않는다.
3. **올리기·내리기**: 테마 평균 7일 조회수가 전체 평균보다 30% 이상 높으면 그 테마 확률 +1, 30% 이상 낮으면 −0.5 (최소 0.5). 조회수가 올랐어도 평균 사용 시간이 20% 이상 줄면 올리지 않는다 (낚시 방지).
4. **탐색 20%**: 확률의 20%는 새 테마·새 선수·새 형식 시험에 남긴다. 성과가 좋은 테마만 남기지 않는다.
5. **한 번에 하나**: 한 주에 바꾸는 것은 1~2개 (테마 비중, 제목 규칙, 썸네일 등). 무엇이 효과였는지 알 수 있게.
6. **기록과 되돌리기**: 바꾼 것은 DECISIONS에 날짜·이유·기대 효과와 함께 적고, 2주 뒤 기대만큼 안 되면 되돌린다.
7. **수익 우선순위** (애드포스트 승인 후): 1천 뷰당 수익 > 조회수 > 체류 시간. 광고 단가 가정(검색광고 입찰가 ≈ 애드포스트 단가)을 실제 수익으로 검증한다.
8. **멈춤 신호**: 2주 연속 발행률 70% 미만이면 발행 방식을 다시 논의, 4주 연속 글당 조회수가 기준선 아래면 포맷(썸네일·제목·카드)을 바꾸는 실험을 먼저 한다.
