# 수익형 글 작성 (네이버 블로그 · 워드프레스)

운영자는 글에 개입하지 않는다(경험 입력·사진 촬영 없음). 그래서 네이버가 높게 치는 경험 신호가 없다. 그 빈자리는 **정보 이득**으로 채운다. 이 스킬의 최우선 규칙은 정보 이득 게이트다. (설계서 12.2, 13.1)

## 입력

- 리서치 팩: 데이터, 출처 URL, 계산 결과, 차트 사양
- 대상 키워드와 투자 메모의 빈틈 목록 (상위 10개 경쟁 콘텐츠 분석)
- 플랫폼: `naver` 또는 `wordpress`
- 글 유형: `정보형` 또는 `비교선택형`
- 기존 글 목록 (내부 링크용)

## 1단계: 정보 이득 게이트 (쓰기 전에)

상위 10개 경쟁 콘텐츠에 없는 것을 최소 1개 명시한다.

- 새로 계산한 숫자·비교표
- 도구(계산기, 체크리스트) 연결
- 더 최신 정보 (변경일 명시)
- 경쟁 글 댓글의 미답변 질문에 대한 답

명시할 수 없으면 **쓰지 않고** "게이트 미통과: 이유"를 반환한다.

## 2단계: 작성 규칙

**구조**
- 첫 문단에 결론. 서론으로 분량 채우지 않는다.
- 소제목은 검색자가 실제로 묻는 질문 형태. 빈틈 목록의 질문을 우선 사용.
- 비교표, 체크리스트, 요약 박스 중 최소 1개.
- 모바일 기준: 문단 3문장 이하, 문장 짧게.

**정확성**
- 모든 수치에 출처. 출처 없는 수치는 쓰지 않는다.
- 기준일을 적는다 (제도·가격은 "YYYY년 M월 기준").

**금지**
- 운영자가 직접 써본 것처럼 쓰는 1인칭 사용 경험, 가짜 후기, 가짜 인물
- "~에 대해 알아보겠습니다", "결론적으로 정리하자면" 같은 틀에 박힌 문장
- 경쟁 글 문장·구성 복제
- 투자 권유, 건강 효능 주장, 과장 광고 표현

**비교선택형**
- 사양·가격·데이터 비교로만 쓴다. "써보니" 같은 사용 후기 표현 금지.
- 제휴 상품 링크는 글당 1~2개까지.
- 제휴 링크가 있으면 글 앞부분에 경제적 이해관계 고지: "이 글에는 제휴 링크가 포함되어 있으며, 구매 시 일정 수수료를 받을 수 있습니다."

**방문자당 페이지 수**
- 대표 글·시리즈 글 구조를 쓴다. 글 끝에 다음 읽을 글 1~2개를 연결한다.

## 3단계: 플랫폼별 차이

| 항목 | 네이버 블로그 | 워드프레스 사이트 |
| --- | --- | --- |
| 목적 | 애드포스트 + 쇼핑커넥트 | 애드센스, 도구·심층 가이드 |
| 길이 | 핵심 위주, 모바일 앱 가독성 | 더 깊게, 도구·표 포함 |
| 형식 | 네이버 에디터에 붙여넣기 좋은 일반 텍스트 + 이미지 위치 표시 | HTML 또는 블록, 제목·메타 설명·슬러그 포함 |
| 이미지 | 시스템이 만든 차트·도표·인포그래픽만, 글당 3~4개, 파일명에 순서·위치 (예: `1_첫문단아래.png`) | 같음 + 대체 텍스트 |

**같은 리서치로 두 플랫폼에 쓸 때:** 구성과 문장을 완전히 다르게 쓴다. 복사하면 네이버 유사 문서 판정으로 블로그 노출이 떨어질 수 있다.

## 산출물 (발행 패키지)

```
게이트: 통과 — 정보 이득: [무엇]
제목 후보 5개 (유형 표시: 숫자형/질문형/비교형/최신형/결론형) + 추천 1개
본문
이미지 목록: 파일명, 위치, 차트 종류, 데이터, 캡션
태그 10개 이내 (네이버) / 메타 설명·슬러그 (워드프레스)
내부 링크 제안
제휴 링크 위치와 고지 문구 (있을 때)
출처 목록
팩트체크 대상 목록: 수치 · 출처 · 확인 필요 여부
실험 기록용 메타: 제목 유형, 글 유형, 길이, 이미지 수
```

팩트체크는 이 글을 쓴 맥락과 분리된 별도 검토로 수행한다.
