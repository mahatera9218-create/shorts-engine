# 쇼츠 대본과 장면 목록

쇼츠는 발견과 주제 검증 창구다. 광고 수익보다 완료율·구독 전환·롱폼 유입이 목표다. 얼굴·스톡 영상 없이, 데이터를 코드로 그린 그래픽 + 합성 음성으로 만든다. (설계서 사업 개요, 3.6, 12장)

## 입력

- 리서치 팩 (데이터, 출처, 차트 사양)
- 채널 설정: 톤, 음성, 색상 템플릿
- 최근 30편의 훅 유형·구조 기록 (원본성 확인용)
- 연결할 롱폼 영상 (있으면)

## 원칙

- **한 편에 한 가지 아이디어.** 숫자 하나, 비교 하나.
- **정보 이득:** 새로 계산한 숫자나 비교를 중심에 둔다. 흔한 정보 재낭독 금지.
- **원본성:** 최근 30편과 훅 유형·구성 순서가 겹치지 않게 변주한다. 템플릿을 찍어내는 패턴은 수익화 제한 대상이다.
- **스톡 영상·타인 영상·타인 이미지 사용 금지.** 모든 화면은 장면 목록으로 새로 생성한다.
- **AI 표시:** 합성 음성·생성 그래픽이면 업로드 시 AI 합성 표시를 켠다.
- 투자 권유, 건강 효능 주장, 과장 금지.

## 형식

- 길이 30~50초 (60초 이하 필수)
- 0~2초: 훅. 숫자 또는 반전으로 시작. 인사·채널 소개 금지.
- 본문: 핵심 1개를 차트 전개로 보여준다.
- 마지막 5초: 롱폼 연결 유도 ("전체 비교는 연결된 영상에서") — 관련 동영상 기능과 함께 쓴다.
- 자막: 한 줄 15자 안팎, 화면당 1~2줄.

## 산출물

```
훅 5안: [유형] 문장  (유형: 숫자형/질문형/반전형/비교형/순위형)
선택 훅과 이유
내레이션 전문 (예상 길이 초)
장면 목록 (JSON)
제목 3안, 설명문 (출처 포함)
AI 합성 표시: 예
팩트체크 대상: 수치 · 출처
실험 기록용 메타: 훅 유형, 길이, 장면 수, 구성 순서
```

## 장면 목록 JSON 규격

```json
{
  "duration_sec": 42,
  "scenes": [
    {"id": 1, "type": "title_number", "start": 0.0, "end": 2.0,
     "text": "월 38만 원 차이", "narration": "..."},
    {"id": 2, "type": "bar_chart", "start": 2.0, "end": 12.0,
     "data": {"labels": ["A", "B"], "values": [120, 158], "unit": "만 원"},
     "source": "URL", "narration": "..."},
    {"id": 3, "type": "cta", "start": 37.0, "end": 42.0,
     "text": "전체 비교는 연결된 영상", "narration": "..."}
  ]
}
```

장면 유형: `title_number`, `bar_chart`, `line_chart`, `map`, `table`, `text_card`, `cta`. 렌더러가 모르는 유형은 쓰지 않는다. 모든 데이터 장면에 `source`를 넣는다.

팩트체크는 대본을 쓴 맥락과 분리된 별도 검토로 수행한다.
