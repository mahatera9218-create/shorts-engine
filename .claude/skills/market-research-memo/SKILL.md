# 시장조사와 투자 메모

쇼츠·네이버 블로그·워드프레스 사이트 수익 사업의 0단계. 콘텐츠를 만들기 전에 어떤 주제·키워드에 들어갈지 데이터로 정한다. 원칙: 광고회사처럼 **투입 1원당 회수액**으로 판단한다. (설계서 0장)

## 입력

- 씨앗 키워드 목록 (`config/seeds.yaml` 또는 이전 메모)
- 네이버 검색광고 키워드 도구 결과 (API 또는 내려받은 CSV)
- NAVER API HUB 결과: 검색(블로그 문서 수, 상위 글 제목·발행일), 데이터랩(검색어 트렌드, 쇼핑 인사이트)
- 유튜브 Data API 결과 (후보 키워드만)

## 데이터 출처 규칙

- 공식 API만 쓴다. 네이버·구글 검색 결과 페이지를 직접 긁지 않는다.
- 네이버 검색·데이터랩은 NAVER API HUB(네이버 클라우드) 방식이다. 인증 헤더는 `X-NCP-APIGW-API-KEY-ID`, `X-NCP-APIGW-API-KEY`. 옛 개발자센터 헤더(`X-Naver-Client-Id`)는 쓰지 않는다. 엔드포인트는 네이버 클라우드 공식 문서에서 확인한다.
- 네이버 키워드 도구는 클릭당 단가를 주지 않는다. 광고 가치는 경쟁도(compIdx), 노출 광고 수(plAvgDepth), 월평균 클릭수로 대신 잰다.
- 유튜브 API는 검색 1회에 100단위, 기본 하루 10,000단위다. 네이버 데이터로 먼저 거른 후보만 유튜브에서 조회한다.
- API 키는 GitHub Secrets에서만 읽는다. 대화·로그·산출물에 적지 않는다.

## 절차

1. **키워드 확장:** 씨앗 → 연관 키워드. 중복·오타·브랜드 단독 키워드 제거.
2. **지표 수집 (코드로):** 점수 계산은 LLM이 아니라 코드로 한다. 결과가 매번 같아야 하고 토큰이 들지 않아야 한다.
3. **틈새 점수:**
   - 수요: 월간 검색량(PC+모바일), 추세 방향(1년 전 같은 달 대비), 계절성
   - 가치: 경쟁도, 노출 광고 수, 월평균 클릭수
   - 공급: 네이버 블로그 문서 수, 유튜브 경쟁 영상 수
   - 이길 가능성: 최근 30일 새 블로그 글 수(적을수록 기회, 최신순 조회), 상위 운영자 규모. 블로그 검색 API의 정확도순 상위는 실제 검색 화면과 달라 쓰지 않는다 (DECISIONS 2026-09-29)
   - 제휴 가치: 쇼핑 인사이트 상품군, 제휴 수수료 가능성
   - 틈새 점수 = 수요 × 가치 × 이길 가능성 × 제휴 가치 ÷ 공급 (가중치는 설정 파일)
4. **규제·민감 업종 표시:** 금융상품·보험·대출·의료·법률 관련 키워드는 점수와 별도로 `규제` 표시. 법률 검토 전에는 진입 후보에서 뺀다.
5. **플랫폼별 신호 분리:** 검색량은 블로그·사이트·롱폼용. 쇼츠 후보는 유튜브 이상치 영상(구독자 대비 조회수가 비정상적으로 높은 영상)으로 따로 본다.
6. **경쟁자 분석 (점수 상위 키워드만):** 상위 10개에 대해 (실제 검색 화면의 상위 10개는 공식 API로 알 수 없으므로, 확인 방법이 정해지기 전에는 최근 글·유튜브 상위로 대신하고 한계를 메모에 적는다)
   - 톤앤매너: 문체, 길이, 소제목 구조, 표·이미지 수
   - 패키징: 제목 패턴, 썸네일 스타일, 영상 길이
   - 이상치, 수익화 흔적(제휴 링크, 협찬 표시)
   - 빈틈: 댓글의 미답변 질문·불만, 상위 글에 없는 정보
   긴 원문을 통째로 LLM에 넣지 않는다. 코드로 지표를 뽑고 필요한 부분만 요약한다.
7. **투자 메모 작성.**

## 투자 메모 양식 (주제당 1페이지)

```
# [주제명] 투자 메모 — YYYY-MM-DD
결론: 진입 / 보류 / 제외 (한 줄 이유)

| 축 | 점수 | 근거 |
| 수요 | | |
| 가치 | | |
| 공급 | | |
| 이길 가능성 | | |
| 제휴 가치 | | |

예상 편당 매출: 범위 (근거)
예상 편당 원가: 범위 (LLM·TTS·호스팅)
상위 경쟁자 요약: 3줄
빈틈과 우리의 정보 이득: 새 숫자 / 도구 / 최신성 / 미답변 질문 중 무엇으로 이길지
대표 키워드 10개: 키워드 · 월 검색량 · 틈새 점수
규제·리스크:
검증할 가정:
```

## 판정 기준

- **진입:** 틈새 점수 상위 + 규제 아님 + 정보 이득 수단이 구체적으로 있음
- **보류:** 점수는 높지만 이길 가능성이 낮거나 정보 이득 수단이 불분명
- **제외:** 규제 업종, 수요 하락 추세, 상위가 최근 글·대형 운영자로 꽉 참, 경험 후기형 글이 있어야 이기는 주제 (운영자는 경험 입력·사진 촬영을 하지 않는다. DECISIONS 2026-09-29)

## 하지 않는 것

- 숫자 없이 감으로 쓰는 메모
- 검증 안 된 수치를 확정처럼 쓰기. 추정은 범위와 근거를 함께.
- 경쟁 글의 문장·구성 복제
