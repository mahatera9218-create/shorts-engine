# market-research-memo

설계서 0.3 ④ 투자 메모 양식을 따른다. 숫자는 코드가 채우고(`market/`), Claude는 판단 칸만 채운다 (14.1).

## 입력

- `reports/market/<날짜>/memo-*.md` — 코드가 만든 초안 (점수, 상위 경쟁자, 규제 표시)
- `reports/market/<날짜>/data.json` — 원자료. 초안에 없는 숫자가 필요하면 여기서 찾는다.

## 양식 (주제별 1페이지)

1. **결론:** 진입 / 보류 / 제외 — 한 줄 이유
2. **점수:** 수요, 가치, 공급, 이길 가능성, 제휴 가치 (코드가 채움, 고치지 않는다)
3. **예상 편당 매출·원가:** 범위로. 가정을 같이 적는다 (예: "1천 뷰당 애드포스트 ○~○원 가정, 미검증")
4. **상위 경쟁자 요약과 빈틈:** 상위 10개 제목 패턴, 오래된 글 비율, 반복 등장 블로그, 유튜브 이상치
5. **차별화 포인트:** 정보 이득 게이트(12.2) 기준 — 새로 계산한 숫자 / 도구 / 더 최신 정보 / 미답변 질문 중 무엇으로 이길지
6. **규제·리스크:** 규제 업종 표시, 계절성, 대형 사업자 경쟁

## 판단 규칙

- 규제 업종(금융·보험·의료·법률) 키워드가 주력이면 **보류**, 이유에 "법률 검토 전 진입 안 함"(0.3).
- 차별화 포인트를 정보 이득 4가지 중 하나로 말할 수 없으면 **진입이 아니다**.
- 경험 후기형 글이 필요해야 이기는 주제는 **제외**. 운영자는 경험 입력·사진 촬영을 하지 않는다 (DECISIONS 2026-09-29).
- 모르는 숫자는 추측하지 않는다. "미확인"으로 적고 확인 방법을 쓴다.
- 결론 제안(코드)은 참고일 뿐이다. 최종 결론과 이유는 Claude가 쓰고, 주제 결정은 운영자가 한다.

## 검증된 규칙 (플레이북, 15.6)

아직 없음. 운영 데이터로 검증된 규칙이 생기면 여기에 추가한다.
