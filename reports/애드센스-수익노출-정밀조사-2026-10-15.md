# 애드센스 수익·노출 정밀 조사 (글 프롬프트 짜기 전 필수)

2026-10-15 · 대표 요청: SEO 순위가 아니라 **애드센스 수익·노출** 관점에서 키워드·제목·글·이미지·광고 각각 **뭐가 유리하고 뭘 하면 불리(승인거절·정지·저수익)**한지 상세히.
출처 성격: 아래 대부분 **2차 실무 자료(방향성)**. 구글 1차 기준은 애드센스 정책센터/도움말(이 작업 환경 DNS가 막아 직접 열지 못함 → 공식 URL은 맨 아래, 발행 전 대표가 한 번 대조 권장). 수치(RPM·% 등)는 거의 출처 불명확 → 방향으로만.

## 0. 우리에게 제일 중요한 3가지 (결론 먼저)

1. **우리는 '자동 생성 글' → 대량·저가치 콘텐츠 정책이 최대 리스크.** 구글은 AI를 금지하진 않지만, **"양 많고 가치 낮은" 페이지(scaled content abuse)**를 때린다(2026 스팸·코어 업데이트로 대량 AI 페이지 트래픽 50~80% 급락 사례). → **편마다 사람 검수 + 고유 정보이득** 필수. (우리 원칙 12.2·14장과 정확히 일치 — 방어선 이미 있음)
2. **금융=YMYL → 승인·심사 더 엄격.** 저자·출처·면책 같은 E-E-A-T를 **사이트에 먼저** 갖춰야 승인·수익이 산다.
3. **무효 트래픽(내 클릭 포함)=계정 정지/영구정지 1순위.** 절대 내 광고 클릭·클릭 유도 금지.

## 1. 글(콘텐츠) — 승인·유지의 핵심

- **거절 1위 = "저가치 콘텐츠"**(얇다/베꼈다/미완성). 그다음 필수 페이지 누락·저작권.
- **필수 페이지(없으면 거절 흔함):** 소개(About)·연락처(Contact)·**개인정보처리방침**·이용약관·**면책(Disclaimer)**.
- **한 주제 집중 + 꾸준한 최신 글.** "30편 얕게보다 15편 깊게가 승인에 유리."
- **공식 수치 기준 없음**(글 수·분량·기간). 업계 관행 15~25편·글당 1,500자+는 관행일 뿐.
- **자동생성 주의:** AI 자체는 금지 아님. **'도움이 되는가'로 판단.** 준복제·저가치면 거절·수익중단.
- **중복 금지:** 네이버판 복붙 = 구글 중복 + 저가치. 반드시 각도·길이·구조를 다르게.

## 2. 키워드 — 뭐가 돈이 되나(수익성)

- **최고 단가군: 보험 > 금융 > 법률**(미국 기준 RPM $30~80 추정). **세무/세금·연금은 개인금융(고가치군)**. 단, 세무 단독 RPM 수치는 확인 안 됨.
- **CPC ≠ 내 RPM.** 실제 수익 = 트래픽 국가(**한국은 미국보다 단가 낮음**)·광고 밀도·주제에 좌우.
- **우리 유리:** 세무·연금·보험·대출 '인접' 주제 = 금융 광고주가 붙어 단가↑. 정체성의 '수익 의뢰층(분양·증권·세무사)'과 겹침 → 유입·수익 한 설계.
- **한국 현실:** 네이버 블로그엔 애드센스 **불가**(그래서 WP). 의미있는 수익은 **일 방문 1,000+**부터(관행 추정). 지급은 100달러 누적 시(환율 영향).

## 3. 제목 — 유리/불리

- **유리:** 검색 질문형 + 정확(본문과 일치) = SEO·신뢰·재방 모두 ↑.
- **불리:** 낚시·과장(본문 불일치)=저가치·신뢰 하락(우리 원칙도 금지). 선정·공포·혐오 조장 제목은 **광고 제한**(derogatory=아예 수익불가, shocking=제한 광고). 세무 주제는 해당 적지만 '세금 폭탄' 같은 공포 과장은 절제.

## 4. 이미지 — 유리/불리

- **광고와 이미지를 '연관된 것처럼' 나란히 두지 말 것**(오클릭 유도로 간주 — 오래됐지만 핵심 정책). 사이 간격만으론 해결 안 됨, '연관돼 보이면' 위반.
- **저작권 이미지 금지**(거절·정지). → 우리는 **직접 제작/가상모델 이미지**(원칙 일치). 뉴스 사진·타인 사진 복제 금지.
- **AI 이미지:** 애드센스 명시 금지 조항은 확인 안 됨. 저작권·오해 소지 없게 쓰면 됨.
- 세무 글은 **표·도식이 사진보다 유용**(스니펫·이해·AI 인용). 이미지는 보조.

## 5. 광고(배치·밀도) — 유리/불리

- **너무 많은 광고 = 역효과**(RPM↓·UX↓·정책 위험). 권장 관행 **긴 글당 3~5개**.
- **유리한 자리:** 제목 바로 아래 / 첫 몇 문단 안 / 섹션 사이 자연 지점 / 모바일 **하단 앵커**. **사이드바는 효과 낮음.**
- **CLS(레이아웃 밀림) 방지:** 광고 자리 크기 미리 확보.
- **오토애드 vs 수동:** 하이브리드 권장(앵커·비네트는 오토, 본문은 수동).
- **카테고리 과도 차단 금지**(광고 경매 경쟁↓ → 단가↓).
- **초기엔 보수적으로**(광고 적게·안전 배치) → 승인·안정 후 A/B로 최적화.

## 6. ★ 불리했던 것 — 실제 정지·수익중단 사유

- **무효 트래픽(최다 정지 사유):** 본인·지인 클릭, "여기 눌러주세요" 유도, 봇·자동 트래픽. **실수 클릭도 무효.** 30일 정지 또는 영구 비활성, 새 계정 우회 불가. → **내 광고 절대 클릭·유도 금지.**
- **대량 저가치(scaled content abuse):** 양치기 AI 페이지 타격. → 정보이득·검수로 방어.
- **MFA(광고를 위한 사이트):** 콘텐츠보다 광고가 주인인 사이트 불이익.
- **저작권/짜깁기:** 거절·정지(원칙 금지).
- **가치 없는 재고(valuable inventory):** 내용 없는/미완성 페이지에 광고 달면 위반.

## 7. 우리 체크리스트 (③ 프롬프트 + 사이트 + 운영에 반영)

**글 프롬프트에 규칙으로:**
- [ ] 편마다 **고유 정보이득**(새 수치·계산·최신·경쟁글이 안 답한 질문) — 저가치·대량생성 회피
- [ ] 네이버판과 **각도·구조 다르게**(중복 금지)
- [ ] 제목 정직(낚시·공포 과장 금지)
- [ ] **표·도식 우선**, 이미지는 저작권free·직접제작, **광고와 혼동 배치 금지**
- [ ] 저자 바이라인·**국세청/법령 출처**·수정일·면책(YMYL)

**사이트/운영:**
- [ ] 필수 페이지 먼저: 소개·연락처·개인정보처리방침·약관·면책
- [ ] 광고 **3~5개**·안전 배치, 초기 보수적
- [ ] **내 광고 클릭 절대 금지**, 클릭 유도 문구 금지
- [ ] 한 주제 집중·꾸준한 발행
- [ ] 애드센스 신청은 **글 쌓이고 E-E-A-T 갖춘 뒤**(astacgroup.com 재사용은 재심사 가능성 있음 — 새 콘텐츠로 다시 볼 수 있음)

## 결론

최대 리스크 2개 = **대량 저가치(자동생성)** + **무효 트래픽**. 둘 다 우리 원칙으로 이미 방어선이 있으니, **프롬프트에 '정보이득·검수'를 못 박고, 운영에서 '내 클릭 금지'**만 지키면 안전하게 수익화 가능. ③ 구글용 글 프롬프트는 위 체크리스트(1·3·4·7)를 규칙으로 심는다.
