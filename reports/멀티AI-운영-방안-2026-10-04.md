# 여러 AI가 역할을 나눠 글·사진을 만드는 방법 (조사, 2026-10-04)

대표 요청: 초안과 사진을 Claude·Gemini·GPT·Grok·Aside가 각자 잘하는 영역을 나눠 만들고, 대표는 복사해서 올리기만.

## 결론
**가능해요. 단, AI끼리 자유롭게 대화시키는 방식이 아니라 "회사 조직도"처럼 만들어요.**
- **사무실** = 지금 쓰는 GitHub 자동화 (매일 아침 자동 실행)
- **공용 칠판(소통 창구)** = 글마다 만드는 작업 폴더. 각 AI가 맡은 결과를 파일로 올리고, 다음 AI가 그걸 읽어요.
- **업무 지침(역할 분담)** = AI마다 지침 파일 1개 (`config/roles/<역할>.md`). 대표님이 지침을 고치면 다음 날부터 그대로 일해요.
- **총괄** = Claude. 일을 나눠 주고, 결과를 모아 규칙 검사(권유·단정·가짜 경험·출처)를 하고 최종 조립.
- **대표님** = 도우미에서 복사 → 업로드 (지금과 같음)

## 역할 분담안 (가설, 시험해서 확정)
| 담당 | 맡을 일 | 이유 (각 회사 공식 기능) |
| --- | --- | --- |
| Grok | 이슈 레이더: X(트위터)에서 지금 뜨는 경제 화제 | API에 X 검색 도구가 있어요 (Grok만 가능) |
| Gemini | 사실 확인: 숫자·날짜를 구글 검색으로 교차 확인 + 사진(그림) | 구글 검색 연동(월 5,000번 무료), 이미지 생성(장당 약 $0.04~) |
| GPT | 제목·첫 문단 후보 여러 개 / 사진 대안 | 시험해서 좋으면 넣음 |
| Claude | 총괄·편집장: 초안 작성, 양식·규칙 검사, 최종 조립 | 지금 역할 그대로 |
| 코드 | 기사 수집, 시세 숫자, 검사 | 지금 그대로 |
| Aside | 크리에이터 어드바이저 캡처 같은 '로그인 화면 작업' | **Mac 전용(macOS 15+)** 이라 휴대폰만으로는 못 써요 |

## 연결 방법 2가지
1. **OpenRouter 한 곳 가입** (추천): 키 1개·결제 1곳으로 GPT·Gemini·Grok·Claude를 모두 부를 수 있어요. 이미지 생성 모델도 일부 지원.
   - 단, Grok의 X 검색은 xAI에 직접 가입해야 쓸 수 있을 가능성이 커요(확인 필요).
2. **각 회사 따로 가입**: OpenAI, Google AI Studio, xAI 각각 키·결제. 기능은 가장 많지만 관리가 번거로워요.

## 꼭 정해야 할 것
1. **AI가 그린 그림을 써도 되나요?** 지금 원칙은 "무료 사진만"이에요. AI 그림을 쓰면 이 원칙을 바꿔야 해요.
   - 바꾸더라도 실존 인물(파월 등)·회사 로고·가짜 차트는 그리지 않아요(오해·초상권). 개념 그림·썸네일 배경만.
   - 네이버 블로그는 'AI 활용' 표기가 자율이지만, 표기하는 걸 추천.
2. **결제**: OpenRouter 1곳 or 각 회사. 가입·결제·키 입력은 대표님 몫이에요 (키는 GitHub Secrets에만).
3. **Mac이 있나요?** 있으면 Aside에 어드바이저 캡처 루틴을 맡길 수 있어요.

## 주의
- AI가 많다고 글이 좋아지는 건 아니에요. 비용·실패 지점이 늘어나요. → **1~2주 비교 시험**(Claude 혼자 vs 여러 AI)을 해서 편집장 점수·조회수로 판단해요.
- 단계적으로: ① Gemini 사실 확인 + 그림 → ② Grok 이슈 레이더 → ③ GPT는 시험에서 이기면.

### 비용
- OpenRouter: 모델 값은 원가 그대로, **충전할 때 5.5% 수수료**(최소 $0.80). $100 충전 → 약 $94.5 사용.
- 하지만 GPT·그림을 빼면 **OpenRouter가 필요 없어요.** Grok의 X 검색도 xAI 직접 가입이 확실.
- 추천: **Gemini(구글 AI 스튜디오) + Grok(xAI) 직접 가입 2곳.**
  - Grok X 검색: 1번에 $0.005(약 7원). 하루 2~3번 → 한 달 수백 원 + 글자 값.
  - Gemini 구글 검색 연동: 월 5,000번까지 무료 → 우리 사용량(한 달 수백 번)은 대부분 무료 구간.
  - → 추가 비용은 **한 달 몇 천 원 수준** 예상 (실제는 1주 돌려 보고 보고).
