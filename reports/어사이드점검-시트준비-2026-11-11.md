# 어사이드 지시문 점검 + 새 구글 드라이브 구조 (2026-11-11)

오늘 결정(드라이브 통로·그록 수집+편집·[실물]플래그·후킹 라이브러리·상태판/지시함·A방향)을 기준으로 어사이드 지시문 결함·누락을 짚고, 대표가 만들 **새 시트 구조**를 준비.

## A. 어사이드 지시문 점검

### A-1. `aside-경제-루틴-자동.md` (일일 드라이버) — ★개정 필요 큼
**살릴 것(네이버 조립 노하우 — 이건 금, 저장 지시문으로 유지):**
- 표 네이버표 변환(B-5), 단락 빈 줄, 서식 단축키, 함께보면좋은글 카드(B-4), AI체크버튼 안 누름, 사진 순서 삽입 — **전부 유지.**

**고칠 것(오케스트레이션·사진·제목이 Claude Code로 이동):**
1. **올인원 → 수집/저장 분리 안 됨.** 아직 어사이드가 클로드 웹(「쿠니 경제」)·지피티 웹을 탭으로 돌림 → A방향: 어사이드는 **조사만 드라이브에 떨구고(수집)**, 글·사진은 Claude Code, 어사이드가 **원고를 드라이브에서 읽어 저장**.
2. **지피티 「경제 사진」 사용(B-2) = 폐기.** 사진은 GPU 생성 / 그록 실물 편집. 이 섹션 통째 제거.
3. **드라이브 바통 없음.** `N_조사→N_원고→N_사진/→N_완료` 흐름 추가.
4. **상태판·지시함 없음.** 시작 시 `지시함.md` 확인, 단계마다 `상태.md` 기록 추가.
5. **[실물] 플래그·그록 편집 없음.** 사진 수집이 옛 방식(그록 URL + 지피티 보완) → 그록 수집+선별+편집(1024²)로.
6. **제목 규칙 옛날.** 후킹 라이브러리·33자·후킹위치 미반영(글이 Claude Code로 가면 자동 해결).
7. **시트 칸:** 경제로그에 `후킹메커니즘` 칸 없음.

→ **조치:** 이 파일을 **`aside-경제-수집`(조사→드라이브) + `aside-경제-저장`(드라이브→네이버, 조립 노하우 전부)** 둘로 분리. (A방향 이전 작업. 기존 파일은 폴백으로 보존.)

### A-2. `aside-제목트렌드-조사.md` — ✅ 오늘 개정됨
- 매일 수집 + ""·'' 후킹 추출 추가됨. 시트 대신 깃헙 이슈에 쌓음(그대로 OK). → 후킹수집 시트로도 받으려면 아래 B 참고.

### A-3. `aside-경제-발행이력-수집.md` — ✅ 오늘 신설

### A-4. `aside-주간-성과수집.md` / `aside-블로그통계-주간.md` — ⚠️ 칸 보강

## B. 새 구글 드라이브 구조 (대표가 생성 → 어사이드에 올림)

### B-1. 시트 1장: 「쇼츠엔진-경제-로그」 (기존 이름 유지, 탭 5개)
어사이드가 쓰고 Claude Code가 읽는 **데이터 창고.**

| 탭 | 용도 | 칸(열 순서대로) |
|---|---|---|
| **경제로그** | 일일 생산 로그 | 날짜 · 테마 · 키워드 · 검색량 · 글수 · 제목후보(12) · 선택제목 · 임시저장 · 모드 · **후킹메커니즘** |
| **성과로그** | 발행 성과 추이 | 발행일 · 키워드 · 제목 · 테마 · 측정일 · 조회수 · 홈판유입% · **제목유형** · **후킹메커니즘** |
| **발행이력-경제** | go-live baseline | 발행일 · 제목 · 키워드/주제 · 테마 · 제목유형 · 조회수(현재누적) · 링크 · 한줄요약 |
| **테스트지시** | 대표가 테스트날 키워드 지정 | 날짜 · 키워드1 · 키워드2 · 키워드3 · 키워드4 · 키워드5 |
| **후킹수집** (신규) | 인플 후킹 누적 | 날짜 · 인플명 · 제목 · 후킹문구(""·'' 안) · 메커니즘 · 메모 |

> **굵은 칸 = 오늘 추가/변경분**(후킹메커니즘·제목유형·후킹수집 탭).

### B-2. 드라이브 폴더 + 파일 (시트 아님 — 작업대/상태/지시)
```
📁 공장
├─ 📁 작업대 / 경제 / 오늘 /   ← 하루 바통: N_조사.md · N_원고.md · N_사진/ · N_완료
├─ 📄 지시함.md   ← 대표가 폰에서 지시 던지는 곳 (템플릿: local-factory/drive-templates/)
└─ 📄 상태.md     ← 공장이 상태 쓰는 곳 (템플릿: local-factory/drive-templates/)
```
- 지시함·상태 템플릿은 이미 저장소 `local-factory/drive-templates/`에 있음 → 그대로 드라이브에 올리면 됨.

### B-3. 후킹 라이브러리 = 시트 아님
- `prompts/project/후킹-라이브러리.md`(정제된 framework)는 **저장소에 유지**(Claude Code 단일 소스). 어사이드는 **후킹수집 탭**에 raw만 쌓고, 제목담당이 읽어 라이브러리.md로 정제.
