# 착장 도우미 설계: 공식 API + 주소 붙이기 혼합 (2026-10-10)

대표 요청: ① 인스타 공식 API와 ② 대표가 게시물 주소 붙이기를 섞어 최적화.
원칙: 인스타를 자동으로 긁거나 남의 사진을 자동으로 가져와 올리는 단계는 만들지 않는다(대표에게 설명함, 작업 환경 안전 검사도 차단). 그 밖은 전부 자동.

## 한눈에

| 단계 | 누가 | 대표 손 |
|---|---|---|
| 1. 오늘 뜨는 연예인 10명 | 코드, 매일 05:17 | 없음 |
| 2. 3~4명 고르기 | 대표 | 체크 3~4번 |
| 3. 게시물 정하기 | **자동 계정**: 코드가 최신 게시물 3개를 미리 받아 둠 / **개인 계정**: 대표가 주소 붙이기 | 자동이면 탭 1번, 개인이면 30초 |
| 4. 상품 링크 | 대표가 렌즈로 찾은 링크(있으면) + 코드가 쇼핑 검색으로 후보 | 선택 |
| 5. 상품 정보 확인 → 제목·본문 | 코드 (기존 프롬프트) | 없음 |
| 6. 임시저장 | 어사이드 (대표 PC) | 없음 |
| 7. 연예인 사진 넣고 발행 | 대표 | 사진 넣기 |

## 핵심: 계정 종류를 코드가 알아서 가른다
- 연예인마다 인스타 아이디를 한 번만 적어 둔다(`config/celeb_instagram.yaml`). Claude가 후보를 찾고, 대표가 처음에 한 번 확인한다.
- 처음 조회할 때 공식 API로 시도한다.
  - **받아지면** '자동' 표시: 크리에이터·비즈니스 계정이다.
  - **안 받아지면** '주소 필요' 표시: 개인 계정이다.
- 대표가 계정 종류를 따로 관리할 필요가 없다.

## 단계별

### 1. 오늘 뜨는 연예인 (새 준비 없음)
- **후보**: 연예 뉴스 RSS의 인물, 어사이드(어드바이저 급상승·홈판), Grok(X 화제)
- **순위**: 네이버 검색광고 월 검색량 + 검색어 트렌드 최근 7일 상승률. 둘 다 이미 키가 있다.
- 최근 3일에 이미 다룬 인물은 감점한다(경제 키워드와 같은 방식).

### 3. 게시물
- **자동 계정**: 인스타 공식 API(Business Discovery)로 최신 게시물 3개를 받는다. 받는 것: 글(캡션), 올린 날짜, 좋아요 수, 게시물 링크, 사진 주소.
  - 도우미에서 대표가 하나를 탭한다. 기본은 최신 게시물이다.
- **개인 계정**: 대표가 인스타 앱에서 게시물 '링크 복사' → 칸에 붙이기.

### 4~5. 상품 → 글
- **브랜드 단서**: 캡션의 @브랜드 태그, '#광고·협찬' 표기, 스타일리스트 태그를 뽑는다.
- **착장 분석**: 자동 계정은 공식 API가 준 사진 주소로 Claude가 착장을 부위별로 분석한다. 분석만 하고 저장하거나 올리지 않는다.
- **상품 후보를 찾는 순서**
  1. 대표가 붙인 렌즈 링크
  2. 캡션 브랜드 + 아이템으로 쇼핑 검색
  3. 기사 교차 확인
- 상품 페이지를 읽어 품번·정가·할인가·판매처를 확인한다(지금 '상품 링크로 글' 기능 그대로).
- 기존 패션 프롬프트(쿠니네 방식)로 제목과 본문을 쓴다.
  - 사진 자리는 "[사진 1: 게시물 1번째 사진]", "[제품 2: 상품 링크]"처럼 표시한다.

### 6. 임시저장 (어사이드)
- 어사이드가 착장 도우미의 완성 글을 열고, 네이버 블로그 에디터(PC)에 제목·본문을 붙인다.
- 제품 자리에는 상품 링크(제휴 링크면 제휴 링크)를 붙인다. 사진 카드로 바뀌면 그대로 둔다.
- 연예인 사진 자리는 표시 문구를 그대로 둔다. 그다음 임시저장한다.
- 막히면(로그인·인증) 멈추고 대표에게 묻는다.

## 허락된 사진 통로 조사 결과

| 통로 | 무엇 | 상태 |
|---|---|---|
| 인스타 공식 임베드(oEmbed) | 게시물을 사진째 끼워 넣는 공식 방법 | Meta가 2025년 11월부터 미리보기 사진(thumbnail) 정보를 뺐고, 앱 검수가 필요하다. 네이버 에디터가 인스타 임베드를 받는지도 확인되지 않았다. **연예인 사진은 현실적으로 대표가 넣는 게 맞다.** |
| 네이버 에디터에 인스타 주소 붙이기 | 링크 미리보기 카드 | 대표가 앱에서 1분 시험하면 바로 확인된다(미확인). |
| 쿠팡 파트너스 | 제휴 링크 + 상품 사진 카드, 판매 수수료 | 제품 사진을 정식으로 쓰는 가장 유력한 길. 오픈 API의 이미지 필드와 가입·승인 조건은 공식 문서로 확인해야 한다(검색으로는 미확인). |
| 네이버 쇼핑커넥트 | 네이버 제휴 링크, 수수료 | 2025년 7월 출시. 에디터에 사진 카드로 들어가는지는 미확인. |

- 제휴 링크를 쓰면 글 끝에 광고 표기 문구를 자동으로 넣는다(CLAUDE.md: 광고 고지 누락 금지).

## 대표가 갖출 것
| 항목 | 필요한 단계 | 비용 |
|---|---|---|
| 인스타 크리에이터 계정 + 페이스북 페이지 + Meta 개발자 앱 | 3단계 '자동' | 무료, 30~40분 |
| 쿠팡 파트너스 가입(선택) | 제품 사진 카드·수수료 | 무료, 승인 조건 확인 필요 |
| 어사이드에 네이버 로그인 | 6단계 임시저장 | 이미 있음 |

## 만드는 순서
1. **지금**: 착장 도우미 화면 + 오늘 뜨는 연예인 + 주소 붙이기 흐름 + 글쓰기 + 어사이드 임시저장 지시문. ②만으로 처음부터 끝까지 돈다.
2. **Meta 세팅 후**: 자동 계정 판별과 최신 게시물 자동 받기, 착장 사진 분석을 붙인다.
3. **쿠팡 파트너스 확인 후**: 제품 사진 카드와 광고 표기를 붙인다.

## 비용 어림 (하루 4명 기준, 10-10 실측 반영)
- 연예인 순위: 거의 0 (네이버 API)
- 사진 분석(자동 계정만): 하루 100~300원
- 상품 페이지 읽기: 1편 **약 20원** (10-10 실측 0.015달러. 전에는 약 510원 → Haiku로 바꾸고 대표 링크만 읽게 해서 96% 줄임)
- 조사 + 제목 + 본문 쓰기: 1편 약 300원
- **합계: 1편 약 350원 → 하루 4편 1,400원 안팎, 월 4만원 안팎** (처음 어림한 월 9만원의 절반 이하)
