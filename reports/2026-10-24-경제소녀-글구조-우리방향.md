# 경제소녀 글 구조 해부 + 우리 부동산 방향 — 2026-10-24

본문 30편(소제목 167개) 분석. 폭등·급락·정책·호재 **전부 같은 틀**. (분석 전용, 복붙·짜깁기·재발행 금지.)

## 경제소녀 글 구조 (확정 — 매우 일관)
1. **도입 4문장**: ① 상황/공감 한 줄 → ② 숫자 요약(전→후·격차) → (반전 단서) → ③ **단지명 공개(도입 마지막 줄)**.
2. **소제목 5~6개**, 전부 **명사구 + 숫자형**. 예: "9억에서 4억대로 내려앉은 실거래 현황", "755가구 단지 구성과 삼성캠퍼스 인접 입지", "2조 6천억 공사비가 드리운 그늘".
3. **소제목마다 사진 1장** (소제목 바로 아래 `(사진)`).
4. **소제목 전개 뼈대(고정)**: ①사건 핵심(숫자) → ②세부 숫자(평형·층·날짜·%) → ③단지 스펙·입지·교통 → ④시장 배경(공급·정책·용적률) → ⑤전망·주의 → ⑥"같이 보고가세요"(관련글 큐).
5. **단락 4~5문장, 1문장 1줄**(짧게 끊음). 말투 해요체+습니다체 섞임.
6. **숫자 구체 반복**: 전용㎡·층·거래일·금액·상승률 계속.
7. **마무리 = 신중·균형 '주의 환기'**(시그니처): "숫자에 매몰되지 말고 차분히", "자금 보수적으로 계산", "입지·물량 따져야". **절대 단정 안 함, 리스크 환기로 닫음.**

## 핵심 관찰 — 경제소녀의 '약점' = 우리 기회
- 정책·사건 소재(예: 분담금 4.2억 '쫓겨납니다')도 **분노 없이 중립 설명 + "자산으로 감당되는지 계산"**으로 닫는다. → **억울·분노가 비어 있다.**
- 해석·대응이 약하고 '시세 브리핑'에 가깝다. 마무리는 늘 '조심스럽게'.
- 이 구조는 **많은 블로거가 쓰는 레드오션** — 100% 미러하면 차별화 0.

## 우리 부동산 방향 (차용 + 차별화)

### 그대로 차용 (먹히는 뼈대)
- 도입 4문장 공식(상황→숫자→단지 공개)
- 소제목 5~6개 명사구+숫자, **소제목마다 사진 1장**
- 1문장 1줄 짧은 단락, 숫자 구체 반복
- 전개 뼈대(사건→세부→입지→시장배경→전망)

### 차별화 (= 경제소녀가 안 하는 것 = 우리 무기)
- **마무리를 뒤집는다:** 신중·주의 환기 ❌ → **해석·대응 + 댓글 도발 질문으로 '열어둠'**("당신이라면 지금 들어갈 건가? 거품인가 실수요인가?").
- **정책 소재엔 억울·분노:** 경제소녀가 중립으로 흘리는 분담금·대출규제·공시가·전세사기를 **"실수요·원주민만 당했다"** 피해자 프레임 + 정책 비판으로.
- **소제목마다 '해석·대응' 한 줄** 추가(경제소녀엔 없음) — 우리 품질 신호.
- **제목 강도 8**(경제소녀는 중간 세기) — 공포·분노어 풀가동.
- **차별화 공식 = 경제소녀 구조(숫자 브리핑) + 우리의 정치색·해석·댓글 싸움.**

### 지킬 선
- **숫자·단지·사실은 조사로 재확인**(경제소녀 숫자 그대로 베끼지 말 것 — 날조·오류 방지). 본문 문장 복제 금지.
- 공포·분노·거품 논쟁은 **사실 근거 위**에서. 실명 개인·기업 비방·음모론·매수매도 단정 ❌.
