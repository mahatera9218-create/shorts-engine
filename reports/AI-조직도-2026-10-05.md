# AI 조직도 (2026-10-05 갱신)

10-04 조직도에 오늘 정한 **그림·영상·목소리 팀**을 더했어요. 원칙은 그대로예요.
① 각 AI는 그 AI가 제일 잘하는 일만 맡아요(중복 없음).
② 쓰는 AI와 검사하는 AI는 다른 회사예요.
③ 계산·수집·편집은 코드로 해요.

## 조직도

```
대표 (사장) ─ 결정 · 발행 · 어드바이저 캡처(선택)
 └ Claude (총괄 · 편집장)
    ├ [취재팀]
    │   ├ 코드        시세 · 뉴스 수집 · 검색량 · 후보 점수
    │   ├ Grok        X 화제 · 투자자 분위기         (대표 가입 중)
    │   └ Claude 웹검색 출처 달린 취재 메모           ✅ (Perplexity 대신, 10-05)
    ├ [검수팀]
    │   ├ Gemini      사실 대조 · 유튜브 요약        (키 대기)
    │   └ GPT         초보 독자 검토 (선택)
    └ [제작팀]
        ├ GPT Image 2   그림 (창고 · 새 장면 · 인형 조각)   ✅ 사용 중
        ├ OpenAI TTS    억선생 목소리 (중년 남자)           ✅ 사용 중
        └ 코드          썸네일 글자 · 인형극 움직임 · 그래프 · 도우미   ✅ 사용 중
```

|---|---|---|---|---|
| **Claude** | 주제 확정, 업무 나누기, 초안, 규칙 검사, 그림 검수(한국 전통미 체크), 최종 조립, 보고 | 총괄 | ✅ | 약 400원 |

| **Claude 웹 검색** | 주제가 정해지면 출처 링크가 달린 취재 메모(배경·기관 전망·일정). Perplexity 대신(10-05 결정) | 쓰는 Claude가 직접 취재, 출처 표시 | ✅ | 약 50원 |
| **Gemini** | 완성 초안의 숫자·날짜를 구글 검색으로 대조, 유튜브 영상(연준 회견 등) 요약 | 구글 검색 연동, 유튜브 링크를 바로 읽음 | 🟡 계정 있음, 키 대기 | 거의 0원 |

| **GPT (글)** | 초안을 경제 초보 눈으로 읽고 어려운 말·지루한 곳 지적 | '다른 회사의 눈' | ⚪ 선택(2주 시험 후 결정) | 약 10원 |

## 하루 흐름 (글 2편 + 쇼츠)

1. **05:30 코드:** 시세·뉴스·검색량 수집 → 후보 점수
2. **Grok:** X 화제 (가입 후)
3. **Claude:** 오늘 2편 확정 (아침 시황 + 오늘의 이슈) → 도우미에 후보 5개와 이유 표시
4. **Claude 웹 검색:** 주제별 취재 메모(출처 포함)
5. **Claude:** 초안 → **Gemini:** 사실 대조 → **Claude:** 고치기
6. **코드 + GPT Image 2:** 창고 그림 고르기, 썸네일 C 구성, 쇼츠 인형극 + **TTS** 목소리
7. **Claude:** 그림 검수(한국 전통미 4가지 확인), 최종 조립 → 도우미
8. **07:00 대표:** 도우미에서 복사 → 블로그 · 쇼츠 · 클립 발행
