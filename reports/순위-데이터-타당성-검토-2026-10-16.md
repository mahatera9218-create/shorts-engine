# 순위 4개 분류 데이터 타당성 검토 (2026-10-16)

> 한계: 조사 환경에서 공공기관·앱스토어 원문이 열리지 않아 **전부 검색 요약(2차 출처) 기준**이다. 평점·리뷰 수·수수료율은 실제 수치를 확인하지 못했다. 구현 전 사람이 공식 1차 원문을 열어 확인해야 한다.

## 1. 한눈에 보기

| 분류 | 구현 가능성 | 권장 형태 | 한 줄 이유 |
|---|---|---|---|
| 세무앱 | 중 | 점수 순위(조건부) | 수수료·표시광고 이력·지원범위는 공개 근거로 점수화 가능. 정확도·편의성·고객지원은 불가 |
| 보험앱 | 중~하 | 공식 서비스 안내 + 비교표 (점수 순위 보류) | 공공데이터는 풍부하나 회사·상품 단위. 앱 단위 객관 지표는 평점·기능뿐 |
| 법무법인 | 하~중 | 비교·가이드형 (서열 없음) | 변협 전문분야 등록·징계 공개가 있으나 API·공개범위 미확인. 광고규정 위험 |
| 세무법인 | 하 | 비교·가이드형 (서열 없음) | 전국 명단 API 없음, 품질을 대리하는 공개 지표 없음 |

## 2. 세무앱
- 확인된 후보: 삼쩜삼(자비스앤빌런즈), 토스 세금 환급, 세이브택스, 홈택스(국세청), 모바일택스, 택스비. **'SSEM(쏘옥)'·'자비스 택스'는 독립 앱으로 확인 못 함 → 현재 목업 데이터 교체 필요.**
- 홈택스는 수수료 0원 관공서 서비스 → 순위 경쟁이 아니라 '기준선' 행으로 분리.
- 점수화 가능: 수수료 투명성(공식 요금 페이지 체크리스트), 표시광고 신뢰도(공정위 확정 시정 이력만. 삼쩜삼 시정명령·과징금 보도 있음, 원문 미확인), 이용자 평점(평가 1,000건 이상만), 지원 신고 유형. 개인정보·보안(ISMS는 KISA 목록과 대조 후).
- 점수화 불가: 환급 정확도, 편의성, 고객지원 품질(객관 데이터 없음) → 목업의 기존 5개 기준 중 일부 교체.
- 반영 금지: 세무사회의 신고·고발(이해당사자 주장), 블로그의 수수료율, 후기 수집.
- 평점 수집: 애플 iTunes Lookup API는 제3자 글 기준 가능하나 약관 미확인, 구글플레이는 공식 API 미확인 → 수동 기록이 안전.

## 3. 보험앱
- 공식 조회 서비스: **내보험찾아줌**(생명보험협회·손해보험협회, 가입 계약·숨은 보험금 조회). 앱스토어의 '내보험다보여' 앱은 개발사가 '박테크'로 표시돼 **공식 앱이 아닐 가능성** → 공식처럼 소개 금지(현재 후보에서 정정 필요).
- 민간 후보: 보맵, 토스 보험(토스인슈어런스), 카카오페이 보험(현재 범위 미확인).
- 공공 데이터: 금감원 금융소비자포털·파인 민원 공시(보험사 계약 100만건당, 반기), 공공데이터포털 금융 OpenAPI(생·손보협회 보험상품 기본정보 등, 키 필요·이용허락 데이터셋별 확인), 손보협회 분기 민원 공시. 단 **앱이 아닌 회사·상품 단위**.
- 불가: 보장분석 정확도, 상담 품질, 보험료 최저가 비교, 지급 만족도. 회사 자체 발표(민원 건수 등)는 점수 사용 금지.
- 권장 화면: [공식 조회(무료) 박스] + [민간 앱 비교표: 기능범위·공식성·민원(운영사 기준)·평점·근거 링크·기준일].

## 4. 세무법인 · 법무법인 (순위형 비권장)
- 후보 명단: 세무 — 전국 명단 API 확인 못 함(세무사회 지역별 조회는 수동 링크로만). 법무 — 변협 변호사·법인 검색, 전문분야 등록(법조경력 3년 이상 등 요건은 변협 안내 확인 필요), 공공데이터 명단 미확인.
- 객관 데이터: 징계(세무사 징계는 관보 공고, 변협 징계정보 공개), 소속 인원·설립연도·자격(수동), 보수 공개 여부(표시만). 구글 Places 평점은 캐싱·저장 제한 → 저장 금지. 네이버 플레이스는 약관 미확인 → 사용 안 함.
- 불가: 성과·품질 점수, 승소율·만족도(공개 데이터 없음, 비교광고 위법 판단 사례 있음).
- 법적 위험(확인된 보도 기준, 원문 대조 필요): 변호사 광고규정('최고·1위·전문' 표기 제한, 과태료 사례), 변호사법 제34조 알선 대가 금지(광고비·소개 수수료 구조 위험), 세무사법 제12조의7 광고 규제(2026년 시행령, 무자격 세무대리 오인 광고 금지), 표시광고법 추천·보증 심사지침(경제적 대가 표시), 명예훼손(징계·평판 사실은 출처·날짜·확정 여부 필수).
- 권장: **서열·점수·추천·'1위' 표현 없이**, 지역·전문분야·보수 공개 여부로 찾는 '찾기 가이드' + 자격 조회 링크 + 상담 전 체크리스트. 정렬은 가나다/무작위. 법률 전문가 1회 검토 후 공개.

## 5. 다음 단계 제안
1. (사람) 공식 1차 원문 확인: 각사 요금 페이지 캡처·URL, 공정위 삼쩜삼 보도자료, 협회·금감원·변협·세무사회 조회 화면 약관.
2. (코드) 순위 JSON에서 근거 없는 후보 제거·정정(쏘옥·자비스·내보험다보여 앱), 세무앱은 새 기준(수수료·표시광고·평점·지원범위)으로 스키마 변경, 보험앱은 '공식 박스 + 비교표', 법인 2개 탭은 '찾기 가이드(비순위)' 구조로 전환.
3. (사람/전문가) 법인 가이드 구조·면책 문구를 변호사·세무사 광고규정 전문가에게 검토.
4. 파일럿: 한 분야 10곳 안팎을 수동으로 만들어 근거 링크 구조를 검증한 뒤 확장.
