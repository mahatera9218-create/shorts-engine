# 스레드·인스타 자동 게시 계획 (초안, 2026-10-06)

## 1. 목적
블로그에 올린 글을 스레드·인스타에 한 번 더 내보내 **블로그로 사람을 데려온다**. SNS는 새 글을 쓰는 곳이 아니라 블로그 글을 짧게 다시 쓰는 곳이다.

## 2. 채널별 형식
| | 스레드 | 인스타그램 |
|---|---|---|
| 중심 | 글 | 그림 |
| 내용 | 핵심 3~5줄 + 끝에 질문 한 줄 + 블로그 링크 | 카드뉴스 5장 + 캡션 + 해시태그 |
| 그림 | 카드 1장(표지) | 표지 / 핵심 1·2·3 / 요약 |
| 링크 | 글에 바로 (누르면 블로그로) | 캡션 링크는 안 눌려서 "프로필 링크에서 보기" |

## 3. 카드뉴스 그림
- 코드가 글 내용으로 직접 만듦 (AI 사진 아님, 0원, 저작권 걱정 없음)
- 경제: 크림 바탕 + 테라코타, 큰 숫자 위주 / 패션: #E0D3BB 바탕, 차분한 글씨
- 대표가 ChatGPT로 받은 블로그 사진은 휴대폰에만 있어서 자동으로 못 씀 (원하면 나중에 도우미에서 올리는 기능 추가)

## 4. 흐름
1. 대표가 블로그 발행 후 도우미에서 **발행 완료** 누름
2. 자동: 그 글로 스레드 글·인스타 캡션·카드뉴스를 만들어 도우미 **SNS 칸**에 띄움 (약 3분)
3. 대표가 보고 **게시** 누름 → 스레드·인스타에 올라감 → 도우미에 게시물 링크 표시
- 외부 공개라 마지막 버튼은 대표가 누름 (원하면 나중에 완전 자동)

## 5. 비용
- 글 요약(Claude) 1편 약 30원, 카드 그림 0원, 게시(API) 0원

## 6. 대표가 처음 한 번 할 일
1. 계정 만들기 (블로그별로 인스타 1개 + 스레드 1개, 스레드는 인스타 계정으로 바로 생김)
2. 인스타를 프로페셔널 계정(크리에이터)으로 바꾸기 (무료)
3. 메타 개발자 앱 만들어 계정 연결 → 받은 키를 GitHub Secrets에 넣기 (Claude가 휴대폰 화면 기준으로 단계별 안내)
- 키는 60일마다 만료 → 코드가 자동으로 연장

## 7. 진행 순서 (추천)
1. 1주차: **경제 스레드만** 시범 (가장 간단, 링크 클릭 됨)
2. 반응(조회·블로그 유입) 보고 경제 인스타 → 패션 스레드·인스타로 넓힘

## 8. 대표 결정 필요
1. 계정: 블로그별로 따로(추천) / 하나로 합치기
2. 시작 범위: 경제 스레드만 먼저(추천) / 처음부터 전부
3. 게시: 대표가 게시 버튼(추천) / 완전 자동

출처: Threads API 게시 한도 24시간 250개, Instagram API 24시간 50~100개 (Meta 개발자 문서)
