# 집 PC 블로그 자동화 운영 기획안 (2026-10-23)

목표: **대표는 "채팅 + 제목 + 발행 버튼"만, 나머지(수집·조합·임시저장)는 집 PC의 어사이드가.** 밖에서도 폰으로 돌린다.

---

## 1. 전체 그림

```
[대표(어디서든 폰)]
     │  원격 데스크톱(크롬 원격)으로 집 PC 접속
     ▼
[집 PC — 24시간 켜둠]
     ├─ 어사이드 (구독 클로드 연결)
     │    ├─ 경제 프로필 → 경제 네이버 로그인
     │    ├─ 패션 프로필 → 패션 네이버 로그인
     │    └─ 건강 프로필 → 건강 네이버 로그인
     │
     ├─ ① 대표가 AI랑 채팅(키워드별) → 글·사진 끝에 *ㄱ키워드
     ├─ ② '조합' 1번 → 글+사진 네이버 임시저장에 쌓임
     └─ ③ 대표가 제목 쓰고 발행 버튼  ← 사람만
```

## 2. 하루 운영 루틴

| 단계 | 누가 | 뭘 |
|---|---|---|
| 1. 키워드 정하기 | 대표 | 조회·홈판 데이터 기반 '승자 주제' |
| 2. AI 채팅 | 대표 | 그록 조사→클로드 글→GPT 사진, 끝에 `*ㄱ키워드` |
| 3. 조합 | **어사이드** | 오늘 `*ㄱ`만 모아 네이버 임시저장 |
| 4. 제목·검수 | 대표 | 임시저장 열어 제목 쓰고 사진 확인 |
| 5. 발행 | 대표 | 발행 버튼 (스팸·계정 안전선) |

→ 자동화되는 건 **3번(수집·조합·임시저장)**. 대표 손은 1·2·4·5.

## 3. 1회 세팅 체크리스트 (집 PC)

- [ ] 어사이드 설치 → **클로드 구독 계정 연결**(필수, 안 하면 토큰 날아감)
- [ ] GPT·그록도 연결
- [ ] 프로필 3개(경제/패션/건강), 각 프로필에 해당 블로그 네이버 로그인
- [ ] 조합 지시문 3개 + 지식인 지시문 준비(저장소 docs/prompts)
- [ ] **전원 설정:** 절전·최대절전 "안 함", 모니터만 끄기, 윈도우 "활성 시간" 설정(멋대로 재부팅 방지)
- [ ] **크롬 원격 데스크톱** 설치 → 폰 앱 연결 테스트
- [ ] 집 PC에서 T3 테스트(짧은 글→조합→임시저장) 1회 통과 확인

## 4. 관리 루틴 (가볍게)

- 주 1회 PC 재부팅(느려짐 방지)
- 몇 달에 한 번 먼지 청소
- 어사이드에 '예약 실행' 기능 있으면 → 정해진 시간 자동 조합(발행은 여전히 사람)

## 5. 안전선 (바뀌지 않음)

- **발행은 사람만.** 자동 발행·같은 링크 반복 = 네이버 스팸 감지 → 계정 정지 위험.
- 지식인도 "찾기·초안"만 자동, 게시는 대표가 하루 2~3개 띄엄띄엄.
- API 키·비밀번호는 코드·대화에 안 남김.
