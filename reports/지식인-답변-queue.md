# 지식iN 답변 대기 큐 (찾기·초안 자동 / 게시 수동)

어사이드가 찾아 쓴 답변 초안을 여기 쌓는다. **게시는 대표가 손으로, 하루 2~3개 이하 띄엄띄엄.**
스팸 방지: 자동 게시 금지, 같은 링크 반복 금지, 매 답변에 링크 금지. (DECISIONS 2026-10-18)

사용법: 어사이드 지시문 = `docs/prompts/aside-지식인-답변.md`. 어사이드가 준 초안을 아래 양식으로 붙인다.

---

## 양식 (복사해서 채우기)

```
## [YYYY-MM-DD] 질문 제목
- 링크: https://kin.naver.com/...
- 상황: (질문 요지 1줄)
- 답변 초안:
  (본문 — 공식 기준 근거, 가짜 경험 금지, 링크는 정말 도움될 때만 끝에 1개)
- 링크 포함: 있음/없음 · 상태: 대기
```

상태 값: `대기` → `게시함(YYYY-MM-DD)` 또는 `버림(사유)`
