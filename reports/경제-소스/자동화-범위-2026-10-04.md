# 경제 블로그: 자동화 범위와 글감 소스 (2026-10-04)

(토요일에 점검해서 평일엔 기사 수가 더 많을 거예요.)

## 1. 글감 소스: 무엇을 쓸까

| 자산 | 주 소스 (자동) | 보조 소스 (자동) | 하루 기사 수 |
| --- | --- | --- | --- |
| 국내주식 | 네이버 뉴스 API | 연합뉴스 마켓+, 한국경제 증권, 매일경제 증권 RSS | 100건 이상 |
| 미국주식 | 네이버 뉴스 API | **야후 파이낸스 종목별 RSS**(S&P500·나스닥·개별 종목), CNBC, MarketWatch (영어, 국내 기사보다 빠름) | 100건 이상 |
| 금 | 네이버 뉴스 API | **야후 금 선물 RSS** | 15~23건 + 야후 13건 |
| 비트코인 | 네이버 뉴스 API | 블록미디어, CoinDesk, 야후 비트코인 RSS | 100건 이상 |

**오늘 숫자(가격)**: 업비트(비트코인·이더리움 원화), CoinGecko, Gold API(국제 금값 달러), 유럽중앙은행 환율. 모두 키 없이 받아져요.
코스피·S&P500 지수 숫자는 키 없는 통로를 못 찾았어요 → 기사에 나온 숫자를 출처·시각과 함께 인용.

**야후 파이낸스(다시 점검)**: 처음엔 갱신이 멈춘 옛 주소로 시험했어요. 종목별 뉴스 주소로 다시 하니 S&P500·나스닥, 엔비디아·애플·테슬라, 금 선물, 비트코인 모두 ✅ (각 하루 13~20건). 종목 기호만 바꾸면 원하는 종목 뉴스를 받을 수 있어요. 코스피·삼성전자는 영어 기사가 적어 네이버 쪽이 나아요.

**Kitco**: 공식 RSS가 없어요(주소 4개 시험 모두 실패). 다른 업체가 Kitco 웹페이지를 긁어 RSS로 만들어 주는 서비스는 있지만, 우리 기준으로는 무단 크롤링이라 쓰지 않아요. 금은 네이버 뉴스 + 야후 금 선물로 충분해요.

**탈락**: Kitco(공식 RSS 없음), 코인데스크코리아(RSS 아님), CNBC Markets(갱신 안 됨), 이투데이(적음).
구글뉴스 RSS는 받아지지만 이용 조건이 애매해서 쓰지 않아요.

결론: **네이버 뉴스 API 하나로 4개 자산이 다 충분하고, 이미 키가 있어요.** RSS는 빠짐 보완용.

## 2. 자동으로 하는 것 (대표님 손 안 감)

1. 글감 수집: 매일 새벽 위 소스에서 제목·요약·링크만
2. 오늘의 이슈 고르기: 같은 사건을 다룬 기사가 많을수록 위로(코드), 최종 선택은 AI
3. 사실 뽑기(AI) + 가격 숫자(시세 API)
4. 글 쓰기: 질문형 제목, 첫 2~3줄에 답, 배경, 기관 전망 정리, 일정, 글쓴이 생각, 출처, 면책 한 줄
5. 검사(코드): 매수·매도 권유 표현, 원인 단정, 가짜 경험, 출처 없는 숫자
6. 무료 사진(Pexels) + 썸네일
7. 발행 도우미에 올리기, 예약 실행·아침 점검 (지금처럼)

## 3. 대표님이 해야 하는 것 (자동화 불가)

1. **네이버 발행 버튼**: 네이버 블로그는 글쓰기 API가 없어요. 도우미에서 복사 → 붙여넣기 → 발행 (1편 2~3분)
2. **블로그 설정**: 이름·카테고리 변경, 애드포스트
3. (권장) 발행 전 30초 훑어보기, 특히 숫자

→ 하루 2편 기준 **대표님 시간 약 5~10분**.

## 4. 하지 않는 것

- 언론사 웹페이지 직접 긁기: RSS·API로 충분하고 원칙상 금지
- 기사 사진: 저작권 → 무료 사진만
- 증권사 리포트 원문: 자동 통로가 없어서, 리포트를 다룬 기사로 대신
- 유료 뉴스(블룸버그·WSJ 등), 네이버 검색 결과·증권 페이지 긁기
