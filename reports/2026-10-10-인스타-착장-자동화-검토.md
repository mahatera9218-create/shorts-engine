# 인스타 착장 → 블로그 글 자동화 검토 (2026-10-10)

대표 요청: 네이버 검색량 상위 연예인 → 인스타 최신 게시물 → 사진 분석으로 상품 정보 → 렌즈 같은 도구로 검증 → 글. OTT 방송 착장 자동화 사례도 참고.

## 결론 먼저

**된다.** 단계마다 공식 통로가 있다. 지금 인프라에 **두 가지만 더하면** 1~5단계를 다 자동으로 돌릴 수 있다.

1. **Meta(인스타) 공식 API**: 인스타 최신 게시물을 공식으로 받는 통로.
2. **구글 클라우드 Vision API (Web Detection)**: 구글 렌즈의 공식 API 판. 같은 사진이 실린 쇼핑몰·기사 페이지를 찾아 준다.

나머지(검색량, 사진 분석, 상품 페이지 읽기, 글쓰기)는 이미 있다.

| 단계 | 쓸 도구 | 지금 있나 |
|---|---|---|
| 1. 검색량 상위 연예인 | 네이버 검색광고 API(월 검색량) + API HUB 검색어 트렌드(최근 상승률) + 어사이드(어드바이저 급상승) | ✅ 있음 |
| 2. 인스타 최신 게시물 | Meta 인스타 API의 Business Discovery | ❌ **새로 필요** |
| 3. 사진 읽고 상품 정보 | Claude 사진 분석 + 게시물 글(캡션)의 @브랜드 태그·협찬 표기 | ✅ 있음 |
| 4. 렌즈처럼 검증 | 구글 Vision Web Detection → 찾은 쇼핑몰 페이지를 Claude가 읽기 | ❌ **새로 필요** (페이지 읽기는 있음) |
| 5. 블로그 글 | 지금 쓰는 '상품 링크로 글' 흐름 | ✅ 있음 |

## 단계별 설계

### 1. 검색량 상위 연예인 찾기 (새 인프라 없음)
- **후보 모으기**
  - 어사이드: 크리에이터 어드바이저 급상승, 홈판 인기글에 나온 인물
  - 연예 뉴스 RSS: 기사 제목에 나온 인물
  - Grok: X에서 화제인 인물
- **순위 매기기**
  - 검색광고 API로 인물 이름의 월 검색량
  - 검색어 트렌드로 최근 7일 상승률. 우리 API HUB 키로 이미 정상 응답을 확인했다.
  - "검색량 많고 + 최근 오르는" 인물 상위 10명을 뽑는다.
- 결과: 도우미 패션 탭에 '오늘 뜨는 연예인' 카드

### 2. 인스타 최신 게시물 (Meta 공식 API 필요)
- **Business Discovery**: 우리 인스타 프로페셔널 계정으로, 다른 프로페셔널 계정(비즈니스·크리에이터)의 공개 게시물을 공식으로 받는 기능이다.
- 받는 것: 게시물 글(캡션), 사진 주소, 게시물 링크, 올린 시각, 좋아요 수
- 인물마다 인스타 아이디를 한 번 정해 둔다(`config/celeb_instagram.yaml`).
  - Claude가 후보를 찾는다.
  - 대표가 처음 한 번만 확인한다.
- **안 되는 것**
  - 개인 계정(프로페셔널 아님)인 연예인은 받을 수 없다.
  - 스토리는 받을 수 없다. 상품 태그가 스토리에 많아서 아쉽다.
  - 저작권 음악이 붙은 릴스는 영상 주소가 빠진다.
  - 한국 연예인 중 몇 %가 크리에이터 계정인지는 **직접 돌려 봐야 안다.**

### 3. 사진 분석 → 상품 정보
- **Claude 사진 분석**: 착장을 부위별로 나눈다(상의·하의·가방·신발·액세서리). 색, 소재, 실루엣, 보이는 로고까지 본다.
- **브랜드를 가장 확실히 알려 주는 건 사진이 아니라 글이다.**
  - 캡션의 @브랜드 태그
  - '#광고·#협찬·유료 광고' 표기
  - 스타일리스트 태그
  - 이걸 따로 뽑는다.
- 류혜영 방송 착장 시험(10/8)에서 배운 점: 사진만으로는 "무엇을 입었는지"는 정확했지만 "어느 브랜드인지"는 거의 못 맞혔다. 그래서 3단계는 사진 + 글을 같이 본다.
- 사진은 **분석만 하고 저장하거나 글에 올리지 않는다**(저작권). 글에 넣을 사진은 지금처럼 대표가 고른다.

### 4. 검증 (구글 Vision 필요)
- **구글 Vision Web Detection**: 사진 주소를 주면 다음을 돌려준다. 구글 렌즈와 같은 원리다.
  - 같은 사진이 실린 페이지
  - 비슷한 사진
  - 구글이 짐작한 이름
- 찾은 쇼핑몰·기사 페이지를 Claude가 읽는다(지금 '상품 링크로 글'에서 쓰는 기능). 그래서 브랜드·제품명·품번·가격을 확인한다.
- 네이버 뉴스 API로 "인물 + 브랜드" 기사를 한 번 더 맞춰 본다.
- 아이템마다 확인 정도를 표시한다.
  - **확정**: 캡션 태그, 기사, 공식몰 중 하나와 일치
  - **추정**: 비슷한 상품만 찾음
  - **모름**

### 5. 글
- 도우미에 '인스타 착장' 카드가 뜬다. 카드 내용: 인물, 게시물 링크, 아이템별 확정·추정, 상품 링크.
- **대표가 고르면**(역할 정리: 키워드 선정은 대표) 지금의 '상품 링크로 글' 흐름으로 바로 쓴다.
- 대표는 '추정' 아이템만 렌즈로 보정하면 된다.

## OTT 방송 착장으로 넓히기
- OTT 영상 자체는 내려받을 수 없다. 약관 위반이고, 우리 원칙의 "타인 영상 다운로드 금지"에도 걸린다.
- 대신 방송사가 유튜브에 올린 **공식 클립**을 쓴다.
  - 유튜브 공식 API로 찾는다(이미 있음).
  - Gemini가 유튜브 주소를 직접 본다(이미 있음, 10/8 시험).
  - 출연자별 착장과 나온 시각을 정리한다.
- 브랜드는 위 2~4단계로 채운다.
  - 출연자·스타일리스트 인스타 캡션
  - "○○ 착용 제품" 기사
  - 공식 썸네일에 Web Detection
- OTT 사례의 그분도 브랜드는 대부분 이런 **글 쪽 단서**(협찬 크레딧, 스타일리스트 게시물, 기사)에서 얻었을 가능성이 크다. 사진만으로 품번까지 맞히는 도구는 아직 없다.

## 하지 말아야 할 방법 (그리고 이유)

| 방법 | 기술적으로 | 왜 안 하나 |
|---|---|---|
| 어사이드가 인스타에 로그인해 돌아다니며 읽기 | 됨 | 인스타 약관이 허락 없는 자동 수집을 금지한다. 걸리면 **대표 인스타 계정이 정지**될 수 있다. 어사이드는 지금처럼 네이버(대표 본인 화면)만 맡긴다. |
| 스크래핑 업체(Apify 등)로 인스타 긁기 | 됨 | 약관 위반 수집이다. CLAUDE.md "무단 크롤링 금지"에 걸린다. |
| 구글 렌즈 결과를 대신 긁어 주는 업체(SerpApi 등) | 됨 | 구글 검색 결과 화면을 긁는 방식이다. CLAUDE.md "검색 결과 페이지 크롤링 금지"에 걸린다. 공식판인 Vision API를 쓴다. |
| 인스타 사진·방송 캡처를 글에 올리기 | 됨 | 저작권. 분석만 하고 올리지 않는다(기존 원칙). |

"못 한다"는 게 아니라, 위 방법들은 **대표 계정과 블로그를 위험에 빠뜨려서** 공식 통로로 같은 결과를 내는 쪽을 고른 것이다.

## 대표가 갖춰야 할 것

| 항목 | 할 일 | 비용 | 시간 |
|---|---|---|---|
| 인스타 프로페셔널 계정 | 기존 계정을 '크리에이터'로 전환하거나 블로그용 계정 새로 만들기 | 무료 | 5분 |
| 페이스북 페이지 | 페이지 1개 만들고 인스타와 연결 | 무료 | 10분 |
| Meta 개발자 앱 | developers.facebook.com에서 앱 만들기, 토큰 발급 → GitHub Secrets | 무료 | 20~30분 (태블릿 권장) |
| 구글 클라우드 | 프로젝트 만들기, 결제 카드 등록, Vision API 켜기, 키 발급 → GitHub Secrets | 매달 1,000건 무료, 이후 1,000건당 3.5달러 | 20분 |

- 토큰·키는 GitHub Secrets에만 넣는다(원칙 그대로).
- Meta 토큰은 60일마다 갱신해야 한다. 갱신은 코드로 자동화할 수 있다.
- Meta 권한 이름과 '앱 검수가 필요한지'는 자료마다 달라서, 세팅할 때 공식 문서로 확인한다.

## 비용 어림 (하루 연예인 10명 × 게시물 5개 = 사진 50장 기준)
- 구글 Vision: 월 1,500건 → 1,000건 무료, 나머지 500건 약 1.75달러 → **월 2,500원 안팎**
- Claude 사진 분석: 1장 1~2센트 → 하루 50장이면 **하루 700~1,400원, 월 2~4만원**
- 대표가 고른 글의 상품 페이지 읽기: 1편 약 500원(10/8 실측)
- 연예인을 5명으로 줄이거나 최신 게시물 2개만 보면 절반 이하로 줄어든다.
- 위 숫자는 어림이다. 첫 1주 실측 후 다시 보고한다.

## 진행 순서 제안
1. **지금 바로 (새 인프라 없음)**: 1단계 '오늘 뜨는 연예인' 카드부터 만든다(검색량 + 상승률).
2. **Meta 세팅 후**: 2~3단계. 인스타 최신 게시물과 착장·캡션 분석을 도우미에 띄운다. 먼저 연예인 20명으로 **크리에이터 계정 비율**부터 확인한다.
3. **구글 세팅 후**: 4단계 검증(확정·추정 표시)을 붙인다.
4. **마지막**: OTT 공식 클립 확장.
