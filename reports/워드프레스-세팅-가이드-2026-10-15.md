# 워드프레스·애드센스 세팅 가이드 (대표 실행용 · 휴대폰 기준)

2026-10-15 · 구글(WP) 블로그를 띄우고 애드센스를 붙이기까지. 대표가 할 것 / Claude가 할 것 구분.
근거: 구글 전략·구조·애드센스 조사(reports/). 로드맵 원본: 워드프레스-애드센스-로드맵-2026-10-14.md.

## 순서 한눈에

도메인 → 호스팅+WP → 기본 세팅(필수 페이지·RankMath·저자) → 글 몇 편 → 애드센스 신청 → 자동화 연결

---

## 1단계. 도메인 재구매 — 대표
- **astacgroup.com** (기존 애드센스 승인 재사용 노림). 가비아·후이즈·Cloudflare가 쌈(연 1~2만원).
- 만료 상태라 선점 가능 → 쓸 거면 너무 미루지 말 것.

## 2단계. 호스팅 + 워드프레스 설치 — 대표
- 가비아/카페24에서 **도메인+호스팅 묶음 + 원클릭 워드프레스**가 제일 간단(월 5천~1만원).
- 설치 후 관리자(wp-admin) 로그인만 되면 됨.

## 3단계. 기본 세팅 — 대표(클릭) + Claude(내용 제공)
애드센스 승인·SEO의 기반. 이게 없으면 승인 거절 흔함.
- **필수 페이지 5개 만들기(애드센스 요건):** 소개 / 연락처 / 개인정보처리방침 / 이용약관 / 면책
  - **소개 = 저자 페이지:** `reports/저자소개-페이지-초안-2026-10-15.md` 내용 그대로.
  - 나머지 4개는 Claude가 초안 드릴 수 있음(요청 주세요).
- **테마:** 가볍고 빠른 기본 테마(모바일·속도 중요).
- **RankMath(무료 SEO 플러그인) 설치:** 제목·메타 템플릿·사이트맵·스키마(Article·Breadcrumb) 자동. 설정 마법사만 따라가면 됨.
- **관련 글 플러그인**(테마 기본 or YARPP): 글 하단 '함께 보면 좋은 글' 자동.
- **퍼머링크:** 설정 → 고유주소 → '글 이름'(슬러그) 방식.
- **앱 비밀번호 발급**(사용자 → 프로필): 나중에 자동 발행 연결용. (발급만 해두면 됨)

## 4단계. 글 몇 편 올리기 — Claude 작성 → 대표 발행
- 승인 전에 **품질 글 10~15편**이 쌓여 있는 게 유리(한 주제 집중).
- 1번 클러스터부터: 소득세율표 → 자녀증여한도 → 증여세 세율… (순서: `reports/구글-키워드-우선순위-2026-10-15.md`)
- Claude가 구글판 프롬프트로 초안(본문+표+도식+alt) → 대표가 WP에 붙여 발행.

## 5단계. 애드센스 신청/재연결 — 대표
- 애드센스 → 사이트 추가(astacgroup.com) → 검토 요청. (기존 목록에 있으면 신규보다 수월할 수 있음)
- **ads.txt**·자동광고 코드 넣기(애드센스가 주는 대로). 광고는 **긴 글당 3~5개**·제목 아래·본문 속·모바일 하단 앵커로(사이드바 약함).
- ⚠️ **내 광고 절대 클릭 금지**(계정 영구정지 1순위). 지인 클릭·클릭 요청도 금지.

## 6단계. 자동화 연결 — Claude
- WP REST API + 앱 비밀번호로 **'비공개 초안(draft)' 자동 업로드** → 대표가 WP에서 발행(외부공개=대표 승인).
- 도식(세율표·계산 카드)은 코드로 생성해 함께 업로드. 이미지 WebP 압축·width/height·alt 자동.
