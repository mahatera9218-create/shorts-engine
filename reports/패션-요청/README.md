# 패션 새 글 요청함 (접수 → 생성 대기)

도우미(eok-fashion-desk.pages.dev) '제품 정보 넣기'에서 대표가 보낸 요청이 접수함 워커(KV)를 거쳐
드레인 워크플로(.github/workflows/fashion-request-drain.yml, 20분마다)로 여기 `*.md`로 쌓인다.

생성 세션(패션 요청 처리 예약)이 이 파일들을 읽어 그 제품으로 발행 패키지를 만들고
(reports/패션글-초안/에 저장), 처리한 요청 파일은 `done/`으로 옮긴다.

각 파일: 맨 위 `# 접수 <시각>`, 그 아래 대표가 적은 제품 정보/링크(자유 텍스트).
