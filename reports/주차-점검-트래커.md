# 주차·점검 트래커 (경제·패션 따로)

경제와 패션은 **독립 주차**로 관리한다. 점검은 '달력 주'가 아니라 **규칙 적용 후 발행분 vs 전**으로 본다. 이 표를 매 점검 때 먼저 확인한다. (최신 갱신 2026-10-14)

## 경제 (억선생의 경제판)

| 구분 | 내용 |
|---|---|
| 발행 시작 | 2026-10-06 |
| 1주차 점검 | **2026-10-13** — 제목 비교(우리 24편 vs 유미·토르 등) `reports/주간/2026-10-13-1주차-제목비교.md` |
| 이번 주 평가 변수 | **제목(강제 규칙) + 주제(증시→증시+부동산)** 만 |
| 다음 주(2주차) 평가 변수 | 세무절세 추가 · 순번 자동수집/관심도순 · 블로그 컨셉·정체성 (10/14에 올린 것) |
| 2주차 점검 예정 | **2026-10-20(월)** — 규칙 적용 후 발행분으로 제목 비교 재측정 + 조회·CTR |
| **3주차 과제 (2026-10-16 대표)** | **제목은 고수처럼 쓰는데 홈판 노출이 너무 저조 → 원인 파악.** 가설: ① 타깃·주제 신호 약함(홈피드 분류 실패) ② 흔한 키워드 과반복 감점 ③ 체류·스크롤 낮음(본문) ④ 신생 블로그 지수 ⑤ 제목만 베끼고 '왜 눌렀나(상황)' 없음. 3주차에 지표(유입경로·체류·스크롤)로 좁혀 판정. |

## 패션 (캐시미어 다이어리)

| 구분 | 내용 |
|---|---|
| 발행 시작 | 2026-10-06 |
| 1주차 점검 | **2026-10-14** — 우리 15편 vs 쿠니네패션 68개 `reports/1주차-점검-패션-2026-10-14.md` |
| 이번 주 평가 변수 | 제목(쿠니네패션 수준: 훅 60%+·27~30자·큰따옴표 다양화·가격/나이) |
| 2주차 점검 예정 | **2026-10-21(화)** — 규칙 적용 후 발행분으로 같은 표 재측정(훅·길이·큰따옴표 격차 좁혀졌나) |

## 관리 규칙

1. **블로그마다 주차를 따로 센다.** 경제 2주차와 패션 2주차 점검일이 하루이틀 다를 수 있다(점검 시작이 달라서). 섞지 않는다.
2. **점검 기준 = 규칙 적용 후 발행분.** 프롬프트 교체 시점이 블로그마다 다를 수 있으니, "며칠부터 규칙 적용분"인지 점검할 때 명시한다.
3. **한 주엔 변수 하나씩.** 성과가 좋아도 무엇 덕인지 가리려면 그 주의 '간판 변수'를 하나로. (경제: 이번 주=제목·주제, 다음 주=세무·자동수집·컨셉)
4. **해석 틀:** 유입·CTR→제목 / 방문층(성별·연령)→주제 / 재방·체류·**스크롤(완독)**→전문성·컨셉·체류설계.
   - **스크롤/완독 지표 추가(2026-10-16, 홈피드 노하우):** 랭커는 클릭률·체류뿐 아니라 **스크롤(얼마나 내려 읽었나)**을 본다. 주간 점검 때 네이버 통계에서 보이는 범위로 글별 스크롤·완독을 함께 적고, 낮은 글은 '체류층(본문)' 설계를 고친다.
5. 월요일 통합 점검일에 각 블로그를 '자기 주차 기준'으로 본다. 날짜는 위 표를 갱신하며 유지.
