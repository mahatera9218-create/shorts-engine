# AI 조직도 (초안, 2026-10-04)

원칙: ① 각 AI는 **그 AI만 할 수 있는 일**만 맡는다(중복 없음) ② **쓴 AI와 검사하는 AI는 다른 회사**(같은 맹점 방지) ③ 계산·수집은 코드.

## 조직도
```
대표 (사장) ─ 결정 · 발행 · 크리에이터 어드바이저 캡처 전달
 └ Claude (총괄 · 편집장) ─ 주제 확정, 업무 배분, 초안, 양식·규칙 검사, 최종 조립, 보고
    ├ Grok        시장 분위기 담당
    ├ Perplexity  취재 담당
    ├ Gemini      팩트체크 담당
    ├ GPT         독자 대표 (선택, 시험 후 결정)
    └ 코드        수집 · 시세 · 무료 사진 · 형식 검사 · 도우미
```

## 누가 무엇에 최적인가
| 담당 | 맡는 일 | 이 AI만의 강점 (공식 API 기능) | 예상 비용 |
| --- | --- | --- | --- |
| **Grok** | 지금 X에서 뜨는 경제 화제 + 투자자 반응(낙관/공포) 요약. 특히 미국주식·코인 | **X(트위터) 검색**은 Grok만 가능 | 검색 1번 약 7원 |
| **Perplexity** | 주제가 정해지면 **출처 링크가 달린 취재 메모**: 배경, 증권사·기관 전망, 앞으로 일정 | 모든 답이 실시간 웹 검색 + 출처 인용 기본, 최근 24시간·언론사만 같은 검색 필터 | 요청 1번 약 10~20원 + 글자 값 |
| **Gemini** | ① 완성 초안의 숫자·날짜·사실을 **구글 검색으로 대조**해 틀린 곳 표시 ② **유튜브 영상 요약**(연준 기자회견, 경제 유튜브) | 구글 검색 연동, **유튜브 링크를 바로 읽는 기능** | 월 5,000번까지 검색 무료 |
| **GPT** | 완성 초안을 **경제 초보 독자 눈으로** 읽고 어려운 말·지루한 곳·남는 궁금증 지적 | 고유 기능이라기보다 '다른 회사의 눈'. 2주 시험 후 효과 없으면 뺌 | 글 1편 약 10원 |
| **Claude** | 위 모든 결과를 모아 판단·작성·검사·조립 | 총괄 | 지금과 비슷 |
| **코드** | 네이버 뉴스·야후 RSS 수집, 시세, 무료 사진(Pexels), 형식 검사 | 계산·수집은 코드 | 무료 |

**겹치지 않게 정리한 것**
- Perplexity(취재) ↔ Gemini(검증): 둘 다 웹 검색을 하지만 **취재와 검증을 다른 회사 검색엔진**이 맡아 서로 확인.
- GPT의 딥리서치는 Perplexity와 겹쳐서 안 씀. 그림 기능은 '무료 사진만' 원칙으로 안 씀.

## 하루 흐름 (글 1편)
1. 코드: 기사·시세 수집
2. Grok: 지금 뜨는 화제
3. (대표 캡처가 있으면) 어드바이저 인기 유입 검색어 읽기
4. **Claude: 오늘 주제 확정**
5. Perplexity: 취재 메모(출처 포함)
6. **Claude: 초안**
7. Gemini: 사실 대조 → 틀린 곳 표시
8. GPT: 독자 검토 (선택)
9. **Claude: 고치고 최종 조립** → 코드: 무료 사진·형식 검사 → 도우미
10. 대표: 복사 → 발행

추가 비용(하루 2편): 대략 **하루 100~250원, 한 달 3천~8천 원** (1주 실측 후 보고)

## 대표 캡처 전달 방법
도우미에 "오늘 키워드 캡처 올리기" 버튼 → 휴대폰 사진 첨부 → Claude가 읽고 경제와 상관없는 단어는 빼고 반영. 없는 날은 자동 후보로.

## 가입 순서 제안 (대표: 가입·결제·키 입력)
1단계 Perplexity + Gemini (효과가 가장 큼) → 2단계 Grok → 3단계 GPT(시험)
