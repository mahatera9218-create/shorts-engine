# 네이버 눈으로 본 우리 글 + 검색 API 쉬운 설명 (2026-10-11)

> 대표 질문: "지금 쓰는 제목·글 수준으로 발행 수를 쌓으면 승산이 있나? 네이버 입장에서 더 면밀하게. 아까 API 얘기는 쉽게."
> 실제 글을 다시 읽고 판단했습니다: 경제 「삼성전자 성과급」(10-10), 패션 「이연희 루이비통 가방」(10-11), 그 밖에 최근 경제 글 9편의 제목·본문.

## 한 줄 결론

**지금 그대로 개수만 늘리면 승산이 낮습니다.** 글이 틀려서가 아니라, 네이버가 높게 쳐 주는 것은 **"여기서만 볼 수 있는 내용"과 "사람들이 눌러서 끝까지 읽는 글"** 인데, 우리 글은 **"정확한 뉴스 정리"** 에 머물러 있기 때문입니다.

---

## 1. 네이버는 글을 어떻게 보나 (쉽게)

네이버가 공개해 온 설명을 쉽게 풀면, 글을 **3개의 눈**으로 봅니다.
※ 아래는 네이버 검색 공식 블로그 등에서 공개한 설명을 정리한 것입니다. 정확한 계산 방식은 공개되지 않았습니다.

| 네이버의 눈 | 쉽게 말하면 | 무엇을 보나 |
|---|---|---|
| **① 블로그 신뢰도** (C-Rank) | "이 블로그, 이 분야 믿을 만한가?" | 한 주제를 꾸준히, 깊이 있게 쓰는지. 읽은 사람의 반응 |
| **② 글 하나의 품질** (D.I.A.) | "이 글에만 있는 게 있나?" | 직접 겪은 것·독자적 정보·질문에 맞는 답. 다른 글과 얼마나 다른지 |
| **③ 홈판 추천** (AiRS) | "사람들이 눌렀고, 오래 읽었나?" | 클릭, 머문 시간, 공감·댓글, 이웃 추가 |

그리고 네이버가 **싫어한다고 밝힌 것**:
- 제목과 본문이 다른 글(낚시)
- 기사를 옮기거나 짜깁기한 글, 비슷한 글 반복
- 기계로 대량으로 찍어낸 티가 나는 글

---

## 2. 우리 글 채점 (네이버 눈 기준)

### 경제 「삼성전자 성과급」

| 항목 | 점수 | 이유 |
|---|---|---|
| 정확성 | 🟢 좋음 | "노조 추산", "확정 아님"을 꼬박꼬박 밝힘. 틀린 숫자 없음 |
| ② 이 글에만 있는 것 | 🔴 낮음 | 내용 전부가 기사 5개(연합·SBS·인사이트·주간조선·뉴시스)에 이미 있던 것. 같은 날 같은 기사를 보고 쓴 블로그가 수십 개 |
| 분량 | 🟠 짧음 | 1,190자에 사진 7장. 글보다 사진 자리가 더 많아 보임 |
| 글쓴이 목소리 | 🔴 없음 | "제 생각은" 같은 관점이 0번. 최근 경제 글 9편 중 8편이 0번 |
| ③ 클릭 유도 | 🟠 약함 | 제목에 답(세후 3.4억)이 이미 나와 있어 누를 이유가 줄어듦 |
| 형식 반복 | 🟠 | 모든 경제 글이 똑같이 "■ 질문형 소제목 3개 → 핵심만 보면 → Q&A 3개 → 참조문헌" 순서. 글이 쌓이면 **한 틀로 찍어낸 블로그**로 보일 수 있음 |

### 패션 「이연희 루이비통 가방」 — 가장 위험

- 제목은 "이연희 + 루이비통 가방"인데, 본문 첫 줄이 **"이연희가 이 가방을 들었다는 소식은 아직 없어요"** 입니다.
- 네이버 눈으로는 이게 바로 **제목·본문 불일치(낚시)** 입니다. 독자는 누르자마자 실망해서 나가고(체류 짧음), 이런 글이 쌓이면 ①블로그 신뢰도까지 깎입니다.
- 편집장도 1차·2차 모두 "제목이 본문과 어긋난다"고 지적했는데 제목이 그대로 나갔습니다.
- 오늘 코드에 **"착용 확인 안 되면 글 안 씀"** 문(門)을 넣어서 앞으로는 이런 글이 안 나옵니다. **이 글은 아직 발행 전이면 발행하지 마시기를 권합니다.**

### 블로그 전체

- **같은 주제 겹침:** 스페이스X 같은 날 2편, 삼성전자 6일 동안 4편, 패션 샤넬 8/17편. 네이버는 내 블로그 안의 비슷한 글끼리도 하나만 골라 보여 주는 경향이 있어 **서로 표를 깎아 먹습니다.**
- **하루 7~8편:** 사람 한 명이 쓰기엔 많습니다. "대량 발행" 신호가 될 수 있습니다.

## 3. 잘 되는 블로거와 무엇이 다른가

| | 잘 되는 블로거 (쿠니네·유미) | 우리 |
|---|---|---|
| 제목 | `삼성전자 주가 '107조 벌고도 뚝뚝...' 개미들만 모르는 소름 이유` → 독자 속마음을 따옴표로, 답은 숨김 | `삼성전자 성과급 7.5억이라더니, 세후는 3.4억대 추산` → 정확하지만 답을 다 보여 줌 |
| 본문 | "내 생각은 이렇다", 개인 관점이 있음 | 기사 정리 + "확정 아님" 반복 |
| 독자가 얻는 것 | "이 사람 말 들으러 또 와야지" | "기사 읽은 거랑 같네" |

**우리가 이기는 것:** 주제를 빨리 고름(코드로 매일), 숫자가 정확함, 지어낸 말이 없음.
**우리가 지는 것:** 클릭(제목), 머무는 시간(관점), 다시 오게 하는 힘(목소리).

## 4. 승산을 만들려면 (우선순위)

1. **글 수를 줄이고 겹침을 코드로 막기** — 블로그당 하루 2편, 같은 주제는 3일 안에 다시 안 씀. *(돈 줄고, 효과 확실)*
2. **제목에 "독자 속마음 따옴표 + 답은 본문에"** — 거짓·과장은 계속 금지.
   예: `삼성전자 성과급 '7.5억 받는다던데...' 실제 통장엔 얼마 들어올까`
3. **본문에 "이 블로그의 관점" 한 단락** — 기사에 없는 것을 하나 넣기. 예: "연봉 5천만원 직장인이면 이렇게 계산된다"처럼 **독자 상황에 맞춘 계산**, 비슷한 과거 사례 비교, 한 줄 의견("저라면 이것부터 보겠습니다"). 지어낸 경험은 금지.
4. **글 틀 바꾸기** — 모든 글이 같은 순서로 끝나지 않게, 2~3가지 틀을 돌려 씀.
5. **2주 동안 숫자 보기** — 조회수·체류를 보고 늘릴지 결정. *(지금은 데이터 0건)*

## 5. 아까 말한 "검색 API" 문제 — 쉽게

### 무엇인가

- 우리 프로그램은 네이버에서 **"검색 창구(API)"** 를 빌려 씁니다. 사람이 네이버에서 검색하는 걸 프로그램이 대신 하는 통로입니다.
- 네이버가 **2026년 9월부터** 이 창구의 규칙을 바꿨습니다(언론 보도 기준).
  > **"검색 창구로 받아 간 결과를 AI에게 넣지 마라. 오래 저장해 두지도 마라."**

### 우리가 걸리는 곳

| 우리가 하는 일 | 규칙과 비교 |
|---|---|
| 패션 키워드 찾을 때: 네이버 **뉴스 검색 결과 제목**을 모아서 **Claude(AI)에게 "여기서 키워드 뽑아"** 라고 넘김 | 🔴 **딱 금지된 것** |
| 도우미 화면에 "같은 키워드 블로그 글 3개", "인물 사진 후보"를 **검색 결과 그대로 저장해서** 보여 줌 | 🟠 애매함 (저장 금지에 걸릴 수 있음) |
| 검색량·검색 추세 (데이터랩·검색광고) | 🟢 괜찮음 (다른 창구) |
| 블로거 새 글(RSS), Grok, Claude 웹검색 | 🟢 괜찮음 (네이버 검색 창구 아님) |

### 걸리면 어떻게 되나

- 네이버가 우리 **검색 창구 열쇠(API 키)를 막을 수** 있습니다. 그러면 점수표의 뉴스 건수·블로그 건수·사진 후보가 한꺼번에 멈춥니다.
- 이건 **블로그 계정 제재와는 다른 문제**로 보입니다(개발자용 열쇠 문제). 그래도 키를 막히면 키워드 고르기가 약해집니다.

### 고치는 법 (대표님 할 일 없음)

- 패션 뉴스 제목은 **언론사 RSS(구독용으로 공개된 통로)** 와 Grok으로 바꿉니다. AI에 넘겨도 되는 통로입니다.
- 도우미의 블로그 글·사진 후보는 결과를 저장하지 않고, **"네이버에서 검색" 버튼(링크)** 으로 바꿉니다. 눌러서 네이버 앱에서 보면 됩니다.
- ⚠️ 약관 원문은 이 환경에서 열지 못했고, 보도 3곳 기준입니다. 원하시면 대표님이 네이버 개발자센터에서 원문을 한 번 확인하시면 됩니다(필수는 아님).
