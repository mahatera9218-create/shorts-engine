# 공장 버전 비교 — 신규(이번 세션) vs 과거 어사이드 올인원 (2026-11-12)

대표 지시로 정리. **결론부터: 되돌릴 기준 = 과거 어사이드 올인원(아래 1번). 이번 세션 신규(2번)에서 '이식할 값어치 있는 것'만 골라 올인원에 얹는다(3번).** 인플은 별도 보관(4번).

## 1. 과거 어사이드 올인원 — 블로그별 최신본 (= 안정 버전, 되돌릴 기준)

구조는 네 블로그 모두 동일: **어사이드가 지휘 → 그록(조사/사진) + 클로드 웹(글·제목) + 지피티(사진) → 네이버 임시저장. 발행=대표.**

| 블로그 | 어사이드 루틴(master) | 그록 탭 | 클로드 탭 | 지피티 탭 | 비고 |
|---|---|---|---|---|---|
| **경제** | `aside-경제-루틴-자동.md` | 「경제 조사」·「경제 부동산조사」 | 「쿠니 경제」(글+제목+사진장면) | 「경제 사진」(생성) | 키워드=틈새표(niche-results 브랜치), 시트=쇼츠엔진-경제-로그, 새벽5시 |
| **패션(사복·캐시미어다이어리)** | `aside-패션-루틴-자동.md` | 「패션 조사」 | 「쿠니 패션」 | 「패션 자동화」(보완컷) | 인스타(Imageye) 실착, 07:00 |
| **연예패션(남는 블로그)** | `aside-연예패션-루틴.md` | 「연예패션 조사」 | 「연예패션 글」 | 「연예패션 사진」 | 인물=크리에이터 어드바이저 유입트렌드, 08:00 |
| **가십(연예스토리·3번째)** | `aside-연예스토리-루틴.md` | 「연예스토리 조사」(+스타연예) | 「연예스토리 글」(+스타연예 글) | 「연예스토리 사진」 | 하루 2~3편, 대표 지정/화제 인물 |

- 클로드 글 프롬프트 원문: `클로드-경제-글` / `클로드-패션-글` / `클로드-연예패션-글` / `클로드-연예스토리-글`·`클로드-스타연예-글`.
- 지피티 사진 프롬프트: `지피티-경제-사진` / `지피티-패션-올인원` / `지피티-연예패션-사진` / `지피티-연예스토리-사진`.
- 그록 조사: `그록-경제-조사`·`그록-경제-부동산조사` / `그록-패션-조사사진` / `그록-연예패션-조사` / `그록-연예스토리-조사`·`그록-스타연예-조사사진`.

## 3. 비교 결론 — 버릴 것 / 올인원에 가져갈 것

### 버린다 (아키텍처가 깨진 것 — PC·드라이브 바통 의존)
- split 수집/저장, Claude Code 뇌, `전체/경제/패션/연예-하루운영` 명령, `공장-지휘-순서`, 배포 시스템, PC ComfyUI(핵심).
- 이유: PC 클로드코드 재부팅 시 세션 죽고 커넥터(드라이브) 안 올라와 바통 끊김 (DECISIONS 2026-11-12).

### 가져간다 (올인원에 얹으면 이득)
1. **후킹 라이브러리** → 올인원 '제목' 단계에서 클로드가 참고(매일 인플 제목 수집·누적·응용). 경제=`후킹-라이브러리`, 패션=`패션-후킹-라이브러리`.
2. **제목 규칙: 키워드 드러내되 정답 숨김(궁금증)** → 이미 `클로드-경제-글`에 반영됨. 유지.
3. **유입 국면 전략(바닥=씨뿌리기, 데이터 먼저)** → DECISIONS 기록(전략, 운영 참고).
4. **사진 리얼리즘 가이드** → 지피티/그록 사진 품질 기준으로 참고.
5. **경제 썸네일 분담**(그록 소스→지피티 편집) → 올인원 B-2에 반영함.

### 대표가 정할 것 (결정 대기)
- **패션 조직 재편(2026-11-11 이번 세션 결정)**: "패션 블로그 1개=사복팀3+연예패션팀2, 기존 연예패션 블로그→가십 전담". 과거 올인원은 **패션/연예패션/연예스토리 3개 블로그 분리**다. → **올인원으로 돌아가면 재편을 유지할지(2팀 통합) 분리로 되돌릴지** 대표가 정해야 함. (루틴 파일은 분리 버전이 최신본으로 남아있음.)
