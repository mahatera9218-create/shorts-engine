# 헤드리스 사이트 배포 가이드 (스테이징 먼저)

2026-10-15 · 대표 결정: "Next.js + 헤드리스" 적용. 단 **라이브·애드센스 안 건드리게 스테이징(임시 주소) 먼저**.

## 지금 상태
- `web/` 에 Next.js 헤드리스 프론트엔드 **코드 완성 + 빌드 통과**.
- 구조: 워드프레스 = 글 쓰는 관리실 / Next.js = 고객이 보는 빠른 화면. 글 발행하면 10분 내 자동 반영.
- 아직 **아무 데도 라이브 아님.** 올려야 눈으로 점수 확인 가능.

## 대표가 할 일 — Vercel에 올리기 (무료, 한 번만)
휴대폰·PC 다 됨. 결제 없음(무료 Hobby).

1. **vercel.com** 접속 → **Continue with GitHub**(깃허브로 로그인)
2. **Add New → Project**
3. 목록에서 **shorts-engine** 저장소 **Import**
4. 설정 화면에서 **Root Directory** 를 **`web`** 으로 바꾸기 (★ 제일 중요. 앱이 web 폴더 안에 있음)
5. **Environment Variables** 에 아래 4개 추가:
   - `WP_API_BASE` = `https://astacgroup.com/wp-json/wp/v2`
   - `NEXT_PUBLIC_SITE_NAME` = `억선생의 경제판`
   - `NEXT_PUBLIC_SITE_URL` = `https://astacgroup.com`
   - `NEXT_PUBLIC_SITE_DESC` = `세무·절세·연금을 쉽게 — 숫자로 정확하게 정리하는 경제 블로그.`
6. **Deploy** 클릭 → 1~2분 뒤 **`...vercel.app`** 주소가 나옴

## 그다음 (점수 확인)
- 그 `vercel.app` 주소를 **PageSpeed Insights**(pagespeed.web.dev)에 넣어 모바일 점수 확인.
- 진짜 빠른지, 글·이미지 잘 나오는지 같이 보고 → **만족하면 그때** 도메인(astacgroup.com)을 Vercel로 전환(애드센스 검토 끝난 뒤가 안전).

## 주의
- Vercel 주소가 나오면 **그 주소만 나한테 알려주세요**(비밀 아님). 점검·수정은 제가 코드로.
- 전환 전까지 **라이브 astacgroup.com은 워드프레스 그대로** → 애드센스 검토 안 끊김.
