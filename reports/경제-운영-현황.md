# 억선생의 경제판 · 운영 현황 (늘 최신으로 고치는 문서)

마지막 갱신: 2026-10-05 · 옛 운영 문서(10-04 설계·종합·멀티AI·조직도, 10-05 점검)는 지우고 이 문서 하나로 모았어요. 결정의 역사는 `DECISIONS.md`에 있어요.

## 1. 한 줄 요약

**새 네이버 블로그 '억선생의 경제판'에 하루 3편.** 대표는 키워드 고르기 → 제목 고르기 → 발행만, 나머지는 자동이에요. 영상(쇼츠·클립·유튜브)은 당분간 보류, 글에 집중해요.

## 2. 하루 흐름

| 순서 | 누가 | 무엇을 | 도우미 버튼 |
|---|---|---|---|
| 05:50 | Grok + 코드 | X·웹 화제 키워드 8개 + 시세 급변 | (자동) |
| 아침 | 대표 | 어드바이저·뉴스 랭킹·트렌드에서 찾은 키워드 넣기, 캡처 올리기, Aside 조사 붙여넣기 | ➕ 내 키워드 넣기 · 📷 캡처 올리기 · 📄 Aside 붙여넣기 |
| ① | 대표 | 키워드 하나 누르기 | 키워드 버튼 |
| ② | Claude | 웹 검색 취재 + 제목 10개 (33~45자) | — |
| ② | 대표 | 제목 하나 누르기 (마음에 안 들면 다시 뽑기) | 제목 버튼 · 🔄 다시 조사 |
| ③ | Claude·GPT·코드 | 글 → 사람 냄새 검사 → **정보 이득 검사** → GPT 사실 대조 → 썸네일 → 본문 그림 3장 | — |
| ④ | 대표 | 복사해서 네이버에 발행, 고친 곳 저장 | 📋 복사 · 💾 고친 내용 저장 · ✅ 발행 완료 |

①~④를 하루 3번 해요. 1편에 대표 시간 약 5분이에요.

## 3. 품질 장치

- **정보 이득 게이트:** 네이버 블로그 검색 상위 10개 글(공식 API, 제목·요약)과 우리 초안을 비교해요. 상위 글에 없는 게 하나도 없으면 한 번 고쳐 쓰고, 그래도 없으면 "⚠️ 발행 보류"로 표시해요. (API 순서는 실제 검색 화면과 조금 다를 수 있어요)
- **사람 냄새:** 생각 없는 문단이 25%를 넘거나 AI 티 표현이 있으면 고쳐 써요. 관찰 표현("지수를 보며", "차트를 들여다보니")은 권장해요.
- **사실 대조:** 쓰는 회사(Claude)와 다른 회사(GPT)가 웹 검색으로 숫자·날짜·직책을 확인해요.
- **금지:** 가짜 매매·현장 경험, 투자 권유, 단정 전망, 도박 말, 남의 문장 옮기기.

## 4. 배우는 고리 (필수)

| 무엇을 | 어떻게 | 어디에 쓰나 |
|---|---|---|
| 대표가 고친 곳 | 💾 고친 내용 저장 → 글 폴더의 `edits.md` | 다음 글부터 바로 참고 + 주간 학습 |
| 어드바이저·통계 캡처 | 📷 캡처 올리기 → Claude가 읽음 → `econ/metrics/` | 키워드 목록 + 📊 성과 화면 + 주간 학습 |
| Aside 참고 블로거 조사 | 📄 붙여넣기 → `econ/ref/<날짜>.md` | 글 구조·흐름 참고(문장은 안 옮김) |
| 주간 학습 | 매주 월요일, 반복되는 고침·성과 → 규칙 제안 `reports/경제-학습/` | 대표 확인 후 스킬에 반영 + DECISIONS 기록 |

## 6. 비용

- 모든 AI 호출을 `econ/costs.csv`에 기록해요(날짜·단계·회사별). 도우미 **📊 성과** 탭에서 이번 달 합계·단계별·1편 평균을 봐요.
- **월 상한 5만원:** 넘으면 새 작업이 멈추고 알려 드려요.
- 예상: 1편 약 600~900원(키워드·제목 포함) × 하루 3편 × 30일 ≈ 월 5.4~8.1만원 → **상한에 닿을 수 있어요.** 첫 주 실측을 보고 다시 보고할게요 (줄일 곳: 취재 검색 횟수, 고쳐 쓰기 횟수).
