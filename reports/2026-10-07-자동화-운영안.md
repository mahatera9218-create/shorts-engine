# 매일 자동 글 + 어사이드 운영안 (2026-10-07 확정)

대표 요청: "어사이드가 조사한 키워드까지 포함해 1~3순위. 네이버를 집중적으로 파는 거라 배점을 잘. 컴퓨터 쓰는 날 / 안 쓰는 날 운영 방안까지."

**확정·적용됨 (대표 결정 2026-10-07):** 어사이드 배점 최대, 쿠니네는 키워드 조사에서 뺌, 최신성 > 뉴스량·검색량, 같은 주제 거르기 없음, 블로그마다 하루 3편, 어사이드 없으면 10시. 아래 표는 확정값입니다.

---

## 1. 지금 구조의 문제 2가지

1. **어사이드 키워드가 '대표가 넣은 키워드'와 구분이 안 됩니다.** 둘 다 출처 점수 15점짜리 하나로 들어갑니다. 어사이드는 "네이버 홈판·인기글에서 여러 곳에 겹쳐 나온 순위"라는 좋은 정보를 주는데, 그게 점수에 안 들어갑니다.
2. **이미 있는 키워드와 겹치면 그냥 버려집니다.** 예를 들어 새벽 자동 수집에 "원달러 환율"이 있었고 어사이드도 "원달러 환율"을 가져오면, 점수가 올라가야 하는데 지금은 같은 키워드라며 무시합니다.

---

## 2. 새 배점 (100점)

어사이드를 **'네이버 인기' 항목으로 따로** 넣습니다. 네이버 홈판·인기글에 실제로 뜨는지는 다른 출처로 알 수 없는 정보라, 출처 점수에 섞지 않고 독립 항목으로 둡니다.

| 항목 | 무엇을 보나 | 경제·패션 |
|---|---|---|
| **네이버 인기 (어사이드)** | 어사이드가 본 홈판·인기글·많이 본 뉴스·인기 검색 종목. 순위 1~3위 만점, 4~6위 75%, 7~10위 50% | **35** |
| 최신 | 최근 6시간 네이버 기사 수 | 25 |
| 출처 겹침 | Grok(X)·참고 블로거·뉴스 RSS·대표 입력이 여러 곳에서 겹치는지 (쿠니네는 뺌) | 20 |
| 뉴스량 | 네이버 뉴스 24시간 기사 수 | 10 |
| 검색량 | 네이버 월 검색 수 | 10 |

- **겹치면 더 올라갑니다.** 어사이드 키워드가 새벽에 모은 키워드와 같은 주제면 하나로 합쳐서, 네이버 인기 점수와 출처 점수를 둘 다 받습니다.
- **어사이드가 없는 날**(컴퓨터 안 쓰는 날)은 나머지 65점을 100점으로 바꿔 계산합니다. 그래야 그날 키워드가 "점수가 낮다"고 숨겨지지 않습니다.
- 대표님이 직접 넣는 키워드(휴대폰 '내 키워드 넣기')는 지금처럼 출처 15점이고, 점수가 낮아도 늘 보입니다.

---

## 3. 자동으로 1~3순위 고르는 규칙

점수순 1~3위를 그대로 고릅니다. 최근에 쓴 주제나 비슷한 주제도 거르지 않습니다(대표: "매일 나와도 괜찮다").

고른 키워드마다 제목 후보를 만들고, ★추천 제목으로 글까지 완성합니다. 다른 제목 후보는 도우미에 그대로 남아서 「이 제목으로 바꾸기」로 바꿀 수 있습니다.

## 4. 하루 운영표

### 컴퓨터 쓰는 날 (평일 출근 등)

| 시각 | 누가 | 하는 일 |
|---|---|---|
| 05:47 | GitHub | 제목 고수 조사 (지금도 켜져 있음) |
| 06:00 | GitHub | 경제·패션 키워드 1차 수집·채점 |
| 07:30 무렵 | 어사이드 (PC) | 홈판·인기글 조사 → 경제·패션 키워드를 도우미에 올림 → **바로 다시 채점** |
| 어사이드가 올리면 바로 | GitHub | 블로그마다 1~N위 선정 → 제목 → ★제목으로 글 완성 (약 10~20분) |
| 출근 후 | 대표 | 도우미에서 제목 확인·수정, 사진 프롬프트 복사 → ChatGPT로 사진 → 발행 |
| (선택, 나중에 시험) | 어사이드 | 완성된 글을 네이버에 붙여넣고 **임시저장**까지 |

### 컴퓨터 안 쓰는 날 (주말·출장·외근)

| 시각 | 누가 | 하는 일 |
|---|---|---|
| 05:47 | GitHub | 제목 고수 조사 |
| 06:00 | GitHub | 키워드 1차 수집·채점 |
| **10:00** | GitHub | 어사이드가 안 왔으면 **어사이드 없이** 선정 → 글 완성 (65점을 100점으로 환산) |
| 아무 때나 | 대표 (휴대폰) | 도우미에서 글 확인 → 사진 프롬프트 → ChatGPT 앱으로 사진 → 네이버 앱 발행 |
| (선택) | 대표 (휴대폰) | 홈판에서 눈에 띈 주제가 있으면 '내 키워드 넣기' → 10시 전이면 선정에 들어감 |

- 결국 **"어사이드가 오면 바로, 안 오면 10시에"** 한 가지 규칙으로 두 날이 모두 돌아갑니다. 대표님이 오늘이 어떤 날인지 따로 알려 주실 필요가 없습니다.
- 발행을 못 한 날 글은 도우미에 그대로 쌓입니다. 경제 글은 하루 이틀 지나면 숫자가 낡아서, **2일 지난 경제 글에는 "오래됨" 표시**를 붙이겠습니다.
- GitHub이 멈춘 날(가끔 있음)은 도우미 맨 위에 "오늘 자동 선정이 안 됐어요"와 다시 돌리기 버튼이 보이게 하겠습니다.
