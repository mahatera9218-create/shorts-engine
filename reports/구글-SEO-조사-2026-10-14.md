# 구글 SEO 조사 — 어디를 어떻게 노릴까 (① 조사 단계)

2026-10-14 · WP(구글) 진입 전 조사. 순서: ①조사(이 문서) → ②전략 → ③글 방향.
주의: 아래는 SEO 업체·실무 블로그 + 우리 SERP 간이 조사 종합. 구글 공식은 Search Central / 품질평가 가이드라인. 특정 수치(%)는 대부분 출처 불명확 → 방향성으로만.

## 1. 구글에서 노릴 수 있는 '자리' (position)

| 자리 | 무엇 | 신생 사이트 난이도 |
|---|---|---|
| **AI 개요(AI Overviews)** | 구글이 AI로 답을 요약하며 **출처 인용** | 구조·신뢰 갖추면 인용 가능(중) |
| **피처드 스니펫(0순위)** | 질문에 직답하는 박스. 보통 상위 10위 안 페이지에서 뽑힘 | 롱테일 질문형이면 노려볼 만(중) |
| **People Also Ask(PAA)** | '관련 질문' 아코디언 | 질문형 글이면 진입 쉬움(중하) |
| **자연검색 상위 10(파란 링크)** | 기본 | 빅키워드 1위는 권위 필요(상) |

→ **신생 사이트는 빅키워드 1위보다, 롱테일 질문형으로 '스니펫·PAA·AI 개요 인용'을 먼저 잡는 게 현실적.**

## 2. 랭킹 작동 원리 (요약)
- **검색 의도 충족** + **유용한 콘텐츠**(구글 'helpful content') 가 핵심.
- **기술 기본:** 색인됨, 모바일, 속도(Core Web Vitals). WP+RankMath로 기본 커버.
- **E-E-A-T**(경험·전문성·권위·신뢰): 품질 판단에 쓰임. 금융은 특히 엄격.
- **권위(백링크·토픽 깊이):** 시간이 쌓아줌. 신생은 토픽 클러스터로 보완.

## 3. 우리가 현실적으로 노릴 지점 (신생 + 금융 YMYL)
1. **롱테일 질문형**을 노린다 — "양도세 1세대1주택 비과세 요건", "연금저축 IRP 세액공제 한도" 류. 빅키워드("부동산")는 뒤로.
2. **YMYL(금융)이라 E-E-A-T 필수:** 저자 정보(실명·이력/소개 페이지), **출처 인용(국세청·법령)**, **업데이트 날짜**, **정확한 수치**. 이게 없으면 금융 글은 순위 안 남.
3. **토픽 클러스터:** 세무·절세·연금 주제를 체계적으로 다작 + 내부 링크 → 사이트 전체 권위. (앞 SERP 조사: 같은 블로거가 여러 세무 키워드 반복 상위 = 이 방식이 통함.)

## 4. AI 개요 시대의 현실 (정직하게)
- 정보 요약형 쿼리는 AI가 답을 요약해 **클릭이 줄 수 있음(제로클릭)**. 그래도 **인용되면 브랜드·신뢰 노출**.
- 대응: **클릭이 살아남는 쿼리**(계산·비교·심화·'내 경우엔 얼마'·계산기/도구)와, **인용되기 좋은 구조**(구절 단위 직답) 둘 다 챙긴다.

## 5. 글 포맷 규칙 (스니펫·AI 인용 겨냥)
- **질문형 H2/H3** → **첫 문장에 바로 답**(짧게) → 그 뒤 설명·표·단계.
- **각 단락이 독립적으로 읽혀도 통하게**(AI가 구절 단위로 인용).
- **표·번호목록·글 안 FAQ** + 구조화데이터. ⚠ 정정(2026-10-15): FAQ 리치결과는 2026-05 폐지 → Article+Breadcrumb 스키마로. 상세 `reports/구글-구조-정밀조사-2026-10-15.md`.
- 저자·출처·수정일 명시.

## 6. 우리 SERP 간이 조사 결과(연결)
- **세무·절세·연금·종부세(제도/계산/요건/한도) = 개인 콘텐츠가 구글 상위에 실제로 뜸 → 승산 큼.**
- **부동산 시세·전망, 증시 시황 = 뉴스·포털·시세DB가 점령 → 신생 WP는 어려움.**
- → **WP 공략 = 세무·절세·연금·세금계산 질문형 롱폼.** (네이버=시세·시황 시의성, 구글=세무 evergreen.)

## 심화 조사 (2026-10-14, 세무 클러스터 SERP 정밀)

구글에서 세무·절세·연금 질문형 다수(양도세·종부세·연금저축·증여세·피부양자·퇴직금·연말정산)를 정밀 확인한 결과:

### 경쟁자 패턴 (아주 중요)
- **같은 소수의 블로그가 거의 모든 세무 키워드 상위에 반복 등장.** 특히 **wikidocs.net/blog**의 몇몇 저자(@Insight_Lab·@TaxSave·@mythos·@knarchive·@openwiki)가 양도세·증여세·피부양자·퇴직금·연금·연말정산에 걸쳐 1페이지를 점령. (그 외 tilnote·zippoom·glasswallet·braindetox·삼쩜삼·heumtax·카드고릴라·미래에셋·ieconomyu 등)
- 이들은 **토픽 클러스터 + 시리즈 연재**(예: "26년 연말정산 ①②③")로, 2026 기준 업데이트·구조화(표·단계·FAQ)된 글을 꾸준히 쌓음.
- **시사점:** 개인/소형 사이트가 **체계적 다작 + 내부링크**로 세무 토픽 전체를 장악할 수 있음을 실증. 우리도 같은 방식으로 진입 가능.

### 네이버·구글 '한 번에' (일 두 번 안 하기)
- 세무·절세·연금·생활경제 제도(연말정산·증여세·종부세·피부양자·퇴직금 등)는 **네이버·구글 양쪽 모두 검색 수요가 큼**(특히 계절성 폭발).
- → **'듀얼 플랫폼' 주제.** 조사·사실(수치·요건·법령)은 **한 번만** 하고, 렌더만 둘로: 네이버 버전(짧고 후킹·홈피드), 구글 버전(롱폼·질문형 H2·표·FAQ·스키마).
- **시세·시황**은 네이버 전용(구글은 뉴스). → 세무 클러스터가 '한 번 조사 → 두 곳 발행'에 최적.

### 남은 공백 = 정량 (결제 복구 후, 한 번에 네이버+구글)
- 지금까진 **구글 SERP 정성** 조사. 빠진 것: **검색량·경쟁도·CPC**.
- 결제 복구(약 18일) 후, 우리 엔진(market-research-memo: **네이버 검색광고 + 구글 키워드플래너**)으로 **네이버·구글 수요를 한 번에** 재서 '틈새 키워드 리스트'(검색량 대비 경쟁 낮은 것)를 뽑는다. → 이게 전략의 정량 근거.

### 조사 결론
- 세무·절세·연금 = 구글 승산 + 네이버 수요 + 듀얼 발행 효율 + 광고 궁합. **WP·네이버 공통 공략 축.**
- 전략은 이 '듀얼 세무 클러스터'를 중심으로, 정량 리스트가 나오면 키워드 우선순위를 확정.
