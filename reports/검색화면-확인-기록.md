# 검색화면 확인 기록

대표가 네이버 앱으로 직접 검색해 **블로그 글이 얼마나 빨리 보이는지** 확인한 기록입니다.
공식 API로는 실제 검색 화면을 알 수 없고 자동 수집은 금지이므로(설계서 0.4), 이 기록이 실제 검색 화면에 대한 근거입니다.

## 2026-09-29 · 2차 (세금·제도)

| 키워드 | 결과 | 메모 |

**배운 것:** 제도 키워드 중 누구나 찾는 큰 키워드(연납·보조금·검사 주기)는 인플루언서·공식 정보가 차지한다. 계산·혜택처럼 조건을 따지는 키워드는 일반 블로그가 보인다.
→ 세금·제도 카테고리는 만들지 않고, 취득세 계산·경차 혜택만 "차급별 유지비"에 넣는다.

## 확인 방법 (다음부터)

- 새 카테고리를 열 때만, 키워드 5~10개씩
- Claude가 누르면 바로 검색되는 링크 목록을 준다
- 블로그 개설 후에는 블로그 통계의 "유입 검색어"로 대신한다
