# 자동 글쓰기 · 2026-09-29

## 한 줄 요약

**매일 아침 6시 47분에 글 1편이 자동으로 써집니다.** 대표님은 `posts` 폴더에서 ✅ 글을 복사해 발행만 하시면 됩니다. 남은 것은 **Claude API 키 1개**(결제 필요, 대표님 결정)입니다.

## 어떻게 돌아가나

| 단계 | 누가 | 내용 |
| --- | --- | --- |
| 1. 주제 | 코드 | 대기열 순서대로 (류현진 → 김도영 → 오타니 → 김혜성 → 김하성 → 손흥민). 비면 뉴스에서 Claude가 다음 선수를 고름 |
| 2. 뉴스 | 코드 | 네이버 뉴스 검색 API로 최신 기사 제목·요약문 (허용된 통로, 기사 본문은 안 받음) |
| 3. 숫자 뽑기 | Claude | 기사마다 연봉·경기·안타 같은 숫자만 뽑음 |
| 4. 숫자 정리 | 코드 | 기사끼리 다르면 규칙으로 결정 (최신 기사 → 같은 날이면 다수 → 차이 표기) |
| 5. 계산·그림 | 코드 | 1경기·1이닝·1안타당 금액, 최저임금 비교, 영수증·썸네일 |
| 6. 글쓰기 | Claude | 말투 스킬 + 글쓰기 스킬 + 이정후 글을 참고해 제목 5개·본문·태그 |
| 7. 검사 | 코드 | AI 티 표현, 숫자표에 없는 숫자, 이미지 자리, 도박·사생활 단어 → 걸리면 Claude가 고쳐 씀 (최대 2번) |
| 8. 저장 | 코드 | `posts/날짜-선수-영수증/`에 발행 패키지, `posts/README.md` 목록 갱신 |

**글에 틀린 숫자가 들어가는 걸 막는 장치:** 계산은 전부 코드가 하고, Claude는 코드가 준 숫자표에 있는 숫자만 쓸 수 있습니다. 표에 없는 숫자를 쓰면 검사에서 걸립니다.

## 비용

- 모델: 설계서 14.1대로 중급 모델(claude-sonnet-5-5)로 시작
- 예상: 편당 약 100~200원, 하루 1편이면 **월 약 3천~7천 원**
- 편당 상한 $1(약 1,400원). 넘으면 고쳐 쓰기를 멈추고 "확인 필요"로 남깁니다.
- 실제 사용량·비용은 매 실행 요약 화면에 나옵니다.

## 먼저 말씀드릴 것 (아직 확인 안 된 것)

- **실제 API로는 아직 한 번도 안 돌려봤습니다.** 키 없이 가짜 데이터로 전체 흐름만 확인했습니다 (예시 모드, 테스트 31개 통과).
- **뉴스 검색 주소**는 블로그 검색과 같은 규칙으로 추정했습니다. 첫 실행에서 틀리면 바로 고칩니다.
- **Claude가 숫자를 잘못 뽑을 수 있습니다** (예: 계약 총액을 연봉으로). 연봉이 말이 안 되는 범위면 코드가 막지만, 범위 안의 오류는 못 막습니다. 첫 몇 편은 제가 직접 검토하고, 틀리면 규칙대로 바로 정정합니다.
- **대기열 글 형식은 "선수 몸값 영수증" 한 가지**입니다. 몸값 대결·팀 순위 글은 자동화 전까지 대화로 씁니다.
- 네이버 블로그는 글쓰기 API가 없어 **발행은 대표님 버튼**으로 남습니다.

## 대표님이 하실 일

1. Claude API 결제·키 발급 여부 결정 → 진행하시면 [안내](../docs/운영자-안내-Claude-API-키.md)대로 `ANTHROPIC_API_KEY` 등록
2. Actions → **자동 글쓰기** → Run workflow (첫 실행 확인)
3. 이후 매일: posts 폴더 → ✅ 글 복사 → 발행 (2~3분)
