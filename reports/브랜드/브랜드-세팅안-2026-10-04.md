# 경제 블로그 브랜드 세팅안 (조선 화풍)

> **2026-10-05 갱신 — 건물 컨셉 확정**
> - 건물(블로그) = 사람이 모이는 **조선 장터**. 매일 그날 돈 이야기를 **장사꾼 이야기꾼**이 쉽게 풀어 준다.
> - 그림: 김홍도·민화 + **화투** 모티프. 색은 **화투 팔레트**(홍·먹·미색·솔잎 녹색·달 금색).
> - 영상: **종이인형극** 모션그래픽, **중년 남자** 목소리.
> - 이름: 경제 블로거답게(닉네임 + 경제 낱말). 아래 1차 후보(엽전일보 등)는 탈락 → 2차 후보는 `블로그이름-점검-2026-10-05.md`.
> - 금지: 도박 장면·말(고스톱·판돈), 카드 스캔 복제, 투자 권유.

## 한국 전통미 원칙 (2026-10-05, 모든 그림·영상)

목표: 한국 사람에겐 정겹고, 해외 사람에겐 "이거 한국이다!" 하고 눈이 멈추게.

**화면 중심에 둘 한국 요소**
- 사람: 한복(저고리·바지·치마), 갓, 상투, 댕기 머리, 짚신
- 장소: 초가, 기와집, 장터, 서당, 주막, 돌담, 장독대
- 그림: 김홍도 풍속화, 민화 호랑이·까치, 십장생(소나무·학·해·구름)
- 물건: 엽전 꾸러미, 궤짝, 보자기, 부채, 지게, 저울, 붓·벼루
- 무늬·색: 조각보, 단청 무늬, 구름무늬, 오방색 + 화투 팔레트

**섞지 않을 것**
- 중국식 말굽 금(원보), 일본식 상투(스모), 기모노, 일본 성곽 같은 다른 나라 요소
- 화투 그대로의 일본식 도안 위주 구성. 화투는 **색과 카드 틀만** 빌리고, 그림 속은 한국 요소로 채워요(예: 엽전 카드, 궤짝 카드, 우리 장사꾼 비광).

**해외판을 위한 설계**
- 글자는 그림에 넣지 않고 코드로 얹어요(썸네일 제목만 예외). 자막과 목소리만 영어로 바꾸면 해외판이 돼요.
- 장사꾼 캐릭터, 낙관, 색이 언어와 상관없이 브랜드 역할을 해요.

**그림마다 확인할 것 (Claude 검수)**
1. 한국 요소가 한눈에 2개 이상 보이는가
2. 다른 나라 요소가 섞이지 않았는가
3. 색이 화투 팔레트·오방색 안에 있는가
4. 실존 인물 얼굴, 회사 로고, 도박 장면이 없는가

## 1. 이름 후보

| 후보 | 느낌 | 추천 |
|---|---|---|
| **엽전일보** | 엽전(돈) + 일보(신문). '조선 경제신문'. 매일 시황·이슈와 잘 맞음 | ★ 1순위 |
| **억소리 장터** | 낙관 '억'을 그대로 씀. 장터 = 시장. 기존 '억소리' 이름과 이어짐 | ★ 2순위 |
| 돈 읽어주는 전기수 | 전기수 = 조선 장터의 이야기꾼. 쇼츠 목소리와 이어짐. 이름이 좀 김 | 3순위 |
| 저잣거리 경제 | 시장 거리에서 쉬운 말로 푸는 경제 | |
| 오늘도 장날 | 매일 열리는 장 = 매일 시황. 가볍고 친근함 | |
| 엽전서당 | 기본기 느낌이 강하고 시황엔 약함 | |

- **엽전일보를 1순위로 추천하는 이유:** 홈판에서 '신문'처럼 믿음이 가고, 짧고, 그림체와 이름이 바로 이어져요. 매일 아침 시황 이름도 "엽전일보 아침판"으로 자연스럽게 붙어요.
- 같은 이름의 블로그가 있는지는 네이버 검색으로 자동 점검 중이에요. 결과는 `블로그이름-점검-2026-10-04.md`에 나와요.

## 4. 지킬 것 (그림·영상)

- **고정 인물은 '그림 속 장사꾼' 캐릭터로만 써요.** 실제 사람인 척하거나 "제가 투자해 보니" 같은 가짜 경험은 쓰지 않아요.
- 실존 인물 얼굴과 회사 로고는 그리지 않아요.
- 숫자는 그림에 넣지 않고 코드로 정확하게 얹어요. 썸네일 제목만 AI가 쓰고, 제가 한 글자씩 검수해요.
