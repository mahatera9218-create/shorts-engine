# 직장가입자 피부양자 자격 판정 도구 규칙 명세 (부업·기타 소득 있는 경우)

작성일 2026-10-18 / 작성: 조사 에이전트

## 0. 조사 한계 (먼저 읽기)

- WebSearch(허용 도메인 한정) 결과 요약과 제목·URL만 근거로 썼다.
- WebFetch와 curl로 nhis.or.kr, law.go.kr 원문 열기를 시도했으나 전부 실패했다. WebFetch는 `getaddrinfo ENOTFOUND`, curl은 프록시 `403 CONNECT tunnel failed`. 그래서 **조문 원문을 직접 읽지 못했다.**
- 아래 "공식" 표시는 공식 도메인 페이지가 검색 결과에 나왔고, 그 검색 요약이 해당 내용을 인용한 경우다. 원문 대조 전이므로 코딩 전에 사람이 별표 원문 1회 대조를 권한다.
- 검색 요약 중 앞뒤가 맞지 않는 부분(예: 지역가입자 개편 시점)은 채택하지 않고 미확인으로 돌렸다.

## 2. 탈락 후 지역가입자 보험료 개요

- 지역가입자 보험료는 소득(정률)과 재산(부과점수) 등을 합쳐 산정한다. 구체 공식과 최저보험료는 이 조사에서 원문 확인 못 함.
- 2026년 보험료율 7.19% (R21). 재산 점수당 211.5원, 재산보험료 상한 4,591,740원·하한 20,160원은 검색 요약 수준(R22).
- 검색 요약에 "2024년 9월 2단계 개편", "전환자 경감 2026년 8월까지"라는 문구가 있었으나, 시점이 서로 맞지 않아 신뢰하지 않는다. 미확인.
- 도구는 보험료 금액 계산을 하지 않고 "지역가입자로 전환될 수 있다"까지만 안내하는 것을 권한다. 금액 안내는 공단 모의계산 링크로 돌린다: https://www.nhis.or.kr/nhis/policy/wbhada07500m01.do

## 3. 2026년 변경사항

- 피부양자 소득·재산 기준 자체의 2026년 개정은 검색에서 **확인되지 않음** (없다고 단정할 수는 없음).
- 검색 요약에 "현재 시행 중인 시행규칙은 2026년 9월 28일 시행본"이라는 언급이 있었으나 근거 URL이 불명확하고 내용 변화도 알 수 없다. **미확인.** 별표 1, 1의2의 최신 시행일 본을 열어 대조해야 한다.
- 확인한 것은 2026년 보험료율 7.19%(R21)뿐이다.

## 4. 판정 의사코드 (통과 / 탈락 가능 / 확인 필요)

```
입력: 관계, 나이, 동거, 혼인, 장애/보훈, 소득 항목별 연액, 사업자등록유무,
      주택임대소득유무, 재산세 과세표준 합계(본인+배우자+부양요건에 따른 범위), 배우자 소득

function judge(p):
  reasons = []

  # 0. 부양요건 (관계)
  if p.관계 in {배우자}: ok
  elif p.관계 in {부모, 조부모 등 직계존속, 직계비속, 직계비속의 배우자, 배우자의 직계비속}:
       현행 별표 1 미확인 부분이 있으므로 동거/미혼 조건이 애매하면 "확인 필요"
  elif p.관계 == 형제자매:
       if not (나이<30 or 나이>=65 or 장애 or 보훈): return 탈락 가능 (형제자매 요건)
       재산한도 = 1.8억
  else: return 확인 필요

  # 1. 소득 합계 (기타 포함)
  S = 이자 + 배당 + 근로 + 기타 + 사업(아래 처리) + 연금(산입비율 미확인 → 경계 처리)
  # 비과세 제외

  # 2. 사업소득
  if p.주택임대소득 > 0: return 탈락 가능 (R7)
  if p.사업자등록 and not (p.장애 or p.보훈):
       if 사업소득 > 0: return 탈락 가능 (R5)
  else:
       if 사업소득 > 500만원: return 탈락 가능
       else 사업소득은 0으로 보고 S에서 제외     # R4/R6
  # 3.3% 프리랜서 소득은 사업소득 입력. 신고 방식 불명이면 확인 필요

  # 3. 소득 총액
  if S > 2000만원: return 탈락 가능
  if 기혼 and 배우자도 R2 요건 미충족: return 탈락 가능

  # 4. 재산
  if 형제자매:
       if 재산 > 1.8억: return 탈락 가능
  else:
       if 재산 > 9억: return 탈락 가능
       if 재산 > 5.4억 and S > 1000만원: return 탈락 가능

  # 5. 경계 처리
  if S가 한도의 90%~110% 구간 (1,800~2,200만원) 또는 재산이 5.4억·9억 ±5% :
       return 확인 필요 (공단 자료 시점 차이 때문)
  if 연금소득 > 0 or 분리과세 소득 > 0 or 기타소득 분류 불명 or 비주택 임대:
       return 확인 필요
  return 통과 (입력상 요건 충족, 공단 확정 아님)
```

주의: 사업소득 500만원 판단에서 "소득"이 수입금액인지 소득금액(필요경비 차감 후)인지 원문 미확인. 도구는 소득금액 기준으로 입력받고 경계 근처면 확인 필요로 돌린다.

## 5. 입력 항목 제안

1. 피부양자가 되려는 사람과 직장가입자의 관계 (배우자/부모/자녀/기타)
2. 나이, 혼인 여부, 동거 여부
3. 장애인 등록 여부, 국가유공자·보훈보상 상이자 여부
4. 연간 소득금액: 이자, 배당, 근로, 사업(3.3% 프리랜서 포함), 기타(원고료·강연료), 연금(공적/사적 구분)
5. 사업자등록 여부, 주택임대소득 여부, 상가 등 비주택 임대 여부
6. 분리과세·비과세 소득이 있는지 (있으면 금액)
7. 재산세 과세표준 합계 (고지서 또는 위택스에서 확인하는 방법 안내)
8. 배우자가 있으면 배우자의 소득 입력
9. 어느 해 자료인지 (판정 기준 시점 안내용)

## 6. 경계 사례 ("확인 필요"로 돌릴 것)

- 소득 합계가 1,800~2,200만원 부근 (소득자료 연도 시차, 필요경비 차이)
- 재산 과세표준이 5.4억·9억·1.8억 부근
- 연금소득 있음 (현행 산입 비율 미확인)
- 분리과세 소득 있음 (포함 여부 미확인)
- 3.3% 프리랜서인데 사업자등록 없이 신고 방식을 모르는 경우, 원고료·강연료가 사업소득인지 기타소득인지 불명
- 비주택 임대 (상가 등) 또는 주택임대 비과세 범위
- 해당 연도 중 사업 개시·폐업, 사업자등록 말소 직후
- 직계비속·직계존속의 비동거 조건, 형제자매 부양요건의 세부 (현행 별표 1 미대조)
- 6월 재산세 자료 이후 재산을 팔았거나 산 경우 (반영은 다음 정기 시점)
- 부부 중 한쪽만 소득이 많은 기혼자 (R2에 따라 부부 모두 보아야 함)

## 7. 손으로 판정한 테스트 케이스 6개

전제: 위 R1~R9, R11이 현행이라고 가정한 결과. 원문 대조 전이다.

| # | 입력 | 기대 결과 | 근거 |
|---|---|---|---|
| T1 | 배우자, 사업자등록 없음, 3.3% 프리랜서 사업소득 400만원, 이자 50만원, 재산 3억 | 통과 | 사업소득 500만 이하 예외로 0 취급(R4), 합계 50만원, 재산 R8 |
| T2 | 배우자, 사업자등록 없음, 사업소득 600만원, 재산 3억 | 탈락 가능 | 500만원 초과(R4 예외 불가, R3) |
| T3 | 배우자, 사업자등록 있음, 사업소득 100만원 | 탈락 가능 | R5 |
| T4 | 부모, 근로소득 없음, 이자·배당 합 1,500만원, 재산 6억 | 탈락 가능 | 재산 5.4억 초과 구간에서 소득 1,000만원 초과(R9) |
