작성일: 2026-10-18 (조사 기준일). 대상: 애드센스·애드포스트·협찬·체험단·제휴 수익의 사업자등록 필요 여부와 세금 처리 안내.

## 0. 조사 방법과 한계 (먼저 읽기)

- WebSearch를 공식 도메인(nts.go.kr, law.go.kr, korea.kr, hometax.go.kr 등)으로 제한해 12회 검색했다.
- **WebFetch로 공식 URL 원문을 열려고 4회 시도했으나 모두 실패했다** (nts.go.kr 2건, korea.kr 1건 포함 `getaddrinfo ENOTFOUND`, 네트워크 차단). 따라서 아래 모든 값은 **검색 결과 요약(공식 도메인 URL이 결과에 나온 것)** 에서 가져온 것이고, 원문 페이지를 직접 읽고 대조하지 못했다.
- 확인수준 표기:
  - **공식**: 공식 도메인 URL이 검색결과에 나왔고 요약이 그 내용을 직접 말함 (원문 미열람).
  - **2차**: 공식 자료를 요약한 간접 진술이거나 연도가 불확실.
  - **미확인**: 근거를 찾지 못함. 도구에 하드코딩 금지.
- 개발 전에 사람이 공식 URL 원문을 한 번 열어 "공식" 항목을 대조해야 한다. (대조 전까지는 사실상 "공식(요약)" 수준)

## 2. 판정 의사코드

세금 판정이 아니라 "안내 분류"를 하는 도구다. 결과는 3분류: `REGISTER_ADVISED`(등록 권고), `REGISTRATION_UNLIKELY`(등록 불필요 가능성), `NEEDS_CHECK`(확인 필요). 법적 단정 문구 금지, 항상 "국세청 126/세무서 확인" 병기.

```
INPUT: 아래 3절 입력 항목

# 1단계: 확인 필요로 돌릴 경계 조건 (먼저 검사)
flags = []
if income_types has 'adpost' or 'affiliate' or 'in_kind_only':
    flags += ['원천징수/소득구분 근거 미확인 (R27~R29)']
if has_foreign_income and has_domestic_ad_income and employs_staff_or_office:
    flags += ['과세사업자 겸업: 영세율/10% 분리 신고 확인']
if activity_started_before_this_year and no_prior_registration and total_income_past > 0:
    flags += ['과거 미등록 기간 가산세 가능성']

# 2단계: 계속성 판단 (R1, R13)
continuity = 0
if months_active_in_year >= 3: continuity += 1        # 임계값은 도구 자체 휴리스틱, 법 기준 아님
if posts_or_contracts_count >= 3: continuity += 1     # 동상
if is_ongoing_plan (앞으로도 계속 수익 활동 의사): continuity += 1
if channel_monetized_continuously (애드센스/애드포스트 상시 수익화): continuity += 2
if only_one_off_event (강연/원고 1회성, 반복 계획 없음): continuity = 0

# 3단계: 분류
if continuity >= 3:
    result = REGISTER_ADVISED
    type = 'A' 면세(940306) if no_staff and no_office else 'B' 과세(921505)
    # 블로그로 판매·중개(공동구매, 알선)면 525104 안내 (R2)
    if sells_or_brokers_goods: type_note = '판매·중개형: 일반/간이 과세 + 업종 525104 확인'
elif continuity >= 1:
    result = NEEDS_CHECK
else: # continuity == 0
    if all(income is one_off 인적용역 and no repeat plan):
        result = REGISTRATION_UNLIKELY   # 기타소득 가능성 (R13)
    else:
        result = NEEDS_CHECK
if flags: result = NEEDS_CHECK (단, 이미 REGISTER_ADVISED면 REGISTER_ADVISED 유지하고 flags 병기)

# 4단계: 세금 처리 안내 (분류와 별개로 출력)
notes = []
if result == REGISTER_ADVISED:
    notes += '사업 개시일부터 20일 이내 등록, 개시 전 신청 가능 (R7)'
    notes += '미등록 시 공급가액 1% 가산세 (R8)'
```

## 3. 입력 항목 제안

1. 수입 종류(복수): 구글 애드센스 / 네이버 애드포스트 / 협찬 현금 / 체험단(현물) / 제휴 수수료 / 직접 판매·공동구매 / 후원·슈퍼챗 / 강연·원고 1회성

3. 앞으로도 계속할 계획인가 (예/아니오)
4. 올해 예상 총수입, 작년 총수입 (원)
5. 수입 지급처: 해외(구글 등) / 국내 / 개인 직접 입금
6. 3.3% 원천징수를 당했는가 (예/아니오/모름)

8. 직장 근로자 여부 (건강보험 안내용)

10. 현물(제품) 받은 대략 시가 (참고용)
11. 직접 판매·중개를 하는가 (R2)

## 4. 경계 사례 (모두 NEEDS_CHECK로 돌릴 것)

- 애드포스트·제휴 수수료: 소득 구분과 원천징수 근거 미확인 (R27, R29).
- 현물 협찬·체험단만 받은 경우: 수입 인식 여부, 시가 평가, 원천징수 미확인 (R28).
- 올해 처음 수익이 났고 앞으로 계획이 불분명한 경우: 계속성은 사실관계 판단 (R13, R14).
- 직장인 겸업: 근로 외 소득의 사업자등록 의무 판단은 같으나, 회사 겸업 금지 규정 등은 세법 밖.
- 해외 수입 + 국내 광고 혼합 + 직원 고용(과세사업자): 영세율/10% 분리 신고 (R10), 복잡하므로 세무사 권고.
- 후원금 직접 계좌 수령: 현금매출명세서(R12) 면세사업자 적용 여부 미확인.
- 과거에 수입이 있었는데 미등록·미신고인 경우: 가산세 계산은 도구에서 하지 않음.
- 단순경비율 판정: 940306이 '다'군인지 미확인이라 단정하지 말고 "홈택스 신고도움서비스로 확인" 안내.
- 중개·판매형 블로그(525104)와 광고형(940306) 경계: 구분 기준 원문 확인 필요.
