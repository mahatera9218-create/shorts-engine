# 온라인 셀러 간이과세 vs 일반과세 판정·비교 계산기: 세법 규칙 명세

작성일 2026-10-18 / 대상: 스마트스토어·쿠팡 등 온라인 소매 셀러(개인사업자)

## 0. 조사 방법과 한계 (먼저 읽기)

- WebSearch(허용 도메인: nts.go.kr, law.go.kr, korea.kr, gov.kr 등)로 8회 검색했다. 결과 문장은 검색 도구가 요약해 준 것이고, 링크는 모두 검색 결과에 실제로 나온 공식 도메인 URL이다.
- WebFetch로 nts.go.kr, law.go.kr 원문을 열려 했으나 3건 모두 `getaddrinfo ENOTFOUND`로 실패했다(네트워크 차단). 그래서 **조문·표 원문을 직접 눈으로 확인한 항목은 없다.** 아래 '공식'은 "공식 도메인 검색 결과에 해당 내용이 나옴", 즉 검색 요약 기준이다. 코드에 넣기 전에 대표가 law.go.kr 원문과 대조하는 것을 권한다.
- 검색 요약끼리 충돌한 부분은 해당 칸에 적었다.
- 확인수준: 공식(공식 도메인 검색 결과에서 확인) / 2차(공식 도메인이지만 보도자료·Q&A·요약, 또는 요약 내용이 서로 어긋남) / 미확인.

## 2. 계산식 (의사코드)

```
VAT_RATE = 0.10
VA_RATE  = {"소매업":0.15, "음식점업":0.15, "제조업":0.20, "숙박업":0.25, "정보통신/건설/운수":0.30, "그밖서비스":0.30, "전문서비스류":0.40}
LIMIT_SIMPLE = 104_000_000     # 1억400만 (미만이면 간이)
LIMIT_EXEMPT = 48_000_000      # 4,800만 (미만이면 납부면제)
LIMIT_INVOICE = 48_000_000     # 직전연도 4,800만 이상 -> 세금계산서 발급 의무

def annualize(amount, months):   # months: 개업월~12월, 1개월 미만 끝수는 1개월
    return amount / months * 12

def eligibility(prev_supply_annualized, is_new, industry, excluded_flag):
    if industry in 배제업종 or excluded_flag: return "일반과세(간이 불가)"
    if is_new: return "개업 시 선택(예상 연매출 기준)"
    if prev_supply_annualized < LIMIT_SIMPLE: return "간이과세 가능"
    return "일반과세"

def simple_tax(supply, purchase_supply, industry, card_sales=0, use_card_credit=False):
    base = supply * VA_RATE[industry] * VAT_RATE
    credit = purchase_supply * 0.005          # 세금계산서/카드 수취 매입의 공급대가
    tax = max(base - credit, 0)               # 환급 없음
    if use_card_credit: tax = max(tax - min(card_sales * 0.013, 10_000_000), 0)   # 선택, 2026.12.31까지
    exempt_basis = supply if not is_partial_year else annualize(supply, months)
    if exempt_basis < LIMIT_EXEMPT: tax = 0   # 납부면제 (신고는 필요)
    return tax

def general_tax(supply_price, purchase_price_with_vat_invoiced):
    sales_tax = supply_price / 1.1 * 0.10
    purch_tax = purchase_price_with_vat_invoiced / 1.1 * 0.10
    return sales_tax - purch_tax              # 음수면 환급
```

비교 출력: `간이 세액`, `일반 세액`, `차이`, `납부면제 여부`, `세금계산서 발급 의무 여부`, `다음 해 7.1 전환 예상`.

## 3. 입력 항목 제안

1. 올해 연 공급대가(부가세 포함 판매 총액, 환불 차감 후). 스마트스토어 정산이 아니라 **판매금액** 기준(수수료 차감 전) 안내 문구 필요.
2. 직전 연도 공급대가(유형 판정용). 신규면 개업월과 그해 누적 공급대가(환산용).
3. 연 매입액(상품 매입 + 비용 중 세금계산서·카드 증빙이 있는 것만) 와 증빙 유형(세금계산서/카드 vs 증빙 없음).
4. 업종: 소매업 기본값. 도매·제조·부동산매매 선택 시 "간이 불가" 경고.
5. 신규 여부, 개업 월.
6. (선택) 신용카드 결제 매출액(발행세액공제용).
7. (선택) 다른 간이과세 불가 사업장 보유 여부, 세금계산서 발급이 필요한 B2B 거래처 여부.

## 4. 경계 사례와 '판정 불가/확인 필요' 규칙

| 사례 | 처리 |
|---|---|
| 직전연도 공급대가 정확히 1억400만원 | 미달이 아니므로 일반과세. 1억399만9천원이면 간이 |
| 정확히 4,800만원 | 면제 아님('미만'만 면제). 세금계산서 발급 의무는 직전연도가 4,800만원 이상이면 발생 |
| 신규 개업 첫해 | 직전 실적 없음. 판정 대신 "예상 연매출 기준 선택" 안내. 면제 판단은 환산액 사용 |
| 개업월 끝수 | 1개월 미만은 1개월로 계산(Q&A). 정확한 일수 규칙은 확인 필요 |
| 2개 이상 사업장 | 합산 기준 여부 미확인이라 '판정 불가: 세무서 확인' |
| 간이 불가 사업장을 하나 더 가진 경우 | 간이 배제될 수 있음(법 제61조 제3항 위임). 판정 불가 |
| 도매/제조/상품중개/부동산매매 | 간이 불가 |
| 고시 배제기준(전문직, 지역·규모) 해당 | 계산기는 확인 못 함. '확인 필요' 표시 |
| 매입이 많아 일반과세 환급이 큰 경우 | 일반이 유리할 수 있음(간이는 환급 없음). 단 세금계산서 수취 매입만 해당 |
| 사업 중 업종 전환·휴폐업 | 판정 불가 |
| 해외 판매·영세율 매출 | 이 계산기 범위 밖 |
| 당해 연도 매출이 기준 초과 | 그해는 간이 유지, 다음 해 7.1 전환(전환 시 7.1 이후 일반과세 신고 방식 변경) |
| 전환 직전 재고 | 재고매입세액 정산 규정 있음. 이번 조사로 현행 조문 확인 못 함 |

## 5. 손으로 계산한 테스트 케이스 5개

전제: 소매업(15%), 모든 매입은 세금계산서·카드 증빙 있음(공급대가 기준), 매출·매입은 부가세 포함 금액. 단위는 만원. 신용카드 발행세액공제는 0으로 둠.

**케이스 1. 납부면제 구간**
- 입력: 직전연도 3,500, 올해 공급대가 4,000, 매입 2,000, 기존 간이.
- 간이: 4,000 x 0.15 x 0.10 = 60. 공제 2,000 x 0.005 = 10. 산출 50. 올해 4,800 미만이라 면제 -> **0원**(신고는 해야 함).
- 일반: 매출세액 4,000/1.1 x 0.1 = 363.64. 매입세액 2,000/1.1 x 0.1 = 181.82. 납부 = **181.82만원**.
- 출력: 간이 0, 일반 181.82, 간이 유리 181.82만원. 세금계산서 발급 의무 없음(직전연도 4,800 미만).

**케이스 2. 일반 구간 비교**
- 입력: 직전연도 7,000, 올해 8,000, 매입 5,000, 기존 간이.
- 간이: 8,000 x 0.015 = 120. 공제 5,000 x 0.005 = 25. 납부 **95**. 면제 아님.
- 일반: 8,000/11 = 727.27, 5,000/11 = 454.55, 납부 **272.73**.
- 출력: 간이 95, 일반 272.73, 차이 177.73(간이 유리). 직전연도 4,800 이상이므로 세금계산서 발급 의무 있음.

**케이스 3. 기준 초과**
- 입력: 직전연도 12,000, 올해 12,000, 매입 7,000.
- 직전연도 12,000 >= 10,400이므로 일반과세 대상.
- 일반: 12,000/11 = 1,090.91, 7,000/11 = 636.36, 납부 **454.55**.
- (참고 가상 간이: 12,000 x 0.015 = 180, 공제 35, 145. 간이 선택 불가이므로 참고만 표시)

**케이스 4. 신규 환산**
- 입력: 신규, 2026년 6월 10일 개업, 2026년 공급대가 6,000, 매입 3,000.
- 개업 기간 6.10~12.31은 6.7개월이므로 끝수를 1개월로 보면 7개월.
- 환산: 6,000/7 x 12 = 10,285.71. 10,400 미만이므로 2027년도 간이 유지(2027.7.1 전환 없음).
- 면제 판단: 환산 10,285.71 >= 4,800이므로 면제 아님.
- 2026년 간이 세액: 6,000 x 0.015 = 90, 공제 3,000 x 0.005 = 15, 납부 **75**.
- 일반 비교: 6,000/11 = 545.45, 3,000/11 = 272.73, 납부 **272.73**.
- 세금계산서: 신규라서 2026년은 발급 불가, 2027년은 직전연도 6,000(실제 금액 기준인지 환산 기준인지 미확인)이면 4,800 이상이라 발급 의무.

**케이스 5. 간이 환급 없음 vs 일반 환급**
- 입력: 직전연도 6,000, 올해 6,000, 매입 9,000(재고 투자 많음).
- 간이: 6,000 x 0.015 = 90, 공제 9,000 x 0.005 = 45, 납부 **45**(환급 불가, 0 미만 아님).
- 일반: 6,000/11 = 545.45, 9,000/11 = 818.18, 납부 = -272.73, 즉 **환급 272.73만원**.
- 출력: 일반이 유리(차이 317.73). 단 올해 일반 선택은 불가하며 기존 간이면 다음 해 7.1까지 간이가 유지되므로, 이 경우 "현 유형 그대로 적용되는 세액"으로 표시하고 비교는 '만약 일반이라면'으로 안내한다. 간이 사업자는 일반 전환 신청이 가능한지(간이포기 신고 제도)는 이번 조사에서 확인 못 함.

## 6. 계산기가 다루지 않는 것

- 종합소득세(사업소득세)와 지방소득세. 부가가치세 유형과 소득세는 별도 세목이라 소득세 계산에는 이 도구가 영향을 주지 않는다는 점을 화면에 명시한다(이번 조사에서 공식 문장으로 확인한 것은 아니고 세목 구분에 따른 설명).
- 건강보험료, 국민연금, 4대보험.
- 연 매출에 따른 소득세 감면, 간편장부·복식부기, 기장 세액공제.
- 가산세(무신고, 과소신고, 세금계산서 미발급, 현금영수증 미발급 등).
- 의제매입세액, 재활용폐자원 공제, 대손세액, 재고매입세액, 고정자산 매입 구분.
- 영세율(수출·구매확인서), 면세 상품(농산물 등) 판매. 면세 매출은 공급대가에서 제외해야 한다.
- 해외 구매대행·해외 직구 판매의 과세 방식.
- 플랫폼 수수료의 세금계산서 처리(수수료 매입세액 공제 가능 여부), 쿠팡 로켓그로스·네이버 정산 구조에 따른 매출 인식 시점 차이.
- 통신판매업 신고, 사업자등록 절차 자체.
- 투자 권유나 "무조건 이것이 유리" 같은 단정. 결과는 참고용이며 세무사 상담을 권한다고 표시한다.
