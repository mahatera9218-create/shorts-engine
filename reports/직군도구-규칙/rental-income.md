## 0. 조사 방법과 한계 (먼저 읽기)

- WebSearch(허용 도메인 한정)를 9회 실행했다. 아래 "출처 URL"은 모두 **검색 결과에 실제로 나온 URL**이다.
- WebFetch로 nts.go.kr, law.go.kr 원문 열람을 5건+1건 시도했으나 **전부 `getaddrinfo ENOTFOUND`로 실패**했다(샌드박스 네트워크 차단). 따라서 원문을 직접 읽지 못했다.
- 그래서 "공식"은 **"공식 URL이 검색에 나왔고, 검색 요약문이 그 내용을 전한 것"**을 뜻한다. 숫자 하나하나를 원문 대조한 것이 아니다. 코드에 넣기 전 사람이 아래 URL을 한 번씩 열어 대조해야 한다(대표 태블릿에서 가능).
- 확인수준: 공식 = 공식 URL 검색 요약 경유(원문 미열람) / 2차 = 추정·역산·간접 / 미확인.

## 2. 2026년 귀속에서 달라진 점

- 확인됨(공식): 고가주택(기준시가 12억 초과) **2주택자**의 보증금 합계가 12억 초과 시 간주임대료 과세대상 포함 -> 2026년 귀속 이후 (https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?mi=2251&cntntsId=7682). 이 계산기는 월세 수입 중심이므로 간주임대료는 "별도 판정 불가" 안내로 처리.
- 40㎡ 이하·2억 이하 소형주택 주택 수 제외 특례가 2026-12-31까지 -> **2027년 이후 달라질 수 있음**(2026 귀속 신고분에는 적용되는 것으로 읽히나 판단 시점 문구 재확인 필요).
- 분리과세 50%/60%, 200만/400만원은 2026.3.20 개정 서식 안내에 그대로 있음(공식, 서식이 귀속연도별 구분 없이 적혀 있어 "2026귀속 불변" 단정은 약함).
- 소형주택 감면: 2028-12-31까지 -> 2026 귀속에도 존재.
- 공동소유 주택 수 계산 방식을 바꾸는 시행령 개정안 언급이 검색에 있었으나 적용시기 **미확인**.
- 2026년 세법개정안(기재부 발표)·2026 귀속 신규 변경 총정리 자료는 검색에서 **나오지 않음 -> 미확인**. 조특법 시행령이 2026-06-23 타법개정(2026-07-01 시행)으로 표시되나 내용 미확인.
- 등록임대주택 제도: 아파트 장기일반민간임대·단기임대 신규 등록 폐지(2020) 이력은 이번 검색에서 확인 못함(미확인). 계산기는 "현재 등록 상태를 사용자가 입력"하는 방식으로 우회.

## 3. 계산식 (의사코드)

```
입력: R(주택임대 연 총수입금액, 부부 각자 기준, 월세 합계), registered(등록임대 요건 충족 여부),
      O(분리과세 대상 외 종합소득금액, 임대 제외), D(종합과세 시 소득공제 합계),
      mode(장부실비 | 단순경비율), 경비율 e 또는 실제경비 E

if R > 20,000,000: return "분리과세 불가, 종합과세 의무"

# --- 분리과세 ---
exp_rate = 0.60 if registered else 0.50
base_deduct = (0 if O > 20,000,000 else (4,000,000 if registered else 2,000,000))
sep_income = max(0, R - R*exp_rate - base_deduct)     # 사업소득금액(공제 후)
sep_tax    = floor(sep_income * 0.14)
sep_local  = floor(sep_tax * 0.10)
sep_total  = sep_tax + sep_local
# 감면(조특법96)은 별도 입력이 있을 때만: sep_tax *= (1 - 감면율) ; 지방소득세 연동 여부 미확인

# --- 종합과세 ---
rent_income = R - (E if 장부 else R*e)
rent_income = max(0, rent_income)  # 결손은 판정불가 영역(아래 경계사례)
def tax(x): 표 1-A 적용, x = max(0, 과세표준)
tax_with = tax(O + rent_income - D)
tax_without = tax(O - D)
comp_tax = tax_with - tax_without              # 임대로 인한 증분세액
comp_local = floor(comp_tax * 0.10)
comp_total = comp_tax + comp_local

# --- 판정 ---
diff = comp_total - sep_total
if abs(diff) < 임계(예: 1만원) : "비슷함"
유리 = 분리과세 if sep_total < comp_total else 종합과세
```

주의: 세액공제(표준세액공제 등), 건강보험료 영향, 가산세는 계산에서 제외 -> 화면에 명시.

## 4. 입력 항목 제안

1. 귀속연도 (고정 2026, 안내문구)
2. 연 주택임대 월세 수입 합계 (부부 각자 본인 몫, 원) - 보증금 간주임대료는 별도 칸이 아니라 안내
3. 등록임대주택 요건 충족 여부 (지자체+세무서 등록, 증가율 5% 이하) 예/아니오/모름
4. 임대 외 종합소득금액 (근로소득금액 = 총급여-근로소득공제 등 "금액" 기준임을 설명). 모르면 대략값 입력 + 2,000만원 경계 경고
5. 종합과세 시 소득공제 합계 (기본값: 본인 150만원 제안, 사용자가 수정)
6. 종합과세 경비 방식: 단순경비율(%, 직접 입력, 홈택스 조회 안내) / 실제경비(원)
7. 소유 주택 수(부부 합산), 기준시가 12억 초과 주택 여부 (비과세/과세 판정용 체크)
8. 공동소유 여부와 지분 (경계 경고용)
9. (선택) 소형주택 세액감면 해당 여부와 감면율 (직접 선택)

## 5. 경계 사례: "판정 불가 / 확인 필요"로 돌릴 것

- 총수입 2,000만원 초과(분리과세 불가, 종합과세만).
- 총수입 2,000만원 "근처"(예: 1,900만 이상): 수입금액 산정(과세기간 중 월세 합계, 간주임대료 포함 여부)에 따라 넘을 수 있음 -> 경고. 간주임대료를 총수입에 포함하는지는 이번 조사에서 원문 미확인.
- 임대 외 종합소득금액이 2,000만원 근처(+-100만원): 기본공제 적용 여부가 갈림. 정확한 금액 확인 요청.
- 부부 합산 여부: 주택 수는 부부 합산이 확인됨. 그러나 **2,000만원 수입 기준이 본인별인지 부부합산인지는 검색 요약이 서로 엇갈려 단정 불가(미확인)**. 부부 모두 임대수입이 있으면 판정 불가로 표시.
- 공동소유(지분 30% 초과, 수입 600만 이상, 기준시가 12억 초과 주택): 주택 수/수입 배분이 복잡 -> 판정 불가.
- 1주택 비과세 여부(기준시가 12억 초과, 국외주택, 과세기간 중 양도·취득).
- 3주택 이상 + 보증금 3억 초과, 고가 2주택 + 보증금 12억 초과: 간주임대료 -> 계산기 범위 밖.
- 등록 여부 "모름" 또는 사후관리(4년/10년 미충족 시 추징 예정): 판정 불가.
- 소형주택 세액감면 적용 의사: 감면과 분리과세 병행 시 계산 순서/중복 가능 여부 미확인.
- 종합과세에서 결손(경비 > 수입) 또는 실제경비 장부 신고(복식·간편장부, 성실신고): 판정 불가.
- 사업소득 등 다른 사업소득·금융소득 종합과세(2,000만 초과)·연금소득이 있는 경우 한계세율 영향 큼 -> 경고.
- 건강보험료(지역가입자 소득 반영)·각종 공제 축소는 계산 범위 밖임을 명시.
- 사업자등록 미이행 가산세 대상.

## 6. 손으로 계산한 테스트 케이스 5개

공통 가정: 단순경비율은 **국세청 예시값 42.6%**(실제 연도·코드값 아님, 테스트용). 종합과세 증분세액 = tax(O+임대소득-D) - tax(O-D). 원 단위는 만원 표기, 반올림 없음.

**T1** 미등록, R=1,000, O=0, D=150, 종합 단순경비율 42.6%
- 분리: 경비 500, 소득 500, O<=2,000이므로 공제 200 -> 300. 세액 300x14%=42. 지방 4.2. 합 46.2
- 종합: 임대소득 1,000x(1-0.426)=574. 과세표준 574-150=424. 424x6%=25.44. 기준 tax(0-150)=0. 지방 2.544. 합 27.984
- 기대: 종합과세 유리 (27.984 < 46.2)

**T2** 등록, R=1,800, O=3,000, D=500
- 분리: O>2,000 -> 공제 0. 경비 60%=1,080, 소득 720. 세액 720x14%=100.8. 지방 10.08. 합 110.88
- 종합: 임대소득 1,800x0.574=1,033.2. 과세표준 3,000+1,033.2-500=3,533.2 -> 3,533.2x15%-126=403.98. 기준 (3,000-500)=2,500 -> 2,500x15%-126=249. 증분 154.98. 지방 15.498. 합 170.478
- 기대: 분리과세 유리 (110.88 < 170.478)

**T3** 등록, R=400, O=0, D=150
- 분리: 경비 240, 소득 160, 공제 400 -> max(0, 160-400)=0. 세액 0, 합 0
- 종합: 임대소득 400x0.574=229.6. 과세표준 229.6-150=79.6. 79.6x6%=4.776. 기준 0. 지방 0.4776. 합 5.2536
- 기대: 분리과세 유리 (0 < 5.2536)

**T4** (경계) 미등록, R=2,000 정확히, O=2,000 정확히(기본공제 적용 경계, "이하"), D=300
- 분리: 경비 1,000, 소득 1,000, 공제 200 -> 800. 세액 112. 지방 11.2. 합 123.2
- 종합: 임대소득 2,000x0.574=1,148. 과세표준 2,000+1,148-300=2,848 -> 2,848x15%-126=301.2. 기준 (2,000-300)=1,700 -> 255-126=129. 증분 172.2. 지방 17.22. 합 189.42
- 기대: 분리과세 유리 (123.2 < 189.42). 같은 입력에서 O=2,000.0001이면 공제 0이 되어 소득 1,000 -> 140+14=154로 바뀌는지 경계 테스트.

**T5** 미등록, R=600, O=2,500(공제 불가), D=400
- 분리: 경비 300, 소득 300, 공제 0. 세액 42. 지방 4.2. 합 46.2
- 종합: 임대소득 600x0.574=344.4. 과세표준 2,500+344.4-400=2,444.4 -> 2,444.4x15%-126=240.66. 기준 (2,500-400)=2,100 -> 315-126=189. 증분 51.66. 지방 5.166. 합 56.826
- 기대: 분리과세 유리 (46.2 < 56.826)

(참고: T1에서 분리과세는 14%의 단일세율이지만 공제 후 소득이 작은 데다 종합 쪽은 낮은 6% 구간과 소득공제 150이 임대소득을 흡수해 종합이 유리해진다. 계산기 결론이 "분리과세가 항상 유리"가 아님을 보여준다.)
