## 100편에서 찾은 공통 모양

| 항목 | 수치 |
|---|---|
| 본문 길이(공백 제외) | 중간값 1,355자 (1,012~1,864자) |
| 제목 길이 | 중간값 38자 (26~53자) |
| 해시태그 | 보통 2개 (`#종목 #종목주가`) |
| 표 | 없음 |
| 소제목 | 4~5개, 두 줄로 끊어 씀 |

- **제목:** `"따옴표 혼잣말" + 종목 주가 + 숫자 전망 + ~라는데/난리/이유` — 100편 중 약 90편이 이 틀.
- **도입:** 출근길·퇴근길 같은 일상 장면 비유, 또는 "○○ 주주분들, 계좌 열어보기 무섭지 않으세요?" 같은 호명.
- **본문 흐름:** 무슨 일 → 숫자(1,000만원 넣었다면 얼마) → 원인 → **"그런데 한 가지 반전"** → 닉네임 마지막 코멘트(도입 장면 다시 꺼내기).
- **끝:** 투자 책임 고지 한 줄.

## 그대로 따라 하지 않은 것 (우리 원칙 때문)
- 원본엔 출처 없는 "AI 예측치로 1월이 바닥" 같은 문장, "금은 한 번도 배신한 적 없다" 같은 단정이 있음 → **금지**로 넣음.
- 원본 블로거 고유 문구(닉네임 "파블로", "잔치국수") → 대표 닉네임으로 바꾸게 함.
- 독자 실제 댓글·계좌 사연 글 → 우리는 실제 공개된 사연만 허용, 지어내기 금지.

## 쓰는 법 (휴대폰)
1. Claude 앱 → 프로젝트 하나 새로 만들기 (예: "경제-스마트머니형").
2. 프로젝트 지침에 위 파일 내용을 전부 붙여넣고, `[내 닉네임]`을 블로그 닉네임으로 바꾸기.
3. 웹 검색 켜기.
4. 채팅에 `삼성전기 주가`처럼 키워드 한 줄만 보내기.
5. ★추천 제목 + 본문 + 태그를 네이버에 붙여넣고 발행.
