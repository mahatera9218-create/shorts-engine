# 네이버 홈판(홈피드) 조사 · 2026-09-29

대표 질문: "현금 수익(애드포스트)이 목표라면, 검색 상위 노출 주제가 아니라 홈판을 노리는 스포츠·연예 같은 주제여야 하지 않나?"

> 조사 한계: 공식 문서와 대부분의 블로그 본문은 제 작업 환경에서 열리지 않아 **검색 결과 요약**으로 조사했습니다. 수치는 업계 블로그 발(發)이며 네이버 공식 수치가 아닙니다. 조회수·수익 계산은 가정입니다.

## 1. 확인한 사실

| 항목 | 내용 | 출처 |
| --- | --- | --- |
| 홈피드 성장 | 도입 후 3분기 사용자 +22%, 콘텐츠 클릭 +86% (1분기 대비) | 더스쿠프 (네이버 발표 인용) |
| 신규 블로그 | 홈피드는 블로그 지수·오래된 계정의 영향이 줄어 초보도 성장 가능하다는 분석 | TILNOTE |
| 신뢰 구축 기간 | 신규 블로그는 홈판 노출까지 3~6개월 걸린다는 주장도 있음 (서로 엇갈림) | 검색 요약 |
| 애드포스트 단가 | 1천 뷰당 약 300~1,500원. 주제에 따라 2~3배 차이, 금융·보험·IT가 높음 | 포스트닷, 애드센스팜 |
| 저품질 원인 | 유사 문서, 짜깁기, 키워드 반복, 부자연스러운 활동 | 다수 |
| 검색 로직 | 공식·인플루언서 블로그 우선 노출 강화 (2025) | 애드센스팜 |
| AI 글 | 네이버가 AI 판별을 공식화하진 않았으나, 반복 표현·짧은 체류시간으로 저품질 판정된다는 분석 | 행머니 |
| 네이버 메이트 | 2026-06 시작. AI 브리핑 인용 수 기준으로 매달 약 3,000명 선정, 월 30만 원 지원금 | 비즈트리뷴, 검색 요약 |
| 연예 사진 | 기사·방송 사진을 블로그에 올리면 언론사 저작권·연예인 초상권 침해 소지. 상업적 사용 1인당 150만 원 배상 판결 사례 | 법률신문, 헬프미 |

## 2. 수익 계산 (가정)

애드포스트만으로 월 30편 발행 기준. 1천 뷰당 단가는 연예·스포츠를 낮은 쪽 **300~700원**, 자동차를 **700~1,500원**으로 가정합니다.

| 시나리오 | 편당 월 조회 | 월 조회 | 월 수익 |
| --- | --- | --- | --- |
| 홈판 약함 | 1,000 | 3만 | 약 0.9만~2.1만 원 |
| 홈판 보통 | 5,000 | 15만 | 약 4.5만~10.5만 원 |
| 홈판 강함 | 20,000 | 60만 | 약 18만~42만 원 |
| 자동차 검색 (2~3개월차) | 200~1,000 (누적) | 0.6만~3만 | 약 0.4만~4.5만 원 |

- 월 100만 원을 내려면 1천 뷰당 500원 기준 **월 200만 뷰**가 필요합니다 (30편이면 편당 약 6.7만 뷰).
- 검색 글은 쌓일수록 조회가 누적됩니다. 홈판 글은 하루이틀 뒤 조회가 끊기므로 계속 발행해야 합니다.

## 3. 분석 요약

- **대표 판단 중 맞는 부분:** 애드포스트만으로 벌려면 단가보다 트래픽 총량이 중요합니다. 신규 블로그가 큰 트래픽을 빨리 얻을 수 있는 곳은 검색보다 홈판입니다. 또 자동차 비교형은 글감이 약 55~60편으로 한계가 있습니다.
- **연예는 우리 구조에 맞지 않습니다.**
  - 기사·방송 사진을 못 씁니다 (저작권·초상권).
  - Claude는 방송을 볼 수 없으니 기사를 짜깁기하게 되고, 이는 저품질 판정의 1순위 원인입니다.
  - 루머·명예훼손 위험도 있습니다.
- **스포츠는 맞는 편입니다.**
  - 기록·순위·경우의 수를 코드로 계산하고 그래픽을 직접 만들면 사진 문제가 없고, 우리 무기(새 숫자)와 겹칩니다.
  - 경기가 매일 있어 글감이 끝이 없습니다.
  - 지금이 가을 야구 포스트시즌과 농구·배구 개막 시기입니다.
- **스포츠의 가장 큰 걸림돌은 발행 타이밍입니다.**
  - 홈판은 경기 직후처럼 관심이 몰리는 순간을 탑니다.
  - 네이버 블로그는 자동 발행 수단이 없고(공식 글쓰기 API 없음, 재확인 필요), 지금 결정은 "주 1회 예약 발행"입니다.
  - 경기 전 미리보기(기록 비교·경우의 수)는 예약할 수 있지만, 결과 글은 대표님이 매일 발행해야 합니다.
- **스포츠 데이터 출처도 확인이 필요합니다.** 공식 API만 쓴다는 규칙상, 경기 기록을 합법적으로 받을 방법을 찾아야 합니다.

## 4. 결정이 필요한 것

1. 파일럿 주제를 자동차에서 스포츠(데이터형) 홈판으로 바꿀지
2. 발행 방식: 주 1회 예약 → 하루 1~2회 휴대폰 발행(편당 2~3분)으로 바꿀지
3. 연예는 하지 않는 것에 동의하는지
