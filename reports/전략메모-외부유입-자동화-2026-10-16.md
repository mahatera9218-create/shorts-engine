# 전략 메모 — 외부 유입 자동화 (Threads·네이버 지식인·디시인사이드) 2026-10-16

## 결론 (한 줄)
**자동화해도 되는 건 Threads 뿐.** 네이버 지식인·디시인사이드의 자동 홍보(매크로)는 **어뷰징 제재·계정정지·법적 리스크**가 커서 안 한다. 대신 그 두 곳은 사람이 **소량·진짜 도움 위주**로만.

## 채널별

### 1) Threads — ✅ 공식 자동화 (메인 유입 채널)
- Meta **공식 API(OAuth)로 자동 게시 지원.** 하루 약 **250건 한도**(실제는 Meta 문서 확인).
- 활용: 새 글 요약 + "순위 이번 주 변동"을 자동 게시 → 링크로 유입.
- 주의(도달 유지): 너무 기계적 패턴은 노출↓ → **하루 5~10개·글 다양화·사람 검수**. 제휴 링크는 **대가성 표시**(표시광고법).
- 구현: 대표가 **Threads API 토큰** 발급 → `content/`에 자동 게시 스크립트 + 워크플로. 글 발행 때 같이 스레드 게시.

### 2) 네이버 지식인 — ⚠️ 자동화 금지
- 네이버가 **매크로 어뷰징 적발 → 경찰 수사의뢰**, anti-abuse·봇 차단 인력 확대 중. 자동 답변 = **계정정지·법적 위험**.
- 할 수 있는 것: **사람이** 실제 질문에 진짜 도움되는 답변 + 자연스러운 출처 링크 1개(홍보성 과하면 삭제됨).
- 권고: **자동화 X.** 수동 소량(주 몇 개), 전문성 있는 답변만.

### 3) 디시인사이드 — ⚠️ 자동 홍보 비추
- 자동 홍보 = 어뷰징 제재 + **커뮤니티 역풍**(홍보 극혐 문화). 허위조작정보 대응 의무 플랫폼.
- 권고: **자동화 X.** 정말 정보성 글을 사람이 가끔, 홍보 티 없이.

## 공통 원칙 (우리 원칙 + 법)
스팸·매크로·가짜 계정·좋아요 조작·뒷광고 금지. 자동화는 **공식 API가 허용하는 Threads만.**

## 추천 실행안
1. **Threads 자동 게시부터 붙인다** (유일한 안전 자동화 채널). 대표가 토큰만 주면 연결.
2. 지식인·디시는 '자동화'가 아니라 **'사람이 진짜 도움'** 전략 — 필요하면 답변 가이드/템플릿만 제공.
