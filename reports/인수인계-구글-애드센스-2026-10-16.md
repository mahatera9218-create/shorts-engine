# 인수인계 — 구글/애드센스(Yield Briefing) 대화창 (2026-10-16)

> 이 문서 하나로 **구글 사이트·애드센스·순위·Threads** 작업을 새 창에서 그대로 이어받는다.
> 저장소·허브는 고정이고 창만 나눈 것. 네이버는 별도 창에서 진행.
> **먼저 읽을 것:** `CLAUDE.md`(원칙·한국어·모바일), `DECISIONS.md`(최신 결정 우선), 이 문서.

## 1. 한 줄 정의
**Yield Briefing** = 구글 검색·애드센스용 **헤드리스 금융 사이트**(astacgroup.com). 재테크·부동산·세금·연금을 공식 자료로 쉽게·정확하게. 글은 Opus가 자동 작성·발행, 사이트는 저장소 글을 직접 읽어 정적 생성.

## 2. 현재 상태 (2026-10-16 기준)
- **구조:** 워드프레스 **폐기**(가비아 방화벽이 발행 차단). Next.js가 `web/content/posts·pages/*.md`를 직접 읽어 정적 생성 → Vercel 배포. 도메인 astacgroup.com은 Cloudflare Worker로 Vercel에 연결.
- **브랜드:** **Yield Briefing**(별+바다 로고). 헤더=로고만, 소개 박스="Yield Briefing".
- **글 자동화:** `publish_fs.py`가 대기 초안(`reports/구글글-초안/`)을 사이트 글로 발행. **하루 2~3편**(wp-drip.yml, 오늘만 2편). 작성기 `wp_write.py`(Opus 4.8)가 매일 새 초안 생성. 글에 **쉬운 도입+가상 예시 스토리텔링**, 본문 사진(Unsplash), 진짜 표.
- **SEO:** sitemap·robots·Article/FAQ 스키마·`llms.txt` 적용. **구글 서치콘솔·네이버 둘 다 등록+사이트맵 제출 완료.** 색인은 시간이 쌓이며 증가.
- **애드센스:** `ca-pub-6435261744776184`, `ads.txt`, auto-ads 스크립트 적용. (광고 단위 ID는 아직 없음)
- **순위 페이지:** `/rank/[slug]` + 앱별 상세 `/rank/[slug]/[app]`. 이름→상세→외부링크, 상세에 **광고 자리 2곳**. 현재 **세무앱 순위**(예시 데이터, **noindex 베타**). 그록 주간 호응도 수집 붙음(`rank_collect.py`, 매주). **공개 전환·버티컬 확장은 방향 미정.**
- **Threads 자동게시:** `threads_post.py`+`threads-post.yml`(하루 3회 소량). **토큰 미설정이라 아직 안 돎.**

## 3. 핵심 파일
- 사이트: `web/` (Next.js). 상수·브랜드 `web/lib/site.ts`, 데이터 로더 `web/lib/wp.ts`(글)·`web/lib/rankings.ts`(순위), 디자인 `web/app/globals.css`, 로고 `web/public/logo.png`·파비콘 `web/app/icon.png`.
- 글 파일: `web/content/posts/*.md`, 페이지 `web/content/pages/*.md`, 순위 `web/content/rankings/*.json`.
- 발행/작성: `content/publish_fs.py`, `content/wp_write.py`, 순위수집 `content/rank_collect.py`, Threads `content/threads_post.py`.
- 워크플로: `.github/workflows/` 의 `wp-drip.yml`(발행)·`wp-write.yml`(작성)·`wp-pages.yml`·`wp-publish.yml`·`rank-collect.yml`·`threads-post.yml`.
- 작성 프롬프트: `prompts/project/클로드-경제-글-구글.md`. 주제 큐: `config/google_topics.yaml`.

## 5. 열린 과제 (새 창에서 결정/진행)
1. **순위 방향** — 세무앱/세무법인/법무법인/보험 중 어디부터, 공개 전환 시점(데이터 검증 후 noindex 해제). *기준: 돈 내는 광고주.*
2. **Threads 켜기** — 대표가 `THREADS_ACCESS_TOKEN`(Meta 개발자) 발급 → GitHub Secrets. (단계 안내 필요)
3. **애드센스 광고 단위** — 광고 단위 만들어 `NEXT_PUBLIC_ADSENSE_SLOT` 넣으면 순위 상세 광고 자리에 실제 광고.
4. **사진 키 확인** — `UNSPLASH_ACCESS_KEY`가 Vercel에 있는지(없으면 글 사진 안 뜸).
5. **가비아 호스팅** — 안 쓰니 결제일에 해지 가능. **단 도메인(astacgroup.com)은 유지.**
6. **SEO 2차** — 네이버 AI Briefing 최적화 등 `fire-your-seo-agency` 체크리스트 중 남은 것.
