## 0. 북극성 (AI 시대 원칙)
- **정보 콘텐츠로 광고 버는 모델은 구조적 쇠퇴 중**(AI 개요·챗봇이 정보성 클릭을 가져감). 영리한 도구·데이터로도 못 막음.
- **AI가 못 뺏는 것 = ① 관계(구독·신뢰) ② 전환(제휴·신청) ③ 사람이 가는 곳(쇼츠·네이버).**
- **애드센스는 '기본 깔개', 진짜 레버는 제휴·협찬·자체상품.**
- **최선은 정답이 아니라 과정:** 싸게 여러 개 던지고 → 숫자로 판단 → 되는 데 몰빵, 안 되는 거 빨리 접기. 한 채널에 결혼하지 않기.
- **복리로 쌓는 하나(시스템·엔진·신뢰·데이터)**는 꾸준히.

## 1. 채널 역할
| 채널 | 역할 | 수익 |
|---|---|---|
| **네이버** | 한국인이 아직 쓰는 검색·커뮤니티, 시의성(폭락 등) | 애드포스트·협찬·유입 |
| **쇼츠** | 발견·구독(AI가 못 대체하는 '보는' 것) | 조회수·협찬·유입 |
| **구글 WP** | 세무 evergreen 권위·롱테일·제휴 베이스 (가볍게, 올인 X) | 애드센스·제휴 |
| **제휴/협찬** | 돈이 실제 움직이는 전환 지점 | CPA·원고·협찬 |

### 1-1. 쇼츠 = 발견 × 연계 (핵심 축)
쇼츠는 **AI가 못 먹는 '발견' 채널**(사람이 '보는' 것) + **블로그로 흘려보내는 깔때기.** 이미 엔진 보유(대본·영상 자동 생성).
- **별개(그 자체 자산):** 발견·구독·조회. 멀티 배포 = **유튜브 쇼츠(구글권) + 네이버 클립(네이버 홈피드 유입) + 인스타 릴스/틱톡**. 한 번 만들어 여러 곳에.
- **연계(funnel):** 쇼츠=훅(15초 핵심) → "자세한 건 블로그" → 네이버/구글 글로 유입·구독 전환. 설명란·고정댓글에 블로그 링크. 쇼츠로 신뢰 쌓고 블로그에서 애드센스·제휴.
- **콘텐츠 연결:** 세무/경제 '한 입' 쇼츠 → 같은 주제 블로그 롱폼. 시의성(폭락 등)은 쇼츠(요약)+블로그(깊이) 세트.
- **솔직한 주의:** 금융/세무 쇼츠는 엔터보다 조회 덜·전환율 낮음. 그래도 발견·구독·신뢰·장기 유입 가치 큼. 얼굴 없이 자막+AI로 가능(우리 방식), AI 생산속도로 싸게 많이 테스트.
- **타이밍:** 블로그 자리잡은 뒤 1~2개 테스트부터 → 숫자 보고 비중 조절(빠른 실험·재배분). 패션 쪽도 궁합 좋음.

## 2. 주제·키워드 선정 기준 (돈 되는 걸 고르는 법)
1. **상업의도 > 정보성** ⭐ — '무엇/뜻'(AI가 먹음, CPC 낮음) 말고 **'어디서·비교·비용·신청·추천'**(AI 방어 + CPC 높음 + 제휴 전환). 예: "ISA 어디서 개설", "전세대출 비교", "세무사 비용", "환급 받는 법".
2. **광고주 역설계** — "이 글 옆 광고 낼 광고주가 부자인가?" 큰손=분양·증권·카드·세무법인·(규제)대출·보험 = 우리 정체성 '수익 의뢰층'과 동일.
3. **계절성** — Q4(10~12월) 광고 단가 연중 최고. 세무는 시즌 명확(연말정산 1~2월, 종소세 5월). **글은 3~6개월 숙성** → 시즌 전에 미리. (👉 지금 10월 = 연말정산 깔 때)
4. **트래픽 함정** — 바이럴은 트래픽 많아도 CPC 바닥. **RPM×트래픽(실수익)**으로 판단. 목표는 '조회수'가 아니라 **방문자당 수익×유지**.
5. **AI 방어** — 클릭이 살아남는 글(계산·비교·'내 경우'·최신·거래의도·도구성) 위주.
6. **듀얼 키워드 조사** — 네이버 검색광고 + **구글 키워드플래너** 둘 다(일 두 번 안 하기).

## 3. 유입 채널 (검색만 바라보지 않기)
- **구글 검색(SEO):** 세무 질문형 롱폼 + E-E-A-T. 단 AI 개요에 정보성은 깎임 → 거래의도·도구성으로.
- **구글 디스커버** ⭐ — 피드(관심사) 기반이라 **AI 개요에 안 뺏김.** 신뢰+신선+흥미면 폭발. 금융·재테크가 잘 먹힘. 흥미 제목·좋은 썸네일·최신성 의식.
- **내부링크 거미줄** — 발행마다 관련 글 연결(허브↔스포크). '링크 0개 고아 글' 금지. (글 쌓이면 자동 점검 도구)
- **백링크(권위)** — ⚠️ **업체/"화이트 백링크" 구매 금지**(구글 SpamBrain이 무효화, YMYL은 페널티 위험, 돈 날림). 네이버엔 백링크 개념 거의 없음(C-rank). → **되는 건 '링커블 자산'**(인용당할 데이터·비교·총정리) + 뉴스재킹(이슈 때 데이터·코멘트) + 커뮤니티 자연참여. 신생은 콘텐츠·신뢰 먼저, 백링크는 천천히 자연히.

## 4. 애드센스 실무 (승인~최적화)
- **승인:** 저가치 콘텐츠·필수페이지(소개/연락처/개인정보/약관/면책) 누락이 거절 1위. 한 주제 깊게(15편>30편 얕게). 자동생성이라도 **정보이득·깊이·검수** 필수(대량 저가치=밴 위험).
- **배치:** 긴 글당 3~5개. 제목 아래·본문 속·모바일 하단 앵커. 사이드바 약함. 하이브리드(앵커·비네트는 Auto, 본문 수동). 과밀 금지.
- **지표·속도:** page RPM이 핵심. 광고가 '보여야' 돈(뷰어빌리티). CWV(LCP<2.5s·CLS<0.1) 챙기면 수익·순위 동반↑. 광고 자리 크기 미리 확보, 하단 lazy(히어로 제외). 'AdSense 실험'으로 A/B.
- **네트워크 사다리:** Mediavine·Raptive는 **미국·영어권 트래픽 조건이라 한국어 블로그엔 사실상 부적합.** → 애드센스가 현실. 레버는 제휴.

## 5. 수익원 레이어
1. **애드센스**(기본 깔개, 안전 배치)
2. **제휴(주 레버)** — 증권 계좌개설 CPA·카드·세무서비스(삼쩜삼류)·쿠팡파트너스. 맥락 맞을 때만, **광고 고지 필수**, 금융상품은 규제 민감.
3. **자체 디지털 상품** — 세무 엑셀 서식·체크리스트 PDF·유료 뉴스레터/멤버십(플랫폼 독립·고마진·AI가 못 뺏는 전환).
4. **업체 협찬·원고** — 전문성 쌓이면 고단가 직접 협찬(정체성 지향점).

## 6. 지급·세금 (한국) — 우리 세무 전문성과 직결
- 지급: 누적 100달러↑(공식 확인), 외화→입금일 환율로 원화 환산.
- 세금: 해외소득도 **5월 종합소득세 신고 대상**(사업소득). 사업자등록 기준은 자료마다 달라 **국세청·세무사 확인**.
- 💡 이 주제 자체가 글감("블로그·유튜브 수익 세금 신고") — 우리가 직접 겪어 정확·경험.

## 7. 금지·주의 (원칙)
- ❌ 대량 저가치 양산 / **새끼 사이트 돌리기**(scaled content=밴)
- ❌ 백링크 구매 / 무효 트래픽(내 광고 클릭·유도=영구정지)
- ❌ 저작권 복제(뉴스사진) / 가짜 경험·가짜 자격·투자권유·절세 과장
- ✅ 대가성 글 광고 고지 / 규제 업종(대출·보험) 신중 / 편당 검수

## 8. 당장 실행 (우선순위)
1. **상업의도 키워드로 기울이기**(어디서·비교·비용·신청).
2. **연말정산 콘텐츠 지금(10월)부터** 깔기(계절성+Q4).
3. **내부링크 거미줄** — 발행마다 관련 글 연결.
4. **듀얼 키워드 조사**(네이버+구글 키워드플래너).
5. (중기) **링커블 자산 1~2개**(데이터/비교/총정리)로 디스커버·백링크·인용 동시.

## 9. 열린 질문 (숫자 쌓인 뒤 재결정)
- 쇼츠를 발견·구독 축으로 얼마나 키울지.
- 제휴 언제·무엇부터(증권/세무/쿠팡) — 규제·고지.
- 구글 WP '가볍게'의 구체 수준(주 몇 편·자동화 어디까지).
- 자체 디지털 상품 첫 후보.
- 판정형 웹앱은 AI 대체 리스크로 보류(필요 시 재검토).
