# astacgroup 외부유입 조사 — 2026-10-18

본진 = astacgroup(세금·재테크 애드센스). 외부 채널에서 본진으로 사람을 보내는 전략.
근거: WebSearch(구글 publisher 리소스·무효트래픽 고객센터·canonical 문서 등). 네이버/카페/브런치 '공식' 정책과 실제 referral 규모는 **미확인**(운영자 후기 수준).

## A. 네이버 → 외부유입, 실제 되나
- "외부링크=저품질"도, "잘 된다"도 **공식 근거 없음**(경험담). 네이버가 경계하는 건 '남의 글 긁어가기'이지 '링크 한두 개'가 아님(2025 카페 수집·복제 금지 공지는 확인됨).
- **안전책은 하나: 요약글 + 원문 링크.** 전문 복붙 금지(같은 글 두 곳 → 본진이 밀림).

## B. 애드센스 트래픽 정책 (공식)
- 허용: 블로그·커뮤니티·소셜의 **자연 추천(referral) 트래픽**.
- 금지(계정 정지): 트래픽 구매·교환, 봇/자동 대량, 클릭 유도("광고 눌러주세요"), 클릭 품앗이. 급증 시 무효트래픽 차감.

### 네이버 vs 브런치 (둘 다 '입구')
- 네이버 = 네이버 검색 사용자층. 바로 시작. 본진과 덜 부딪힘(울타리).
- 브런치 = 구글 신뢰도 빌려 구글 색인·유입 당김. 작가심사 필요. **구글 같은 링이라 전문 복붙 시 본진 밀어냄 → 요약만.**

## D. 지금 당장 쓸 전술 (우선순위, 가볍게)
1. 지식iN 성실답변 + 심화글 링크 (노력·위험 낮음)
2. 네이버 세금 요약글 + astacgroup 링크 (효과 큼, 발행 손 필요)
3. Threads 수동 세금팁 (자동 금지)
4. (승인·여유 후) 브런치 작가신청 → 요약 교차발행
- 공통: 외부엔 '요약'만, 표·계산기·사례는 본진에만 둬서 클릭 이유를 만든다.

## E. 하지 말 것
- 트래픽 구매·교환·클릭 품앗이 → 계정 정지
- 봇·자동 대량 포스팅(네이버 저품질 + 애드센스 무효트래픽)
- 남의 글 전문 복제
- 같은 글 전문을 여러 곳 재게시(중복 → 본진 밀림). canonical은 '힌트'일 뿐, 네이버·브런치는 사실상 지정 불가 → 요약 전략만 안전.

## 우리 자산 연결 (주의)
기존 네이버 경제 블로그는 **별개 사업·경제 주제**라 세금 링크를 섞으면 주제 불일치로 양쪽 손해. astacgroup 외부유입용은 **세금 주제로 따로** 운영해야 함. 외부유입은 '마중물'이고 본류는 구글 검색이므로, 글·시간이 먼저.
