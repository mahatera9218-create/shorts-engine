## 우리가 확인 못 한 것 (솔직히)
- **왜 상위에 뜨는지는 이 숫자로 증명 못 해요.** 공식 검색 API 순서로는 69개 "선수 + 연봉" 검색어 중 이 블로그가 1곳(노시환 연봉 14위)에만 보였어요. API 순서는 실제 검색 화면과 달라서, 대표님이 휴대폰에서 본 "대부분 상위"와 다를 수 있어요. 블로그가 쌓은 신뢰도 몫이 클 거예요.
- 제목 92자는 RSS에 나온 제목 그대로 잰 값이에요. 실제 화면에서도 그렇게 긴지 대표님이 한두 개 봐주시면 확실해져요.

## 제안 (대표님 결정 필요한 것만 표시)
1. **태그 5개 → 15개 안팎** (선수·팀·리그·연도·"연봉" 조합, 특수문자 없이). 비용 0, 제가 바로 적용 가능. 30개 꽉 채우기는 억지 태그가 섞여서 15개부터.
2. **제목에 검색어 한두 개 더** (예: 이름 + 연봉 + 연도 + 계약). 썸네일 짝 규칙은 그대로 두고 뒤에 괄호로 덧붙이는 식. 1주 시험 후 조회수로 판정.
3. **[결정] 순위·총정리형 글을 주 1~2편 섞기** (예: 2026 KBO 연봉 순위). 확인된 연봉표를 넓히는 일과 같이 가요. 쇼츠 C(순위표)와도 짝이 맞아요.
4. **[결정] 발행 시각을 저녁 8~10시로 옮겨 보기.** 글은 아침에 준비되니 대표님이 저녁에 발행 버튼만 누르면 돼요.
5. 따라 하지 않을 것: 남의 제목·문장·구성 그대로 가져오기, 억지 키워드 나열.
