# 설계 — 도우미를 키워드 전용 도구로 개편

2026-10-13 · 대표 결정 반영. 확인 후 단계적으로 적용.

## 왜

글·제목·사진은 이제 구독 프로젝트(클로드·GPT)가 쓴다. 도우미가 떠안던 '오늘 글·글 만들기·제목 후보'는 죽은 짐. **도우미 = 키워드 고르는 도구**로 축소한다. 키워드 조사 로직은 그대로 유지.

## 최종 화면 (보이는 탭 3개)

1. **경제 순번** — 지금 만든 체크리스트(투자/부동산/예적금/중장년, ✓완료·전체 리셋).
2. **경제 키워드** — 섹션별(국내주식·해외주식·금/비트·부동산·환율·생활경제) 키워드 목록 + 🔄 다시 모으기. 이미 쓴 키워드 ✅·숨기기 유지.
3. **패션 키워드** — **셀럽 이름(명단 62명) 든 키워드만, 상위 5개**(이름 없으면 개수 줄어도 됨). 출처 표시 + 🔄 다시 모으기.

## 없애는 것 (대표 결정)

- **성과 탭:** 코드·데이터·캡처 읽기 로직은 **그대로 유지**, **화면(탭)만 숨김.** 나중에 다시 켜기 쉬움.
- **어사이드 탭 / 사진 탭 / 캡처 올리기 버튼:** 제거.
- **패션 조사 세트:** 제거(이제 불필요).
- **경제·패션 탭 안의 오늘 글·글 만들기·제목 후보:** 제거(키워드만 남김).

## 키워드 조사 로직 (유지)

- 수집은 '🔄 다시 모으기' 누를 때만 돈다(자동 스케줄 꺼짐 유지).
- 무료 경로(뉴스 RSS·검색량 급상승)가 기본. **확장 주제(부동산·예적금·중장년)**도 이미 씨앗이 있어 같이 모인다.
- **그록 API:** 패션엔 계속 쓸지는 대표 판단. 경제 확장엔 **보조로만**(중장년은 X보다 뉴스·급상승이 정확) — 이건 다음 단계로.

## 키워드를 누르면? (미결 1개 — 기본값 제안)

키워드 도구니까, **누르면 그 키워드가 복사된다**(프로젝트 입력창에 붙여넣기용)로 기본 제안. 
- 다른 안: 아무 동작 없음(눈으로 보고 직접 타이핑) / 예전처럼 깃허브 이슈 열기.
- 특별히 말 없으시면 **'복사'**로 만들겠습니다.

## 단계 (되돌리기 쉽게)

1. 성과·어사이드·사진·캡처·조사 세트 숨김/제거 + 패션 키워드 5개·셀럽 필터.
2. 경제·패션 탭을 키워드만 남기고 정리(순번/경제 키워드/패션 키워드 3탭 완성).
3. (선택) 경제 확장 주제용 그록 보조 연결.

## 확인 부탁

- 위 3탭 구성·없애는 목록 이대로 가면 되는지.
- 키워드 누르면 '복사'로 해도 되는지.
→ OK 주시면 1단계부터 바로 적용.
