# 쿠니네 프롬프트 2개 vs 우리 적용 (2026-10-06)

표시: **그대로** = 원문대로 / **바꿈** = 원문대로 못 해서 다른 방법으로 / **더함** = 원문에 없는데 넣음 / **뺌** = 원문에 있는데 안 함

## 1. 경제 프롬프트 (prompts/kunine-blog.md)

| 항목 | 쿠니네 원문 | 우리 | 구분 |
|---|---|---|---|
| 조사 | 글 쓰면서 네이버·구글 최신 뉴스 직접 검색·교차검증 | Grok이 어제·오늘 웹·X 조사 → Claude는 그 메모만 근거 | 바꿈 |
| 내부 분석 | 궁금·억울·화남·기대·놀람·공감·찬반 등 분석, 본문엔 노출 금지 | 조사 메모에 같은 항목 요청, 본문 노출 금지 | 그대로 |
| 출처 | 언론사명·URL·각주 전부 금지, "정부 발표에 따르면" 정도만 | 같음 + 코드가 언론사명·링크를 찾아 다시 쓰게 함 | 그대로 |
| 제목 | 6유형 × 5개, 유형별 BEST, 최종 BEST 5 | 같음 | 그대로 |
| 제목 기준 | 45자 이내, 핵심키워드 포함, 약 30% 강하게 가능 | 같음 + 45자 넘거나 키워드 없으면 도우미에 경고 표시 | 그대로 |
| 제목 참고 | 없음 | 제목 고수 경제토르 공식(구조만, 문장 복사 금지) | 더함 |
| 키워드 반복 | 본문 20회 이내 | 같음 (코드 검사) | 그대로 |
| 문체 | 사람이 쓴 자연스러운 블로그 문체, AI 상투어 금지 | 같음 + 담백한 설명체, 캐릭터·비유 설정 없음 | 그대로+더함 |
| 경험 | 없음 | 하지 않은 경험("사 보니", "제 계좌") 금지 | 더함 |
| 투자 권유 | 없음 | "사세요", "반드시 오른다" 금지, 전망은 누가 어떻게 보는지로만 | 더함 |
| 분량 | 본문 1,500자 이내 | 같음 (코드 검사) | 그대로 |
| 표·Q&A·해시태그 | 숫자 비교 표, Q&A 3줄, 해시태그 20개 | 같음 | 그대로 |
| 참조문헌 문구 | Q&A 뒤 "참조문헌: 뉴스, 언론보도 및 공식자료" 한 번 | 같음 (코드가 넣음) | 그대로 |
| 사진 장수 | 구간마다 실제 사진 최소 2장 | 구간마다 2장, 본문 최대 6장 | 그대로 |
| 사진 출처 | 실제 뉴스 현장·인물·기업 사진 | 회사: 위키미디어 실제 사진 → AI(진짜 간판) → Pexels / 그 외: AI 실사 → Pexels | 바꿈 (남의 사진 무단 사용 금지) |
| 사진 속 사람 | 실제 인물 사진 우선 | 실존 인물 얼굴 안 그림 (뒷모습·손) | 바꿈 (초상권) |
| 사진 속 글자 | 없음 | 회사 간판 말고는 글자·숫자·차트 그림 없음 | 더함 |
| 썸네일 | 없음 | 제목 주인공 한 장, 가운데 크게, 비유 없음 | 더함 |
| 끝 안내문 | 없음 | "일부 이미지는 AI로 만든 이미지입니다. 정보 제공용이며 투자 권유가 아닙니다." | 더함 |

## 2. 연예인 패션 프롬프트 (prompts/ent-fashion-blog.md)

| 항목 | 쿠니네 원문 | 우리 | 구분 |
|---|---|---|---|
| 조사 | 사용자가 준 사진·제품·가격 우선, 필요하면 최신 자료 조사 | Grok이 어제·오늘 웹·X 조사 → 메모만 근거 (대표가 주는 자료는 없음) | 바꿈 |
| 메타 문장 | "검색해보니", "첨부 자료" 등 제작 과정 문장 금지 | 같음 (코드 검사) | 그대로 |
| 가격 | 숫자로, 제품별로 따로, 모르는 가격은 안 만듦 | 같음 + 메모에 없으면 가격 안 씀 | 그대로 |
| 제목 | 3그룹 × 5개(이름 숨김·이름 노출·관련 인물) + 최종 1개, 30자 우선 | 같음 | 그대로 |
| 제목 금지 | 기사체(근황·화제·역대급 등), 대괄호·소괄호·단독·속보·공식 | 같음 | 그대로 |
| 제목 참고 | 없음 | 제목 고수 유미·jayuyu 공식(구조만, 외모 평가 표현 제외) | 더함 |
| 인사말 | "삐까쮸 삐까 삐까 입니다." | "캐시미어 다이어리의 캐다입니다." | 바꿈 (블로그 이름) |
| 말투 | 친숙한 여성 블로거, 사진 보고 느낀 듯이 | 차분·우아한 올드머니 톤, 감탄 절제 | 바꿈 (블로그 페르소나) |
| 경험 | "직접 구매형"은 실제 확인된 경우만 | 블로거가 직접 사거나 입어 본 것처럼 쓰지 않음 (사진 감상은 괜찮음) | 더 엄격하게 |
| 분량 | 1,500자 이상 (1,800~2,500 권장) | 같음 (코드 검사) | 그대로 |
| 본문 흐름 | 착장 → 제품 → 브랜드 → 가격 → 소재 → 실루엣 → 따라 입기 | 같음, 소제목 구간 3~5개 | 그대로 |
| 요약 | 숫자·순서 말 없는 짧은 요약 | 같음 (코드 검사) | 그대로 |
| 저작권·비하 | 문장 복사·사생활 추측·외모/나이/성별 비하·협찬 단정 금지 | 같음 | 그대로 |
| 해시태그 | 20개 미만 | 19개 이하 (코드 검사) | 그대로 |
| 사진 장수 | 최대한 많이, 구간마다 최소 2장 | 구간마다 2장, 최대 8장 | 그대로 |
| 사진 출처 | 착장 사진·방송 장면·SNS·행사·공항·브랜드 공식 사진 | 위키미디어 자유 이용 실제 사진 → 제품만 나오는 AI 사진(로고 없음) → Pexels. 방송·SNS·언론 사진 안 씀 | 바꿈 (저작권·초상권 신고 위험) |
| 사진 출처 표시 | 없음 | CC BY 사진은 사진 아래 작가·라이선스 표시 | 더함 (라이선스 조건) |
| 썸네일 | 없음 | 주인공 인물 실제 사진, 없으면 제품 | 더함 |

## 뺄 수 없는 것 (법·사업 원칙)
남의 사진 무단 사용 금지(사진 출처 바꿈), 실존 인물 얼굴 AI로 안 그림, 가짜 경험 금지, 투자 권유 금지.
그 밖의 '더함'은 대표가 원하면 바꾸거나 뺄 수 있음.
