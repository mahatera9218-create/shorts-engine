# 홈판 주제 후보 조사 · 2026-09-29

목표는 애드포스트 현금이고, 트래픽 총량이 큰 홈판을 주력으로 합니다 (DECISIONS 2026-09-29).
이 기준에서 스포츠 외에 추가할 만한 주제를 찾았습니다.

## 평가 기준 (광고 사업 관점)

| 기준 | 왜 중요한가 |
| --- | --- |
| 홈판 수요 | 조회수 총량 = 매출 |
| 합법적 데이터·사진 출처 | 사진이 클릭을 부른다. 출처가 없으면 짜깁기가 되고, 짜깁기는 저품질 판정 → 블로그 전체 매출 0 |
| 발행 타이밍 부담 | 실시간이 필요하면 운영자 시간이 든다 |
| 광고 단가 | 같은 조회수라도 2~3배 차이 |
| 글감의 양 | 매일 쓸 거리가 끊기지 않아야 한다 |
| 법적 위험 | 소송·제재는 손실 |

## 먼저 알려드릴 것: 스포츠 데이터 출처 문제

- **KBO는 공식 공개 API가 없습니다.** 공식 기록은 KBO STATS 앱으로만 제공됩니다.
- **기록 데이터 저작권은 KBO에 있고 상업적 이용이 제한된다**는 조사 결과가 있습니다.
- GitHub에 KBO 데이터 프로젝트가 여럿 있지만, 전부 공식 사이트를 긁는 방식입니다 (비공식).
- **판단:** 경기 점수·순위처럼 **기사에 나오는 몇 개의 사실**을 글에 인용하는 것은 가능할 것으로 봅니다. 하지만 기록을 **대량으로 자동 수집해서 가공하는 것**은 공식 API 원칙에도 어긋나고 권리 문제도 있습니다. 해외 축구는 라이선스 데이터 API(유료·무료)가 있는지 따로 확인이 필요합니다.
- 그래서 스포츠는 "매일 자동으로 숫자를 뽑는 공장"이 되기 어렵고, **순위표·경우의 수처럼 작은 숫자를 직접 계산하는 방식**에 머물 가능성이 큽니다.

## 1순위 제안: 여행·축제·나들이

- **사진 문제가 풀립니다.** 홈판은 사진이 클릭을 좌우합니다. 한국관광공사 관광사진은 공공누리 1유형이라 상업적 사용과 편집이 가능합니다 (출처 표기 필수).
- **발행을 예약할 수 있습니다.** 축제·행사 일정이 미리 나오므로 "이번 주말 가볼 만한 축제" 같은 글을 미리 써서 예약할 수 있습니다. 운영자 부담이 스포츠보다 훨씬 적습니다.
- **글감이 끝이 없습니다.** 전국 축제·행사가 연중 이어지고, 계절(단풍·눈·벚꽃)과 지역을 곱하면 매주 새 글이 나옵니다.
- **지금이 성수기입니다.** 10~11월은 가을 축제와 단풍 시즌입니다.
- **우리 무기와도 맞습니다.** "이번 주말 축제 N곳 비교표(입장료·주차·교통)"나 "지역별 단풍 절정 예상일 지도"처럼 공식 데이터를 계산하고 정리하는 글이 됩니다.
- **약점:**
  - 직접 다녀온 여행 블로거의 생생한 사진과 경쟁하는데, 공식 사진은 흔한 편이라 클릭률이 낮을 수 있습니다.
  - 1차 조사에서 여행을 제외한 이유는 검색(개별 숙소 후기)이었고, 홈판 축제 정보는 성격이 다릅니다.

## 2순위: 생활 경제 숫자

- **글감:** "이번 주 기름값 가장 싼 지역", "우리 동네 아파트 실거래가 변동", "이번 달 청약 일정·경쟁률" 같은 글입니다.
- **장점:** 광고 단가가 높고, 매주 새 숫자가 나옵니다.
- **위험:** 투자 권유로 보이면 안 됩니다. 사실과 숫자만 쓰고 "사라·팔아라"는 쓰지 않습니다. 부동산은 민감하므로 문구 규칙을 따로 정해야 합니다.

## 운영 구조 (1채널 1테마)

블로그는 본인 명의 최대 3개이고, 두 번째 블로그는 첫 블로그가 검증된 뒤에 엽니다 (DECISIONS). 그래서 **지금은 파일럿 1개만 고르고**, 나머지는 2·3번째 블로그와 쇼츠 채널 후보로 둡니다.

## 확인이 더 필요한 것

- TourAPI 약관의 블로그 게시 조건과 사진별 공공누리 유형 (사진마다 유형이 다를 수 있음)
- 부동산 실거래가·청약 API의 이용 조건
- 해외 축구 라이선스 데이터 API의 유무와 비용
- 공식 문서는 제 작업 환경에서 대부분 열리지 않아, 첫 실행으로 확인합니다
