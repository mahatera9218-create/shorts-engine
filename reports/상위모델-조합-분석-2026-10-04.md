# 편당 비용을 올리면 어디에 쓰는 게 효과가 가장 클까 (2026-10-04)

대표 질문: 상위 모델·API로 올렸을 때 블로그 + 클립 + 쇼츠까지 효과가 가장 큰 조합. 영상 생성(씨댄스·힉스필드), 유튜브 쇼츠 동시, TTS 포함.
가격은 각 회사 공개 가격 기준 추정(1달러 = 1,400원 가정). **1주 시험으로 실측 후 확정.**

## 결론 먼저
**돈은 '사람이 멈추고 클릭하는 순간'에 몰아 쓴다.** 전체를 고급으로 바꾸는 것보다 아래 4곳에 쓰는 게 효과가 커요.
1. **주제 고르기** (방문자를 결정) — 싸고 효과 큼
2. **제목·첫 문단** (클릭을 결정)
3. **클립 첫 2~3초 장면** (피드에서 손가락을 멈추게 함) ← 가장 큰 차이
4. **목소리** (끝까지 보게 함)

## 1. 글 (블로그)
| 단계 | 지금 | 올린다면 | 왜 |
| --- | --- | --- | --- |
| 화제 찾기 | 뉴스 수 | **Grok 4.5 + X 검색** (검색 1번 약 7원) | 미국주식·코인 화제는 X가 가장 빠름 |
| 취재 메모 | 없음 | **Perplexity Sonar Pro** (1번 수십 원). '돈 굴리기' 기본기 글은 **Sonar Deep Research** | 출처 달린 자료, 기본기 글은 깊이가 생명 |
| 주제 확정·초안·편집 | Claude Sonnet 5.5 | **Claude Opus 5.5** (Sonnet의 2배 값) | 제목·첫 문단·판단 품질 = 클릭 |
| 사실 대조 | 코드 검사 | **Gemini 3 Pro + 구글 검색** (월 5,000번 무료) | 틀린 숫자 하나가 신뢰를 깸 |
| 독자 검토 | 없음 | GPT (편당 약 10원) | 다른 회사의 눈 |
→ 글 1편 약 **700~1,400원** (지금 약 400원)

## 2. 클립·쇼츠 (한 번 만들어 네이버 클립 + 유튜브 쇼츠 같이)
| 방식 | 내용 | 1편(약 20초) 비용 | 판단 |
| --- | --- | --- | --- |
| 지금 | 코드 그래픽 + 무료 배경 영상 + 구글 목소리 | 거의 0 | 자동재생에서 멈추게 하는 힘 약함 (대표 지적) |
| **추천: 첫 장면만 AI 영상** | 첫 3~6초 = AI 영상(예: 금괴가 쏟아지는 장면), 숫자·글자는 코드가 정확하게 덧입힘, 목소리 고급 TTS | **약 700~2,500원** | 멈추게 하는 힘 ↑, 숫자는 정확, 비용 낮음 |
| 전부 AI 영상 | 20~30초 전체를 Veo 3.1 등으로 (소리 포함) | 약 1만~1만7천 원 | AI 영상은 글자·숫자를 자주 틀리게 그림 + 비쌈 → 비추천 |

**영상 모델 (초당 가격, 공개 가격)**
- 힉스필드 API: 키 1개로 50개+ 영상 모델(클링·씨댄스 등) 사용, 충전식. Kling 2.5 약 $0.042/초, Seedance 2.5 약 $0.074/초, Kling 3.0 약 $0.11/초
- 구글 Veo 3.1: Lite $0.05~0.08/초, Fast $0.10~0.12/초, 표준 $0.40/초 (소리 포함)
- → **추천: 힉스필드 API 하나로 시작**해 2~3개 모델을 같은 장면으로 비교 → 제일 나은 것 고정 (영상판 오픈라우터)

**목소리 (TTS)**
- 지금: 구글 Chirp 3 HD
- 후보: **타입캐스트**(한국어 감정 표현에 강하다는 평, API 있음), 일레븐랩스(영어에 강함)
- → 같은 대본으로 2~3개 비교 들어 보고 대표님이 고르기

**유튜브 쇼츠 동시 발행**
- 같은 9:16 영상을 네이버 클립(대표 업로드)과 유튜브 쇼츠에 같이 씀
- 유튜브는 공식 API로 **'비공개'로 자동 업로드** → 대표님이 앱에서 '공개' 한 번 (외부 공개는 대표 버튼 원칙)

## 3. 지켜야 할 것 (영상)
- **유튜브 '진정성 없는 콘텐츠' 정책** (2025-07 이름 변경, 2026-07 강화): 'TTS 목소리 + 스톡 영상'을 대량으로 찍어내는 채널을 수익 정지 → 하루 1~2편, 매번 다른 구성, 정보가 있는 대본으로
- 실제처럼 보이는 AI 영상은 유튜브 업로드 때 **'변경되거나 합성된 콘텐츠' 표시**
- 실존 인물(파월·머스크 등)·회사 로고는 AI로 만들지 않음, 개념 장면만
- **결정 필요**: 블로그는 '무료 사진만'으로 정했는데, **영상의 첫 장면 AI 사용**은 별도로 허용할지
