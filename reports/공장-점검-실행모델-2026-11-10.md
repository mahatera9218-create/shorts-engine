## ✅ 고친 것 (옛 "크롬확장" 잔재 = 실행모델 충돌)
Claude가 브라우저를 직접 못 누르는데 아직 "크롬확장이 저장/성과기록" 또는 "권한 승인은 기술보안팀이 대신 처리"로 써둔 곳 → 전부 **어사이드 + 드라이브 감지·알림**으로 통일.
1. `경제-저장담당` 설명 — "크롬확장 후보" → 어사이드 확정.
2. `경제-제목담당` — 참고 인플 제목 "크롬확장" → 어사이드/RSS.
3. `경제-하루운영` — 발행 후 "크롬확장이 성과기록" → 어사이드가 통계 읽어 기록.
4. `연예-하루운영`·`패션-하루운영` 설명 — "저장 크롬확장" → 저장=어사이드.
5. `패션·연예·인플 하루운영` 본문 — "권한 승인은 기술보안팀이 처리" → 어사이드 멈추면 드라이브 감지→상태판→대표 알림.
6. `기술보안팀` — "팝업 대신 누름"(불가) → 드라이브로 멈춤 감지, Claude/GPU/파일만 직접 복구, 브라우저 건은 알림.
