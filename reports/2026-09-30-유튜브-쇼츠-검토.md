# 네이버 클립 영상을 유튜브 쇼츠에도 올려도 되나 (2026-09-30)

## 한 줄 요약
**올려도 돼요.** 우리가 직접 만든 영상이라 규칙 위반이 아니에요. 하지만 **제가 직접 공개로 올리는 건 지금은 안 돼요.** 유튜브는 심사를 통과하지 않은 프로그램이 올린 영상을 "비공개"로 잠가요. 심사는 몇 주에서 몇 달이 걸려요.

## 1. 같은 영상을 두 곳에 올려도 되나

| 어디 | 결론 | 근거 |
| --- | --- | --- |
| 유튜브 | 올려도 됨 | 우리가 만든 원본 영상이라 저작권 문제가 없어요. 다른 곳에 먼저 올린 영상이어도 괜찮아요 |
| 유튜브 수익 (나중에) | 주의 | 2025년 7월부터 "틀로 찍어 낸 듯 거의 차이가 없는 영상"은 수익 창출에서 뺀다고 정책을 분명히 했어요. 우리 클립은 선수·숫자·비교 물건이 매번 다르지만, 화면 틀이 같아요. 수익 신청 전에 형식을 더 다양하게 만들어야 할 수 있어요 |
| 네이버 클립 | 문제없어 보임 (공식 문서는 못 찾음) | 네이버 공식 문서에서 "다른 곳에도 올린 영상 금지" 규칙은 찾지 못했어요. 외부 안내글에는 "다른 앱 워터마크가 찍힌 영상은 노출이 줄 수 있다"는 말이 있어요. 우리는 워터마크 없는 원본 파일을 두 곳에 따로 올리니 해당하지 않아요 |

**지킬 것**
- 네이버에 먼저 올리고, 유튜브는 그다음에 올려요. 블로그로 사람을 데려오는 게 본업이라서요.
- 유튜브 앱에서 받은 파일을 네이버에 올리거나, 그 반대로 하지 않아요. 워터마크가 붙어요. 두 곳 모두 도우미에서 저장한 원본 파일을 써요.
- 음악은 곳마다 따로 넣어요. 네이버 클립 음악은 유튜브로 가져갈 수 없고, 유튜브 쇼츠 앱에 있는 음악을 써요. 우리 영상 파일에는 소리가 없어요.

## 2. 제가 직접 올릴 수 있나

유튜브에는 영상을 올리는 공식 API(프로그램이 쓰는 통로)가 있어요. 그런데 조건이 붙어요.

- **심사 전에는 비공개로만 올라가요.** 2020년 7월 28일 이후 만든 API 프로젝트는 심사를 통과하기 전까지 올린 영상이 전부 비공개로 잠겨요. "공개"로 올려도 비공개가 돼요. 풀려면 유튜브 API 심사 신청서를 내서 통과해야 해요.
- **심사 기간은 정해져 있지 않아요.** 몇 주에서 몇 달이 걸린다는 경험담이 많고, 통과 보장도 없어요.
- **대표님 계정 연결이 한 번 필요해요.** 구글 클라우드 프로젝트를 만들고, 대표님 구글 계정으로 "이 프로그램이 내 채널에 영상을 올려도 된다"를 한 번 허락해 주셔야 해요. 그 허락 열쇠는 GitHub Secrets에만 넣어요.
- 하루 업로드 한도는 우리 양(하루 1개)으로는 문제없어 보여요. 다만 공식 문서를 이 작업 환경에서 열 수 없었어요. 실제로 만들 때 다시 확인할게요.

## 3. 방법 두 가지

| | A. 대표님이 앱으로 올리기 | B. 제가 자동으로 올리기 |
| --- | --- | --- |
| 언제부터 | 채널만 만들면 바로 | 심사 통과 뒤 (몇 주~몇 달) |
| 대표님 일 | 매일 1분 (클립과 같은 방식: 도우미에서 저장 → 유튜브 앱 + → 쇼츠 → 음악 → 올리기) | 처음 한 번 계정 연결. 그 뒤엔 없음 |
| 제 일 | 도우미에 유튜브 제목·설명 복사 버튼 추가 | 업로드 코드, 심사 신청서 초안 |
| 비용 | 없음 | 없음 (유튜브 API는 무료) |

**추천: A로 시작하고, 동시에 B 심사를 신청하기.** 심사를 기다리는 동안에도 영상이 쌓이고, 통과하면 B로 바꿔요.

## 4. 대표님이 정할 것
1. 유튜브 쇼츠를 시작할지, 언제부터 할지 (운영 계획에는 11월 시험으로 되어 있어요)
2. 시작한다면 **유튜브 채널 만들기**. 계정을 만드는 일이라 대표님이 하셔야 해요. 채널 이름은 블로그와 같은 "억소리 나는 스포츠"를 추천해요
3. B도 할지 (구글 클라우드 프로젝트 만들기와 계정 연결을 같이 하게 돼요)
