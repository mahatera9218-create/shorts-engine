# 워드프레스 + 애드센스 로드맵 (경제 구글 SEO)

2026-10-14 · 대표 결정. 역할 분담(설계서): 네이버=네이버 검색, **워드프레스=구글 검색·애드센스**, 쇼츠=발견.

## 배경 (확인된 사실)
- 애드센스 **계정 살아있음**. 대시보드 '내 사이트'에 **astacgroup.com**이 과거 승인·자동광고 설정으로 남아 있음.
- 그러나 **도메인 astacgroup.com은 만료돼 현재 구매 가능(available)** 상태(GoDaddy whois 확인).
- **결정: astacgroup.com을 다시 사서 기존 애드센스 승인 재사용을 노린다.**(재사용 보장은 아님, 새 콘텐츠 시 구글 재검토 가능.) 도메인 이름이 브랜드와 안 맞는 건 블로그 제목·메타로 보완.

## 텍스트 우선 원칙
경제 글(텍스트) → 구글 SEO 최적화 → 워드프레스 자동 발행이 1순위. 클립·인스타·스레드는 후순위.

## 단계 (대표 실행 / Claude 실행 구분)

1. **도메인 재구매** — 대표. astacgroup.com. 가비아·후이즈·Cloudflare가 GoDaddy보다 쌈.
2. **웹호스팅 + 원클릭 워드프레스** — 대표. 가비아/카페24에서 도메인+호스팅 한 곳으로 묶으면 간단. 월 5천~1만원.
3. **WP 기본 세팅** — 대표(원클릭)+Claude 가이드. 테마, **RankMath(무료 SEO)**, 퍼머링크(슬러그) 설정, **앱 비밀번호 발급**(자동화 연결용).
4. **애드센스 재연결** — 대표. ads.txt·자동광고 코드 넣고, astacgroup.com '수정 요청/검토' 다시. (이미 목록에 있어 신규 승인보다 수월할 가능성.)
5. **자동 발행 + 구글 SEO 프롬프트** — Claude. WP REST API로 글 자동 발행(초기엔 '자동 초안→대표 발행'), 구글용 글 프롬프트(검색의도 롱폼·헤딩·메타·스키마·내부링크). GitHub 결제 풀린 뒤 실제 가동.

## 비용 (고정비)
- 도메인 재구매 연 1~2만원 + 호스팅 월 5천~1만원 ≈ **연 6~12만원**.

## 주의
- **중복 콘텐츠:** 네이버 글 그대로 복붙 금지(구글 중복). WP용은 구글 키워드로 각도·길이 다르게.
- **품질/YMYL:** 금융 글은 구글이 전문성(E-E-A-T) 엄격. 자동 양산 티 나면 애드센스 제재. 우리 '전문 경제 블로그' 컨셉으로 커버.
- **발행 통제:** 우리 원칙=외부 공개는 대표 승인. 초기엔 자동 초안→대표 발행, 검증 후 완전 자동.
- 도메인은 빈 상태라 선점 가능 → 쓸 거면 너무 오래 두지 말 것.
