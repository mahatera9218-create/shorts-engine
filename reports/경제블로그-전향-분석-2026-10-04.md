# 경제 블로그 전향 분석 (2026-10-04)

대표 제안: 국내주식·미국주식·금·비트코인 뉴스 기사를 크롤링 → 블로그식으로 변환 → 사진 붙여 게시.

---

## 한 줄 결론

- **경제로 주제를 바꾸는 건 찬성**이에요. 광고 단가가 가장 높은 분야이고, 매일 쓸 거리가 생깁니다.
- **"기사 크롤링 → 변환 → 사진 붙이기" 방식은 반대**예요. 저작권, 네이버 저품질 판정, 정보 이득 0. 세 가지 문제가 한꺼번에 걸립니다.
- **대안: "데이터 계산형"**으로 가면 지금 만든 시스템(숫자 계산·표·차트·클립·도우미)을 거의 그대로 쓸 수 있어요.

---

## 1. 기대되는 점 (좋은 점)

| 항목 | 내용 |
| --- | --- |
| 광고 단가 | 금융·투자 키워드는 애드포스트 단가가 높은 편이에요. (정확한 숫자는 검색광고 API로 재 봐야 함, 아래 6번) |
| 매일 생기는 수요 | 금 시세, 비트코인 가격, 코스피, 미국 증시는 매일 검색돼요. 글감이 마를 일이 없어요. |
| 4개 자산 = 비교 거리 | "100만원을 각각 넣었다면" 같은 비교가 매주 새로 나와요. |
| 우리 시스템과 궁합 | 지금 '연봉 → 모델Y 몇 대' 계산 엔진이 그대로 "비트코인 1개 → 아반떼 몇 대"가 돼요. |

---

## 2. 제안 방식의 문제 (단점)

### ① 저작권 — 가장 큰 위험
- 기사는 **요약·재가공해도 침해가 될 수 있어요.** 사실(숫자) 자체는 자유지만, 문장·구성은 언론사 저작물이에요. 실제로 연합뉴스가 뉴시스를 상대로 낸 소송에서 기사 477건 중 380건이 침해로 인정됐어요.
- **언론사 사진은 거의 전부 저작물**이에요. "사진 붙여서"가 이 방식에서 제일 위험한 부분이에요.
- 무단 크롤링·기사 문장 복제는 우리 운영 원칙(CLAUDE.md)에서도 금지예요.

### ② 네이버 저품질 판정
- 네이버는 **뉴스 등 남의 콘텐츠를 복사·짜깁기해 AI로 대량 생산하는 것**을 문제로 보고 있어요.
- 경제 카테고리는 이미 "기사 요약 블로그"가 넘쳐요. 비슷한 글끼리 묶이면 우리 글은 노출이 안 되고, 심하면 블로그 지수 전체가 떨어져요.

### ③ 검색 수요가 블로그로 안 와요
- "코스피 오늘", "비트코인 시세" 같은 검색은 네이버가 **뉴스·증권 시세 화면을 먼저** 보여줘요.
- 기사 요약 글은 원문보다 늦고 덜 정확해서 굳이 누를 이유가 없어요. AI 브리핑도 원문 기사를 인용해요.

### ④ 정보 이득 0
- 우리 발행 규칙(상위 10개 글에 없는 정보가 있어야 발행)에 따르면, 기사 요약은 원문이 이미 상위에 있으니 **원칙적으로 통과할 수 없어요.**

### ⑤ 금융 콘텐츠의 특수한 위험
- **특정 종목·코인 매수·매도 권유는 금지**예요(우리 규칙). 돈을 받고 투자 조언을 하면 유사투자자문업 신고 문제가 생길 수 있어요. 정보 제공·계산까지만 해야 안전해요.
- 증권사·코인거래소 제휴 광고는 별도 광고 규정이 있어서, 붙이기 전에 확인이 필요해요.
- **틀린 숫자 하나가 치명적**이에요. 뉴스 요약은 지난 숫자가 섞이기 쉬워요.

### ⑥ 수익 구조 변화
- 쇼핑커넥트(상품 태그)는 경제 글과 잘 안 맞아요. 수익은 **애드포스트 중심**이 돼요.

## 3. 대안: "데이터 계산형 경제 블로그" (추천)

| 단계 | 방식 |
| --- | --- |
| 수집 (코드) | 기사 대신 **공식 시세 데이터**. 후보: 공공데이터포털·한국거래소(주가), 한국은행 ECOS(환율·금리), 업비트 공개 시세(비트코인), 금 시세. 각 이용 약관 확인 후 사용. 뉴스는 지금처럼 "사실 한 줄 + 출처 링크"만. |
| 계산 (코드) | 수익률, 1년 전 대비, 원화 환산, 생활 물가 비교. 지금 엔진 그대로. |
| 글 (AI) | 숫자에 대한 해석·의견. 권유는 안 함. |
| 이미지 | 기사 사진 대신 **코드가 그린 차트** + 무료 사진. 경제 글은 사진보다 차트가 훨씬 잘 맞아요. |
| 클립·쇼츠 | "오늘 금 1돈이면 살 수 있는 것" 숫자 애니메이션. 지금 클립 엔진 재사용. |

**글 예시**
- 매일: "오늘 금 1돈 얼마? 한 달 전보다 OO원 올랐다"
- 매주: "이번 주 코스피·S&P500·금·비트코인, 100만원씩 넣었다면?"
- 평생형: "비트코인 5년 전 100만원은 지금 얼마?", "삼성전자 배당금으로 월세 내려면 몇 주?"

**좋은 점**: 저작권 안전, 매일 새 숫자라 정보 이득이 생김, 평생 검색되는 글과 매일 글을 둘 다 쓸 수 있음.

> 그래도 뉴스 변환형으로 가신다면 최소 조건: 네이버 뉴스 검색 API 같은 허용된 통로로만 받고, 숫자·사실만 인용 + 원문 링크, 문장은 처음부터 새로 쓰고, **기사 사진은 절대 쓰지 않기**.

---

## 4. 대표님이 정할 것

1. **방식**: 뉴스 변환형(비추천) / 데이터 계산형(추천)
2. **블로그**: 지금 블로그를 경제로 전환 / 새 블로그 만들기
   - 지금 블로그는 시작한 지 1주일이라 쌓인 지수가 적어요. 전환해도 손해가 작아요. "억소리"라는 이름도 돈 이야기에 잘 맞아요(예: "억소리 나는 경제").
   - 네이버는 주제 일관성을 보기 때문에, 스포츠와 경제를 한 블로그에 섞는 건 비추천이에요.
3. **스포츠 자동화**: 멈출지, 클립·쇼츠만 남길지

## 5. 작업량·비용 (대략)
- 새로 만들 것: 4개 자산 시세 수집, 경제 테마·글쓰기 규칙(권유 금지 강화), 차트 종류 몇 개
- 그대로 쓰는 것: 계산·표·검사, 클립·쇼츠, 발행 도우미, 버튼
- 글 1편당 AI 비용은 지금과 비슷할 거예요.

## 6. 다음 단계 제안
결정 전에 **4개 자산 키워드 검색량·광고 단가 조사**를 먼저 돌려볼 수 있어요(이미 등록된 검색광고 키 사용, 추가 비용 없음). 숫자를 보고 정하시는 걸 권해요.
