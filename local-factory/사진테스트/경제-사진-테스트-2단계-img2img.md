# 경제 사진 GPU 테스트 2단계 — 실물 원본 가공 (img2img)

목적: **GPU가 실물 원본(그 단지·그 회사 실제 사진)의 "건물·대상 정체성"을 유지한 채 톤·구도·배경만 바꾸나** 검증.
이게 되면 — 썸네일(식별성 생명) + 본문 애매컷(상징·특정건물)을 전부 "그록 원본 → GPU 가공"으로 품질 지키며 처리 가능. **사진 라인의 마지막 미지수.**

## 품질 바 (대표가 눈으로)
1. **그 건물/대상이 그대로인가?** — 원본과 **같은 건물**로 알아보나(형태·배치 유지). 다른 건물로 바뀌면 ❌ (핵심).
2. **톤·분위기는 바뀌었나?** — 흐린 날/차분함 같은 분위기가 입혀졌나(글 분위기용).
3. **실사 유지?** — 일러스트·뭉갬 없이 사진 그대로.
4. **잡요소 정리?** — 원본의 산만한 배경·행인·간판글자가 자연스럽게 정리/약화됐나(선택).

## 입력 원본 (한 장)
- **실제 건물 사진 1장** 필요. 둘 중 편한 걸로:
  - (a) 대표가 **실제 아파트단지/빌딩 사진 1장**을 PC `C:\factory\사진테스트\원본\`에 넣기, 또는
  - (b) 집 PC Claude가 **일반 건물 실사 사진 1장**을 받아서(기술 검증용 — 특정인 콘텐츠 복제 아님, 그냥 메커니즘 테스트) 쓰기.
- ※ 실제 운영에선 이 원본을 **그록/어사이드가 '그 단지' 실물**로 수집. 지금은 **기법이 되나**만 본다.

## 실행 (집 PC Claude, ComfyUI API 127.0.0.1:8188)
1. **ControlNet 모델 확인:** `models/controlnet`에 SDXL용(depth / canny / lineart)이 있나 본다. 없으면 보고(없어도 2번 plain img2img는 됨).
2. **두 방식 비교 생성** (같은 원본, RealVisXL V4.0):
   - **A. plain img2img** — denoise **0.45~0.55**, 프롬프트 = "photorealistic, overcast calm tone, documentary photo" + negative(기존).
   - **B. img2img + ControlNet(depth 또는 canny)** — 있으면. 구조 더 강하게 유지.
3. **톤 변주도 1개** — 같은 원본에 "warm morning light" 버전 하나(분위기 변주 되나 확인).
4. **저장·보고:** `C:\factory\사진테스트\` 에 `원본.png` / `2단계_A_img2img.png` / `2단계_B_controlnet.png` / `2단계_톤변주.png`. **대표에게 원본+결과 나란히** 보여주고, ControlNet 유무·장당 시간·VRAM 여유(8GB 터지나) 보고.
5. 판정은 대표(위 품질 바). **건물 유지가 핵심** — denoise 높이면 톤은 잘 바뀌나 건물이 바뀜, 낮추면 원본 그대로. **"건물 유지 + 톤 변화"의 sweet spot denoise**를 찾는 게 이 테스트의 결과물.
